# 天賦機制：計算與邊界算例

以下為固定版本原始碼的靜態推導，未進行遊戲內測試。各例的前提與限制一併列出。

## 冷卻代表：veteran_replenish_grenades

不同手雷能力選用不同補給週期、缺額才開始計時、滿額重設、嚴格時間比較，並牽涉共用能力資源上限。詳細來源及正式描述見[職業文件](../skills/talents/Veteran/README.md#veteran_replenish_grenades)。

以下為直接閱讀執行邏輯後的手動狀態推演，未執行 Lua 或遊戲測試。設破片手雷週期 60 秒，缺額首次被更新函式觀察到的時間為 100 秒。

| 邊界案例 | 原始碼推導預期 |
|---|---|
| 首次缺 1 顆，t=100 | 設截止時間 160；本次不補給 |
| t=159.999、t=160 | 均不補給，因使用 `next_grenade_t < t` |
| 首次更新時的 t>160 | 補 1 顆，清除計時；實際時刻取決於更新排程 |
| t=130 又投出 1 顆 | 缺額變大，但既有截止時間仍為 160 |
| t=140 拾取補滿，之後缺額 | 觀察到滿額便清除進度；新缺額重新計滿週期 |
| 補 1 顆後仍缺額 | 下一次更新才設定下一個截止時間，不一次補滿、不追補多個逾期週期 |
| 改以穿甲手雷首次缺額 t=100 | 截止時間 190；相同嚴格大於規則 |
| 沒有手雷能力 | 清除 next_grenade_t 與缺額狀態 |


## 條件觸發代表：veteran_ranged_power_out_of_melee

比對殘留距離文案與實際受擊時間條件，並追到傷害加算階段。正式說明與來源見[職業文件](../skills/talents/Veteran/README.md#veteran_ranged_power_out_of_melee)。

| 手動推演案例 | 預期 |
|---|---|
| last_hit_t=100，t=108 | 條件為 false |
| last_hit_t=100，t>108 | 條件為 true，提供 +0.15 ranged_damage |
| t=107 再受合格近戰命中 | last_hit_t 變 107，必須 t>115 |
| 周遭有敵人但超過門檻未受近戰命中 | 本 Buff 不作距離檢查，條件仍可成立 |
| 只收到遠程命中 | 不重設這個計時器 |
| 其他一般 damage 加算合計1.25 | 加入此項後該合計1.40，不宣稱最終傷害另乘1.15 |


## 疊層代表：振奮擊倒

遠程弱點擊殺條件、韌性恢復、連乘減傷、共同計時及逐層衰退。正式說明與永久來源見[振奮擊倒](../skills/talents/Veteran/README.md#veteran_replenish_toughness_on_weakspot_kill)。

| 手動推演案例 | 預期 |
|---|---|
| 遠程弱點命中但未擊殺 | 不觸發 |
| 符合條件的擊殺，最大韌性100、目前95、無恢復加成 | 實際補5；仍增加一層減傷 |
| 最大韌性100且已滿 | 實際補0；仍增加一層減傷 |
| 有效層數1／2／3 | 韌性受傷倍率0.9／0.81／0.729 |
| 三層，最近一次觸發時間100 | t=108尚未到期；首個t>108的更新降二層並重新計時 |
| 內部計數4，但有效層數3 | 不提供第四層減傷；到期同輪更新可移除溢出計數並降至二層 |
| 持續符合條件的擊殺 | 持續刷新共同計時，效果仍最多三層 |

區分多一次充能、每次成本增加、共用資源池、恢復時間與配裝分支。來源與完整推導見[掩護射擊](../skills/talents/Veteran/README.md#veteran_combat_ability_extra_charge)。

| 手動推演案例 | 預期 |
|---|---|
| 只有本升級，沒有其他成本或恢復加成 | 上限由1變2；每次成本40×1.33=53.2 |
| 資源0，連續按每秒1恢復 | 約53.2秒可用1次、106.4秒補滿2次；實際以更新及精度判定 |
| 第二次使用前已有部分恢復進度 | 扣除一次成本，已累積的小數進度保留 |
| 恢復已到容量上限 | 不持續儲存超額資源 |
| 重生或配裝令上限變動 | 共用程式有補新增容量與重生例外，不能一概視為送滿充能 |

## 狂信徒：結算與邊界

- 傷害：靈巧只放大弱點／爆擊額外部分；獻祭手雷先按難度取威力，再做每次亂數，不是從四個難度值隨機選一個；投擲刀區分普通命中與弱點、暴擊、穿甲。
- 恢復：合唱區分脈衝恢復、持續恢復、上限提高與目前值增加；純潔信標受完整傷口下限限制；近戰擊殺恢復區分同階段加算與獨立倍率。
- 冷卻：倍增狂熱兩次充能共用進度、依序恢復；返還百分比以單格成本計算；暴擊與背刺的額外恢復有刷新和每次揮擊限制，不當成每次命中立即扣固定秒數。
- 疊層：殉道按整格傷口計算；勢能區分累積與消耗後的生效時間；個人狂怒刷新不等於已分享給隊友的效果一併延長。
- 名稱與圖示：主頁以翻譯表統一用詞，7 個新增名稱維持待確認；圖示只作呈現，不作機制證據。

## 歐格林：結算與邊界

- 門檻：低生命恢復要求低於50%；高耐力減傷要求高於75%，恰好門檻不生效。痛楚爆發需再次失層，玩家可見層數與內部子層偏移分開計算。

- 自然恢復、按單份成本直接恢復與能力維持耗電分開追查；單份比例恢復明確忽略資源恢復屬性加成。電能放電最多消耗3份，即使總上限已提高至4或5份。
- 進階戰鬥教範的啟動費、持續耗電、射擊成本及換彈暫停分開計算；職業擊殺回充在該能力啟用期間停止。
- 協同集合包含本人；彈藥存放另透過任務玩家清單分發，且多來源不重複增加15%。
- 力場電弧依吸收次數向上取整並限制1至4道；可用目標不足時實際數量減少。類別中未由能力設定啟用的替代成本不當成玩家可用功能。
- 弦爪連續出招與首次啟用分開；每次扣充能不等於每次都觸發所有「使用能力」效果。
- 原始碼中未使用的格式數值、未被當前技能樹引用的定義，以及其他模式的效果都留在技術資料。

## 護教軍：限制

未進行遊戲內傷害、計時、操作或多人同步實測；算例僅反映固定版本原始碼的推導。
