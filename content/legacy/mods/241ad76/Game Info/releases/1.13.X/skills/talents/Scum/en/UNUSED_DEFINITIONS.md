# Scum: talent definitions not directly referenced by the talent tree or base lists

[繁體中文](../UNUSED_DEFINITIONS.md) | [Player descriptions](README.md) | [Technical index](SOURCE_INDEX.md)

- Fixed source: Release 1.13.1 / `7e662fcda16219d775b84af50322be2e9cd9d62e`.
- The main talent tree has 79 selectable nodes: 75 class definitions and 4 shared stat definitions. There are also 5 base settings, 1 conditional Stimm and a zero-point starting description for the independent recipe tree. Its 29 recipes are generated dynamically from settings.
- Of the class file's 114 direct definitions, subtracting those 82 leaves 32 not directly selected by these lists. This does not mean Buffs, special rules or old data of the same name are entirely unused; for example, Blitz replenishment and extra-Dodge Buffs are still used by base talents.
