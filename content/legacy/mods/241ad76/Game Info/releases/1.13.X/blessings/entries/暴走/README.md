# 暴走(Rampage)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8cdb466d-9982-426e-813a-155007e3091a" width="72" height="72" alt="暴走祝福圖示">

- **觸發方式**：裝備有「暴走」的武器必須在手上；同一個近戰攻擊命中至少三個有效目標，且攻擊物品須與這把武器相同。普通、重擊、推擊後接續掃擊及特殊模式掃擊都依實際命中判定；純推擊不符合近戰條件。
- **生效時機**：第三個合格命中的傷害先結算，之後才排入事件；不會回頭加成觸發命中。事件經固定更新處理並重算屬性後，後續計算才可能讀到新威力；同次掃擊後續目標是否已使用新傷害或削韌值不作保證。穿透上限在掃擊開始時快照，觸發後不改變正在進行的掃擊上限。
- **效果**：依武器與等級取得表列近戰威力修正，持續 3.5 秒。修正影響傷害、削韌與掃擊穿透的威力計算；實際結果依攻擊 profile 與曲線，不代表最終傷害固定增加同一百分比。
- **刷新與切換**：期間再次達成條件會重設同一效果期限，不會疊額外層數；沒有獨立冷卻時間。切到其他武器時期限仍倒數、加成暫不套用；期限內切回可用剩餘時間。卸下該武器會移除效果實例。
- **例外動作**：切換／啟用特殊狀態、格擋和純推擊本身不觸發。特殊反擊、格擋後反擊與推擊後接續掃擊若實際走近戰掃擊，仍須各自命中三個合格目標；鏈鋸黏附鋸切追加命中不觸發也不刷新。
- **命中限制**：檢查近戰類型、同一攻擊命中序號至少三、相同裝備物品和目前持用欄位。沒有擊殺、精英、弱點或暴擊要求；目標須在該目標傷害結算前仍存活且有敵人類型資料。

## 計算與算例

- **前提**：假設 Power Type curve 後、套用本項前 Power Level=100，沒有其他修正；同一把武器在手上，三個命中來自同一近戰掃擊。
- **代入**：第三個目標傷害先結算；事件處理後，一般七類武器 IV 級修正 0.36，倍率是 1+0.36。
- **結果**：後續近戰攻擊曲線後 Power Level=100×1.36=136，期限 3.5 秒。
- **玩家意義**：卡面 +36% 是近戰攻擊威力修正，不代表最終傷害一定 +36%。

- **前提**：相同條件，改用穿音速雙刀 布蘭克斯 Mk XI IV 級。
- **代入**：此型號 IV 級修正 0.18，倍率是 1+0.18。
- **結果**：曲線後 Power Level=100×1.18=118，期限同為 3.5 秒。
- **玩家意義**：卡面顯示 18%；差異在 tier 數值，觸發和期限相同。
