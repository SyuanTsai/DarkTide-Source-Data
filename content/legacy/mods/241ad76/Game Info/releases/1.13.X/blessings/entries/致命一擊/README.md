# 致命一擊(Deathblow)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/727852d8-6e95-4327-9114-a8b78126a891" width="72" height="72" alt="致命一擊祝福圖示">

- **觸發方式**：持用帶有致命一擊的重劍 圖妥斯基 Mk VI、Mk VII 或 Mk IX，持用條件生效並更新屬性快取後，I／II／III／IV 分別增加 7.5／10／12.5／15 個百分點的近戰弱點傷害修正。這項傷害加成不需要先擊殺，也不排除歐格林。
- **傷害作用區域**：增量加入弱點額外傷害部分，不直接把整次攻擊的最終傷害乘以 1.075／1.10／1.125／1.15。首次合格近戰弱點命中即可依當時已更新的屬性快取受益。
- **弱點擊殺與穿透**：同一次揮擊中，僅前三個角色擊殺位置上的非歐格林弱點擊殺，會在該次傷害結算後回退目前目標計入的命中質量並解除後續中止。前面的非弱點擊殺也會占用位置；沒有擊殺、非弱點命中、歐格林或第四個以後的擊殺，均不觸發這項回退。
- **傷害先後與限制**：目前目標的質量、護甲及攻擊設定，可能先令這次命中採用中止時的傷害設定；若它仍符合上述擊殺條件，回退只影響後續命中，不能補回剛剛已結算的傷害。後續目標仍各自接受質量、護甲及攻擊中止判定，不保證無限穿透。
- **後續目標的傷害順位**：合格弱點擊殺分支亦略過正常的傷害目標順位遞增；下一個目標可沿用該順位設定。目標護甲、命中部位等因素仍不同，不能據此保證下一個目標受到相同最終傷害。
- **普通與特殊攻擊**：三型號的輕擊、重擊、推擊後斬擊、特殊斬擊與特殊追擊均有實際近戰揮擊路徑，可使用弱點傷害加成並依條件回退質量。每個新揮擊動作重新開始質量與角色擊殺計數，不把先前動作的擊殺帶入。
- **純推擊**：純推擊使用獨立推擊分支，不造成生命傷害，也不走本項弱點傷害消費或揮擊質量回退分支。推擊後斬擊是另一個揮擊動作，按它自己的弱點、擊殺及計數條件判斷。
- **層數、期限與移除**：本祝福沒有觸發層數、倒數、冷卻或逐次刷新；前三個擊殺位置是本次揮擊的限制，並非可保留的祝福層數。移除實際效果後，不再提供本項屬性與關鍵字。
- **切換武器**：切出此劍時持用條件關閉，傷害修正與回退關鍵字停用；切回後依持用條件與屬性快取更新恢復，不需要重新累積擊殺。切換本身不等於卸下祝福。

## 計算與算例

- **弱點傷害前提**：IV 級，持用條件與屬性快取有效，其他傷害部分 B=100、基礎弱點額外傷害 F=50、既有同乘區修正 S=1；後續護甲、背刺、側擊等因素中性，且沒有力場轉換。
- **代入與結果**：原總傷害 `100+50×1=150`；加入 t=0.15 後為 `100+50×(1+0.15)=157.5`。弱點額外部分由 50 增至 57.5、相對增加 15%；整次傷害只增加 7.5，亦即 `7.5÷150=5%`。
- **玩家意義**：等級 IV 的 +15% 作用於弱點額外部分，並非整擊傷害直接乘以 1.15；實際總增幅隨攻擊的基礎與額外部分、其他修正及目標因素而變。
- **質量回退前提**：僅作條件演示，設本次攻擊上限 M=10、先前累積 H=4、目前目標質量 h=6、護甲質量倍率 a=1，並且沒有其他無限穿透效果。10／4／6 是示例值，不是三型號的固定遊戲數值。
- **代入與結果**：`H+h×a=4+6×1=10`，達到上限，先令中止分支成立。如果目前目標是前三個角色擊殺位置之一的非歐格林弱點擊殺，且中止時的傷害設定仍足以殺死它，結算後累積回到 4、解除後續中止，後方目標才可繼續接受判定。
- **不符合條件時**：若剛才那一擊未擊殺、不是弱點，或位置已為第四個以後，質量不回退；前面的非弱點擊殺同樣會占用前三個位置。
