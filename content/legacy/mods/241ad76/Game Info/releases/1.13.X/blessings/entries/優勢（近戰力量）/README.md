# 優勢（近戰力量）(Superiority)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ad66f531-3350-4401-84f3-5c5d7b4cd4c9" width="72" height="72" alt="優勢（近戰力量）祝福圖示">

- **觸發方式**：此祝福仍安裝在武器欄位、且事件處理時正持用該欄位武器，才符合持用條件。擊殺事件須判定目標已死亡，且目標標籤含精英或專家，才增加一層。觸發檢查只讀死亡結果與目標標籤，不比對事件來源武器或攻擊種類；RAW 未要求必須由同一把武器完成擊殺。
- **每層效果**：I／II／III／IV 每個有效層數分別提高 4%／6%／8%／10% 的近戰威力計算修正。這是近戰力量計算中的修正，不是直接增加同一比例的最終傷害。
- **層數上限**：最多 3 個有效層。每個合格擊殺加一層；達到上限時不再加層，但合格事件仍會重新開始 5 秒衰退計時。
- **衰退**：若沒有後續合格擊殺，超過 5 秒後在固定更新移除一層；之後每跨過 5 秒期間繼續移除。若一次更新跨越多個期間，原生計時會依經過時間移除相應層數。全部有效層移除後，加成停止。
- **首次生效**：產生擊殺結果的那次攻擊已完成力量與傷害計算；擊殺事件處理並更新玩家 buff 數值快取後，新層才供後續近戰攻擊讀取。
- **切換與卸下**：切到其他欄位會關閉此武器的觸發與數值條件，但不暫停已啟動的 5 秒計時；剩餘時間內切回才恢復尚存層數。從裝備欄位卸下該武器會移除其裝備時安裝的 parent buff，並由 parent 清除其 child 層。
- **招式覆蓋**：兩個實際 Mark 的普通輕擊、蓄力重擊、推擊後續與特殊模式近戰揮擊都走近戰攻擊路徑；符合死亡結果與目標標籤條件時可觸發。純推擊的攻擊傷害設定為 0，不能單靠純推擊造成生命值擊殺；推擊後續的近戰揮擊仍可擊殺。
- **特殊追加效果**：動力劍 P3 的特殊類別沒有命中追加處理。雙刀 P1 的特殊命中鉤子在本 Mark 沒有推力模板，因此不會施加額外位移推力，也不會再執行一次傷害攻擊。

## 計算與算例

**例一｜三層如何進入力量計算**

- **前提**：Tier IV；三次合格擊殺都在衰退期限內；只看 melee PowerLevel modifier，假設公式中其餘加算項保持 neutral 1。
- **代入**：每層 `p=0.10`，有效層 `s=3`，modifier pool 為 `1 + p×s = 1 + 0.10×3 = 1.30`。
- **結果**：若曲線轉換後 PowerLevel 是100，套入本項後該力量計算階段為 `100×1.30=130`。
- **玩家意義**：該階段相對 neutral 增加30%；目標護甲、命中部位、finesse 與傷害 profile 仍影響後續結果，不能解讀成最終傷害必定提高30%。

**例二｜上限事件刷新、切換不暫停**

- **前提**：Tier II，手持穿音速雙刀 布蘭克斯 Mk XI；三次合格事件於 `t=0、1、2` 秒處理，第四次在 `t=4` 秒處理。
- **代入**：每層 `p=0.06`；`t=2` 已有3層，第四次的 child 增量被 cap 限為0，但 parent 仍把計時起點更新成 `t=4`。
- **結果**：加成仍是 `3×6%=18%`。若在 `t=5` 切出，計時繼續；超過 `t=9` 的下一次固定更新移除一層。若該層仍在時切回，held gate 會重新開啟。
- **玩家意義**：達上限的合格擊殺會刷新衰退時間；切出不會凍結計時，切回效果取決於當時剩餘層數。
