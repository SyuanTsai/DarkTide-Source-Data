# 振奮彈幕(Inspiring Barrage)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/6c280f68-08ec-4f4b-a377-34050fcf4a27" width="72" height="72" alt="振奮彈幕祝福圖示">

- **觸發方式**：帶有此祝福的武器，連續射擊每跨過一個射擊次數門檻，就恢復一次韌性。

- 重伐木槍：門檻為總彈匣容量5%。

- 撕裂槍：門檻為總彈匣容量8%。

- 其他適用武器：門檻為總彈匣容量10%。

- 次數門檻向下取整，至少一發。

- 無需命中敵人，免費射擊也會累積次數。

- 雙持自動手槍每次交替發射計一次，容量按兩個彈匣合計。

- 撕裂槍每發霰彈計一次，彈丸與命中目標數不增加次數。

- 淨化噴火器按短噴或持續噴火的射擊週期計數，燃燒傷害與命中目標數不增加次數。

- **恢復量**：每次門檻恢復最大韌性的1／2／3／4%，依序對應I／II／III／IV級，再乘以目前步數。

- 倍率最多五倍。

- IV級前五次分別恢復4／8／12／16／20%最大韌性，第六次起仍可恢復20%。

- 這是分次恢復，不是提高最大韌性，也不是每秒恢復率。

- **恢復限制**：最多補滿目前缺少的韌性。

- 忽略一般韌性恢復量加成，但會受到禁止恢復韌性的狀態限制。

- 滿韌性時實際恢復零點。

- **停火與切換**：停火超過下表間隔後，累積射擊次數重設。

- 換彈期間顯示步數為零，射擊計數依停火規則重設。

- 切出後停止觸發，計數依當時持用武器的停火設定重設。

|---|---|---|
| 雙鏈重型機槍 | 0.25秒 | 克魯克、戈爾工0.1秒；阿克利斯0.25秒 |
| 電弧步槍 | 0.25秒 | 0.1秒 |

## 計算與算例

- **10%門檻逐步恢復**：假設總彈匣容量100發、最大韌性200點，使用IV級，連射不被重設且每次均有足夠缺額。

- 門檻為`floor(100 × 10%) = 10次射擊`。

- 第10次恢復`200 × 4% × 1 = 8點`，第20次16點、第30次24點、第40次32點、第50次40點，前五次合計120點。

- 第60次再恢復40點，並非第五次後停止。

- **重伐木槍5%門檻**：同樣假設100發、最大韌性200、IV級；每5次射擊跨一步，第5／10／15／20／25次恢復8／16／24／32／40點，第30次起每步仍40點。

- **撕裂槍8%門檻**：假設總彈匣容量25發，門檻為`floor(25 × 8%) = 2次射擊`，第10次達第五步。

- **取整門檻**：10%門檻武器總匣容量119發時，門檻為`floor(119 × 0.1) = 11次射擊`。

- 第55次達第五步，未要求真的消耗11.9發。

- **缺額與加成**：假設最大韌性200、第五步IV級應恢復40點，但當前195點，只補`min(40,200−195)=5點`。

- 若有一般+25%韌性恢復量修正，本效果忽略該修正，原要求仍40點，不變50點。

## 遊戲描述勘誤

- 本體以「消耗彈藥」描述，但實際用彈匣容量換算射擊次數門檻，免費射擊即使耗彈為零也會計入。

- 重伐木槍描述顯示10%，實際射擊門檻為5%總彈匣容量。

- 應以「連射每累積相應次數」理解，不以彈匣淨減少量判斷。
