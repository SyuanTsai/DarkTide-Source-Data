# 散熱器(Heatsink)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ba35493b-2c99-4ff6-9b8b-17ec82be4b2b" width="72" height="72" alt="散熱器祝福圖示">

- **觸發方式**：持用帶有散熱器的武器時，攻擊第一個命中目標以弱點命中或暴擊造成擊殺，啟動3秒定期散熱；不要求武器已充能。

- **計數限制**：同次攻擊後面的擊殺不觸發；第一個目標只有命中而未擊殺也不觸發。

- **擊殺條件**：弱點擊殺或暴擊擊殺任一成立即可；同時符合兩者仍只觸發一次。

- **鎖定時散熱**：I–IV每秒扣除約1.333、2、2.667、3.333個百分點熱量。

- **非鎖定時散熱**：速度為鎖定時的四分之一，I–IV每秒約扣0.333、0.5、0.667、0.833個百分點。

- **扣熱節奏**：效果按既有每秒節拍扣熱，擊殺後不是立刻扣除整筆熱量；實際次數取決於每秒節拍與到期更新時序；期限邊界可先扣一次熱，再結束效果。

- **持續與刷新**：最多一份散熱效果；再次合格擊殺會把期限延至該次擊殺後3秒，不提高扣熱速度，也不重設每秒節拍。

- **中斷情況**：一般命中、揮空或不合格擊殺不會立即取消既有效果；期限到後停止這份定期散熱。

- **熱量下限**：熱量最低降到0%；鎖定中的武器降至0%才解除鎖定，未降至0%仍維持鎖定。

- **切換武器**：切出後，已啟動的散熱仍作用於原武器，3秒期限照常流逝；切出期間不能替它觸發新的一份。

## 計算與算例

- **非鎖定前提**：IV級在50%熱量觸發，沒有新增產熱與自然散熱，3秒窗口內發生三次有效扣熱。

- **非鎖定結果**：每次扣`10÷3×0.25≈0.833個百分點`，三次共扣2.5個百分點，熱量由50%降至47.5%。

- **鎖定前提**：IV級武器已鎖定且熱量75%，同樣在3秒窗口內有效扣熱三次，不計其他散熱。

- **鎖定結果**：每次扣`10÷3≈3.333個百分點`，三次共扣10個百分點，熱量由75%降至65%；仍處於鎖定。

- **到零前提**：IV級處於鎖定，下一次扣熱前只剩2%熱量。

- **到零結果**：扣熱受0%下限限制，熱量歸零並解除鎖定；之後若散熱仍在期限內，按非鎖定速度處理。

- **刷新前提**：10.25秒合格擊殺，12.25秒再次合格擊殺；每秒扣熱節拍在約11、12、13、14、15秒。

- **刷新結果**：期限由13.25秒延至15.25秒；既有節拍繼續，扣熱速度不加倍。

- **切換前提**：IV級非鎖定，10.25秒觸發後在10.5秒切出，期限內原武器沒有其他熱量變化，11、12、13秒各扣一次。

- **切換結果**：原武器仍共扣約2.5個百分點熱量；13.25秒後到期，切回不會重新啟動散熱。

## 遊戲描述勘誤

- **原文未列首目標限制**：只有攻擊第一個命中目標的弱點或暴擊擊殺符合條件。

- **原文未分鎖定狀態**：描述的I–IV四、六、八、十個百分點，是鎖定狀態下三次扣熱的總量；非鎖定狀態三次只有1、1.5、2、2.5個百分點。

- **原文未列節拍與刷新**：扣熱按既有每秒節拍執行，再次擊殺只刷新3秒期限；不能把每次擊殺都視為額外取得完整總量。
