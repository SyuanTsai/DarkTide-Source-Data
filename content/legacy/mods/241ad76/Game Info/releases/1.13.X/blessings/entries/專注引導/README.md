# 專注引導(Focused Channelling)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/3778f955-df91-47c2-997d-02817524ac32" width="72" height="72" alt="專注引導祝福圖示">

- **觸發方式**：持用裝有本祝福的型號，進入該型號設定的蓄能動作期間生效：虛空爆破力場法杖 陰陽 Mk III、電流力場法杖 諾瑪努斯 Mk VI、虛空打擊力場法杖 陰陽 Mk IV 以蓄能動作為條件；烈焰力場法杖 裂隙避難所 Mk II 以火焰蓄能為條件。虛空打擊法杖的蓄能後投射物發射另符合不可中斷關鍵字條件，但不套用蓄能移動懲罰公式。
- **階級效果**：I–IV 分別減輕 20%、30%、40%、50% 的該次蓄能移動速度懲罰；這是減少既有懲罰，不是直接提高同數值的移動速度。
- **不可中斷與推擊**：條件成立時提供 `uninterruptible` 與 `stun_immune` 關鍵字。明確設定忽略免疫的中斷呼叫仍可略過前者；推擊呼叫或模板要求忽略 stun immunity 時，後者也不會阻擋。這不提供傷害免疫，也不代表免疫所有控制。
- **各型號差異**：虛空爆破力場法杖與電流力場法杖只在蓄能期間符合；烈焰力場法杖只在火焰蓄能期間符合；虛空打擊力場法杖的蓄能及蓄能後投射物發射符合關鍵字條件。四型號的特殊近戰、普通近戰、推擊與通風動作都不在本祝福條件內。
- **原生動作例外**：法杖設定本身已有部分 `uninterruptible` 動作，例如一般射擊、火焰射擊、連鎖閃電釋放與通風。那些原生設定與本祝福條件分開；不符合本祝福條件的動作，不會因此取得本祝福的移動懲罰減免。
- **首次生效與切換**：祝福在武器裝備時安裝；本項屬性和關鍵字依目前持用武器及動作條件更新。切換武器會讓持用條件關閉，切回並進入符合動作後恢復；真正卸下武器時才移除該武器的祝福。沒有命中觸發、層數、持續時間或冷卻。

## 計算與算例

- **前提**：目前持用對應法杖且符合蓄能條件；動作原本的移動速度倍率 `m_action=0.50`，表示原有懲罰為 50%；不計替代射擊及其他移速修正。
- **代入**：IV 的懲罰剩餘倍率 `c=0.50`，所以 `m_charge=1-(1-m_action)×c=1-(1-0.50)×0.50=0.75`。
- **結果**：移動倍率由 0.50 變為 0.75；懲罰由 50% 降至 25%，減少中性基準的 25 個百分點，或相對原懲罰減半。
- **玩家意義**：效果縮小蓄能時既有的移速損失；若動作原本沒有移速懲罰，就不會憑空加速。實際最終移速仍會乘上其他獨立修正。
