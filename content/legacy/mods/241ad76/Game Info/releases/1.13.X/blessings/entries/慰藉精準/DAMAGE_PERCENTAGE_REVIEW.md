# 慰藉精準：百分比與結算

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

令 `M` 為事件處理時的目前最大韌性（包含已生效的最大值加成），`p` 為對應武器的 tier fraction，`D` 為當下缺損。合格且仍可回復時，預算 `B=M×p`，實際回復 `R=min(B,D)`。Callback 使用 `ignore_stat_buffs=true`，不乘一般韌性補充倍率；兩個 own template 都沒有 `toughness_regain_multiplier` producer，故倍率取預設1。

- 臂鎧 IV：假設 `M=100`、`D=50`、`p=.36`。代入 `B=100×.36=36`，所以 `R=min(36,50)=36`；韌性由50升至86。意義：+36%指最大韌性預算，不是缺損的36%。
- 手槍 IV：假設 `M=100`、`D=10`、`p=.16`。代入 `B=100×.16=16`，所以 `R=min(16,10)=10`；韌性回滿至100。意義：缺損不足時以缺損封頂。
- 上述 `M` 必須是事件當下的目前最大韌性，`D` 也是事件當下缺損；數值表示韌性點數，不是最大韌性永久增加。非暴擊擊殺、未擊殺、持用/item gate 不符、已滿韌性或原生回復被禁用時，這次回復為0。

- 描述鍵 `loc_trait_bespoke_toughness_on_crit_kills_desc` 的英文與繁中共用 hash `f3f6d906`；兩者都有 toughness placeholder。兩套 own formatter 都以 percentage 格式及 `+` 前綴顯示 tier 值，與實作四級數值一致。
- 描述明列致命一擊擊殺；額外的 exact-item、事件處理時持用、攻擊型態實際接線及投射物旗標保存條件沒有寫入描述，分類為文件未涵蓋。
- 描述沒有指定分母為目前最大韌性、缺損封頂、直接回復而非回復速率，或原生拒絕回復狀態（倒地檢查另有 `force_assist` 例外）；這些是實作細節，文件未涵蓋，未發現相反數值宣告。
- 兩種武器的事件有效動作不同：手槍 push 不傳暴擊旗標；臂鎧特殊動作的直接命中可帶暴擊，但其附加爆炸固定非暴擊。榴彈路徑保留發射時旗標與 item，仍需通過本項 held check。
