# 煉獄(Infernus)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/55a772ae-58cf-4db6-9a47-7dbb7fd230cd" width="72" height="72" alt="煉獄祝福圖示">

- **觸發方式**：持用有煉獄的武器，以遠程暴擊造成正傷害，對仍存活的受擊敵人添加燃燒層。

- **一般武器 I–IV**：步兵鐳射槍、冥潮鐳射槍、重型鐳射手槍與重伐木槍，每次新增1／2／3／4層，上限3／6／9／12層。

- **磷光爆破手槍 I–IV**：每次新增2／3／4／5層，上限4／9／12／15層。

- **連射**：每次符合條件的暴擊命中分別添加燃燒層。

- **穿透多目標**：一發實際穿透多名敵人時，每名符合條件的存活目標各自疊層。

- **特殊攻擊**：近戰刺刀、推擊與擊打不觸發；磷光爆破手槍的主彈直接命中可觸發，背爆炸不觸發。

- **期限刷新**：新增燃燒層會刷新基礎4秒期限；剛好到達本級上限後再觸發，也會刷新期限。燃燒持續時間加成會延長這個期限。

- **消退方式**：刷新期限結束後，按每0.5秒的傷害節拍移除一層，並非一次清除全部燃燒。

- **共同燃燒**：會與使用同一燃燒效果的其他來源共用層數；本祝福只補到自身等級上限。已有層數超過這個上限時，不再添層或刷新期限。

- **切換武器**：切出後停止由這把武器觸發新層；敵人身上的燃燒繼續作用與消退。

- **觸發冷卻**：沒有額外冷卻。

## 計算與算例

- **一般武器 IV級前提**：同一敵人存活，起始0層，沒有其他燃燒來源或持續時間加成，消退前連續承受三次符合條件的遠程暴擊。

- **一般武器 IV級結果**：每次加4層，依序4→8→12層；第四次仍維持12層，並刷新基礎4秒期限。

- **磷光爆破手槍 IV級前提**：同一敵人從0層開始，消退前承受三次符合條件的主彈直接命中暴擊。

- **磷光爆破手槍 IV級結果**：每次加5層，依序5→10→15層；背爆炸另有自身燃燒效果，不能當作額外一次煉獄觸發。

- **穿透算例**：一般武器 IV級的一發暴擊實際穿透兩名存活敵人，兩者都受正傷害，便各新增4層。

- **燃燒威力算例**：令 `x = 當前層數 ÷ 31`，威力參數為 `500 × x² × (3 − 2x)`；12層約166.762，15層約237.907。這些是傷害結算的輸入，實際生命傷害還受目標裝甲與燃燒傷害加成影響。

- **消退算例**：最後一次刷新後維持12層，且沒有其他來源再刷新或持續時間加成，先經過4秒期限，再按節拍移除12層；名義上約9.5–10秒清空，另受遊戲更新步長影響。

## 遊戲描述勘誤

- **暴擊條件**：本體「致命一擊」指暴擊，還需符合遠程、正傷害與持用武器條件。

- **等級差異**：磷光爆破手槍的層數與上限不同，不能套用其他武器的表格。

- **持續時間**：本體描述未列基礎4秒刷新期限與逐層消退方式。
