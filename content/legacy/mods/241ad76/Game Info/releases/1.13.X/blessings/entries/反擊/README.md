# 反擊(Counterattack)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/b67a8546-2e99-4ab7-aaf5-5af04f9ea255" width="72" height="72" alt="反擊祝福圖示">

- **觸發方式**：持用帶有反擊的武器，實際擋住一次攻擊即可觸發；一般格擋與完美格擋都有效。

- **等級效果**：等級I–IV分別增加6%、8%、10%、12%近戰攻擊速度。

- **持續時間**：每次觸發持續6秒；再次格擋會從該次格擋重新計時6秒。

- **疊加規則**：連續格擋只刷新期限，反擊本身不累加攻速，也沒有額外觸發冷卻。

- **生效時機**：觸發後開始的新攻擊動作採用攻速加成；已經開始的動作保留開始時的速度。

- **切換武器**：切出這把武器時暫停提供攻速，6秒期限照常流逝；期限內切回即可恢復剩餘時間的效果。

- **到期與重觸發**：期限到期後攻速恢復；再次格擋即可重新獲得完整6秒。

- **盾牌格擋**：法務官電擊鎚和鎮壓護盾擋住可格擋的遠程攻擊也能觸發。

- **破防情況**：實際格擋耗盡體力並造成破防時，這次格擋仍可觸發反擊。

## 計算與算例

- **攻擊時間前提**：假設一個近戰動作原本需1秒，沒有其他攻速效果，且未達速度上限。

- **IV級計算**：攻速倍率為`1＋0.12＝1.12`；動作用時為`1÷1.12≈0.893秒`，縮短約10.71%。

- **已有攻速前提**：假設同一動作已有20%同階段攻速加成，生效前需`1÷1.20≈0.833秒`。

- **已有攻速結果**：IV級反擊使倍率變成`1＋0.20＋0.12＝1.32`，用時約`1÷1.32＝0.758秒`；相對生效前，速度增加`(1.32−1.20)÷1.20＝10%`。

- **刷新前提**：0秒格擋觸發IV級反擊，原本會在6秒到期；4秒再次格擋。

- **刷新結果**：攻速仍是增加12%，期限改為10秒到期，並非增加24%。

- **切換前提**：0秒觸發，2秒切出，5秒切回，期間沒有再次格擋。

- **切換結果**：切回時剩約1秒；6秒到期。若7秒再次格擋，則重新持續至13秒。
