# 破甲(Sunder)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/08663e44-f8da-4e08-a202-96dec24ee060" width="72" height="72" alt="破甲祝福圖示">

- **觸發方式**：持用適用動力劍，且該欄位的原生特殊狀態生效、條件與屬性快取已更新時，本祝福提供穿透效果與近戰重擊傷害修正。啟用特殊狀態本身不造成命中，不需要先擊殺或累積層數。
- **穿透效果**：近戰揮擊略過護甲造成的中止條件；活著的非玩家、非道具物件及非生物道具物件的合資格敵方角色，按原受擊質量四分之一計入，之後仍套用其他目標與動作質量修正。其他目標依其原生質量分支處理。
- **穿透的限制**：效果提高揮擊穿透能力，沒有另加一份輕擊直接傷害修正，也不取消目標護甲的傷害減免。累積質量上限與敵種中止條件仍可停止揮擊，因此不保證無限穿透。
- **近戰重擊數值**：斯干達 Mk III／阿克利斯 Mk VI 的 I／II／III／IV 增量為 5／10／15／20 個百分點；布蘭克斯 Mk VI 為 4／6／8／10 個百分點。數值加入同一傷害修正池，仍依其他修正與目標因素結算，並非最終命中傷害必定等幅提高。
- **普通與特殊攻擊**：特殊狀態有效的實際近戰揮擊可使用穿透效果；輕擊與重擊仍各依其原生傷害設定。只有實際近戰重擊強度設定取得上述傷害增量，不要求完全蓄力，單憑攻擊名稱不能代替強度判定。
- **純推擊與追擊**：純推擊使用獨立推擊分支，不走揮擊的質量／護甲中止處理，也不取得重擊傷害增量。三型號的推擊後追擊是獨立近戰揮擊，可在特殊狀態有效時受穿透效果影響；實際追擊設定均為輕擊強度，所以不取得重擊傷害增量。
- **原生狀態、首次生效與刷新**：未搭配其他改變特殊充能的效果時，斯干達／阿克利斯預設特殊狀態為三秒、一次攻擊窗，可於作用中再次啟用；布蘭克斯為四秒、最多六格充能。原生攻擊消耗、再次啟用與到期控制該狀態；本祝福本身不加充能、不延長時間，也沒有獨立觸發層、冷卻或刷新計時。
- **切換與移除**：切出此劍時持用條件失效。斯干達／阿克利斯的原生特殊狀態關閉；布蘭克斯尚未耗盡的充能會保留，但保留充能不等於目前特殊狀態或本祝福仍生效。切回後，須該武器的特殊狀態實際生效並完成條件／屬性快取更新才提供效果；移除實際祝福效果後不再提供這些屬性或關鍵字。

## 計算與算例

- **重擊傷害前提**：武器仍在手上，特殊狀態及條件快取均已生效；profile 判定為近戰重擊；令非弱點、非爆擊的基礎傷害（套用本祝福 damage-stat 修正前）B=100，其他同池傷害修正 q=0，下游倍率為 1。
- **代入與結果**：斯干達／阿克利斯 IV 為 100 × (1 + 0.20) = 120；布蘭克斯 IV 為 100 × (1 + 0.10) = 110。這個例子只隔離近戰重擊傷害修正，不表示實際總命中傷害固定提高相同比例。
- **玩家意義**：若有弱點、爆擊、其他同池 damage-stat 修正、目標承傷倍率或額外傷害，總傷害須依相同乘區與下游計算；輕斬和純推擊不會取得這項重擊加成。
- **受擊質量前提**：活著的非玩家、非 prop、非 living-prop 敵方生物一般受擊質量為 20，先忽略目標自身受擊質量修正。
- **代入與限制**：20 × 0.25 = 5。揮擊仍會累計命中質量，達到動作上限或觸發敵種中止規則時仍可停止；本效果不等於無限穿透，也不取消傷害減免。
