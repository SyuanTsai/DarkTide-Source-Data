## 執行與計算

MasterItems 交集包含九種實際遠程武器、九個 trait 實作和二十一個 Mark 綁定；每個武器的 own wrapper 均逐項核對為 parent clone、child clone 及本身綁定，無後置覆寫。九組 I–IV 的 `stat_buffs.power_level_modifier` 都是 .05/.055/.06/.065；八組 child duration 為 3.5 秒，雙管霰彈槍 P2 為 5 秒。Base parent 的 `on_kill`、exact item 與 `on_ranged_close_kill` 條件共同執行，且 parent/child 都有 held-slot 條件；基礎 child `.01` 是 fallback。Buff 建立 child context 時以 parent template 找回 trait tier override；Buff 統計列舉 child conditional key 時，同名 `power_level_modifier` 覆寫 `.01`，按有效子層數聚合，不另加永久 parent stat。Base child `max_stacks=5`, `stack_offset=-1`；parent 起始一個佔位層、實體容量六，故最多五個有效層。

Attack 只有在目標結果為 `died` 後才送出 `on_kill`，其中包含實際 attack type、damage profile、attacking item 及 hit position。`on_ranged_close_kill` 接受 `attack_type=ranged` 或 profile 明確 `count_as_ranged_attack` 的死亡事件，再以 hit position 與攻擊者當前位置做平方距離比較。此武器使用其 own item exact match，距離邊界為含等號的 12.5 m。Direct hitscan/pellet 走 ranged dispatch。普通遠程攻擊和載入特殊彈後的直接彈丸使用同一條判定；近戰刺擊、盾推擊及重擊 profile 沒有 ranged 標記。戰鬥霰彈槍 P1 的燃燒 tick和鐵腕 Mk III 的電擊 tick雖能造成延遲傷害，其實際間隔事件是 `attack_type=buff`，所用 profile 亦沒有遠程標記，故 tick 不會觸發。

Parent proc event batch 每個通過的 `on_kill` 可增加一個子層，最多六個實體（含一個負 offset 佔位）。有效層上限為五。Child duration 是一個共用期限；合格事件新增子層並刷新倒數，即使已滿層、請求增加數為零仍刷新。期限到期後按 `stacks_to_remove=5` 清除有效層。此項沒有額外 cooldown。擊殺傷害在 on_kill 被送出及 BuffExtension 後續處理之前已經結算，因此新層不追溯增益該擊；僅在事件和屬性快取更新後才供後續攻擊讀取。

Trait buff 以 `on_equip` 安裝，切換武器不會立即移除父子 Buff；但持用條件使離手時的觸發與 conditional stat 關閉，期限繼續流逝。切回時只有仍未到期的層可在條件／快取更新後恢復。真正移除武器或祝福會移除 on_equip parent，父 class 的 destroy 路徑會清理 children。

令 `p` 為每有效層數值（I–IV：.05/.055/.06/.065），`n` 為有效層數（0–5），`q` 為其他適用威力修正在同一計算池的合計偏移，`B` 為攻擊威力類型曲線完成後、通用威力修正前的輸入。則威力輸入 `P=B×(1+q+n×p)`。本祝福只改通用威力輸入；傷害分布、目標護甲等後續計算仍決定最終生命傷害。五層的增量依序為 .25/.275/.30/.325。成功事件處理後，子層倒數共用且每次符合條件的擊殺刷新；達到期限時整批有效層清除。近距離檢查是 `distance_squared(hit_world_position, current_attacker_position) ≤ 12.5² = 156.25 m²`。
