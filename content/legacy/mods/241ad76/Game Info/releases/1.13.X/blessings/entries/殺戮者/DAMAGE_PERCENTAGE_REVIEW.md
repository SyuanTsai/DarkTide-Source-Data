# 殺戮者：百分比與結算

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

令 `p` 是 I–IV 每層的 `.05/.06/.07/.08`，`n` 是有效層數（0–5），`q` 是該次攻擊條件下其他合計威力修正，`B` 是威力類型曲線已換算、尚未套用威力修正的輸入。`PowerLevel` 先算威力類型曲線，再乘合併修正，因此本祝福使威力輸入為 `P = B × (1 + q + n×p)`。此結果會進入後續攻擊/衝擊等計算；不直接決定固定比例的最終生命傷害。

已核對七個 own tier formatter、七個完整 wrapper、17 個實際武器/Mark 綁定，以及 base parent/child 的事件、持用、層數和到期設定。特殊啟動與其後的 melee sweep 分開處理；純推擊及 Force Sword P1 投擲擊飛不符合近戰擊殺條件。數例只計威力輸入，不宣稱最終生命傷害比例。

另核對34段觸發／受益差異來源；這些證據另覆蓋17個純推擊、3條力場甩飛，以及31個碾壓者／雷鎚強化揮掃接線記錄；已有層數對通用威力消費端與新層的 melee gate 分開檢查。
