## 執行與計算

七個 own wrapper 都 clone `BaseWeaponTraitBuffTemplates.pass_past_armor_on_crit`，沒有後置改寫。Own tier 將 conditional `melee_critical_strike_damage` 設為 .025/.05/.075/.10；同 key tier override 取代 base .025 fallback。Base condition 要求持用槽符合且 `critical_strike_component.is_active`；Buff.init 對兩個 conditional keyword 沿用同一 predicate，stat 與 keywords 同 gate。

ActionSweep 在動作／目標處理時讀即時爆擊元件及最近的 keyword cache。HitMass 僅對存活合資格 breed 角色套 .25，其他質量修正仍在。Sweep 分開判斷累積質量預算、護甲中止與品種中止。近戰爆擊 stat 只加入弱點／爆擊共用的 finesse 額外部分。

廁所鏟特殊動作按型號分流：Mk III（M1）是掃掠拳擊；Mk XIX（M2）沒有額外後退設定；Mk V（M3）在特殊狀態啟用且命中前目標存活時，會另推動玩家自身後退。即使這一擊隨後擊殺目標，也不改變已捕捉的存活狀態。這項移動不推敵人或增加一次傷害。

- 令 F 為基礎弱點／爆擊的精準額外傷害，S 為不含本祝福的合併乘區，t 為 I–IV 的 0.025／0.05／0.075／0.10。本次是近戰爆擊且條件快取已更新時，額外部分為 `F×(S+t)`；弱點與爆擊項合併在同一 S，本祝福的 t 只加一次。
- 若其他傷害為 B、後續部位／背刺／減傷等修正中立、沒有力場覆寫或其他爆擊率轉傷害效果，最終傷害由 `B+F×S` 變為 `B+F×(S+t)`。其他修正有效時須依完整結算，不能將此受控公式當作所有命中的最終傷害。
- 合資格角色的掃掠基礎目標質量由 H 變為 `0.25×H`，其他目標、攻擊者與動作質量倍率仍有效；護甲中止被略過不代表無限順劈。
