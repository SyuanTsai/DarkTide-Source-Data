# 全孔射擊(Full Bore)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

- **觸發方式**：來源武器必須持用；完成一發彈丸射擊後，程式先確認該次射擊中是否有某個目標接到全部彈丸，再另外檢查事件所帶的目標是否屬於 Minion 分類的敵人。單一目標射擊時兩項通常指向同一目標；多目標穿透時，這兩項是分開挑選與檢查，不能保證全數命中的目標就是事件檢查的 Minion 分類敵人。
- 該發的直接彈丸命中先結算，不會回溯套用同發才建立的加成。Full Bore 事件處理並更新屬性快取後，後續攻擊才可能讀到它。加成為一層、最多5秒；再次合格觸發會刷新期限，不會疊成多層。
- 五個霰彈槍／霰彈手槍家族 I–IV 提供14／16／18／20%通用威力修正；反衝者 洛倫茲 Mk V 提供18／22／26／30%。這是攻擊威力輸入修正，不是固定生命值傷害百分比。
- 實際適用型號：戰鬥霰彈槍 紮羅娜 Mk VI；戰鬥霰彈槍 阿格里皮娜 Mk VII；戰鬥霰彈槍 奧克塔蘭 Mk IX；雙管霰彈槍 十字星 Mk XI；雙管霰彈槍 克魯克 Mk IV；獵人霰彈槍 奧克塔蘭 Mk III；滅絕者霰彈槍 鐵腕 Mk III；滅絕者霰彈槍 鐵腕 Mk VIII；衝覆者霰彈手槍和防暴盾牌 審判 Mk IV；反衝者 洛倫茲 Mk V。
- 裝填特殊彈本身不觸發；之後真正發射該彈種仍依同一彈丸事件檢查。獵人霰彈槍的特殊功能是手電筒切換，並非射擊。反衝者與多個霰彈槍的bash／重擊bash為近戰掃擊，不會產生本項要求的射擊事件；已存在的通用威力修正仍可影響該近戰威力計算。
- 戰鬥霰彈槍 奧克塔蘭 Mk IX 的燃燒特殊彈會在彈丸命中後附加 flamer_assault；後續燃燒 tick 以擁有者當時的威力屬性重新計算。若 Full Bore 已完成事件處理、屬性快取已更新且仍持用來源槍，tick 可讀到加成；切槽並更新快取後，tick 不讀取這項加成，也不會把射擊時的威力快照留給持續傷害。
- 衝覆者霰彈手槍和防暴盾牌的普通射擊與格擋射擊都使用彈丸射擊事件；純盾推不是本項觸發事件。其推擊會將通用威力修正送入衝擊／踉蹌計算，但推擊profile的生命傷害為0；若目標進入相應盾牌反應，該推擊profile的固定值20可取代傳入力度，覆寫該盾牌反應；這不代表所有最終踉蹌強度都固定為20。
- 加成條件要求仍持用來源物品。切換武器會在下一次屬性快取更新後停用這項效果，但5秒計時繼續；期限內切回可恢復剩餘時間的效果。真正卸下來源武器才移除該祝福。

## 計算與算例

- **前提**：以戰鬥霰彈槍 紮羅娜 Mk VI 的13枚標準彈丸射擊單一Minion 分類的敵人，假設13枚都命中同一目標、其為事件檢查目標；這只展示一次合格射擊。另令攻擊已通過武器自身威力曲線、尚未套用本祝福的威力輸入 B=500，其他威力修正為中性。
- **代入**：IV提供 p=0.20，後續攻擊的通用威力輸入為 B×(1+p)=500×1.20。
- **結果**：輸入由500變為600，增加100威力單位（相對該輸入增加20%）。這不是生命值傷害增加20%的保證，因後續還有各攻擊的傷害、部位與目標修正。
- **玩家意義**：合格射擊只建立後續5秒的加成；建立加成的這發不回溯受益。其他武器家族的級別值依集中表，反衝者數值較高。
