# 湧動(Surge)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/c8817fbb-dac1-4242-be45-082494de8f2c" width="72" height="72" alt="湧動祝福圖示">

- **持用效果與首次生效**：持用適用法杖時，遠程致命一擊機率立即按條件生效，I–IV 增加 2／3／4／5 個百分點。這是機率加算，不是致命一擊傷害加成。

- **觸發方式**：在適用射擊動作開始時，若這次遠程射擊判定為致命一擊，就安排多發一枚投射物；不必先命中目標。一般射擊原本一枚，符合條件時總共兩枚，兩枚沿用同一次致命一擊結果，第二枚不另擲骰。

- **適用射擊**：虛空爆破與電流力場法杖僅一般主要射擊會追加投射物；虛空打擊力場法杖的一般主要射擊及蓄力次要射擊都會追加。近戰、推擊均不追加。

- **蓄力攻擊的差別**：虛空爆破的蓄力爆炸、電流的蓄力連鎖閃電不追加投射物，但兩者仍使用遠程致命一擊判定，因此持用時仍獲得上述機率加成。近戰致命一擊判定不讀取這項遠程機率。

- **發射時序與中斷**：第二枚按動作時間設定晚 0.1 秒發出，實際間隔再除以動作速度倍率。若動作結束時第二枚尚未發射，會被清除；兩枚並非保證同時發出。已發射的投射物保留當次致命一擊結果，不因後續切換武器重判。

- **疊層、期限與刷新**：這是持用期間的條件效果，沒有擊中後的層數、倒數或額外冷卻。每次新的適用射擊動作都重新判定；切走後持用條件失效，切回後恢復。切換不會讓本祝福自行追發第三枚。

- **實際傷害**：多一枚代表多一次投射物的碰撞與攻擊機會。是否命中、是否打到同一目標，以及穿透、爆炸與最終傷害，仍各自依實際攻擊結算；不能保證總傷害翻倍。

## 計算與算例

- **機率加算**：假設職業、武器與其他效果加總後的遠程致命一擊機率為 10%，沒有保證或禁止致命一擊，也沒有機率轉傷效果。IV 代入為 10% + 5 個百分點 = 15%；增加的是 5 個百分點，相對原值增加 50%，不是 10% × 1.05 = 10.5%。實際射擊序列仍經偽隨機判定，不保證每 20 發恰有 3 發致命一擊。

- **投射物與傷害**：假設虛空打擊法杖的適用射擊判定為致命一擊，兩枚均成功發出、擊中同一個仍存活的目標，且每枚結算後均造成 150 傷害。投射物數為 1 + 1 = 2；總傷害為 150 + 150 = 300，比只命中一枚的 150 增加 100%。這是上述兩枚均命中的算例；第二枚落空、被中斷或目標已死時，不能照套 300。

- **發射間隔**：第一枚與第二枚的動作時間偏移差為 0.1。速度倍率 1 時，間隔為 0.1 ÷ 1 = 0.1 秒；倍率 1.25 時為 0.1 ÷ 1.25 = 0.08 秒。這是設定時序，實際更新與網路時序仍影響觀測時間。

- **蓄力差異**：上述 10% → 15% 的 IV 機率算例也適用於虛空爆破的蓄力爆炸與電流的蓄力連鎖閃電；即使判定為致命一擊，這兩種動作也不額外生成投射物。虛空打擊的蓄力次要射擊則可追加。

## 遊戲描述勘誤

- 繁中兩個描述使用「再射擊{value:%s}次」，而 formatter 將 value 固定填為 2，文字容易被理解為原射擊之外再射兩次。實作是在原本一枚上增加一枚，總共兩枚；英文的「2 Shots」與此總數一致。追加數量應說明為「額外一枚，總共兩枚」，不是額外兩枚。
