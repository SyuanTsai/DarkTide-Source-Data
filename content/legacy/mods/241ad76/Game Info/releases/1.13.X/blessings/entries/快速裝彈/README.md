# 快速裝彈(Speedload)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ed5c7d7f-02a2-4bea-9463-c4380478a244" width="72" height="72" alt="快速裝彈祝福圖示">

- **觸發方式**：一般路徑是在裝有本項的遠程武器造成死亡時，檢查是否由同一武器命中、攻擊類型為遠程（或傷害設定明確標為可計作遠程），且該次命中位置距事件攻擊者不超過12.5公尺；事件處理時也必須仍持用該武器。
- 普通射擊、蓄力、投射物直擊、追加爆炸、特殊攻擊或推擊後續攻擊，都不因動作名稱自動取得層數；只有實際送出並通過上述死亡事件條件的攻擊才走一般路徑。沒有造成死亡的純推擊不會送出此路徑所需的死亡事件。
- 每個有效層依等級增加裝填速度：I +7%、II +8%、III +9%、IV +10%；最多5個有效層，層數效果相加。
- 每次合格事件增加一層並重新起算整個效果時間；到達5層時，新的合格事件不再增加層數，但仍重新起算時間。沒有逐層獨立計時。
- 持續時間依實際武器：步兵自動槍與槍托自動槍2.5秒；撕裂者自動手槍與雙持自動手槍2秒；偵察鐳射槍、重型鐳射手槍、針彈手槍、雙管霰彈槍、獵人霰彈槍、滅絕者霰彈槍3秒；衝覆者霰彈手槍和防暴盾牌、快拔左輪手槍4秒。
- 新層會在後續玩家統計快取更新後提供裝填速度；開始中的裝填段不會被追溯改寫。切換武器不會立即清除已取得層數，也不會暫停倒數；切出後不能用未持用的本項武器取得新層。既有子效果沒有持用條件，因此剩餘期限內的裝填速度加成仍會生效；切換後，其他實際讀取裝填速度的裝填動作也可使用這份加成。效果到期後的固定更新會移除全部有效層；若效果本身被銷毀，清理流程會移除它追蹤的子效果。
- 效果只影響實際讀取裝填速度的裝填動作，不增加射擊傷害或射速。這23個實際型號的裝填路徑包括整段裝填、逐發補彈與滅絕者霰彈槍特殊彈裝填；逐發補彈每段各自取樣。滅絕者特殊彈裝填會直接讀取裝填速度；霰彈槍切換特殊動作與針彈手槍化學彈切換則不是裝填動作。
- 針彈手槍另有標記死亡路徑：遠程命中存活目標時會標記；毒素效果消失後，標記不會立刻清除；更新確認其最近記錄已超過一個固定影格的寬限後，才移除標記。若標記仍在，毒素傷害造成該目標死亡，且死亡事件攻擊者距事件位置不超過12.5公尺，可能提出一層請求。死亡事件可由其他攻擊者造成；本項持有者仍須在事件處理時持用副手武器。這條路徑按毒素死亡事件欄位與存留標記判定，不重查當下毒素關鍵字或攻擊武器。
- 逐發裝填及特殊彈裝填均在各自動作開始時計算速度；若該動作已開始，之後觸發或到期都不回頭改寫已保存的動作時間倍率。

## 計算與算例

- **前提**：用同一個實際裝填動作段做控制變因示例，假設沒有其他 `reload_speed` 加成（q=0）、Handling 不變、時間倍率上限沒有介入，基準段時間 T₀=10 秒；這是公式代入，不是實機測得的武器總裝填時間。
- **代入**：IV 級一個有效層為 p=0.10、n=1：裝填速度倍率 `1+n×p=1.10`；新段時間 `10÷1.10=9.09 秒`。
- **結果**：這一段約少 0.91 秒，時間縮短約 9.09%。
- **玩家意義**：「裝填速度 +10%」不等於完整動作時間縮短10%；實際處理時間由原時間除以速度倍率。
- **五層代入**：假設在本武器顯示的時間窗內取得5個有效層，IV級 n=5、p=0.10，速度倍率為1.50，新段時間 `10÷1.50=6.67秒`，比基準段短約33.33%，不是短50%。
