# 飛鏢彈(Flechette)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ded2c83c-1daf-4bce-9e73-d85c11228095" width="72" height="72" alt="飛鏢彈祝福圖示">

- **觸發方式**：持用帶有此祝福的武器，以暴擊彈丸射擊命中敵人並造成傷害；處理命中事件時目標仍存活，才會施加流血。

- **等級效果**：I–IV 每次符合條件的射擊，對每名受傷目標新增3／4／5／6層流血；四種武器的數值相同。

- **彈丸計數**：同一射擊的多顆彈丸會按敵人合併計算。即使多顆彈丸擊中同一敵人，也只施加一次等級層數。

- **多目標**：同一暴擊射擊若對多名敵人造成傷害，各名符合條件且存活的敵人各獲得一組層數；不限第一名目標。

- **射擊條件**：不要求弱點命中、擊殺或先連續射擊。只有命中而未造成傷害的目標不會獲得層數。

- **特殊射擊**：裝填特殊彈或切換射擊模式本身不施加流血；之後的彈丸射擊若暴擊並造成傷害，同樣能觸發。

- **近戰攻擊**：槍托、刺刀等近戰攻擊不會觸發這個彈丸射擊祝福；流血跳傷也不會自行再次觸發。

- **層數上限**：同一敵人最多16層流血，相同流血效果共用層數。

- **流血與消退**：流血每約0.5秒跳傷，最後一次施加或刷新後約1.5秒開始退層。此後每次先按目前層數跳傷，再移除1層，直到全部消失。

- **再次施加**：新增層數及滿層再觸發都會刷新等待退層的期限，並保留原跳傷節奏。

- **切換武器**：已施加的流血繼續存在；新層數要求處理彈丸命中事件時仍持用帶有祝福的武器。

- **傷害成長**：流血跳傷依當前層數曲線、護甲與其他傷害修正計算；層數不代表固定傷害百分比。

## 計算與算例

- **IV級單一目標**：同一暴擊射擊有5顆彈丸擊中一名存活敵人並造成傷害，該敵人新增6層流血；命中1顆而造成傷害時，同樣新增6層。

- **IV級多目標**：同一次暴擊射擊對兩名存活敵人各造成傷害，兩名敵人各新增6層。

- **疊到上限**：在退層前連續3次符合條件的IV級射擊，層數依序為0→6→12→16；第4次維持16層並刷新期限。

- **停止射擊**：刷新時有16層，之後不再施加，名義上約9–9.5秒逐層退完；範圍依原跳傷節拍而定，另加固定更新延遲。

- **傷害變化**：6層流血的輸入威力約158.203，16層為500；這些輸入另經流血傷害設定與護甲結算，並非直接扣血值。

## 遊戲描述勘誤

- 本體只寫「暴擊命中」，實際觸發的是彈丸射擊對每個目標的彙總事件。同次射擊多顆彈丸命中同一敵人，只新增一組等級層數。

- 繁中「致命一擊」指暴擊；不要求擊殺。流血1.5秒期限後開始逐層消退。
