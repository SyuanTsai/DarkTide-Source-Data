# 放血者(Bloodletter)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/cb07e9cd-d287-452c-bbcd-827d4808e0df" width="72" height="72" alt="放血者祝福圖示">

- **觸發方式**：持用帶有此祝福的鏈鋸武器，啟動後以斬擊或鋸擊對敵人造成傷害，施加流血；只按下啟動鍵不會施加。

- **等級效果**：I–IV的新增層數依武器而異：突擊鏈斧10／12／14／16層；重型開膛劍3／4／5／6層；突擊鏈鋸劍11／12／13／14層。

- **持續鋸擊**：層數按每次符合條件的傷害施加；同一次貼附敵人的鋸擊中，不限只觸發一次。

- **命中條件**：不要求暴擊、弱點或擊殺。事件處理時敵人須仍存活，且仍持用帶有祝福的武器。

- **普通攻擊差異**：重型開膛劍MkXV的普通輕擊若貼附敵人，第一段鋸擊能施加流血，最後一段不會。其餘型號的普通未啟動攻擊不觸發；詳見下表。

| 武器與型號 | 未啟動時的普通攻擊 |
|---|---|
| 突擊鏈斧 奧瑞斯特斯 MkIV／MkXII | 不觸發。 |
| 重型開膛劍 泰格魯斯 MkIII | 不觸發；普通重擊的單段貼附鋸擊也不觸發。 |
| 重型開膛劍 泰格魯斯 MkXV | 普通輕擊的第一段貼附鋸擊觸發；最後一段、普通重擊及直接斬擊不觸發。 |
| 突擊鏈鋸劍 卡迪亞 MkIV／MkXIIIg | 不觸發；未啟動時不會開始貼附鋸擊。 |

- **多目標**：直接斬擊傷害可逐一處理命中的敵人，不限第一名目標；貼附鋸擊對其貼附目標施加。

- **層數上限**：同一敵人最多16層流血，相同流血效果共用層數。

- **跳傷與消退**：流血每約0.5秒跳傷；最後一次施加或刷新後約1.5秒開始退層。此後每次先按當前層數跳傷，再移除1層。

- **再次施加**：新增層數或滿層再次觸發都會刷新等待退層的期限，並保留既有跳傷節奏。

- **切換武器**：已施加在敵人身上的流血繼續存在，不因切換武器消失。

- **傷害成長**：跳傷依流血層數曲線、護甲與其他傷害修正計算；每層不是固定扣血或生命百分比。

## 計算與算例

- **IV級突擊鏈斧**：第一個符合條件的啟動命中，對原本沒有流血的存活敵人直接加到16層。

- **IV級重型開膛劍**：在退層前，同一敵人受到3次符合條件的斬擊或鋸擊傷害，層數依序為0→6→12→16；同一次啟動鋸擊內也能多次施加。

- **IV級突擊鏈鋸劍**：目標原有14層，一次符合條件的命中新增14層後封頂16層，並刷新期限。

- **MkXV普通輕擊**：IV級貼附鋸擊的第一段造成傷害時新增6層；最後一段不會再新增。

- **停止施加**：最後刷新時有8層或16層，名義上分別約5–5.5秒或9–9.5秒退完；範圍依原有跳傷節奏而定，另加固定更新延遲。

## 遊戲描述勘誤

- 本體描述只寫「特殊攻擊」，補充區分啟動斬擊、鋸擊與MkXV普通輕擊的第一段鋸擊例外。

- 同名祝福依武器有不同層數，逐項列出I–IV，不合併為單一數值。

- 1.5秒後開始逐層消退，流血不會在該時點一次清空。
