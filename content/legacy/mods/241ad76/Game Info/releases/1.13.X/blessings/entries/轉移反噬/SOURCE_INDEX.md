## 執行與計算

三個實際 trait wrapper 都複製共用的 vents_warpcharge_on_weakspot_hits Buff，並以 P1/P3 或 P4 自己的 I–IV trait 欄位覆寫共用 wrapper 的 0.05 vent_percentage。P1/P3 own tier 為 0.07／0.08／0.09／0.10；P4 為 0.065／0.07／0.075／0.08。這是替換同一欄位，不是加上 0.05。共用 Buff 的 max_stacks=1 是 proc Buff 上限，不是玩家可累積的排除層數。
wrapper 監聽 on_hit，並檢查目前手持槽、攻擊物品相符、弱點命中；沒有額外 ranged-only gate。Attack.execute 進入 local _execute，依目標 breed 與 hit_zone_name 呼叫 Weakspot.hit_weakspot 算出 hit_weakspot；local _handle_buffs 再把該旗標、attack_type、damage_type、damage_profile、attacking_item 等資料送入事件。P1 蓄力爆炸與 P4 實際產生的碰撞爆炸，在 center_mass actor 可用時都優先選取該 actor；P3 ChainLightning.execute_attack 明確傳入 center_mass；兩者仍須由通用攻擊程式算出 hit_weakspot=true 才符合本祝福；不能只憑 center_mass 名稱判定命中一定不是弱點。damage profile 的通用略過旗標與 damage type no-proc 名單仍可擋住事件。proc callback 只設 template_data.proc=true。PlayerUnitBuffExtension.fixed_update 先更新 Buff，稍後才派送 proc event；後續實際 Buff update 看到旗標後呼叫 WarpCharge.decrease_immediate，並清除旗標，因此更新前多個合格命中合併成一次固定排除。
remove_immediate 以 normalized current_percentage 減去 tier fraction，再 clamp 到 0–1，並傳回 idle。它不依目前反噬乘出剩餘比例。若減量執行時組件仍處於 exploding，WarpCharge.decrease_immediate 會呼叫 psyker ability interrupt、記錄 survived hook，接著採用 idle 狀態；此分支只在延後排除執行當下仍為 exploding 時成立。

P4 action_shoot_charged 另選 force_staff_ball_heavy；對可傷害目標的直接碰撞先由 delete_on_hit_mass 關閉原碰撞爆炸，只有 hit_mass_stop 成立且後續門檻允許時才恢復並建立 attack_type=explosion 的 force_staff_p4_demolition 攻擊；穿透而未停止不產生這次碰撞爆炸。不可傷害表面走不同碰撞分支，原本為 true 的 do_impact_explosion 不經該 hit-mass 關閉步驟，仍可依後續 gate 產生爆炸。P4 實際產生的爆炸與 P1 蓄力爆炸一樣，若目標有 center_mass hit-zone actor 就優先選取。實際發生的直接攻擊與爆炸都保留原武器物品，爆炸由 WeaponSystem 依每個目標實際 hit actor 取得 hit-zone 後分別呼叫 Attack.execute。

令 P 為排除前已讀取的 normalized 目前反噬比例，v 為該級排除量。實際結算為 P′ = clamp(P − v, 0, 1)；轉成百分點時 v × 100。P1/P3 的 v 為 0.07、0.08、0.09、0.10；P4 為 0.065、0.07、0.075、0.08。Buff 的 tier override 取代共用 fallback 0.05。
proc callback 只設一個布林待處理標記；一次 Buff update 最多依此標記排除一次，並在排除後清除。玩家 Buff 固定更新先執行 Buff 更新，再派送本幀 proc event，所以本幀稍後到達的合格事件要等下一次 Buff 更新才能排除。
