# 憤怒(Wrath)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/48e41633-a873-48b4-9818-796d3437e85f" width="72" height="72" alt="憤怒祝福圖示">

- **觸發方式**：近戰揮擊結束時，只要命中至少一名敵人，就獲得1層順劈加成，供後續攻擊使用。

- **每次新增**：一次揮擊命中多名敵人仍只加1層，最多5層。

- **命中要求**：不要求暴擊、弱點或擊殺，也沒有正傷害門檻。

- **一般武器 I–IV**：每層順劈增加25%／30%／35%／40%。

- **動力劍 I–IV**：斯干達 Mk III／阿克利斯 Mk VI 每層增加35%／40%／45%／50%。

- **骨鋸 I–IV**：外科醫師 型號4 每層增加10%／15%／20%／25%。

- **持續與刷新**：每次命中成功的揮擊結束都刷新3.5秒期限；已滿5層時也會刷新。

- **揮空與逾時**：沒有命中敵人的揮擊結束會清除全部加成；超過3.5秒未再刷新，也會一次清除全部層數。

- **切換武器**：切出時加成暫停生效，計時繼續；期限內重新持用可恢復留下的層數。

- **順劈含義**：提高攻擊可穿過的敵人質量上限，不直接提高傷害或衝擊順劈質量，也不保證固定多打幾名敵人。

- **黏附鋸擊**：鏈鋸黏住敵人的連續鋸傷不會每次各加一層；結束黏附、完成揮擊結算時才加一層。

- **推擊與啟動**：單純推擊、啟動或切換武器特殊模式不加層；後續命中的近戰揮擊可以觸發。

## 計算與算例

- **一般武器 III級**：從0層開始，期限內連續三次揮擊各命中敵人，得到3層；僅計此祝福時，順劈倍率 `1 + 0.35 × 3 = 2.05`。五層時為2.75倍。

- **動力劍 IV級**：斯干達 Mk III／阿克利斯 Mk VI 每層50%，五層時 `1 + 0.50 × 5 = 3.50` 倍。

- **骨鋸 IV級**：外科醫師 型號4每層25%，五層時 `1 + 0.25 × 5 = 2.25` 倍。

- **多目標算例**：一刀命中四名敵人，仍只加一層；原本兩層便變三層，不會立即堆滿。

- **滿層刷新算例**：五層後兩秒再成功命中，保持五層並重新開始3.5秒計時；下一刀揮空會清掉全部層數。

- **加算例**：一般武器 IV級五層提供+200%，另有+20%同類順劈修正時，倍率為 `1 + 2.00 + 0.20 = 3.20`，不把3倍與1.2倍相乘。前四項倍率只計本祝福，另有來源時依實際修正合併。

- **鋸擊算例**：從兩層開始，鏈鋸黏住敵人並造成多段鋸傷，且黏附結束前原有層數尚未逾時；黏附結束的揮擊結算只加一層，變三層。

## 遊戲描述勘誤

- **命中條件**：繁中「在攻擊時」應為「命中敵人時」。實際在命中敵人的近戰揮擊結束時增加1層；揮空會清除層數。
