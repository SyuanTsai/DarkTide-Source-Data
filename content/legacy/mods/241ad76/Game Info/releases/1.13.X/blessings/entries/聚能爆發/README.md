# 聚能爆發(Power Blast)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/4a53a4b2-051a-4e71-8098-1e15c55f0db8" width="72" height="72" alt="聚能爆發祝福圖示">

- **適用型號**：電漿槍 M35 熔岩核心 Mk II（Plasma Gun M35 Magnacore Mk II）；這項祝福的適用型號只有 Mk II。

- **觸發方式**：持握此電漿槍開火時，依射擊開始判定爆擊的當下已計算充能階數，增加通用爆擊機率。加成按百分點加算；它不是爆擊傷害倍率。

- **階級效果**：I／II／III／IV 級每階充能分別增加 +2／+3／+4／+5 個百分點；有效充能階數為 0–5，五階合計最高為 +10／+15／+20／+25 個百分點。

- **充能階數**：以該發爆擊判定能讀到的最近一次更新充能值為準，充能值除以 0.2 後向下取整，限制在 0–5 階。單次射擊增加的是當時階數乘上等級數值。

- **普通未蓄力單發**：這是可正常發射的射擊。尚未蓄力時為 0 階，因此本祝福增加 0 個百分點；該射擊仍有武器本身的 +5 個百分點加成及其他適用爆擊來源。

- **普通蓄力射擊**：一般蓄力流程可到 52.5% 充能，對應最多 2 階；中斷後提前射出的情形依射擊開始時的有效充能階數計算。

- **架槍／替代射擊**：該模式可達 100% 充能，滿充為 5 階；尚未達滿充或中斷時，依當次爆擊判定讀取的已計算階數。開始充能、改變充能與爆擊機率資料更新並非同一個即時步驟，射擊開始後才發生的變化不會回頭改寫該發結果。

- **維持、移除與切換**：武器充能從 0 開始，階數隨充能更新，沒有獨立的增益期限或命中疊層。射擊準備時會先保存本發使用的充能，再把充能歸零；之後的資料更新會讓本祝福加成歸零，已先判定的該發爆擊結果不回溯改變。切出武器後，持握條件在資料更新時不再成立；切回後依新射擊能讀取的充能及已更新資料重新計算。

- **爆擊與傷害**：加成先加入爆擊機率池，機率經上限及可用的機率轉傷害效果處理後，才以偽隨機機率判定（PRD）決定是否爆擊；數值不是保證爆擊次數。過熱爆炸不是這個射擊爆擊判定，該爆炸固定不爆擊。

- **特殊動作**：換氣與裝填本身不進行射擊爆擊判定；過熱爆炸固定不爆擊。射擊後的充能歸零與其後資料更新依前述規則處理。

## 計算與算例

前提：暴擊機率資料已更新到各例列出的充能值；只為展示機率輸入，假設角色原有爆擊機率為 10%、本武器該射擊的處理加成為 +5 個百分點、沒有其他爆擊加成、沒有保證或禁止爆擊效果、未觸及 100% 上限，且爆擊機率轉傷害係數為 0。下列數字是送入 PRD 的理論機率輸入，不是每發必定依該比例命中，也不是傷害百分比。

- **IV 級、未蓄力單發**：充能 c=0，n=clamp(floor(c÷0.2),0,5)=0；本祝福 +0 個百分點。輸入為 10%+5%+0%=15%。這個普通首發可正常射擊，但沒有本祝福加成。

- **IV 級、達一階**：c=0.2，n=1；本祝福 +5 個百分點。輸入為 10%+5%+5%=20%。相較未蓄力例的 15%，理論機率輸入提高 5 個百分點。

- **IV 級、普通蓄力達上限**：c=0.525，n=2；本祝福 +10 個百分點。輸入為 10%+5%+10%=25%。普通蓄力達上限也只取得兩階加成，比未蓄力例高 10 個百分點。

- **IV 級、架槍滿充**：c=1，n=5；本祝福 +25 個百分點。輸入為 10%+5%+25%=40%。架槍滿充取得五階，比未蓄力例高 25 個百分點，仍需經爆擊判定。

## 遊戲描述勘誤

- **繁中原文勘誤**：繁中 RAW 說明「提升2%至10%暴擊機率」（其餘階級最低值為3%／4%／5%），但可正常發射的未蓄力普通單發在爆擊判定時為 0 階，這項祝福實際增加 0 個百分點。正確範圍為 I–IV 級每充能階 +2／+3／+4／+5 個百分點，0–5 階最高 +10／+15／+20／+25 個百分點；普通蓄力射擊最大 52.5% 充能（最多2階），架槍滿充才達5階。英文 RAW 同樣有最低值矛盾，並非只限繁中翻譯。
