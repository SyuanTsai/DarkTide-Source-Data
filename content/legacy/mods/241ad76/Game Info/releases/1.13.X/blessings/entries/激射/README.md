# 激射(Hot-Shot)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a4cfe045-7131-4b43-a81b-0cfb1012b545" width="72" height="72" alt="激射祝福圖示">

- **觸發方式**：持用裝有激射的武器，命中敵人弱點時生效；此減耗就在該次弱點命中的順劈質量計算中套用。

- **等級效果**：電能步槍 I–IV 為減少 20%／25%／30%／35% 的目標命中質量消耗；冥潮鐳射槍與針彈手槍 I–IV 為 20%／30%／40%／50%。

- **影響範圍**：每次合格命中都依該敵人的命中質量重新計算；減少消耗會保留攻擊順劈與衝擊順劈預算。身體命中不套用這項弱點減耗。

- **傷害與衝擊**：這不是直接增加同百分比的順劈預算，也不提高該擊傷害或衝擊強度。保留下來的預算可能讓攻擊繼續命中後續目標，但仍受目標質量、剩餘預算、攻擊設定與裝甲中止條件限制。

- **瞄準與特殊攻擊**：沒有瞄準、蓄力或攻擊類型限制；腰射與瞄準射擊的弱點命中都會套用。電能步槍的刺擊和冥潮鐳射槍的刺刀攻擊若命中弱點也會套用此質量倍率。針彈手槍的化學特殊射擊採即時命中掃描（hitscan）；附加爆炸及毒素各自結算，此祝福不增加毒素傷害。

- **切換武器**：切出對應武器時，此持用條件停止提供效果；切回後，弱點命中再次套用。沒有累積層數或祝福自身的持續時間。

- **化學射擊的爆炸**：命中敵人的化學飛鏢須耗盡攻擊與衝擊兩種順劈預算，才依擊殺結果選擇附加爆炸；弱點減耗因此會影響何時爆炸。射擊碰到場景物件時，另外依原有穿透停止規則處理。

## 計算與算例

- **共同假設**：只示範順劈預算；假設目標命中質量為10、攻擊與衝擊預算各為25、其他質量倍率皆為1，且沒有裝甲中止或其他攻擊設定改變。

- **電能步槍IV弱點命中**：消耗10×0.65=6.5；攻擊與衝擊預算各剩25−6.5=18.5。

- **冥潮鐳射槍／針彈手槍IV弱點命中**：消耗10×0.5=5；兩種預算各剩20。

- **身體命中**：不套用弱點倍率，消耗仍為10；各預算剩15。

- **理想化連續容量**：若所有目標質量相同且每次命中弱點，消耗倍率0.8與0.5分別對應1/0.8=1.25倍與1/0.5=2倍的可承受總質量；這不是整數目標數或實戰穿透承諾。

- **解讀限制**：實際能否多命中目標，仍看下一目標質量、剩餘預算、攻擊設定與裝甲條件；算例不是最終傷害或衝擊值。
