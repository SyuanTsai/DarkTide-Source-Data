# 榮耀獵手(Gloryhunter)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a6ae35d2-8afe-4bf2-8640-e32f423bbc64" width="72" height="72" alt="榮耀獵手祝福圖示">

- **觸發方式**：正持用裝有「榮耀獵手」的武器並擊殺精英；擊殺必須歸屬於這把武器。
- **觸發時點**：攻擊結果回報目標死亡後，處理合格擊殺事件時會直接計算一次韌性恢復；首次合格擊殺即可生效，沒有另外等待疊層或啟動計時。
- **恢復量**：依武器版本與祝福等級，恢復最大韌性的 10%–35%；各武器的 I–IV 實際值見下方等級表。百分比以最大韌性為基數，不是目前剩餘韌性的百分比。
- **恢復修正**：這項直接恢復會忽略一般韌性補充數值加成；模板恢復倍率未設定時為1。
- **上限**：實際回復不會超過當下缺少的韌性；韌性已滿時即使觸發也沒有可回復量。若韌性恢復被其他狀態停用，恢復函式會回傳 0。
- **堆疊與期限**：每次合格擊殺直接恢復韌性；共用模板沒有每次擊殺累積的層數、持續時間或冷卻欄位，也不建立會在期限後消失的獨立增益。
- **切換與移除**：切到其他武器後，持用欄位條件不成立，之後的擊殺不由這把武器的祝福觸發；切回後可再次觸發。已經直接回復的韌性不會因切槽或移除祝福而被回扣。
- **攻擊模式**：共用條件不篩選攻擊類型、充能或武器特殊旗標；只有模式本身產生相同武器物品的合格擊殺事件才適用。額外傷害／持續傷害也須歸屬於同一把武器，不能僅憑傷害來源名稱推定。
- **目標範圍**：只計遊戲分類為精英的目標；特殊敵人或高生命值敵人不會僅因這些特徵就算精英。
- **普通射擊與近戰特殊動作**：一般射擊、電漿蓄力射擊，以及有傷害的推擊式揮擊／槍托攻擊，均可在保留同一武器物品並擊殺精英時觸發。臂鎧的普通攻擊是近戰；其瞄準射擊才發射榴彈，特殊動作另接爆炸近戰。手電筒或化學模式的切換本身沒有擊殺，不會單獨觸發。
- **針彈手槍的追加毒傷**：普通彈丸直接擊殺可觸發；後續毒傷跳傷、MkVI的毒性死亡爆炸與MKII的毒氣死亡爆炸都沒有保留武器物品，不能觸發「榮耀獵手」。毒傷由這把槍開始施加，也不會改變後續擊殺缺少物品的判定。
- **磷光爆破手槍的追加傷害**：命中敵人或可受傷的活體物件時接入的爆炸，以及直接命中或爆炸附加的磷光燃燒，均保留此槍的物品；爆炸或後續燃燒擊殺精英時，若事件處理時仍持用此槍，可觸發恢復。爆炸附加燃燒須由目標先存活於爆炸傷害後。
- **臂鎧與震盪槍的彈體**：臂鎧瞄準榴彈的直接命中、撞擊／引信爆炸，以及爆炸近戰的直接揮擊／爆炸，都保留臂鎧物品。震盪槍的腰射／瞄準彈體直接命中與撞擊爆炸同樣保留物品；各路徑擊殺精英時均可觸發，延遲爆炸則仍須在事件處理時持用相應武器。
- **電漿過熱爆炸**：兩個實際型號的對敵過熱範圍爆炸保留電漿槽物品，可在符合精英擊殺與持用條件時觸發。過熱自傷不是精英擊殺，不會藉此恢復韌性。

## 計算與算例

- **例一：基礎值。**
  - 前提：假設最大韌性為 100、目前為 0；正持用已裝有「榮耀獵手」I 級的矛頭爆矢槍 洛克 Mk IIb，且擊殺目標帶有 `elite` 標記；恢復未停用，也沒有額外倍率。
  - 代入：100 × 10% = 10 點請求恢復；目前缺少 100 點。
  - 結果：實際恢復 10 點，韌性由 0 變成 10。
  - 玩家意義：這是最大韌性的 10%，不是「目前韌性 0 的 10%」。
- **例二：目前韌性不作百分比基數。**
  - 前提：最大韌性 100、目前 63；正持用 針彈手槍 布蘭克斯 MkVI，祝福 III 級為 22.5%，並擊殺合格精英。
  - 代入：100 × 22.5% = 22.5 點請求恢復；缺少 37 點。
  - 結果：實際恢復 22.5 點，韌性到 85.5。
  - 玩家意義：計算從最大韌性得出 22.5，而不是從目前 63 計算 14.175。
- **例三：缺少量封頂。**
  - 前提：最大韌性 100、目前 98；正持用 擲彈兵臂鎧 布拉斯托姆 Mk III，祝福 IV 級為 35%，並擊殺合格精英。
  - 代入：100 × 35% = 35 點請求恢復；但只缺 2 點。
  - 結果：實際恢復 2 點，韌性到 100，不會超過上限。
  - 玩家意義：卡面百分比是恢復請求量的基礎，上限仍是當下最大韌性。
