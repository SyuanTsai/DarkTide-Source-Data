# 毀滅打擊(Devastating Strike)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/bff62972-f31b-4ea9-a311-5dde971011cd" width="72" height="72" alt="毀滅打擊祝福圖示">

- **效果**：使近戰攻擊側的最大命中質量提高本級百分比；這是順劈判定用的質量上限，不是直接傷害倍率，也不會令順劈變成無限。

- **觸發方式**：手持裝有本祝福的武器，以近戰攻擊對目標造成正傷害且爆擊時觸發；攻擊事件必須帶回同一武器物品。沒有擊殺或踉蹌要求。純推擊、武器切換鍵本身都不是符合條件的近戰傷害爆擊。

- **持續與刷新**：效果為5秒，不疊加層數；另一個合格爆擊事件可重新開始5秒計時。戰鬥中切換武器只會暫停本效果套用，計時仍繼續；5秒內切回才會恢復尚未到期的加成。若實際從裝備欄卸下這把武器，隨裝備套用的祝福效果會被移除。

- **等級**：I／II／III／IV 分別提高近戰攻擊側最大命中質量 +65%／+70%／+75%／+80%。

- **動作範圍**：實際設定為 `kind=sweep` 的普通、重擊、推擊後攻擊及特殊掃擊會走近戰命中事件；仍須本祝福的武器、正傷害與爆擊條件成立。純推擊與只有狀態切換的特殊動作不觸發。部分鏈鋸劍黏附profile會略過命中事件。Mk XIIIg直接掃擊profile未設略過旗標，但其四種獨立黏附追擊profile全部略過命中事件；型號差異見變體頁。

- **生效時點**：掃擊開始時已依當下狀態計算該次掃擊的最大命中質量；命中後才排入並處理爆擊事件。因此首次觸發的那次掃擊不會回頭提高自己的質量上限，事件處理及屬性快取更新後開始的後續掃擊才可能使用加成。

- **上限意義**：程式把攻擊側與衝擊側最大命中質量分開計算，再取較大值；本祝福只改攻擊側。實際能順劈幾個目標仍受攻擊profile、目標質量與其他動作限制。

## 計算與算例

- **算例一｜I級，攻擊側為較大值**
  - **前提**：假設掃擊開始前，未受本祝福時攻擊側最大命中質量為10、衝擊側為8；其他命中質量修正中性，I級效果已先進屬性快取。
  - **代入**：中性倍率1加本級0.65，攻擊側倍率為1.65；攻擊側10×1.65=16.5，衝擊側仍是8。
  - **結果**：ActionSweep取較大值，從10變成16.5。
  - **玩家意義**：攻擊側順劈質量上限提高65%；16.5不是敵人數量，也不是傷害提高65%。

- **算例二｜IV級，衝擊側仍較大**
  - **前提**：掃擊開始前攻擊側為10、衝擊側為20；其他修正中性，IV級效果已先進屬性快取。
  - **代入**：攻擊側10×(1+0.80)=18；衝擊側保持20。
  - **結果**：取較大值後仍是20，與原先上限相同。
  - **玩家意義**：祝福仍把攻擊側提高80%，但衝擊側較高時，最終使用的上限可能不變；不能把攻擊側加成讀成總傷害或固定增加穿透目標數。
