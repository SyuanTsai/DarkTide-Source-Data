# 精確定位(Pinpointing target)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/87b6548a-cbe0-4d68-a8bc-f0e457c17276" width="72" height="72" alt="精確定位祝福圖示">

- **觸發方式**：電能步槍、磷光爆破手槍與衝覆者霰彈手槍／防暴盾牌，瞄準時每滿 0.4 秒增加一層威力，最多 5 層；衝覆者須處於格擋瞄準狀態。
- **各家族數值**：電能步槍每層 +1／1.5／2／2.5%，磷光手槍每層 +1／2／3／4%，擲彈兵臂鎧與衝覆者手槍每層 +5／6／7／8%。各級上限與步幅見集中表。
- **首次生效**：達到第一個 0.4 秒門檻後，效果在狀態更新後供後續攻擊使用；同一瞬間開始瞄準與攻擊時，不保證攻擊已取得第一層。
- **射擊後**：除擲彈兵臂鎧外，射擊後會清空目前層數，更新後的攻擊從零層開始。衝覆者整發霰彈只算一次射擊，不按 pellet 數重複清除。
- **擲彈兵臂鎧例外**：榴彈發射後 0.8 秒內沿用原有層數；保留時間過後才依最近一次瞄準或發射時間重算。這種榴彈不會像其他三者那樣在發射後清空層數。榴彈離手時保留發射當下的威力修正，飛行途中不隨玩家狀態改變。
- **攻擊適用**：本項提升攻擊威力輸入，不是生命傷害百分比。只要實際攻擊使用當時的通用威力修正，遠程或近戰攻擊都可能受益；實際生命傷害仍由攻擊設定與目標決定。
- **特殊動作**：電能步槍特殊 bash、磷光手槍鞭擊與衝覆者盾擊／推擊會結束瞄準，因此不會延續瞄準累積。擲彈兵臂鎧的蓄力近戰及爆炸特殊攻擊，在臂鎧仍持用且瞄準修正仍生效時，也讀取通用威力修正；右重擊的推方向設定不代表它是獨立推擊動作。
- **切換與卸下**：電能步槍、磷光手槍與衝覆者沒有額外的「必須持用該武器」條件，但效果仍取決角色當前瞄準狀態與攻擊讀取的威力修正。擲彈兵臂鎧只在持用時提供加成；切換後不作用，重新持用且條件成立後恢復。真正卸下祝福才移除效果。

## 計算與算例

- **前提**：狀態已更新，沒有其他特殊攻擊修正；`B=100` 是威力曲線換算後、套用本項與同類加成前的攻擊威力輸入。第四級瞄準滿 0.8 秒，得到兩層。
- **電能步槍**：每層 2.5%，兩層為 5%；`100×1.05=105`。若同類加成已是 20%，基準為 120，加入本項後 `100×(1+0.20+0.05)=125`，相對基準增加 4.17%，不是把 1.20 再乘 1.05。
- **磷光手槍**：第四級兩層合計 8%；同一前提下 `100×1.08=108`。
- **擲彈兵臂鎧與衝覆者手槍**：第四級兩層合計 16%；同一前提下 `100×1.16=116`。若是臂鎧榴彈，該值只取決於發射當下複製的威力修正。
- **結果意義**：比較的是攻擊威力輸入，不是生命傷害固定增加值；最後傷害會依攻擊 profile 與目標結算。

## 遊戲描述勘誤

僅 Ogryn Gauntlet P1 的「射擊後清除所有層數」與實際 wrapper 不符：榴彈發射只送另一種投射物事件，自訂步數 wrapper 不監聽該事件，且最近發射後0.8秒內沿用舊步數。其他未描述的間隔、持用、切換及快照條件屬文件未涵蓋。
