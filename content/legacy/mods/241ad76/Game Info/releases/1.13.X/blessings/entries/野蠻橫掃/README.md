# 野蠻橫掃(Savage Sweep)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/d72aa1c7-93e6-466a-a90f-6562bf9b9738" width="72" height="72" alt="野蠻橫掃祝福圖示">

- **效果**：順劈加成作用於近戰攻擊側的最大命中質量，不是傷害倍率，也不等於固定增加敵人數；攻擊與衝擊兩種命中質量分開計算，最後依武器攻擊取較大的結果。

- **觸發方式**：手持裝有本祝福的武器，以近戰攻擊處理多個目標。以同一次揮擊的當前命中序號達到3或以上為門檻，並須符合這把武器及攻擊設定的命中事件條件；不另要求擊殺或造成正生命傷害。序號會把先前命中時仍存活的角色目標累積，再加入當前可結算目標，不能把任意三次場景碰撞或命中屍體當成穩定累積次數。

- **持續時間**：3秒；效果期間再出現合格命中會刷新時間，不會疊加層數。

- **等級**：重型開膛劍、突擊鏈鋸劍、重劍、砍刀與「惡魔之爪」劍 I–IV 分別增加攻擊側順劈上限140%、160%、180%、200%；穿音速雙刀為120%、130%、140%、150%。

- **可觸發動作**：普通或重擊的直接近戰掃擊、推擊後接出的近戰掃擊，以及各型號實際配置的直接特殊掃擊，均可在命中門檻、同武器與攻擊設定條件都成立時觸發。純推擊和特殊模式切換本身不會觸發。鏈鋸劍的部分黏附攻擊會略過一般命中事件；黏附追加傷害只使用目標序號1；型號差異見逐型號說明。

- **切換武器**：切出後持用欄位條件不成立，順劈加成不作用；3秒時間仍會流逝。武器仍裝備且加成未逾時時，切回後才可能重新符合持用條件。

- **上限**：加成不會令順劈無限，也不改衝擊質量；裝甲、目標質量和動作自身上限仍會影響實際可穿透目標。

- **首次生效**：每次揮擊在開始時已決定順劈質量上限。第三個目標的合格命中啟動效果後，還須完成屬性更新；新加成供之後開始的揮擊使用，不會回頭擴大正在進行的那次揮擊。

- **到期與移除**：最後一次合格命中後，效果共用3秒期限；達到期限後不再提供加成。卸下武器或移除本祝福會移除其效果；切換特殊模式本身不會把3秒期限重新起算。

## 計算與算例

- **算例一｜一般實作 I 級**
  - **前提**：假設某直接掃擊算出的攻擊側基礎最大命中質量為10、衝擊側為8；其他相關修正皆為中性，本祝福 I 級的效果已啟動，且屬性更新後才開始本次揮擊。
  - **代入**：additive_multiplier 的中性值1加上該級 tier 值1.4，攻擊側倍率為2.4；10×2.4=24，衝擊側仍為8。
  - **結果**：ActionSweep取兩者較大值，因此此例有效上限由10變為24。
  - **玩家意義**：該攻擊可按更高的攻擊側命中質量計算順劈；24不是24名敵人，也不是傷害增加240%。

- **算例二｜穿音速雙刀 IV 級且衝擊側較高**
  - **前提**：假設攻擊側基礎最大命中質量12、衝擊側25，其他修正皆中性；穿音速雙刀 IV 級效果已啟動且完成屬性更新後才開始本次揮擊，其等級值為1.5。
  - **代入**：攻擊側倍率1+1.5=2.5，12×2.5=30；衝擊側保持25。
  - **結果**：取較大值後有效上限從25變為30，差5質量。
  - **玩家意義**：RAW 的+150%只施於攻擊側命中質量；衝擊側較高時會遮住部分或全部可見差距，不代表傷害提高150%。
