# 轉移反噬(Transfer Peril)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/c87f7d38-0583-4a95-9bf5-f6face936882" width="72" height="72" alt="轉移反噬祝福圖示">

- **觸發方式**：裝備並手持對應力場法杖；該武器送出的合格 on-hit 事件必須被判定為弱點命中，且事件所帶武器物品須與這個祝福相符。觸發不要求擊殺，也沒有只限遠程攻擊的額外條件；仍受攻擊事件本身的通用略過旗標及傷害類型規則限制。純推擊本體不會觸發。
- **I–IV 效果**：P1 與 P3 分別消除 7、8、9、10 個百分點的目前反噬；P4 分別消除 6.5、7、7.5、8 個百分點。數值是固定反噬比例的減量，不是依目前反噬比例再乘一次。
- **生效時點**：合格命中先把本項 proc 標記排入事件佇列；玩家固定更新會先更新 Buff，之後才派送本幀 proc 事件。因此排除由後續 Buff 更新執行，不會回溯修改已結算的同一攻擊。多個合格命中若在同一次 Buff 更新前都設下同一布林標記，該次更新只排除一次。
- **手持、切換與卸下**：新命中只有在對應法杖處於手持槽且攻擊物品符合本 Buff 時才通過條件；若事件已通過並排入標記，排除函式本身不再檢查手持槽，所以單純切到另一武器不會取消仍安裝中的待處理標記，後續更新仍可能處理。真正卸下法杖時，武器擴充會移除該武器的 on_equip Buff，這與切槽不同。切回不會追回切出期間不符合手持條件的命中。祝福本身沒有額外玩家層數、冷卻或持續時間。
- **反噬邊界**：排除後將目前反噬限制在 0% 至 100%。若實際執行排除時反噬狀態仍是 exploding，程式會先呼叫 psyker ability interrupt，再採用排除函式傳回的 idle 狀態；這只適用於排除結算當下仍處於 exploding 的情況，不代表能撤銷已完成的爆炸。
- **行動差異**：P1、P3、P4 的普通 `rapid_left` 都以 `force_staff_ball` 發射直接投射物；P4 蓄力 `action_shoot_charged` 改用 `force_staff_ball_heavy`。投射物碰撞後的直接攻擊會把原持用武器物品及實際 hit-zone 傳給 `Attack.execute`，再按目標 breed 的 hit-zone 對照計算 `hit_weakspot`。P4 重型投射物在碰撞時先執行直接攻擊。對可傷害目標的直接命中，模板的 `delete_on_hit_mass` 會先關閉原碰撞爆炸；只有碰撞達到 hit-mass stop 且後續 gate 允許時，才會恢復並另建立 `attack_type=explosion` 爆炸。穿透可傷害目標而未停止，不會產生該次碰撞爆炸。撞上不可傷害表面時走另一碰撞分支，原本允許的碰撞爆炸仍可依後續 gate 產生。實際產生的爆炸保留同一武器物品，逐個目標從 hit actor 取得 hit-zone 並各自計算弱點旗標；直接命中與爆炸是兩個獨立事件，任一事件只有在自身 `hit_weakspot=true` 且通過通用 on-hit 篩選時才可能觸發。P1 蓄力爆炸與 P4 實際產生的碰撞爆炸，都會在可用時優先選取目標的 `center_mass` hit-zone actor；P3 連鎖閃電則明確以 `center_mass` 作為 `hit_zone_name` 呼叫攻擊。通用攻擊程式再依目標 breed 的 hit-zone 弱點對照及可能的 guaranteed-weakspot keyword 計算旗標，因此不能只憑 `center_mass` 名稱判定命中一定不是弱點。三者特殊刺擊的輕擊與重擊走近戰掃擊，傳入原武器物品及實際 hit-zone，仍須該攻擊自己的弱點旗標為真；推擊本體與排放反噬是分開的行動，不會因受推目標而自動成為本項弱點 on-hit。

## 計算與算例

- **前提**：P1 或 P3 的 IV 級；排除結算前目前反噬為 75%；一個符合弱點條件的命中已排入標記，並由後續 Buff 更新處理。
- **代入**：clamp(0.75 − 0.10, 0, 1)。
- **結果**：反噬變為 0.65，即 65%；固定排除 10 個百分點。
- **玩家意義**：效果不是把 75% 反噬乘以 90%；同一更新前再有第二個合格命中也不會自動翻倍，因為多個命中共用一個布林標記。

- **前提**：P4 的 I 級；目前反噬為 75%；同一 Buff 更新前收到兩個合格弱點命中，並在後續更新處理標記。
- **代入**：clamp(0.75 − 0.065, 0, 1)；兩次命中先合併為一個待處理標記。
- **結果**：反噬變為 0.685，即 68.5%，而非 62%。
- **玩家意義**：P4 I 級固定排除 6.5 個百分點；同批次觸發只排除一次，低於排除量時則由 0% 下限截住。
