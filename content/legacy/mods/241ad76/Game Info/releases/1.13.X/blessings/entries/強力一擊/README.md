# 強力一擊(Haymaker)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/9a68dfab-1a01-42c6-a9fa-ffe4d8295036" width="72" height="72" alt="強力一擊祝福圖示">

- **觸發方式**：持用帶有強力一擊的戰刃、短刀或惡霸棍棒，以近戰重擊命中即可增加一層；不要求特定連擊步數。每個合格命中事件各加一層，因此一揮命中多個目標可取得多層，最多五層。
- **效果與上限**：I／II／III／IV 每層分別增加 1／2／3／4 個百分點的秒殺機率；五層時為 5%／10%／15%／20%。這是額外秒殺判定的機率，不增加普通重擊傷害，也不保證秒殺。
- **首次生效與順序**：初始有效層數為零，首次命中不會取得自己新增那層的秒殺機率。一般命中先結算，秒殺判定讀取事件處理前的層數，之後才增加層數；同一批待處理事件中的所有目標都讀取原有層數，不能把該批新增的層數提前套用。
- **目標限制**：秒殺只檢查由此武器重擊命中、一般傷害後仍存活且有敵人種類資料的目標；排除帶 captain、monster、ogryn、cultist_captain 標籤者。這是種類標籤限制，並非按幾何身高判斷「人類大小」。一般重擊已擊殺目標或命中排除目標時，合格重擊事件仍可加層。
- **期限與刷新**：有效層數共用五秒閒置計時；每個合格重擊事件都重新起算，已達五層仍能刷新。超過五秒未再觸發便減少一層，之後每五秒再少一層；一次閒置不會把所有層數同時清除。輕擊、純推擊和投擲不會刷新這個加層計時。
- **重擊追擊與特殊攻擊**：戰刃兩型號的重擊設定推擊後追擊可觸發；短刀型號 3 的重擊追擊可觸發，型號 1 的輕擊追擊不觸發。純推擊、短刀投擲、戰刃特殊輕擊與本組惡霸棍棒特殊拳擊均不符合重擊條件。
- **切換與移除**：切出此武器會停止加層與秒殺效果，已有層數的閒置計時仍繼續；切回後可使用尚未衰退的層數。移除實際父效果會一併移除其控制的子層。此祝福沒有另外設定的觸發冷卻。
- **秒殺後的事件**：額外秒殺仍會送出一般命中與擊殺事件；其他效果依自身武器、攻擊種類與觸發條件判定，不能概括為全部停用，也不能保證某個指定效果必定觸發。

## 計算與算例

- **前提**：IV 級，目標符合種類限制，普通重擊結算後仍存活；沒有其他機率修正，效果事件已依序處理。
- **已有層數的算例**：已有兩層時，下一批合格重擊的秒殺機率是 `2×4%=8%`；若該批只有一個合格命中，處理完增至三層，下一個分開處理的合格命中才使用 `3×4%=12%`。
- **首次與多目標算例**：由零層開始，同一批重擊命中三個合格目標，三次秒殺判定都使用 `0×4%=0%`；該批處理完才取得三層，後續批次使用 12%。一揮多目標可以快速加層，但不能提高同一批目標的判定機率。
- **上限與衰退算例**：五層 IV 級為 `5×4%=20%`。最後一次合格重擊後，若持續沒有新觸發，第一次超過五秒的計時檢查降至四層、機率 16%；再經下一個五秒區間降至三層、機率 12%。在五層時再命中仍維持 20%，並重設閒置計時。
- **玩家意義**：4% 是每層增加的四個百分點，8%→12% 增加四個百分點，相對原 8% 增加 50%；這些數字都描述秒殺機率，並非額外傷害或最終傷害增幅。

## 遊戲描述勘誤

- **秒殺時其他效果**：英文與繁中 RAW 概括表示秒殺不會觸發其他效果；實際額外秒殺呼叫仍送出一般命中／擊殺事件，沒有一律禁止其他效果的條件。接收端仍有自己的條件，這不代表任一指定祝福必定觸發。
