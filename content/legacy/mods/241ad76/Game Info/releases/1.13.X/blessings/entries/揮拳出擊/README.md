# 揮拳出擊(Take a Swing)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/f65d27d9-85f5-45c6-a5e1-253f85ba8ea9" width="72" height="72" alt="揮拳出擊祝福圖示">

- **觸發方式**：手持裝有本祝福的武器，完成一次至少命中一個有效目標的推擊。三個實作涵蓋的五個型號都有推擊動作；整次推擊只判定一次，不會因推開多個目標疊加層數。

- **觸發限制**：推擊必須完成有效判定；若在判定前中斷，或此次沒有有效目標，就不會啟動或刷新。有效目標須是不同目標，並符合該型號的推擊範圍、方向及可作用條件；不符合條件的單位不計入。本祝福不要求擊殺、弱點命中或造成正傷害，也不要求推擊必須由同一把武器發出；只要求裝有祝福的武器仍拿在手上，而且本次至少命中一個有效目標。

- **效果**：成功後，在裝有祝福的武器仍拿在手上時，提高弱點傷害：I、II、III、IV 級分別為 +45%、+50%、+55%、+60%。加成只會作用在之後被判定為弱點命中的額外弱點傷害部分；不會把推擊本身變成弱點命中，也不是整次攻擊或最終生命值傷害的固定百分比。

- **時限與刷新**：工兵鏟三型號及撬棍型號持續 3 秒；碎骨者型號持續 6 秒。期間再次完成有效推擊會重新起算時間，不增加層數；同一推擊打中多個目標仍只刷新一次。沒有獨立層數或冷卻。

- **首次生效**：推擊先完成對各目標的攻擊，再於整次推擊結束時判定是否符合觸發條件。效果更新並納入角色屬性計算後，後續弱點命中才會得到加成；觸發推擊本身不會回溯使用新效果。

- **一般攻擊與特殊動作**：普通、蓄力、特殊近戰掃掠及推擊後追擊本身不會觸發或刷新，因為這些動作不會送出本祝福所需的推擊結束判定。但在效果有效、裝有祝福的武器仍拿在手上，且攻擊命中被判定為弱點時，這些攻擊可得到弱點傷害加成。切換特殊模式本身也不觸發。

- **切槽與卸下**：切到其他武器時，效果期限仍繼續倒數，但手上不是裝有祝福的武器時不提供加成；期限內切回並等角色屬性更新後，可恢復剩餘時間的效果。真正卸下武器或移除祝福會移除該武器提供的加成並清除此效果。

## 計算與算例

- **範例一：推擊後的非暴擊弱點追擊**
  - **前提**：使用撬棍 科技教士 型號6，IV 級；該型號的實際 `action_pushfollow` 使用 `light_crowbar_tank` profile。先以推擊命中至少一個有效目標，再讓後續追擊以**非暴擊**方式命中弱點。為單獨顯示本祝福，假設來源武器持續拿在手上、其他弱點／額外傷害修正為中性；將此 profile 在該目標上的基礎弱點額外傷害分量正規化為 100 單位。這是中間傷害分量，不是該 profile 的固定最終傷害。
  - **代入**：有效推擊後，IV 級的弱點額外傷害部分使用 `100 × (1 + 0.60)`。
  - **結果**：弱點額外傷害分量為 160 單位，比未計本祝福的 100 多 60 單位；這不代表總攻擊或目標生命值傷害也增加 60%。
  - **玩家意義**：先以有效推擊啟動，再讓撬棍追擊以非暴擊方式命中弱點；加成只作用在命中判定為弱點的額外傷害部分。

- **範例二：多目標仍是一次刷新**
  - **前提**：使用碎骨者 克魯克 Mk IIa，II 級。`t=10` 的推擊依其 3 公尺範圍、角度及推擊作用條件命中 2 個有效目標；`t=14` 又完成一次命中至少一個有效目標的推擊。其他條件都維持來源武器拿在手上。
  - **代入**：第一次推擊於整次動作結束時只判定並觸發一次，即使本次命中 2 個有效目標也不會觸發兩次；II 級效果持續 6 秒。第二次推擊在效果尚未結束時重新起算時間，起點更新為 `t=14`。
  - **結果**：效果在 `t=14` 後持續至約 `t=20`；兩次推擊不會累積成兩層，第二次只是刷新同一個非疊層效果。
  - **玩家意義**：一次推開多名有效目標也只啟動／刷新一次；再次推擊可延長效果，但不提高 +50% 的值。
