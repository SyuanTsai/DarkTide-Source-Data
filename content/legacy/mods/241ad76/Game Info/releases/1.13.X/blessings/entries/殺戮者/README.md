# 殺戮者(Slaughterer)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/49d940eb-8e9b-4d06-b9ea-f8692ee158ef" width="72" height="72" alt="殺戮者祝福圖示">

- **觸發方式**：持用裝有本祝福的武器，並以這把武器造成近戰擊殺；目標必須由近戰攻擊擊殺，單純推擊不算。
- **效果與等級**：每次合格擊殺增加一層通用威力修正。I／II／III／IV 每層分別提高 5／6／7／8 個百分點，最多五層，五層合計 25／30／35／40 個百分點；數值用於威力計算輸入，不等於生命傷害增加比例。
- **首次生效**：擊殺攻擊先完成傷害結算，之後才處理擊殺事件與新增層數；新增層數不回溯加到造成該擊殺的攻擊，事件與屬性更新後才供後續攻擊使用。
- **持續與刷新**：層數共用 4.5 秒期限。每次合格擊殺都增加一層並重新起算期限；已達五層時仍會刷新期限。期限到後，現有有效層一併移除；本效果沒有另外設定冷卻時間。
- **切換武器**：改持其他武器時，新的擊殺不會替原武器增加層數，原有威力加成暫停；4.5 秒仍繼續倒數。期限內切回，剩餘層數可在條件更新後恢復；真正卸下或移除武器祝福會清除其子層。
- **特殊攻擊與追擊**：特殊效果啟用本身不造成擊殺；以近戰揮掃實際造成的擊殺仍符合條件，包括蓄能後揮擊、特殊上勾拳與推擊後續斬擊。鏈斧黏附追加傷害若另行結算成近戰擊殺，也可符合條件。
- **不計入的動作**：單純推擊不算近戰揮擊；烈焰力場劍的推擊後甩飛走遠程攻擊路徑，也不會增加層數。
- **既有層數對推擊與甩飛的作用**：純推擊不能增加層數，也不造成生命傷害，但既有威力層數可參與其衝擊、踉蹌計算。力場劍甩飛同樣不能增加層數；該攻擊的生命傷害護甲倍率皆為零，既有層數可影響的是衝擊路徑。敵人護盾採固定踉蹌覆寫時，不會按本祝福威力值等比例提高，不能保證所有目標都更容易被推倒。
- **碾壓者的強化爆炸**：兩個型號的強化直接揮擊仍屬近戰，可在合格擊殺時增加層數；命中後另外產生的範圍爆炸屬爆炸攻擊，其擊殺不能增加層數。爆炸可使用當時已生效、仍持用此武器的既有威力層數；不要把同次直接命中剛取得的新層當成必定已套用到後續爆炸。
- **雷鎚的強化揮擊**：兩個型號都以直接近戰揮擊結算，合格擊殺可增加層數；強化命中的肢解表現不代表另外結算一個範圍爆炸。

## 計算與算例

- **前提**：IV 級、已取得五個有效層並完成屬性更新；`B=500` 是該攻擊套用威力類型曲線後、套用威力修正前的輸入，不一定等於遊戲中原始設定值；暫不計其他威力修正及下游傷害條件。
- **代入與結果**：每層 `p=.08`，五層 `n×p=5×.08=.40`；威力輸入 `500×(1+.40)=700`。這使威力修正由0%增加到40%，即增加40個百分點；在沒有其他同池修正時，威力輸入700相對500增加40%。這兩種表示的比較基準不同，均不代表生命傷害固定增加40%。
- **已有同池修正**：若其他符合該攻擊條件的威力修正合計 `q=.20`，原輸入為 `500×1.20=600`；加上本祝福五層後為 `500×(1+.20+.40)=800`。相較 600 增加 200，比例為 `200÷600=33.33%`；它們加在威力修正池中，不把 `1.20` 再乘 `1.40`。
- **玩家意義**：增加的是供傷害、衝擊等後續曲線使用的威力輸入；實際生命傷害仍由攻擊設定、目標護甲和後續計算決定。觸發擊殺的當次攻擊已結算，不會回溯使用新層。
