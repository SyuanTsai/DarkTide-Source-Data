# 能量循環(Power Cycler)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/05e48334-0184-4507-ba85-700d7d36844b" width="72" height="72" alt="能量循環祝福圖示">

- **觸發方式**：持用帶有能量循環的動力劍 斯干達 Mk III 或阿克利斯 Mk VI，啟用特殊充能後接續輕擊、重擊或合格的推擊後追擊。啟用與蓄力準備本身不造成命中。
- **效果與上限**：原生每次啟用可用一次充能揮擊；本祝福按目前有效連擊步增加可用次數。I／II 的有效步數上限為 1，III／IV 為 2，因此在連擊有效、每個傷害窗消耗一次且未提早關閉的情況下，合計最多 2／2／3／3 次充能揮擊。
- **近戰衝擊**：I／II／III／IV 每個有效步分別加入 2.5／5／7.5／10 個百分點的衝擊修正；III／IV 第二步合計為 15%／20%，再多步也不增加。這項加成影響衝擊，不增加傷害，也不保證最終踉蹌幅度同樣增加。
- **首次生效與連擊**：一般接續揮擊開始後，連擊步數才更新，祝福再隨效果資料更新讀取新步數；不可把動作開始時的舊步數當成此次必定取得的加成。接續斬擊增加連擊，蓄力準備保留連擊；動作結束後閒置超過 0.2 秒，連擊會重置。沒有有效步數時，本祝福增量為 0。
- **消耗與刷新**：充能狀態中的一個傷害窗命中至少一個敵人，或因攻擊中止結束，便消耗一次充能揮擊；同一窗命中多個敵人仍只計一次。沒有命中且沒有中止的傷害窗不計次數。命中存活目標及合格傷害窗結束會刷新充能期限；自最近啟用或刷新起滿 3 秒，或已消耗次數達到當前可用上限，充能關閉。
- **推擊與型號差異**：純推擊會清除連擊，且本身不受近戰衝擊加成；清除連擊也會降低當前可用次數，已消耗次數達到降低後的上限時，充能會在檢查時關閉。推擊後追擊是另一個斬擊，只有開始時充能仍有效才使用充能傷害配置。阿克利斯 Mk VI 另有右側特殊啟用接蓄力重斬的路徑。
- **再啟用與切換**：充能期間可再啟用以刷新期限，但啟用本身不清除已消耗的次數。切出此劍會關閉充能並清除該次計數，切回須重新啟用；衝刺、受暈與攀越本身保留充能，仍受期限與次數限制。
- **移除**：本祝福沒有獨立觸發冷卻或逐層獨立期限；它讀取武器目前的充能與連擊狀態。充能關閉、未持用此劍或移除祝福時，不再提供此增量。

## 計算與算例

- **前提**：IV 級，啟用後正常接續斬擊；每次傷害窗命中並消耗一次，效果資料已依序讀到有效步數 1、2、2，途中沒有推擊、閒置重置、切換或三秒逾時，其他衝擊修正均為中性。
- **代入與結果**：當前可用上限為原生一次加有效步數，即 `1+s`。三次揮擊的上限依序為 2、3、3，消耗後計數為 1、2、3；第三次達上限而關閉。合計三次充能揮擊，其中兩次是本祝福額外提供。
- **衝擊算例**：以原衝擊修正為 1.00、其他條件中性且乘區前衝擊輸入 100 為例，IV 級在步數 1、2、2 時修正為 `1+0.10×s`，輸入變為 110、120、120。這是進入後續踉蹌計算前的比較，不是最終踉蹌幅度或傷害的保證。
- **已有同類加成**：若已有同類 +20% 修正，原乘數是 1.20。IV 第一步為 `1.20+0.10=1.30`，第二步為 1.40；相對原 1.20 分別增加約 8.33%／16.67%，不是把 1.20 乘以 1.20 得到 1.44。
- **中斷算例**：若已消耗一次，純推擊讓有效步數回到 0，當前上限降為 `1+0=1`。下一次充能檢查讀到該狀態便會關閉，不能把未用完的連擊額度當成保留次數；未命中的揮擊也仍受三秒刷新期限限制。
