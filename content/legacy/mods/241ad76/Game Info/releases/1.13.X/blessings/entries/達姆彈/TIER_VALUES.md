# 達姆彈：等級數值

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

步兵自動槍、偵察鐳射槍與重型鐳射手槍：

| 等級 | 每層近距離傷害 | 五層完整加成 |
|---|---|---|
| I | +4.5% | +22.5% |
| II | +5% | +25% |
| III | +5.5% | +27.5% |
| IV | +6% | +30% |

有效層共同期限2秒，上限5；距離衰減不影響命中計數。
