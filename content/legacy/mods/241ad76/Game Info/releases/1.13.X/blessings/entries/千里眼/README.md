# 千里眼(Telescopic Sight)

<img src="https://github.com/user-attachments/assets/4dbeb712-e6a5-4bd9-8798-a5e3a93cd4ea" width="72" height="72" alt="千里眼祝福圖示">

- **適用型號**：步兵鐳射槍 卡特雷爾 Mk VII、Mk IIb、Mk IX；這三款是已確認的實際綁定型號。

- **觸發方式**：持用其中一款並進入瞄準狀態時，祝福條件成立；單純腰射與腰射時切換手電筒不會進入瞄準。放開瞄準或切出武器後，條件會退出。

- **階級效果**：I、II、III、IV 級的視角乘數都為 0.85，沒有階級數值差異。這是垂直視角角度乘數，不是「增加 85% 放大倍率」。

- **瞄準與特殊動作**：三款的瞄準射擊仍使用瞄準狀態；瞄準時切換手電筒可留在瞄準路徑。腰射時切換手電筒本身只切換特殊功能，不會開啟瞄準。

- **退出與切換**：放開瞄準或切換武器會結束替代瞄準狀態。切回後需重新瞄準；效果依一般角色屬性與相機更新恢復，未主張同一影格立即更新。

- **視角說明**：三款瞄準相機的輸入垂直視角都是 45°。瞄準相機會取用前後兩次的視角乘數，因此逐影格畫面還受平滑取樣、鏡頭轉場及玩家視角設定影響。

- **首次生效與持續**：不需射擊或命中；持用並瞄準的條件成立後，角色屬性快取與鏡頭平滑更新才反映加成。本項沒有命中疊層、獨立倒數或刷新窗口；持續瞄準便維持條件，重複射擊不提高數值。退出瞄準後同樣經狀態與相機更新退出，沒有另一段保留加成的倒數。

## 計算與算例

以下是固定條件的數學示例，不是遊戲畫面或實測。假設使用已核對型號、第一人稱一般瞄準、鏡頭轉場已完成、沒有其他視角修正、外部與玩家全域視角乘數皆為 1，且前一次與目前取樣的祝福乘數都代入 0.85。

- **代入**：垂直視角 = 45° × 0.85（前次取樣）× 0.85（目前取樣）× 1 × 1。
- **結果**：45° × 0.7225 = **32.5125°**；同條件下不套用本項乘數時為 45°。
- **玩家意義**：受控條件下垂直視角較窄，瞄準畫面構圖更緊；27.75% 是視角角度差值比例，不等同螢幕放大倍率。

實際逐影格數值會隨前後乘數樣本與相機轉場改變；玩家全域視角設定也會另行作用，所以算例不保證任一實機影格正好顯示 32.5125°。
