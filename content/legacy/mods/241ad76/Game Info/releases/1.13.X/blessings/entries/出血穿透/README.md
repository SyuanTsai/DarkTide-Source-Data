# 出血穿透(Puncture)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/0fbf88fb-7c0c-4b57-ac56-9687c1e5198d" width="72" height="72" alt="出血穿透祝福圖示">

- **觸發方式**：持用帶有此祝福的矛頭爆矢槍或爆彈手槍，射擊直接命中敵人並造成傷害，對仍存活的敵人施加流血。

- **等級效果**：I–IV每次符合條件的命中新增1／2／3／4層；兩種武器的數值相同。

- **命中條件**：不要求暴擊、弱點、擊殺、連續射擊或穿透掩體／敵人。只命中而未造成傷害的目標不獲得層數。

- **射擊模式**：一般射擊與瞄準射擊的直接命中都能觸發；每次符合條件的命中各自新增層數。

- **爆炸與近戰**：爆彈子爆炸不會另外施加本祝福的流血；近戰推擊也不觸發。

- **多目標**：射擊若直接對多名敵人各造成傷害，各名符合條件且存活的目標各獲得層數，不限第一名敵人。

- **層數上限**：同一敵人最多16層流血，相同流血效果共用層數。

- **跳傷與消退**：流血每約0.5秒跳傷；最後一次施加或刷新後約1.5秒開始退層。此後每次先按目前層數跳傷，再移除1層。

- **再次施加**：新增層數與滿層再次觸發都刷新等待退層的期限，並保留原跳傷節奏。

- **切換武器**：已施加的流血繼續存在；新的觸發要求處理命中事件時仍持用帶有祝福的武器。

- **傷害成長**：跳傷依流血層數曲線、護甲與其他傷害修正計算；每層不是固定扣血或生命百分比。

## 計算與算例

- **IV級直接命中**：一般射擊命中一名存活敵人並造成傷害，新增4層流血；暴擊時同樣新增4層。

- **爆炸傷害**：射擊直接命中的目標可新增層數；僅被同發爆彈爆炸波及的旁邊敵人不會因子爆炸新增。

- **疊到上限**：退層前連續4次IV級觸發，層數依序0→4→8→12→16；第5次維持16層並刷新期限。

- **停止施加**：最後刷新時有8層或16層，名義上分別約5–5.5秒或9–9.5秒退完，範圍依原跳傷節奏而定，另加固定更新延遲。

## 遊戲描述勘誤

- 本體「遠程攻擊命中」補明為直接命中且造成傷害；爆彈子爆炸另按爆炸類型判定，不觸發本祝福。

- 名稱中的「穿透」並非觸發要求。

- 流血1.5秒後開始逐層消退，不會在該時點一次清空。
