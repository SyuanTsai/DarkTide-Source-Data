# 大口徑彈藥(Man-Stopper)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/019dc966-034d-47aa-8564-a4308bb0bca8" width="72" height="72" alt="大口徑彈藥祝福圖示">

- **觸發方式**：持用帶有「大口徑彈藥」的武器即可獲得遠程踉蹌加成；攻擊暴擊時，另外獲得順劈效果。

- **等級效果**：I、II、III、IV級分別使遠程攻擊的踉蹌威力提高10%、15%、20%、25%。這項加成不需要暴擊。

- **暴擊順劈**：使用順劈計算的暴擊攻擊不受一般攻擊側順劈上限限制；暴擊只改變順劈攻擊側上限，不代表攻擊能穿過所有敵人、裝甲或場景物件。

- **霰彈命中**：霰彈的每顆彈丸有自己的順劈預算；同一發射擊的彈丸共用該次射擊的暴擊狀態。特殊彈仍沿用彈丸攻擊路徑；彈種與彈丸數依型號及射擊模式而異。

- **戰鬥霰彈槍特殊彈**：紮羅娜 Mk VI特殊彈為13顆彈丸；阿格里皮娜 Mk VII為單顆獨頭彈，另有自己的物件穿透設定；奧克塔蘭 Mk IX的特殊彈與瞄準特殊彈皆為18顆彈丸。

- **雙管霰彈槍模式**：十字星 Mk XI在瞄準射擊時可用32顆特殊彈丸；克魯克 Mk IV在腰射時切換單／雙管彈種，瞄準時使用單管彈種。兩者符合暴擊時，仍依同一彈丸路徑計算順劈。

- **磷光爆炸**：磷光爆破手槍的直接子彈命中可使用遠程攻擊與暴擊順劈計算；命中後觸發的範圍爆炸是另一種攻擊，不沿用子彈的順劈路徑，也不取得遠程踉蹌加成。

- **近戰特攻**：電能步槍刺擊、磷光爆破手槍槍托揮擊及衝覆者盾牌重擊走揮擊式近戰路徑，若暴擊可套用暴擊順劈效果；盾牌輕推走推擠路徑，不使用此順劈質量計算。遠程踉蹌加成不作用於近戰攻擊。

- **生效界線**：祝福不會取消攻擊自身的停止條件，也不會把物件穿透深度、敵人裝甲判定或範圍爆炸改成無限穿透。

- **切換武器**：切出此武器後，遠程衝擊與暴擊順劈效果都會暫停；切回持用時恢復，不需要先擊殺或累積層數。

## 計算與算例

- **踉蹌威力算例前提**：假設某次遠程攻擊在套用此祝福前的踉蹌威力輸入為300，且沒有其他影響踉蹌的修正。

- **踉蹌威力算例結果**：I級在後續百分比換算前將該輸入提高至330；IV級提高至375。這是踉蹌計算中的中間威力輸入，不等同於最終踉蹌距離、時間或生命傷害增加10%／25%。

- **暴擊順劈算例前提**：持用此武器，並用會執行順劈質量檢查的攻擊造成暴擊。

- **暴擊順劈算例結果**：順劈計算的攻擊側質量上限改為無限；衝擊側質量預算仍依攻擊設定計算。物件碰撞、物件穿透設定及可中止攻擊的裝甲規則仍會限制實際命中路徑。

- **散彈算例前提**：一發散彈包含多顆彈丸，且該次射擊為暴擊。

- **散彈算例結果**：每顆彈丸分別建立自己的命中質量預算，但使用同一射擊的暴擊狀態；因此不能把一次暴擊說成全場景穿透，也不能把一顆彈丸的預算當成整發共用預算。

- **其他衝擊加成**：假設同一結算階段原有+20%修正，再加IV級+25%，合計倍率為1.45；基礎踉蹌威力輸入300會變成435。相對原有360，增加 `(435−360) ÷ 360 ≈ 20.83%`；這仍是中間威力輸入，並非最終踉蹌時間或傷害比例。
