# 超級充能(Supercharge)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/73b6c65e-a09c-4c98-9002-22e0c8cfd0c1" width="72" height="72" alt="超級充能祝福圖示">

- **觸發方式**：持用帶有超級充能的武器，以充能近戰攻擊命中仍存活的敵人，讓目標疊加脆弱。

- **動力劍等級效果**：一般動力劍與機械神教動力劍的I–IV，每次合格命中增加1、2、3、4層。

- **動力錘等級效果**：動力錘的I–IV，每次合格命中增加10、12、14、16層。

- **每層效果**：每層提供2.5%脆弱；動力劍單次增加2.5%／5%／7.5%／10%，動力錘單次增加25%／30%／35%／40%。

- **層數上限**：同一敵人最多16層，也就是40%脆弱；不是每把武器或每位玩家各有16層。

- **持續與刷新**：脆弱維持5秒；合格命中刷新全部現有層數的倒數，滿層後再次命中也刷新。

- **計數單位**：每個符合條件的敵人命中事件分別施加層數；不要求暴擊、弱點、擊殺或只打第一個目標。

- **動力錘爆炸**：充能打擊的直接近戰命中可施加脆弱，周圍爆炸不會額外施加本祝福的脆弱。

- **生效時機**：觸發的那一擊先完成傷害結算，再施加脆弱；新層數不回溯增加同一擊傷害，效果生效後的後續攻擊才受益。

- **隊友與切換**：脆弱留在敵人身上，隊友和其他武器的攻擊也能受益；切出原武器不會清掉已施加的層數。

- **停止與移除**：切出武器後不再提供新的合格充能命中；5秒內沒有再次施加或刷新時，整組脆弱到期消失。

- **傷害意義**：脆弱改善裝甲結算，並非固定增加相同百分比的最終傷害；無護甲傷害分類不從這筆脆弱提高傷害。

## 計算與算例

- **層數算例前提**：敵人原本沒有脆弱，IV級動力劍連續合格命中，各次脆弱已生效且中途未到期。

- **層數算例結果**：依序4、8、12、16層，脆弱為10%、20%、30%、40%；之後保持16層並刷新5秒。IV級動力錘一個合格命中就能施加16層。

- **傷害算例前提**：裝甲前傷害100、原裝甲倍率10%，該傷害分類適用脆弱；只比較裝甲結算階段，沒有其他撕裂或脆弱。

- **傷害算例結果**：10%脆弱生效後該階段傷害由10到20；滿層40%時由10到50。觸發首擊仍按原本狀態計算，不能把首擊寫成50傷害。

- **溢出算例前提**：同樣裝甲前傷害100，原裝甲倍率90%，敵人已有滿層40%脆弱。

- **溢出算例結果**：先補10個百分點到100%，餘下30個百分點以四分之一效率計入，該階段倍率107.5%，傷害107.5；後續弱點、部位和減傷仍另算。

## 遊戲描述勘誤

- **本體未列武器差異**：動力劍與動力錘每次給的層數不同，需依適用武器讀取。

- **本體未列層數與期限細節**：每層2.5%、上限16層、合格命中刷新5秒。

- **本體未區分動力錘爆炸**：本祝福只由帶有充能特殊旗標的命中新增層數，周圍爆炸不新增。
