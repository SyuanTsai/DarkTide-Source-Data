# 亞空間樞紐(Warp Nexus)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/7b314280-0bfe-4a53-8bf5-a278d868bfb7" width="72" height="72" alt="亞空間樞紐祝福圖示">

- **觸發方式**：裝備並手持本祝福支援的力場法杖時，祝福依屬性重算時讀取的原始反噬比例啟用；每完整 20% 反噬增加一階，最多四階。未滿首個完整 20% 門檻時增量為 0；實際攻擊檢查使用最近一次屬性重算更新的快取。毋須命中、擊殺或其他獨立觸發事件。
- **增益如何累加**：I–IV 每階分別增加 3.5、4、4.5、5 個百分點的致命一擊機率；四階上限依序為 14、16、18、20 個百分點。這是加到致命一擊機率的增量，不是最終機率，也不是傷害百分比。
- **適用行動**：支援武器實際會進行致命一擊檢查的射擊、蓄力攻擊及特殊近戰掃擊。各型號的投射物、火焰與連鎖路徑不同；連鎖攻擊沿用該次動作的致命一擊結果，不會每跳額外觸發本祝福。
- **換槽與刷新**：效果只在該力場法杖處於手持武器槽時納入屬性。玩家固定更新會刷新祝福屬性；換出後會在重算時停用，換回後依當時原始反噬比例重新計算，不保存先前階數。已完成致命一擊檢查的攻擊不會回溯改判。
- **不會觸發的動作**：純推擊、排放反噬或切換武器本身不會進行本祝福的致命一擊檢查，也不會建立獨立層數、計時或冷卻；這些動作改變反噬後，會由後續屬性重算反映在增益中。

## 計算與算例

- **前提**：選擇 III 級力場法杖；攻擊開始進行致命一擊檢查時，原始反噬比例為 73%；指定的原始反噬比例已完成屬性快取更新，該次致命一擊檢查讀取此快取；不計其他致命一擊修正。
- **代入**：`min(4, floor(0.73 / 0.20)) = 3` 階；每階 `0.045`。
- **結果**：`3 × 0.045 = 0.135`，即增加 13.5 個百分點；卡面四階上限為 18%。
- **玩家意義**：這只代表祝福提供的致命一擊機率增量；實際總機率仍與職業基礎值、其他屬性及武器修正相加並受上限限制。

- **前提**：選擇 II 級力場法杖；原始反噬比例剛好為 80%；指定的原始反噬比例已完成屬性快取更新，該次致命一擊檢查讀取此快取；不計其他致命一擊修正。
- **代入**：`min(4, floor(0.80 / 0.20)) = 4` 階；每階 `0.04`。
- **結果**：`4 × 0.04 = 0.16`，即增加 16 個百分點；卡面四階上限為 16%。
- **玩家意義**：階數按原始比例的完整 20% 門檻計算，不按畫面四捨五入後的反噬數字猜測。
