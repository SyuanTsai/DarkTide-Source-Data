# 優勢（通用力量）(Superiority)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ad66f531-3350-4401-84f3-5c5d7b4cd4c9" width="72" height="72" alt="優勢（通用力量）祝福圖示">

- **觸發方式**：自己的攻擊產生「擊殺」事件、目標帶有精英或專家標籤其中之一，且觸發當刻正持用此祝福所在的武器槽時，增加一層力量修正。只命中、未擊殺，或目標兩種標籤都沒有時不觸發。程式檢查祝福武器槽是否持用，不另比對擊殺事件記錄的來源武器是否同一件。
- **每層效果**：I–IV 每層分別增加 +5、+7.5、+10、+12.5 個百分點的通用力量修正；力量輸入會影響後續攻擊、衝擊與順劈各自的結算，不代表生命值傷害直接同比增加。
- **層數上限**：最多三層有效加成。內部保留一個佔位層，不提供力量；效果啟用期間仍可再觸發，未滿時加一層，已滿時不再增加有效層。
- **持續與衰退**：每次新增一層會重設共同的七秒衰退計時；達到三層後再次合格擊殺雖不增加有效層，仍會刷新計時。沒有新觸發時，每超過一個七秒間隔移除一層，直至歸零。
- **生效時點**：擊殺事件在該次攻擊結算後處理，力量快取隨後更新；新層不會回頭加在已完成擊殺的攻擊上，下一次使用更新後力量快取的攻擊才受益。
- **切換與移除**：換持其他武器時，效果與新觸發會因持用槽條件暫停，但七秒計時仍繼續；在層數衰退前切回，可使用尚存層數。從裝備配置移除此祝福時，父 Buff 會清除它管理的子層。
- **攻擊模式與追加命中**：撬棍普通左右起手透過 BASE_ACTIONS aliases 接 light/heavy，另有 left_2/right_2 windup chain 接 light_3/light_4 與 heavy_1/heavy_2。特殊鍵只切換 toggle_special；特殊與 from-activate 攻擊仍按各自 profile 造成命中，特殊黏附追加命中另經 Attack.execute 以 melee 類型和原武器執行。Crowbar 黏附後若閃避離開，追加的 sticky_dodge_push 為 attack=0、impact 非零；它能產生衝擊／擊退，但不造成 HP 傷害，也不能自行形成擊殺觸發。Force Sword 朦朧 Mk II 與戴莫斯 Mk IV 在特殊啟用掃擊符合黏附條件並中止時，會附著 light/heavy sticky settings，追加攻擊以 melee Attack.execute 和 Force Sword 原武器 item 執行；這些實際傷害命中若造成合格擊殺，可觸發本項。伊利斯 Mk V 的特殊啟用走 active-cleave profiles，這裡的 M1/M2 黏附追加路徑不套用。
- **推擊與甩擊的力量範圍**：純 push profile 的 attack=0、impact 非零，力量可影響衝擊／擊退，不等於一般生命值傷害；撬棍 pushfollow 是 light_crowbar_tank melee sweep，可能在擊殺時觸發。Force Sword pushfollow fling 雖然三 Mark 的 damage_type 傷害類型依序為 warp／physical／physical，ActionDamageTarget 實際以 attack_type=ranged 執行；本祝福的 global power 也適用於它。
- **已有效層的攻擊效果**：global power 修正會進入近戰、遠程與 push 類型共用的力量倍率；Force Sword 朦朧 Mk II／戴莫斯 Mk IV 特殊啟用後的黏附追加命中經 Attack.execute 以 melee 類型和原武器 item 執行，因此在祝福槽持用、力量 conditional 有效時也使用此修正。力量之後分別進入傷害、衝擊與順劈曲線；純推擊 profile 的 attack=0，因此不能把衝擊提高寫成普通 HP 傷害增加。

## 計算與算例

### 算例一：IV 級三層

- **前提**：原生武器力量曲線換算後、套用力量修正前的力量為 500；其他當次適用力量修正總和為中性（q=0）；IV 級已累積三層。
- **代入**：每層 p=0.125，n=3；`S_after = 500 × (1 + 0 + 3 × 0.125)`。
- **結果**：`S_after = 687.5`，相對 500 增加 37.5%。
- **玩家意義**：三層把後續力量輸入提高 37.5%；這不保證最終生命值傷害、衝擊或順劈都提高 37.5%。

### 算例二：II 級一層且其他修正為 +20%

- **前提**：S_native=500；其餘當次適用力量修正合計 q=0.20；II 級一層 p=0.075。
- **代入**：未加本祝福時 `500 × (1 + 0.20)=600`；加一層後 `500 × (1 + 0.20 + 0.075)`。
- **結果**：力量輸入為 637.5；增加 37.5 點，對原本 600 的力量輸入相對增加 6.25%，倍率本身增加 7.5 個百分點。
- **玩家意義**：百分點是相對基準倍率的直接加數；有其他加成時，相對於已加成結果的百分比會較小。
