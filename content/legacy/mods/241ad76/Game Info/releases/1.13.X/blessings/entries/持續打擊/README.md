# 持續打擊(Relentless Strikes)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/b7eea9d3-8f5f-4ead-bc52-651a5a42f7e3" width="72" height="72" alt="持續打擊祝福圖示">

- **觸發方式**：手持已裝上本祝福的武器，對目標造成會送出命中事件的武器命中。第一個合格命中先記下目標，尚不加層；其後再命中同一目標才在該次傷害結算後增加一層。四種實作的父增益都檢查手持武器與來源物品，但沒有近戰攻擊類型檢查。
- **實際型號（8 Mark）**：戰術斧 埃托克斯 Mk II、Mk IV、Mk VII；決鬥劍 馬卡比安 Mk II、Mk IV、Mk V；法務官電擊鎚 布蘭克斯 Mk III；骨鋸 外科醫師 型號4。
- **每層威力**：I、II、III、IV 級每個有效層分別增加 4%、6%、8%、10% 近戰威力修正，最多五層，合計最多增加 20%、30%、40%、50% 的近戰威力修正。這是中間威力計算的修正，不是保證等比例增加最終傷害。
- **目標與計數**：第一個命中不同目標的事件會改記新目標並清除舊層，但不刷新既有兩秒期限；同一目標後續命中才累積並刷新。每次同目標命中增加一層計數，達五層後不再增加，但仍會重新計時。攻擊傷害先結算，事件與屬性快取更新後才可讓後續攻擊使用新層。
- **期限**：有效層共用兩秒期限；同目標合格命中會刷新全層期限，即使已滿五層也會刷新。新目標的第一個命中用來重設追蹤，不延續舊目標層數。沒有命中時期限到期，父增益更新會移除子層。
- **適用攻擊**：戰術斧與決鬥劍的普通、重擊、推後連擊及特殊掃掠，以及電擊鎚的普通、重擊、推後連擊與特殊掃掠，都是各自武器物品發出的近戰命中。推擊也可能送出帶有該武器物品的命中事件，並可更新同目標追蹤；但推擊攻擊類型不消費近戰威力修正，因此推擊本身不因本祝福增加近戰威力。
- **特殊武器差異**：電擊鎚的特殊掃掠是直接近戰命中；命中另外可能依目標是否已觸電而套用不同暈眩效果，本項沒有接入爆炸。骨鋸的黏附重擊初次命中可照一般近戰命中判定；延遲撕裂仍使用近戰威力計算，但其兩種實際撕裂 profile 都略過命中觸發，不會增加層數或刷新期限。骨鋸特殊鍵是塗層切換，不是命中。
- **切換與移除**：切到其他武器時，原武器已存在的層與倒數可繼續保留，但手持條件不成立，近戰攻擊不取得這份加成，也不能用其他武器的命中累積它；期限內切回才可使用剩餘層。卸下武器或移除此祝福會移除其父增益與子層。
- **不適用邊界**：投射物、投擲或爆炸不在這八個實際綁定 Mark 的動作表內；不把其他家族電擊鎚的爆炸路徑套用到 Branx Mk III。格擋、蓄力／連擊起手、骨鋸塗層切換和換槽本身不造成命中，不會單獨加層或刷新。

## 計算與算例

- **範例一：戰術斧埃托克斯 Mk II 的第二次同目標命中**
  - **前提**：使用 Atrox Mk II 的 `action_left_down_light`，實際 profile 為 `default_light_hatchet_smiter`；假設第一個命中已把目標 A 設為追蹤目標且沒有有效層。為解釋中間威力而將曲線後、其他修正合併前的近戰威力正規化為 100，令其他威力修正合併因子為 1，選 II 級。
  - **代入**：第二個同目標命中先按目前威力結算；命中事件處理後建立一層，II 級每層為 6%，所以後續同目標近戰攻擊使用 `100 × (1 + 0.06)`。
  - **結果**：後續攻擊的中間近戰威力為 106，比 100 多 6 個正規化威力單位，也就是本祝福增加 6 個百分點的威力修正；這不等於最終生命傷害必然增加 6%。
  - **玩家意義**：第一下只是選定追蹤目標，第二下才建立第一層；新增層不回頭改變觸發它的那一下。

- **範例二：骨鋸 Mk IV 五層下的延遲撕裂**
  - **前提**：使用外科醫師型號4，在同一目標上已建立五個有效層並選 IV 級；手持條件仍成立、層數尚未到期。把套用曲線後、其他修正合併前的近戰威力正規化為 100，令其他修正合併因子為 1。
  - **代入**：五層 × 每層 10% = 本祝福總計 50% 近戰威力修正；後續近戰命中與延遲撕裂所用攻擊類型均為 melee，威力因子為 `1 + 5 × 0.10`。撕裂 profile 的 `skip_on_hit_proc=true` 只阻止命中觸發，不會把它改成非近戰攻擊。
  - **結果**：該撕裂攻擊讀取的中間近戰威力為 `100 × 1.50 = 150`；相對此正規化輸入增加 50%，但實際傷害仍取決於撕裂 profile、目標與其他傷害修正。撕裂本身不加層，也不刷新兩秒期限。
  - **玩家意義**：骨鋸的特殊重擊初次黏附命中可按一般條件觸發；稍後的撕裂可以使用仍有效的威力加成，卻不會再次觸發或延長它。
