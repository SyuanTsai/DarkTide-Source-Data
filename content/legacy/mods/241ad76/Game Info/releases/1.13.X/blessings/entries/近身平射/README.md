# 近身平射(Point Blank)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/1f0e089c-39ab-4e22-952e-fedd5e91f0d9" width="72" height="72" alt="近身平射祝福圖示">

- **觸發方式**：以近戰攻擊擊殺敵人即可啟動；不要求在近距離，也不要求由附有此祝福的手槍完成擊殺。

- **等級效果**：I、II、III、IV級分別使遠程爆擊率提高14、16、18、20個百分點。爆彈手槍與針彈手槍持續3.5秒；快拔左輪手槍持續2.5秒。

- **切換與射擊**：近戰擊殺後可以切回附有此祝福的手槍；切換不會取消計時，期間射擊也不會消耗效果。

- **重複觸發**：效果尚未結束時再次以近戰攻擊擊殺，會從新一次擊殺重新計時，不會疊加多層。

- **期限、疊層與冷卻**：期限結束後失效；沒有額外觸發冷卻或疊層。再次合格擊殺重設期限，並非把完整持續時間加到剩餘時間上。

- **特殊動作**：爆彈手槍的近戰推撞與左輪鞭打造成擊殺時可以觸發。針彈模式切換不攻擊；針頭、化學爆炸與毒素擊殺的攻擊類型都不是近戰，不能單獨觸發。

- **適用的攻擊**：提升的是遠程爆擊率，近戰爆擊率不提高；普通與瞄準射擊都會讀取生效中的遠程加成。

- **爆彈手槍爆炸**：效果有效時，爆彈手槍的直接射擊可受遠程爆擊率加成；另行生成的擊殺／停止與穿透停止爆炸固定為非爆擊。

## 計算與算例

- **機率算例前提**：假設武器原有基礎與其他遠程爆擊率加成合計為20%，沒有爆擊率轉傷害的修正，且加總後未超過上限。

- **機率算例結果**：I級合計為34%，II級36%，III級38%，IV級40%；此祝福分別增加14、16、18、20個百分點。

- **既有加成與上限**：若其他加成合計為92%，IV級再加20個百分點後會由112%封頂為100%。

- **計時算例**：爆彈手槍或針彈手槍在t=0近戰擊殺後，效果到t=3.5秒；若t=2秒再次近戰擊殺，計時更新為t=5.5秒。快拔左輪手槍同樣重新起算，但每次持續2.5秒。

- **切換算例**：t=0用另一把近戰武器擊殺後切到受祝福手槍，符合等級效果的時間窗內遠程攻擊會讀取此爆擊率加成；手槍射擊不會扣除時間窗。

- **零層與首次受益**：觸發前沒有此加成；首次合格近戰擊殺即提供該級完整加成，不須累積多次擊殺。IV 在20%原有機率的前提下成為40%，增加20個百分點，相對機率增加(40−20)÷20=100%。

- **射擊、中斷與期限**：爆彈手槍在0秒觸發，1秒切回並射擊後仍以3.5秒為期限；3.5秒結束後回到原有機率。4秒再次近戰擊殺則重新生效至7.5秒。
