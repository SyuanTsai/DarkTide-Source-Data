# 斷肢者：百分比與結算

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

令 `B` 為武器 power-type 曲線完成後、套用本項 melee modifier 前的威力輸入，`q` 為同一階段其他 additive melee-power modifiers 的合計，`p` 為本項在目前持用與最新統計快取中實際提供的 tier 值。當本項快取選中加成組時，近戰威力輸入為 `P = B × (1 + q + p)`；未持用或目前快取選中等待期組時 `p=0`。`p` 不要求該攻擊本身通過本項來源物品／on_hit 條件；那些條件只決定命中事件是否在傷害結算後重設等待。六家族 `p=.60`，碎骨者各級 `p=.175/.20/.225/.25`。這仍是威力階段輸入，不是最終生命傷害百分比；後續 profile、護甲、力場等計算仍生效。

固定 Release 1.13.1 RAW 的 first attack／Strength 核心與威力值、格式相符；RAW 未涵蓋持用條件、初始截止為 0 時首個快取即可提供加成、來源物品與 melee on_hit gate、事件在傷害後才重設等待、切換和真正卸下的差別。事件 gate 不應誤寫成 p 的消費 gate。骨鋸延遲撕裂不另觸發或刷新，但仍可能讀取結算時當前的近戰威力快取。百分比描述的是 melee power modifier，不是固定最終生命傷害比例。
