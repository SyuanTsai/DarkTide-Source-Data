## 執行與計算

- 六個 trait 自己定義 I–IV：戰刃、決鬥劍、力場巨劍、力場劍原始 finesse_modifier_bonus 為.45/.50/.55/.60；短刀與穿音速雙刀為.30/.35/.40/.45。六份 own tier 都覆寫 active_duration=2。
- 六個 wrapper 各自 clone dodge_grants_finesse_bonus base。Base 的 .05／5秒為 fallback；完整 rarity override 取代 fallback，不相加。
- Base ProcBuff 監聽 on_successful_dodge；只接受成功事件。觸發與 active stat 均受 is_item_slot_wielded 條件控制；切換不暫停計時。期間重觸發刷新單一 timed buff，不疊層。
- Damage calculation 僅在 is_critical_strike 或 hit_weakspot 時呼叫 Finesse helper。helper 將通用 finesse_modifier_bonus 加進 Finesse-stage multiplier，得到完整 Finesse component；外層把該 component 加回 hit。
- finesse_modifier_bonus 在 buff_settings 為 additive_multiplier，基線1；其他同 stat 的 active raw 值會加算。普通、特殊、投射物或風刃沒有新的 melee/ranged stat gate，但每個 hit 必須進入 crit/weakspot Finesse branch，且使用的增益數值有效；投刀讀生成時保留的快照，風刃與一般命中讀當下增益。

- 令 B 為靈巧結算前的主傷害部分、F0 為暴擊或弱點所選出的基礎靈巧額外傷害、p 為本祝福階級值。四家族 p=.45/.50/.55/.60；短刀與穿音速雙刀 p=.30/.35/.40/.45。
- 假設其他靈巧階段加成為0，靈巧部分為 F0×(1+p)，這次命中的階段值為 B+F0×(1+p)。本祝福新增傷害為 p×F0，整次命中的相對增幅為 p×F0÷(B+F0)。
- 若既有同階段加成為 q，啟動前 B+F0×(1+q)，啟動後 B+F0×(1+q+p)；本祝福仍新增 p×F0，整次命中的相對增幅為 p×F0÷[B+F0×(1+q)]。此加算也包含同一靈巧結算階段的其他倍率增量。
- 暴擊與弱點同時成立時，依傷害設定選出一份合併的 F0，再乘上上述倍率；不分別重複加成本祝福。未暴擊且未命中弱點時，不進入這個結算分支。
- 主傷害 B 本身不乘以1+p。之後的背刺、側擊、命中部位、傷害隨時間、護甲及遞減等仍依來源順序結算；上述算例將未列出的後續修正取中性值。
