# 虹吸(Syphon)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/167e264e-36c8-4869-bf55-23dc1b42e6d7" width="72" height="72" alt="虹吸祝福圖示">

- **適用型號**：上古神刃 軍務部 Mk X與 Mk II；兩者共用 I–IV 效果。

- **觸發方式**：武器特殊能力須在近戰橫掃開始時啟用；同一次橫掃中，當合格近戰命中的目標序號達到第 3 個或之後時，嘗試恢復韌性。同一單位在該次橫掃只計一次。這個序號不是先前累積三個合格命中事件，也不等於「造成正傷的三個敵人」；該次命中仍須符合程式的觸發條件，格擋或零傷也可能計入。

- **恢復量**：I／II／III／IV 級分別請求最大韌性的 10%／12%／14%／16%。這是最大韌性的固定比例，不是目前缺額的百分比；實際恢復量最多到目前缺額。

- **一次橫掃限制**：第一個當前目標序號達到門檻的合格事件會先消耗該橫掃的觸發資格，再嘗試恢復；即使韌性已滿或恢復狀態門檻拒絕本次恢復，同一橫掃也不會重試。之後新的橫掃可重新判斷，無須先累積祝福層數。

- **特殊能力與動作**：一般輕擊、重擊、衝刺橫掃及推擊後的橫掃，在特殊能力啟用時可符合；推擊本身不是近戰橫掃，也不符合近戰命中條件。按下特殊攻擊鍵切換能力本身不恢復韌性。

- **首次與切換**：不需預先疊加或等待。第一次符合條件的橫掃即可觸發；事件處理時也須仍持有該武器槽。若橫掃開始時特殊能力未啟用，之後才開啟不會使該次橫掃補上資格。

- **例外**：該次橫掃沒有任何合格近戰命中事件的目標序號達到 3、推空、一般推擊或無法送出合格命中事件時，不會觸發；已滿韌性、死亡或其他禁止韌性恢復狀態時，則沒有實際恢復。倒地也受韌性恢復狀態門檻限制；這類拒絕不會讓同一橫掃重新嘗試。觸發不要求爆擊、正傷、踉蹌或擊殺。

- **資格期限**：本項沒有可累積的祝福層數或獨立倒數；資格只保留在本次橫掃，符合門檻即消耗，橫掃結束也會清除。下一次橫掃重新檢查特殊能力狀態。

## 計算與算例

- **前提**：假設最大韌性為 100、目前韌性為 60，因此缺額為 40；在特殊能力啟用的橫掃中，某個符合條件的近戰命中，其目標序號是第 3 個。

- **代入**：IV 級請求量 = 100 × 0.16 = 16。實際恢復 = min（缺額 40，請求量 16）= 16；目前韌性由 60 升至 76。「第 3 個」是這次命中的目標序號；前兩個序號不必各自曾觸發祝福。

- **接近滿韌性時**：仍假設最大韌性為 100，但目前為 96，缺額只有 4。IV 級雖請求 100 × 0.16 = 16，實際恢復為 min（4，16）= 4，韌性到 100 即封頂。

- **玩家意義**：等級百分比以最大韌性為基數，恢復會受缺額限制；若已滿韌性，該次實際恢復為 0。
