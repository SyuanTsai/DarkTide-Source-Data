# 電靈超載(Voltagheist Overload)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/493a9f0e-5e68-4416-bbf3-d99bdfc85b1b" width="72" height="72" alt="電靈超載祝福圖示">

- **觸發方式**：持用帶有電靈超載的武器，電弧命中仍存活且符合條件的敵人時判定處決。

- **等級效果**：I–IV每次判定的處決機率為5%、7.5%、10%、12.5%。

- **有效攻擊**：只計電弧命中；普通鎚擊、推擊或電擊狀態本身不算一次處決判定。

- **每個目標**：同一道電弧連到數名合格敵人時，各自判定；不是整次揮擊只抽一次，也不是一人成功便處決整條電弧。

- **排除敵人**：歐格林、魔物與首領不會被本祝福處決；判定不要求精英或特感，也不要求暴擊、弱點或敵人殘血。

- **存活條件**：判定時已死亡的敵人不再抽處決；原本電弧傷害直接殺死的敵人不需要再由本祝福處決。

- **處決效果**：成功時另外結算一次致死攻擊，並非提高這次電弧的傷害百分比；無敵狀態仍能阻止傷害。

- **持續與層數**：沒有疊層、效果倒數或觸發冷卻；一次失敗不會增加下一次的機率。

- **切換武器**：切出後不再判定新的處決；已完成的處決不會因切換而撤回。

- **其他效果**：處決不會全面停發通用事件：命中事件依一般命中條件產生，擊殺事件需要目標死亡，傷害事件需要傷害量大於0；其他效果仍須符合自身條件。這次處決未附帶原武器項目，要求同一武器命中的效果不會由它觸發。

## 計算與算例

- **單次判定前提**：IV級，敵人仍存活且不在排除類型，收到一次符合條件的電弧命中。

- **單次判定結果**：處決機率12.5%；失敗機率87.5%。連續失敗後仍維持12.5%，沒有保底。

- **多目標前提**：IV級，四個合格且仍存活的目標各收到一次電弧命中，把四次判定視為獨立抽樣。

- **多目標結果**：至少一次成功的機率為`1－0.875⁴≒41.38%`；不能把四次12.5%直接相加成50%。

- **期望值前提**：IV級，總共八次合格判定，目標在各次判定時都仍存活。

- **期望值結果**：期望處決數為`8×0.125＝1`，但並非第八次必定處決；八次全失敗仍有`0.875⁸≒34.36%`機率。

- **排除前提**：同樣的電弧命中一名歐格林、魔物或首領。

- **排除結果**：沒有本祝福的處決判定；原本電弧傷害仍按武器規則結算。

## 遊戲描述勘誤

- **本體繁中未翻譯**：名稱與描述仍為英文；本頁使用文件譯名「電靈超載」，並在原文比較保留本體名稱與描述。

- **本體只寫人類體型**：實際依敵人類型排除歐格林、魔物與首領，不靠外觀身高判定。

- **本體把其他觸發說成全部停用**：程式沒有對這次處決全面停發命中、擊殺或傷害事件；須依每個效果自己的條件判斷。
