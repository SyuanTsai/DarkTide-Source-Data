# 能量洩漏(Energy Leakage)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8709846a-8fcd-47ed-8a5b-6d57b666b45e" width="72" height="72" alt="能量洩漏祝福圖示">

- **觸發方式**：持用帶有能量洩漏的武器時，依這把武器目前熱量提供威力加成；不需要命中、擊殺或連續攻擊。

- **等級效果**：I–IV每段增加1.5%、2%、3%、4%威力，最多5段，上限為7.5%、10%、15%、20%。

- **分段方式**：計算段數時，先以熱量減去10%基準，再把剩餘90%範圍換成0至5段並四捨五入；加成是階梯變化。

- **熱量門檻**：1至5段的門檻依序約為19%、37%、55%、73%、91%熱量；低於第一門檻沒有加成。

- **滿段條件**：熱量約91%起便達5段，不必等到100%過熱鎖定。

- **影響範圍**：威力加到傷害、順劈與踉蹌的計算；實際傷害提升依攻擊、目標與其他加成而定。

- **散熱變化**：熱量下降時段數也跟著下降；停用充能後，只要還有足夠熱量，普通攻擊仍能受益。

- **持續與重算**：沒有固定持續秒數或觸發冷卻，也不按命中累積層數；熱量決定當下段數。

- **切換武器**：切出時停止提供加成；切回後依這把武器當時的熱量重新計算，其他武器不承接此加成。

## 計算與算例

- **分段前提**：持用IV級武器，比較50%、60%、95%熱量，沒有其他同階段威力加成。

- **50%熱量**：換算為`(0.50−0.10)÷0.90×5≈2.222`，四捨五入為2段，威力增加`2×4%＝8%`。

- **60%熱量**：換算為約2.778，取3段，威力增加12%。

- **95%熱量**：換算為約4.722，取5段，威力增加20%。

- **威力前提**：假設某一結算階段已經過武器曲線，威力為500，沒有其他同階段加成。

- **威力結果**：50%、60%、95%熱量分別變成`500×1.08＝540`、`500×1.12＝560`、`500×1.20＝600威力`；這些數字是威力值。

- **已有加成前提**：沿用曲線後500威力，原本已有25%同階段加成，生效前為625威力；IV級熱量95%。

- **已有加成結果**：生效後為`500×(1＋0.25＋0.20)＝725威力`，相對625增加16%。

- **散熱前提**：IV級在60%熱量停用充能，之後散熱到30%、10%。

- **散熱結果**：加成由3段12%降為1段4%，再降為0；沒有等待固定倒數秒數。

- **切換前提**：IV級60%熱量時切出，切回當下熱量為30%。

- **切換結果**：切出期間沒有此加成；切回依30%熱量取得1段4%，不保留切出前的12%。
