# 粉碎(Shred)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/5c459ca2-a946-4f54-b8b5-91c8f0e5b69a" width="72" height="72" alt="粉碎祝福圖示">

- **觸發方式**：持用帶有此祝福的武器，每次近戰揮擊命中敵人後取得一層。

- 命中多名敵人仍只加一層。

- 新層數在揮擊結束後取得，供後續攻擊判定使用。

- **爆擊率**：每層增加2.5／3／3.5／4個百分點，依序對應I／II／III／IV級，最多5層。

- 滿層分別增加12.5／15／17.5／20個百分點。

- 這是爆擊機率，沒有直接增加暴擊傷害。

- **刷新與移除**：命中刷新共同3.5秒期限，滿層也刷新。

- 揮空或逾期清空有效層數。

- 更換目標不重置。

- **切換武器**：切出時停止加成，倒數繼續。

- 期限內切回可沿用剩餘層數。

## 特殊攻擊

- 黏附在敵人身上的近戰攻擊，其連續傷害不會逐段疊層。

- 黏附結束後，整次合格攻擊取得一層。

- 鏈鋸啟動、力場充能及雙刀姿態切換本身不取得層數。

- 力場劍與力場巨劍的靈能推擊不屬於近戰揮擊，不取得層數。

## 計算與算例

- **機率加算**：假設其他因素合計5%爆擊率，沒有爆擊率轉傷害或保證暴擊效果。

- IV級每層4個百分點，一層為`5% + 4% = 9%`，五層為`5% + 5 × 4% = 25%`，提高20個百分點。

- **已有加成**：基準5%、另有10個百分點同類加成時，原值15%。

- IV級滿層後為`5% + 10% + 20% = 35%`。

- 不是把15%乘以1.20。

- **首次生效**：假設連續命中且間隔未超過3.5秒，由零層開始。

- 第一擊用原爆擊率，結束後取得1層。

- 第5擊結束滿層，第6擊可用滿層。

- 爆擊判定使用偽隨機分布，不保證每四擊必定出現一次暴擊。
