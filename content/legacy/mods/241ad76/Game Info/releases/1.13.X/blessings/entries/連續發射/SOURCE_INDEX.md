- 八個 wrapper 各自完整覆寫 I–IV；Arc Rifle P1 每步 1/1.5/2/3%，其他六個 5/6/7/8%，Ripper P1 5/6/7/8%但 step helper 為彈匣容量 8%。Tier formatter 各自讀自己的 trait override；wrapper 的 `.02` 是 fallback，實際 tier override 取代 fallback，不再疊加一份 `.02`。

## 計數來源、步距與上限

- 八個實際 wrapper 都選 `BaseWeaponTraitBuffTemplates.stacking_buff_on_continuous_fire`，`use_combo` 未設定，故 `_number_of_continuous_fire_steps` 讀 player `shooting_status.num_shots`，計算 `floor(N/S)` 並封頂 5。底層是 `stepped_stat_buff`，`max_stacks=1`、`stack_offset=-1`、範圍 0–5；這是單一 step-stat Buff，不是五個 ProcBuff child。
- 七個 formatter 標成 10% 且選 `default_continuous_fire_step_func`；Ripper P1 選 `ogryn_rippergun_continuous_fire_step_func` 8%。兩者皆以已裝備槽的最大在用彈匣容量計算，floor 後至少 1；重裝/沒有槽位回傳 0。
- `ActionShoot._prepare_shooting` 只在 `is_first_combo_bullet` 條件成立時增加共享 `num_shots`。範圍內實作為 hitscan、pellet burst、flamer gas，均繼承 ActionShoot；Dual Autopistols 是 alternating。實際模板沒有 projectile shot route；通用 ActionSpawnProjectile 也可寫同一共享欄位，所以短暫殘留計數不做來源物品比對。
- Force Staff P2 的普通 `flamer_gas_burst` 與蓄力 `flamer_gas` 均以 warp charge 運作，weapon template 是 `no_ammo` 且容量為 0。其門檻 helper 仍以 `max(1, floor(C×10%))` 算出 1；準備射擊事件可累積計數，但每 frame rays、命中與 DoT 不會各自寫入該欄位。

## 生效、切換與消除

- `_continuous_fire_start_func` 捕捉 player 射擊狀態、weapon action 與指定 inventory slot；held 條件比對當下 wielded slot。on-equip 安裝，切換會關閉 held stat，卸下 item slot 移除 Buff。沒有逐層 expiry timer。
- 清除計數由 `PlayerUnitWeaponExtension.fixed_update` 執行：需不在射擊、目前動作未設 `dont_clear_num_shots`，且時間嚴格大於 `shooting_end_time + current spread template 的 movement-state num_shots_clear_time`。切槽不直接將欄位歸零；新持用武器/動作可以改變清除時間來源，`spread_template=none` 時來源值為 0。
- 更新流程由 ActionShoot 準備更新共享計數，Buff fixed update 再重算 stat buffs/keywords；新步數在 stat cache 更新後反映，不回溯套到已結算 hit。

## PowerLevel 的實際影響範圍

- `power_level_modifier` 是一般 PowerLevel pool 欄位，不受 attack_type 的 melee/ranged 分支限制；melee/ranged 專屬欄位才各有 gate。profile curve 後，該 pool 參與 attack/impact/cleave distribution 與 damage calculation。
- 範圍內 flame 直接攻擊由 FlamerAction 經 RangedAction/Attack 的 profile 路徑結算；之後燃燒 stacks 是另一個 dot Buff 路徑。實際 Flamer P1／Force Staff P2 的燃燒跳傷會使用玩家當前攻擊力量快取；持用條件成立且有效步仍在快取中時，跳傷可能受本項一般力量修正影響。切出或射擊計數清零並更新快取後，剩餘跳傷不再受本祝福加成；燃燒期限與射擊計數分開，且不能推成最終生命傷害固定增加相同比例。
- 各實作特殊模式是否增加射擊計數、是否經一般攻擊力量修正池，以及 hip／瞄準的實際 spread 清除時間，逐項列在下方型號差異註記；清除仍須符合前述停止射擊與動作允許條件。

設 `C` 為最大在用彈匣容量，`r` 為步距比例（一般 `0.10`，撕裂槍系列 `0.08`），`N` 為玩家共用射擊計數，`p` 為每步修正：

`S=0`（重裝或沒有可用槽位）；否則 `S=max(1,floor(C×r))`。`K=0`（`S=0`）；否則 `K=min(5,floor(N÷S))`；`Δ=K×p`。其他攻擊力量修正為中性時，修正池為 `1+Δ`。

例如重伐木槍 戈爾貢努姆 Mk IIIa Tier IV：`C=30,N=15,r=.10,p=.08`，得 `S=3,K=5,1+Δ=1.40`。原生攻擊力量仍會經 profile 曲線、傷害 profile、護甲、命中部位與距離等結算，因此 `1.40` 不是最終生命傷害倍率。Force Staff P2 `C=0` 仍有 `S=1`，其特殊路徑見算例與勘誤。
