# 接連不斷(Cavalcade)

- **觸發方式**：持用下列實際適用武器並射擊時，玩家共用射擊次數 N 依彈匣步距累積；每跨過門檻，爆擊率增加一層，最多五層。計數在命中前增加，不要求命中；多彈丸或多目標不會額外增加次數。
- **實際型號**：撕裂者自動手槍 尤斯 Mk IV、矛頭爆矢槍 洛克 Mk IIb、矛頭爆矢槍 洛克 Mk III、雙持自動手槍 布蘭克斯 MkIII、重伐木槍 克魯克 Mk IIa、重伐木槍 戈爾貢努姆 Mk IIIa、重伐木槍 阿克利斯 Mk II、撕裂槍 碎敵 Mk II、撕裂槍 碎敵 Mk V、撕裂槍 碎敵 Mk VI。
- 每層增加 I–IV 的爆擊率 3.5／4／4.5／5 個百分點。自動手槍、爆矢槍、雙持自動手槍、重伐木槍每10%最大彈匣容量為一步；撕裂槍P1以8%計。依向下取整及最小一步數，實際發數可能與RAW字面比例不同。
- 步數依「共用 N÷步距」向下取整，最多五步。重裝或沒有有效武器彈匣時，步距函式回傳0；該次stat快取計算暫時沒有本項貢獻，不代表保留舊加成。新步數要等stat cache更新才生效；跨門檻的當發不保證已使用新值。
- 停火計數只在閒置、未禁止清除，且時間嚴格超過「射擊結束時間＋目前spread／移動狀態計時」時歸零。切槽本身不歸零，N屬玩家共用，切換期間其他遠程武器也可推進 N；切回前是否歸零取決於實際停火清除門檻。
- **特殊攻擊、推擊與切槽**：自動手槍和重伐木槍的特殊鍵只切換手電筒，不會攻擊或擲本項爆擊。爆矢槍的特殊輸入名稱為 action_push，但兩個實際 Mark 定義 kind=sweep；雙持自動手槍 pistol-whip 與撕裂槍 stab 也都是 Sweep 近戰攻擊，會走近戰爆擊判定，可讀當時有效的通用爆擊率；這三種特殊攻擊都不增加 N。一般純推擊是 attack_type=push，本身不做爆擊判定；若另有獨立追擊攻擊，須按該攻擊自己的爆擊路徑判斷。切出來源武器後，持用條件使本項stat暫時停用，但共用 N 保留；若在清除前切回，剩餘 N 可重新貢獻。真正卸下武器會移除其 on_equip trait buff。

## 計算與算例

### 算例一：重伐木槍 克魯克 Mk IIa，II 級

- **前提**：固定武器彈匣最大容量 M=40；未重裝；快取已讀到共用射擊次數 N=8；其他當次適用爆擊率輸入 B=5%，轉傷害修正為0。
- **代入**：S=max(1,floor(40×10%))=4發；k=min(floor(8÷4),5)=2層；II級 p=.04，所以祝福貢獻 k×p=2×.04=.08，即8個百分點。
- **結果**：簡化的判定輸入為 B+k×p=5%+8%=13%（之後仍經遊戲的clamp、兩位小數rounding及PRD）。
- **玩家意義**：此武器P2 M1每4次射擊累積一步，最多五步；這是爆擊率輸入示例，不是命中率保證或傷害倍率。

### 算例二：撕裂槍 碎敵 Mk II，III 級

- **前提**：固定M1彈匣容量依ammo模板在12至24間插值；未重裝；快取已讀到 N=5。
- **代入**：S=max(1,floor(M×8%))；M=12時floor(.96)=0、M=24時floor(1.92)=1，套最小值後兩端S都為1；k=min(floor(5÷1),5)=5層。
- **結果**：III級 p=.045，五層貢獻5×.045=.225，即22.5個百分點。
- **玩家意義**：自身格式器8%與程式helper相同；floor和最小1發使此容量範圍可每次計數加一步。RAW未列此取整細節，並非互相矛盾。
