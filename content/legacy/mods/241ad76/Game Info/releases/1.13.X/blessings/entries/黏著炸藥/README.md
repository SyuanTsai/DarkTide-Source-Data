# 黏著炸藥(Adhesive Charge)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/dcea9788-55f7-488d-bad7-a473f9dd1816" width="72" height="72" alt="黏著炸藥祝福圖示">

- **觸發方式**：裝備並持握震盪槍 洛倫茲 Mk VI（Rumbler Lorenz Mk VI）；傷害加成不需先命中或黏住目標來啟動。
- 你的手榴彈可黏在帶有「歐格林」或「巨獸」標籤的存活目標上。黏附由目標標籤判定，不看護甲種類；投射物先結算直接命中，再檢查能否黏附，因此直接命中擊殺目標時不會再黏住它。
- 持握時，對帶有上述任一標籤的目標，通用傷害加成為 I +6%、II +9%、III +12%、IV +15%。這項加成也可作用於震盪槍槍托特攻對這些目標造成的近戰傷害；槍托攻擊本身不會黏附手榴彈。
- 一般腰射投擲與瞄準／架槍投擲使用相同的黏附標籤判定與爆炸路徑。腰射投射物另有依飛行速度調整直接命中蓄力值的設定；這不是需要玩家蓄力的投擲，也不改變本祝福的階級加成。
- 傷害數值在投射物生成時複製當時持有者的已計算數值；發射後切換武器不會改寫該枚投射物的傷害快照。黏附檢查則在撞擊時解析仍存活的持有者並查詢當下的黏附關鍵字：切走但仍裝備震盪槍時，關鍵字仍隨裝備的特質存在；卸下震盪槍後，特質 Buff 移除，之後才發生的撞擊便不再能靠此特質黏附。
- **首次生效與疊層**：傷害加成在持握條件成立、數值更新後即可作用，不必先擊中敵人；沒有命中疊層，也沒有命中後倒數或刷新時間。切出震盪槍後，之後的持有者攻擊不再取得此加成，但已發射手榴彈的傷害快照保留。
- **黏附後的引信**：成功黏附會把該枚手榴彈的生存計時歸零。兩種投擲均設定 1.5 秒引信及 0.5 秒最短生存門檻，爆炸檢查另計延遲補償；這是手榴彈本身的引信，並非祝福只持續 1.5 秒。
- 同時帶有歐格林與巨獸標籤的目標只取得一次階級加成。重新命中不會把 +6%～+15% 疊成更多層。

## 計算與算例

前提：以手榴彈傷害作例，目標帶歐格林或巨獸標籤；攻擊在生成時已複製持握震盪槍時的加成；令進入通用攻擊者傷害統計階段的基礎值 B=100，其他同階攻擊者加成 q 已知；護甲、部位、距離、目標承傷倍率與後續計算固定不變。這是公式代入示例，不是遊戲內固定傷害值。

- **I 級、沒有其他同階加成**：p=0.06、q=0；100×(1+q+p)=100×1.06=106。相較沒有此特質時的 100，該傷害統計階段增加 6；最終生命值傷害仍受武器傷害設定與目標條件影響。
- **IV 級、已有 +20% 同階加成**：p=0.15、q=0.20；沒有此特質時 100×1.20=120，有此特質時 100×(1+0.20+0.15)=135，增加 15；相對原本的 120 是 +12.5%，不是把整次最終傷害再乘 1.15。
