# 烈火熱焰(Fire Frenzy)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/61395be2-3c80-48d8-adde-b7c751f07e2d" width="72" height="72" alt="烈火熱焰祝福圖示">

- **觸發方式**：持用裝有本祝福的遠程武器，以這把武器在近距離擊殺敵人；命中位置須距玩家不超過12.5公尺。沒有額外敵種或菁英限制。
- **首次生效與傷害結算**：擊殺傷害先結算，之後才加入新層；新層不會回溯提高觸發擊殺的傷害，只影響後續傷害。
- **層數與刷新**：每次合格擊殺增加一層，最多5層。I／II／III／IV 每層分別增加7%／8%／9%／10%；共用3.5秒期限，每次合格擊殺都重新計時，滿層時仍可刷新。
- **到期與卸除**：最後一次合格擊殺後，經過3.5秒期限的固定更新會移除效果，現有層數全部移除；從武器上卸下本祝福也會移除效果。重新裝填不會重設期限。
- **切換武器**：切出這把武器時，層數暫時不生效，但期限照常倒數；到期前切回會恢復尚未到期的層數，已到期的層數不會恢復。
- **受益距離與傷害範圍**：每層加成作用在原生傷害計算的近端距離值：攻擊者與目標在12.5公尺內時使用完整近端值；12.5至30公尺間依距離以平方根曲線逐漸銜接遠端值；30公尺到達遠端值。此距離取該次傷害結算時雙方的位置，與觸發時用命中位置判定是否近距離擊殺分開計算。遠程擊殺是觸發條件；效果存續時，讀取同一距離傷害值的其他攻擊也可能受益，包括部分近戰特殊攻擊，但不代表所有攻擊的最終傷害都按相同百分比增加。
- **加成如何合併**：此祝福提高的是近端距離值；內插後的增量會與其他適用的傷害加法修正相加，不能把卡面百分比直接乘到所有攻擊的最終傷害。
- **特殊射擊與追加傷害**：戰鬥霰彈槍 Mk VI 的穿透彈、Mk VII 的獨頭彈，以及各型號特殊彈的直接命中，符合相同近距離遠程擊殺條件時可增加層數；Mk IX 的燃燒間隔傷害、滅絕者霰彈槍 Mk III 的眩暈間隔傷害不能增加層數。滅絕者 Mk VIII 特殊彈施加破甲減益，該減益本身沒有週期傷害。
- **近戰特殊攻擊與推擊**：槍托自動槍、矛頭爆矢槍的槍托打擊，撕裂槍刺擊及霰彈手槍盾牌重擊都屬近戰揮擊，不能增加層數；效果仍存續且持用此武器時，其生命傷害可讀取同一近端距離加成。盾牌輕擊是沒有生命傷害的純推擊，不能藉本祝福產生生命傷害。步兵自動槍的特殊手電筒只切換照明，不造成傷害。

## 計算與算例

- **前提**：II 級、已有3層；本次傷害結算距離在12.5公尺內，且遠近距離以外的修正先假設為中性1.00。
- **代入**：每層0.08，0.08×3=0.24；近端距離值為1.00+0.24=1.24。
- **結果**：該距離分支的倍率值增加0.24；相對中性1.00是增加24%。同樣五層時，I／II／III／IV 的近端值依序為1.35／1.40／1.45／1.50。
- **玩家意義**：近端加成由0%增加至24%，是增加24個百分點；在中性1.00前提下，距離分支值1.24相對1.00也增加24%。這兩種表示的比較基準不同，均不代表最終傷害必定增加24%；距離分支的增量還會與其他適用的傷害修正相加，再經其餘傷害結算。

- **前提**：IV 級、5層；本次傷害結算時攻擊者與目標相距20公尺，遠端值與其他遠距修正假設為中性1.00。
- **代入**：近端值=1+0.10×5=1.50；距離比例s=(20−12.5)/(30−12.5)=3/7，平方根約0.65465；由1.50向1.00內插後約為1.17267。
- **結果**：20公尺時，此近端加成在距離分支留下約0.17267倍率值；到30公尺時，近端加值衰減至0。
- **玩家意義**：在遠端中性假設下，1.17267相對1.00約增加17.27%；這只描述距離分支，不能視為所有傷害或最終傷害的固定百分比。

## 遊戲描述勘誤

繁體中文 RAW 把 Close Damage 譯為「近戰傷害」，容易使人以為只限近戰。實際消費端依攻擊距離使用近端值，沒有近戰專屬限制；近戰攻擊另有獨立的近戰傷害欄位與判斷。本文以「近距離傷害」說明祝福加成，避免混淆。
