## 執行與計算

16 個實際 trait variant 各自有完整 I–IV tier 定義；其 formatter 輸出 `range=5m/6m/7m/8m`，own tier 的實際 `suppression_settings` 則各級皆為 `distance=12`、`instant_aggro=true`、`suppression_falloff=false`，`suppression_value=15/20/25/30`。16 個 wrapper 分別只有對應 base `suppression_on_close_kill` 的 clone，未見本項後置 wrapper 覆寫。base 是 `ProcBuff`：只監聽 `on_kill`；同時需要 exact `attacking_item` match、持用條件及 ranged-close 或 explosion-close predicate。遠程 predicate 接受 `attack_type=ranged` 或 profile 的 `count_as_ranged_attack=true`；爆炸 predicate 要求 `attack_type=explosion`。兩者都要求目標死亡且具 `hit_world_position`，距離以該命中位置與處理事件時 `POSITION_LOOKUP[attacking_unit]` 位置比較；邊界為 12.5m。

符合條件時，`proc_func` 對 attacker 當時位置作 area suppression，固定半徑 12m、無 falloff、instant aggro；另外對 6m 內有 cover extension 的目標可釋出掩體位置，時間由設定隨機取 3–8 秒。這項副效不是 suppression 狀態的 TTL。`1.5s active_duration` 與 `cooldown_duration=0` 搭配 ProcBuff active gate，代表同一窗口期間不再啟動下一次 proc；它不是 enemy suppression status 的固定期限。Suppression receiver 另外套用 enabled／immunity／suppression-type／breed LoS 等條件及各自 threshold，因此「施加 suppression」不等於一定進入 suppressed 狀態。

實際 coverage：每個綁定模板的 hitscan、pellet、直接 ranged projectile 在 attack type 上走 ranged；Force Staff P1 特殊蓄力 AoE 用 explosion，P3 chain lightning 預設 ranged；Flamer P2 直接火焰 attack 是 ranged，但延遲 flamer_assault tick 用 buff type 和無 ranged-count profile，故不通過；武器模板中的 melee sweeps 及 PushAttack 分別用 melee／push，且其所用 push profiles 不帶 ranged-count，不能把「遠程武器上的特殊鍵」當作遠程攻擊。

設 `K` 為觸發合格的擊殺事件，`w` 為本 trait 綁定武器物品。`K = died AND (attack_type=ranged OR damage_profile.count_as_ranged_attack OR attack_type=explosion) AND same_item(w) AND held_gate AND d²(hit_world_position, attacker_position_when_checked) ≤ 12.5² AND ProcBuff_not_active`。成功後：`suppression_event = area(center=attacker_position_when_proc_runs, radius=12m, falloff=false, value=15/20/25/30, instant_aggro=true)`。receiver 只在其自身設定允許時接收；在 6m 內具 cover extension 時另可能 release cover slot 3–8s；`is_suppressed` 取決於 `suppression_threshold ≤ min(current+value, max)`，並非傷害或固定控制秒數。`ProcBuff.active_duration=1.5s` 且 `cooldown_duration=0` 控制下一次本祝福觸發的時間；不是 area target 的 suppression timer。條件中的 12.5m close threshold、12m suppression area、RAW rarity formatter 5–8m 是三個不同觀察值。
