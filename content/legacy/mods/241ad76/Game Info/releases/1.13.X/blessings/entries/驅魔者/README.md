# 驅魔者(Exorcist)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/bc5a089b-7227-4993-882a-a5fe0085e6f2" width="72" height="72" alt="驅魔者祝福圖示">

- **觸發方式**：裝備並持用有「驅魔者」的烈焰力場劍，近戰揮擊命中敵人弱點後，在揮擊結束時計算；同一記揮擊命中多名敵人時，只要其中一名命中弱點就符合條件。

- **首次起算**：第一記符合條件的弱點揮擊只建立計數；連擊中的後續弱點揮擊才會開始消解反噬。若遊戲連擊計數已歸零，下一記弱點揮擊會重新起算。

- **等級效果**：I／II／III／IV級每次有效後續揮擊分別消解反噬表的2／3／4／5個百分點；反噬不會低於0%。

- **揮擊判定**：一記揮擊最多消解一次；同一揮擊命中多名弱點目標仍只算一次。沒有命中弱點的揮擊不會推進或重置本祝福的計數。

- **特殊攻擊**：單獨按下特殊攻擊鍵不會觸發；特殊效果啟用後，若近戰蓄能揮擊命中弱點，該次揮擊可以觸發。

- **切換武器**：切出烈焰力場劍時不會觸發，但計數不因切換本身重置；切回時若遊戲連擊已歸零，下一記弱點揮擊會重新起算。祝福武器被卸下或替換時，原效果移除，重新裝備後重新起算。

- **連段中斷**：三種型號在動作已結束後，閒置超過0.2秒會讓遊戲連段歸零；這不是從上一次弱點命中起算的0.2秒期限。連段仍持續時，中間一刀揮空或命中身體，不會直接清除祝福的弱點計數。

## 計算與算例

- **IV級首次與後續**：假設反噬為40%，過程中沒有其他反噬增減；首次弱點揮擊只起算，仍為40%。維持連段的下一記弱點揮擊結束時降低5個百分點，變35%；再一記符合條件的弱點揮擊變30%。

- **多目標**：沿用40%反噬、已建立計數的IV級連段，一刀同時命中三名敵人的弱點也只降低一次，`40% − 5個百分點 = 35%`。

- **儀表下限**：反噬只剩3%，IV級下一次合格消解為 `max(0%, 3% − 5個百分點) = 0%`，不會變成負值。

- **百分點**：反噬40%時，IV級降低的是5個百分點，結果35%；不按目前值乘95%得到38%。

- **中間打身體**：已建立弱點計數後，一刀打身體，再一刀命中弱點；假設遊戲連段始終未中斷，身體那刀不消解也不重設祝福計數，下一刀弱點仍能消解。

- **重新起算**：連段歸零後，下一記弱點揮擊只重新建立計數；之後維持連段再命中弱點，才恢復每刀消解。

## 遊戲描述勘誤

- **方向寫反**：繁中「增加{warp_charge:%s}反噬」應為降低反噬。英文「Quell」與實際結算都表示消解反噬。
