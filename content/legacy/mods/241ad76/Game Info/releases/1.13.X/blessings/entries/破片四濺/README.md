# 破片四濺(Shrapnel)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/76d7ae66-9a8f-4e19-8443-246a889eee83" width="72" height="72" alt="破片四濺祝福圖示">

- **觸發方式**：持用震盪槍時，榴彈爆炸內圈命中存活敵人，依等級施加流血。

- **近距離判定**：內圈以敵人與爆炸中心的距離及敵人尺寸判定；黏附目標也列入內圈。玩家與敵人的距離不決定這次效果，爆炸外圈不會施加流血。

- **等級效果**：I、II、III、IV級每次有效命中分別添加1、2、3、4層；各敵人分開累積，與其他來源共用16層上限。

- **流血刷新**：基本刷新時間1.5秒，每0.5秒結算一次流血傷害。再次施加會刷新時間，已達16層也會刷新。

- **流血退層**：刷新時間到期後，每次傷害結算再移除1層，直到歸零；完整存續時間依層數決定，會超過1.5秒。

- **射擊方式**：腰射與瞄準射擊使用相同爆炸效果；直接撞擊和槍托近戰不會施加此祝福的流血。榴彈第一次碰撞不會立即觸發碰撞爆炸，引信爆炸與後續碰撞爆炸則依內圈命中判定。

- **切換武器**：爆炸命中時需仍持用震盪槍。切出後不能新增此祝福的流血，敵人已有的流血仍繼續結算及退層。

## 計算與算例

- **群體命中前提**：持用IV級震盪槍，爆炸內圈命中三名存活敵人，各自原本沒有流血。

- **群體命中結果**：每名敵人各獲得4層，彼此分開計算；不是三人共分4層。

- **上限算例**：IV級命中已有14層的敵人，結果為16層並刷新時間；不會疊至18層。

- **傷害算例**：4層流血送入傷害計算的威力為78.125，16層為500；兩者都是威力輸入，實際生命傷害還會依流血傷害設定與目標防禦結算。
