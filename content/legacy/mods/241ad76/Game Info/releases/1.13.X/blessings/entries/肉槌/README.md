# 肉槌(Tenderiser)

- **觸發方式**：持用砍刀克魯克 Mk VI、蠻牛屠夫 Mk III 或克魯克 Mk IV，以特殊上勾成功命中目標。普通輕擊、重擊／蓄力攻擊與推擊後追斬不能啟動或刷新；純推擊也不觸發。

- **效果**：I／II／III／IV 級分別提高15%／20%／25%／30%的近戰威力輸入。這是威力修正，不代表最終生命傷害、踉蹌或順劈目標數按相同比例增加。

- **首次生效**：觸發用的命中先完成傷害與踉蹌計算，之後才處理祝福；該次命中不會回溯提高。狀態與威力快取更新後，後續近戰命中才能受益。同一段仍開啟的上勾掃掠若跨過快取更新，較晚命中也可受益；不保證同一次固定更新中的第二個目標已取得加成。

- **計數與刷新**：每次合格特殊上勾命中都將內部計數重設為4。通常觸發用的上勾掃掠結束時先從4扣到3，再供之後三個近戰掃掠使用；每個持用且效果啟用中的掃掠結束扣1，扣到0時停止，並在祝福更新後移出威力快取。計數單位是掃掠動作結束，不是命中目標或掃掠線數；後續揮空也會扣數。

- **期限與疊層**：本項只有一份啟用狀態與剩餘掃掠計數，沒有獨立秒數期限，也不以重複命中疊加多份威力加成；再次合格命中重設計數。

- **推擊與追斬**：純推擊不受此近戰威力修正，也不扣本項計數。推擊後接續的斬擊則是近戰掃掠；效果啟用且仍持用時可受益，掃掠結束再扣1。

- **順劈取樣**：一般近戰掃掠在動作開始時計算並保存順劈預算。因此當次上勾途中才觸發加成，即使較晚命中能取得更新後的傷害／踉蹌威力，也不會自動重算這段已保存的順劈預算；伺服器動作校正會重新計算。

- **切換與移除**：切出武器後，持用條件使加成在祝福快取更新後停止生效，也不再扣本項掃掠計數。來源武器仍留在裝備欄時，啟用狀態與計數保留，切回後在祝福更新後可繼續使用。將來源武器物品從裝備欄卸下時，祝福一併移除。

## 計算與算例

- **前提**：只看已通過原生武器類型曲線、尚未套用本項修正的近戰威力輸入S；其他威力修正中性，profile、目標和護甲條件固定。這是輸入階段的數學示例，不是實測傷害。

- **IV級、沒有其他同類修正**：S=100、p=.30，修正後100×(1+.30)=130，該階段增加30（+30%）。

- **IV級、已有同一威力修正q=.20**：只有既有修正時100×(1+.20)=120；加入本祝福後100×(1+.20+.30)=150。比120多30，約增加25%；不是把120再乘1.30算成156。

- **讀法**：這只描述進入後續damage、impact與cleave結算前的威力輸入；最後生命傷害、踉蹌及順劈數另受profile、曲線、目標和掃掠開始時保存的順劈預算影響。
