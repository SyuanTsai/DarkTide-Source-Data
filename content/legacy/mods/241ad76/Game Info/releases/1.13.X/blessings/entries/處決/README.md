# 處決(Execution)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/32e5f2ee-798c-4a48-9b8d-5a2727edf70a" width="72" height="72" alt="處決祝福圖示">

- **觸發方式**：持用裝有處決的適用武器，且目標在傷害計算時已有踉蹌計數，或正處於「視為踉蹌」效果，該次傷害便取得加成。不以畫面晃動單獨判定，也不要求踉蹌由自己造成。

- **效果**：所有適用型號的 I–IV 級均為 +5%／+10%／+15%／+20%，加入一般傷害加算池。它不按輕、中、重踉蹌分級，也不隨踉蹌次數疊高；整次最終傷害比例仍受其他同池加成、弱點額外傷害及後續結算影響。

- **首次生效**：攻擊先讀目標既有踉蹌狀態並計算傷害，稍後才施加本次命中反應。因此把未踉蹌目標打出第一次踉蹌的那筆傷害，不會事後回溯增傷；後續傷害按各自結算時的狀態重新判定。

- **持續、刷新與移除**：本祝福沒有自己的層數、冷卻或命中後倒數。一般踉蹌行為結束會清除計數；若也沒有有效的「視為踉蹌」效果，就停止加成。重複打出踉蹌可維持目標條件，但不增加階級百分比；替代狀態依提供它的效果期限移除，並非一般踉蹌的固定時長。

- **普通、蓄力與推擊**：碎骨者、法務官電擊鎚及電弧鎚的普通攻擊、蓄力重擊與推擊後追擊，皆按各次傷害判定。三者的純推擊攻擊傷害設定為 0；本祝福不增加推開或踉蹌強度，推擊後追擊是另一筆傷害。

- **近戰特殊動作**：碎骨者的特殊重擊、法務官電擊鎚的特殊強化，以及電弧鎚的特殊強化命中，仍按目標當時狀態判定。電弧鎚連鎖電弧逐目標結算；第一個目標符合條件，不表示其他連鎖目標也自動符合。

- **爆彈手槍**：戈德溫–布蘭克斯 Mk IV、Mk VI 的腰射、瞄準射擊與槍托攻擊可依目標狀態受益。依實際設定觸發的擊殺或彈丸停止次生爆炸，亦對每個爆炸目標重新判定；不是每次直擊都必定爆炸，也不直接沿用直擊目標的踉蹌結果。

- **滅絕者霰彈槍**：鐵腕 Mk III、Mk VIII 的普通、瞄準及特殊彈射擊，各次彈丸傷害都按目標狀態判定。Mk III 特殊彈在全輪彈丸傷害後施加 3 秒電擊；Mk VIII 特殊彈施加 8 秒、+25% 破甲。電擊或破甲本身都不替代本祝福所需的踉蹌判定。

- **間隔追加傷害**：法務官電擊鎚及 Mk III 霰彈槍實際施加的間隔電擊傷害，讀取攻擊者當下可用的傷害加成，並再次檢查目標踉蹌狀態。霰彈槍的間隔效果對正在踉蹌的瘟疫爆破者跳過該次傷害；本祝福不會讓被跳過的傷害重新產生。

- **切換武器**：離開對應武器的持用狀態，它便不再提供這份加成。切回不必先命中解鎖；目標仍符合條件即可生效。切換不延長目標的踉蹌或替代狀態期限，延後結算的追加傷害也依當下可用的加成判定。

## 計算與算例

- **前提**：只隔離一般傷害加算池，目標已符合條件，適用武器仍持用；不含弱點／致命一擊額外傷害、額外平加、破甲、背刺、側擊、轉換、上限或遞減，後續因素保持中性。以下是公式代入，並非遊戲測量值。

- **IV 級、無同池加成**：基礎主傷害 B＝100、其他同池比例 q＝0、本祝福 p＝0.20。原本 B×(1＋q)＝100；加入後 B×(1＋q＋p)＝120，增加 20，隔離主傷害相對增加 20%。

- **IV 級、已有同池 +30%**：B＝100、q＝0.30、p＝0.20。原本 100×1.30＝130；加入後 100×1.50＝150，仍增加 20，相對原本是 20÷130≈15.38%。同池加成越高，本祝福對既有結果的相對增幅越小；不能把 130 再乘 1.20。

- **逐級與未觸發對照**：B＝100、q＝0 時，I–IV 級依序是 105／110／115／120；目標未符合條件時 p＝0。首次把目標打出踉蹌，亦不回溯提高該筆已算完的傷害。
