# 幽靈(Ghost)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/6b238342-7828-4bb3-af20-1e092a318887" width="72" height="72" alt="幽靈祝福圖示">

- **觸發方式**：持用裝有幽靈的武器，以同一把武器命中敵人弱點；不要求暴擊或擊殺。
- **效果與期限**：I–IV 分別持續 0.6／0.8／1.0／1.2 秒，將符合遠程閃避判定的可閃避攻擊算作閃避。無法閃避的攻擊仍可命中；這個效果不提供所有遠程傷害免疫。
- **疊層與冷卻**：沒有額外層數或觸發冷卻；效果期間再次命中弱點會從新命中時間重設期限。
- **移除與切換武器**：期限結束後失效。切出此武器時閃避效果停止生效，期限繼續倒數；期限內切回會恢復剩餘時間。
- **多目標**：同一次攻擊中的各筆合格弱點命中都能觸發或更新計時，不限第一個目標。
- **普通與瞄準射擊**：列出的所有型號都可以用射擊命中弱點觸發。
- **槍托與刺擊**：機動自動槍的槍托輕、重擊，以及電能步槍的刺擊，命中弱點也能觸發。
- **推擊**：重型鐳射手槍的普通與靈能推擊按軀幹命中判定；推中敵人不會自動成為弱點命中。
- **模式切換**：手電筒開關與針彈手槍切換化學彈不造成命中，不能單獨觸發。
- **針彈化學彈**：針頭直擊弱點能觸發。化學爆炸是獨立命中，按爆炸自己的命中部位判定弱點，不繼承針頭的弱點結果。
- **毒素跳傷**：針彈所加毒素沒有保存針彈武器來源；對已有同名毒素加層也不會改寫初始來源，所以跳傷不會以針彈觸發幽靈。
- **保證弱點效果**：外部效果能將一次命中直接視為弱點；幽靈仍要求命中來源是裝有它的同一把武器。保證弱點不能補上毒素跳傷缺少的針彈來源。

## 計算與算例

- **前提**：III 級於 10.0 秒時以弱點命中觸發，持續 1.0 秒。

- **再次命中**：10.4 秒時再次合格命中，計時重設為 10.4 至 11.4 秒，不另加一層。

- **切換武器**：10.6 秒切出此武器後，閃避效果暫停生效，計時仍前進；11.0 秒切回時若未有其他命中，剩餘0.4 秒內恢復。

- **弱點保證節奏**：counter 初始為 0，首次在 5 次命中後取得一次性弱點保證，下一次攻擊即使命中軀幹也可回報為弱點；重設為 -1 後，之後需再累積 6 次命中才取得下一次保證。

- **毒素來源**：針彈所加的毒素不會保存針彈來源；若同名毒素先由其他來源建立，針彈後續加層也不會改寫初始來源，因此跳傷不能以針彈觸發幽靈。
- **期限與防禦範圍**：上述刷新後在 11.4 秒結束；可閃避的遠程命中會在效果中被算作閃避，標示為無法閃避的攻擊不受這個效果阻擋。

## 遊戲描述勘誤

- **勘誤**：原文與繁中本體都寫成「免疫遠端攻擊」，但實際程式僅在玩家遠端閃避判定中使用此效果；無法閃避的攻擊會略過閃避檢查，因此不能把文案理解為所有遠端傷害免疫。
