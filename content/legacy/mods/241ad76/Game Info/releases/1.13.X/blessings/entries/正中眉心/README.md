# 正中眉心(Between the Eyes)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8c0a5c18-354f-4503-aa10-004d7e6ef333" width="72" height="72" alt="正中眉心祝福圖示">

- **觸發方式**：持用已裝備「正中眉心」的對應武器，並以該武器命中實際弱點。事件必須來自目前同一把武器；未被判定為弱點的身體命中、切換到別把武器後用它命中，或只按特殊鍵／裝填，不會觸發。
- **效果**：合格弱點命中會清除持用者目前累積的壓制，並給予 `suppression_immune`，在下一次屬性／關鍵字快取更新後生效。I、II、III、IV 分別持續 2.4、2.8、3.2、3.6 秒。
- **刷新與到期**：沒有額外冷卻或可疊層數；持續期間再次合格命中會從該事件處理時間重設單一期限。期限採嚴格未到期判定，到期後關鍵字不再提供。
- **射擊**：14 個適用型號的腰射與瞄準射擊都走 hitscan。自動槍、鐳射槍、手槍、針彈手槍及重伐木槍的各型號與特殊路徑見逐型號說明；每個命中仍須有真實弱點事件且攻擊檔案允許 `on_hit`。
- **特殊近戰與推擊**：自動槍槍托是近戰掃擊；電能步槍布蘭克斯 Mk CV 的 `action_bash` 也是近戰掃擊，雖使用 `is_push=true` 的攻擊檔案，掃擊仍以實際碰撞部位判定弱點。兩者的攻擊檔案允許 `on_hit` 且命中確實帶弱點旗標時可觸發。重型鐳射手槍的普通與 psyker 純推擊走 `PushAttack`，一般固定以軀幹部位命中，通常不觸發；若外部效果提供 `guaranteed_weakspot_on_hit`，則以覆寫後的實際弱點旗標為準。
- **針彈手槍化學路徑**：直擊由命中掃描器依實際碰撞部位判定弱點。化學彈的 AoE 是另一個保留原武器來源的爆炸攻擊；爆炸選用可用的 center-mass 部位，只有該敵種的部位映射（或外部 `guaranteed_weakspot_on_hit` 覆寫）使事件帶有弱點旗標時才觸發。AoE 附加的毒素間隔傷害雖保留來源武器，但以 `attack_type=buff` 且不傳入命中部位，通常不會成為弱點事件；外部保證弱點關鍵字仍可覆寫判定；本祝福本身不提供保證弱點。切換化學彈本身不是命中事件。
- **切換與非攻擊動作**：切出後持用條件不成立，壓制免疫會在快取更新時停用；如果切回時單一期限仍未到期，且快取已更新，效果可重新生效。卸下祝福或武器時，該祝福 buff 依裝備變更移除。裝填、手電筒切換及化學彈切換本身不觸發。

## 計算與算例

- **前提**：機動自動槍 哥倫努 Mk III（`autogun_p3_m1`）裝有 IV 級「正中眉心」；t=10.0 秒指合格的弱點 `on_hit` 事件被處理的時間，來源物品是該槍且攻擊檔案未略過 `on_hit`。
- **代入**：IV 級 `active_duration = 3.6` 秒；事件處理時間為 t=10.0，事件後更新關鍵字快取。
- **結果**：該攻擊先按自身路徑結算，接著清除目前壓制；其後在 t<13.6 秒提供壓制免疫，t=13.6 秒到期。
- **玩家意義**：3.6 秒是免疫時間，不是傷害增幅；首次觸發不會回頭改變造成觸發的那次射擊。時間指事件被處理的時點，不是底層排程或碰撞必然同步發生的保證。

- **前提**：電能步槍 布蘭克斯 Mk CV（`galvanic_rifle_p1_m1`）裝有 I 級祝福。使用實際 `action_bash`（`kind="sweep"`，攻擊檔案 `galvanic_rifle_weapon_special_push`；該檔案的 `is_push=true` 不會把 Sweep 的攻擊類型改成純推擊）。在 t=20.0 秒，一個帶 `hit_weakspot=true` 的合格 `on_hit` 事件被處理；來源物品仍是這把步槍且攻擊檔案允許 `on_hit`。t=22.0 秒再處理一次相同條件的事件。
- **代入**：I 級期限為 2.4 秒。第一次事件處理時設期限為 t<22.4；第二次事件於 t=22.0 處理時仍在期內，並將開始時間重設為該事件處理時間。
- **結果**：第二次觸發後有效期間延至 t<24.4 秒；每次只維持一個期限，不會增加層數。
- **玩家意義**：此特殊近戰沒有被祝福的攻擊類型條件排除，但必須由掃擊實際部位算出弱點旗標；一般槍托碰撞不能一概當成弱點。時間是合格事件的處理時點，不是物理命中或幀排程的精確保證。
