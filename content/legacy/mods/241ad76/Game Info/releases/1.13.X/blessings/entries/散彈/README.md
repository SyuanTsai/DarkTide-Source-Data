# 散彈(Scattershot)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/61b31e74-8402-4d31-84da-ddd9c5763b3b" width="72" height="72" alt="散彈祝福圖示">

- **觸發方式**：持用裝有此祝福的霰彈武器，以一發散彈命中至少兩個不同的可受傷害目標；該發散彈結算後，按不同目標數增加層數。

- **每個目標只算一次**：同一目標被多顆彈丸、不同身體部位或弱點重複命中，仍只計為一個目標；命中零個或一個不同目標不會增加層數。

- **每層加成**：戰鬥霰彈槍、雙管霰彈槍、獵人霰彈槍、滅絕者霰彈槍、衝覆者霰彈手槍和防暴盾牌的 I–IV 級，每層分別增加遠程爆擊率 6、8、10、12 個百分點，最多五層。

- **同一發可加多層**：一發命中三個不同目標可一次增加三層；每個綁定型號均使用相同等級數值。

- **生效順序**：命中數在本發散彈完成後才結算，所以不能提高造成這次命中的同一發；已有層數會影響後續遠程爆擊檢定。

- **射擊模式**：戰鬥霰彈槍、獵人霰彈槍與滅絕者霰彈槍的腰射、瞄準與裝填後接續射擊都可觸發。雙管霰彈槍的單發或特殊雙管散彈，以及衝覆者手槍格擋中射擊，都按該次射擊命中的不同目標計算。

- **近戰與特殊功能**：雙管霰彈槍槍托攻擊、衝覆者盾牌近戰、獵人霰彈槍的模式切換本身不會加層；加成只影響遠程爆擊率，不提高盾牌近戰爆擊率。

- **清除與時間**：層數沒有獨立持續時間或冷卻；任何武器開始散彈射擊時，都會清除這個祝福保留的層數。換彈、瞄準、切換特殊模式、近戰或單純切換武器本身不會清除。

- **切換武器**：加成只在手持裝有祝福的武器時生效；單純切出或只做非散彈射擊動作不會清除層數，但任何武器開始散彈射擊都會清除。若沒有其他散彈射擊就切回，原武器下一發的初始爆擊檢定仍先使用保留層數，之後才處理清除事件。

## 計算與算例

- **零層與觸發門檻**：I 級開始沒有層數。一發只命中一個不同目標仍為零層；同一發命中兩個不同目標時，完成後得到兩層，每層+6個百分點，共+12個百分點。

- **每層與相對變化**：假設 II 級一發命中三個不同目標，得到三層，增加 `3×8=24` 個百分點。若原有同一遠程爆擊池為20%，算例是20%+24%=44%，相對變化 `(44−20)÷20=120%`；這是機率變化，不是傷害增幅。

- **滿層上限**：IV級一發命中五個以上不同目標最多五層，提供 `5×12=60` 個百分點。若其他同池來源合計50%，原始合計110%會限制為100%；更多目標不會突破五層。

- **同目標多顆彈丸**：一發的多顆彈丸集中命中同一目標，即使打中不同部位或弱點仍只算一個目標；命中兩個不同目標則加兩層，不按彈丸數加層。

- **已有五層後再開火**：本武器下一發的初始爆擊判定先使用舊五層；開始射擊的清除事件隨後將層數歸零。如果該發只命中兩個不同目標，命中結算後重新得到兩層；落空或只命中一個目標則維持零層。層數不會把上一發五層直接加到下一發命中數。

- **揮空、裝填與切換**：揮空或只命中一個不同目標不加層。換彈和切換沒有獨立倒數；切出時加成失效，既有層數不會因切換直接刪除。若另一把會發射散彈的武器開火，射擊開始事件會清除這個祝福的保留層數；中間只有裝填或近戰等非散彈動作則會保留。

- **四級滿層比較**：假設原有遠程爆擊機率池20%，沒有其他變動或爆擊轉傷害效果，五層時 I／II／III／IV 分別為50%／60%／70%／80%；祝福分別加入30／40／50／60個百分點。

## 遊戲描述勘誤

- **明確差異**：RAW 英文與繁中限制為「Enemy／敵人」，但程式依不同 damageable target unit 計數，沒有 enemy/breed gate；active 且可受傷害的危險物件也會進入 unique-target map。因此可在不是所有計數目標都為敵人的命中組合中加層，實際判定範圍比 RAW 用語寬。
