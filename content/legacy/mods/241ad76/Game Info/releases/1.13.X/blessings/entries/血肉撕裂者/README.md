# 血肉撕裂者(Flesh Tearer)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/5fb9da44-aabb-4e67-94b0-caa0a9d335a8" width="72" height="72" alt="血肉撕裂者祝福圖示">

- **觸發方式**：持用帶有祝福的戰刃或短刀，以近戰暴擊命中並造成傷害；處理命中事件時目標仍存活，才會施加流血。

- **等級效果**：I–IV 每次符合條件的命中新增5／6／7／8層流血；兩種武器數值相同。

- **命中條件**：不要求命中弱點或擊殺。一般近戰暴擊造成傷害即可觸發。

- **特殊攻擊**：戰刃的特殊攻擊被祝福排除；短刀的特殊動作是投擲，屬於遠程攻擊。

- **多目標**：同一揮擊若暴擊命中多名敵人，每個符合條件且仍存活的敵人各獲得一組層數；不限第一名目標。

- **層數上限**：同一敵人最多16層。相同流血效果共用層數，新的符合命中把層數補到上限。

- **流血傷害**：每約0.5秒跳傷一次，傷害隨當時流血層數變化；每層並非固定增加相同傷害。

- **層數消退**：最後一次施加或刷新後，約1.5秒開始退層。之後每次跳傷先按目前層數結算，再移除1層，直到全數消失。

- **再次施加**：新增層數會刷新1.5秒的退層等待期；滿16層再次觸發也會刷新。正在消退的流血因此能重新維持層數，跳傷節奏仍持續。

- **切換武器**：已存在的流血不因換武器而消失；新的觸發要求處理命中事件時仍持用帶有祝福的武器。

- **傷害分類**：流血跳傷屬於狀態傷害，並非新的近戰暴擊命中，不會自行再次觸發本祝福。

## 計算與算例

- **疊層**：IV級，原本沒有流血的敵人承受一次符合條件的暴擊後獲得8層；在退層前再次觸發，8+8=16層。第三次仍為16層，刷新等待退層的期限。

- **多目標**：同一次IV級暴擊揮擊對兩名存活敵人各造成傷害，兩名敵人各獲得8層。

- **退層**：停止施加後約1.5秒，開始按16→15→14→…→1→0消退，每約0.5秒跳傷並退1層。

- **總持續時間**：刷新時有8層，之後完全不再施加，名義上約需5–5.5秒退完；16層約9–9.5秒。範圍差異來自保留的跳傷節拍，另加固定更新的延遲。

- **傷害變化**：流血威力使用曲線計算，8層的輸入威力為250、16層為500；實際扣血仍依流血傷害設定、護甲與其他傷害修正結算。

## 遊戲描述勘誤

- 本體繁中「致命一擊」在這個祝福中指暴擊命中，不是擊殺。描述沒有列出近戰、傷害大於0與目標仍存活的條件。

- 流血設定的1.5秒是開始逐層消退前的期限；不是1.5秒後所有層數同時消失。

- 戰刃特殊攻擊與短刀投擲不能觸發；逐武器覆寫優先於共用父模板。
