# 亞空間斬(Warp Slice)

- **觸發方式**：冷卻就緒時，實際的掃掠開始事件若記錄當前武器特殊模式已啟用，就會啟動冷卻；不要求掃掠命中。事件開始冷卻後，ProcBuff 的就緒狀態要等後續一次 Buff 更新才刷新，keyword cache 再於該次更新後重建，因此冷卻啟動與保證暴擊關鍵字移除不一定發生在同一批更新。
- **卡面冷卻**：I／II／III／IV 為 30／25／20／15 秒；這些數字是秒數，不是暴擊率或傷害加成。
- **作用招式**：誓約 Mk VI、Mk VIII 烈焰力場巨劍啟用特殊模式後，符合武器自身條件的特殊輕擊或重擊掃掠會建立風斬效果。效果建立時讀取當下的一般暴擊狀態與已快取的祝福關鍵字；其中一項為真時，保存的暴擊旗標會沿用於風斬沿途有效命中。普通輕擊、普通重擊不會因本祝福自行變成暴擊。
- **推擊與額外攻擊**：純推擊、推擊擲出目標的攻擊、找目標動作不是本祝福的掃掠開始事件，不會觸發；連段後續若實際使用掃掠，仍依事件當下記錄的特殊模式旗標判斷。兩個適用型號的 action table 沒有投擲或飛行投射物動作；風斬是沿途查找目標的移動攻擊效果，不是生成投射物單位。
- **裝備、切換與卸下**：本祝福在武器裝備時加入角色的 on-equip Buff；首次裝備後要等 ProcBuff 更新並重建 keyword cache，才可讀到就緒關鍵字。只切到另一個欄位不會移除 Buff 或重設倒數；任何武器若確實走 ActionSweep 且其事件 payload 的 special_active 為 true，都可能在本祝福就緒時消耗冷卻。真正卸下該武器欄位會移除它的 on-equip Buff 與祝福狀態；之後重新裝備要重新經過 Buff 更新與 cache 重建。
- **取消與命中**：掃掠開始事件通過後，之後沒有命中或取消不會回滾已開始的冷卻。力場巨劍風斬在發射前仍檢查是否持用；風斬開始移動後會依保存的命中路徑完成剩餘行程。
- **層數與快取時點**：只有一個冷卻倒數，沒有可疊層數或另一個短效 TTL。固定更新先更新 Buff，再處理排隊的 ProcBuff 事件，最後重建 keyword cache；事件分支只記下冷卻起始時間，不會在同一分支更新 ProcBuff 的就緒 context。因此，觸發當次更新尾端可能仍保留舊的就緒關鍵字，直到後續一次 ProcBuff 更新判定正在冷卻並重建 cache 才移除。冷卻到期時則相反：ProcBuff 更新可先判定就緒，但 native 風斬仍讀取重建前的舊 cache；若同一更新內就開始風斬，不能保證讀到新關鍵字。


## 計算與算例

- **前提**：誓約 Mk VI 烈焰力場巨劍裝有本祝福，I 級冷卻已就緒；特殊模式已啟用。首次裝備後已有一次 ProcBuff 更新與 keyword-cache 重建，保證暴擊關鍵字已在 cache；武器特殊掃掠可建立風斬。
- **代入**：特殊輕擊掃掠於 t=100 秒開始，ActionSweep 事件記錄 special_active=true；I 級冷卻為 30 秒。
- **結果**：事件通過就緒檢查，ProcBuff 從 t=100 開始冷卻，最早 t=130 再次就緒。風斬效果讀取建立當下的 keyword cache 並保存暴擊旗標；觸發事件只更新冷卻起始時間，同一更新尾端的 cache 可能仍保留舊的就緒關鍵字，之後一次 ProcBuff 更新才會把 context 改為冷卻並在該次 cache 重建移除關鍵字。快照不會被後續 cache 更新回溯改寫。即使沒有命中，冷卻仍已開始。
- **玩家意義**：觸發點是特殊模式掃掠開始，不是命中；快取移除要等後續 Buff 更新，暴擊旗標則在風斬建立時決定。

- **前提**：祝福裝在誓約 Mk VIII 烈焰力場巨劍的欄位，IV 級就緒且就緒關鍵字已快取；切到另一把有 ActionSweep 動作的武器。該武器的掃掠事件確實帶 special_active=true。
- **代入**：另一把武器於 t=200 秒開始掃掠並消耗冷卻；IV 級冷卻為 15 秒。觸發後至少已經過一次 ProcBuff 更新與 keyword-cache 重建；t=207 切回力場巨劍，特殊能量足以開始一次風斬。
- **結果**：冷卻從 t=200 計時至 t=215。t=207 的風斬開始時祝福仍在冷卻，先前就緒關鍵字已在後續更新中移除，因此只會沿用一般暴擊狀態。若 t=215 的 ProcBuff 更新完成後才開始風斬，並且其間沒有另一個掃掠事件消耗就緒狀態，尾端 cache 重建後的新風斬才可讀到保證暴擊關鍵字；若風斬在該次 cache 重建前建立，仍讀舊 cache，不能保證暴擊。
- **玩家意義**：只切欄位不會移除 Buff 或重設倒數；另一武器的特殊掃掠可以消耗就緒機會，冷卻到期與新關鍵字進入 cache 之間仍有一次更新時序差。
