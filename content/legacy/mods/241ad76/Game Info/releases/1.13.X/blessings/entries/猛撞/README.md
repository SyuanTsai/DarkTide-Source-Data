# 猛撞(Bash)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

- **觸發方式**：持用適用武器時，推擊處理到至少一個合格目標（通過碰撞篩選並有可用推擊傷害設定），就在該次推擊處理完後啟動效果；推空不觸發。目標不必實際受傷或踉蹌，耐力不足的弱推仍可觸發。

- **撬棍**：科技教士型號6的I／II／III／IV級分別提高5／7.5／10／12.5個百分點的近戰爆擊率，持續3秒。

- **砍刀**：奧格林砍刀各適用型號的I／II／III／IV級分別提高7.5／10／12.5／15個百分點的近戰爆擊率，持續3秒。

- **首次生效**：第一次有效推擊後即取得該級全額加成；推擊本身固定不爆擊，隨後的普通、蓄力攻擊及推後攻擊在出手判定時可以受益。

- **刷新與移除**：同一次推擊碰到多個目標，也只啟動一份效果。期間再次有效推擊會重設3秒期限；加成不疊加，沒有額外冷卻，期限結束後消失。

- **切換武器**：切出時加成暫停，3秒期限繼續倒數；到期前切回原武器，恢復剩餘時間的效果。離手期間其他武器的推擊不會替它刷新。

- **特殊攻擊**：撬棍切換姿態本身不觸發；奧格林砍刀的上勾拳會按近戰爆擊率判定，可受加成，但上勾拳本身不觸發推擊效果。

- **加成範圍**：加成加入近戰爆擊機率池；實際判定另受100%上限、機率轉傷害效果及整數百分比取整影響。

## 計算與算例

- **算例前提**：假設其他來源合計的近戰爆擊機率池為20%，沒有機率轉傷害效果；以下只比較猛撞的加成。

- **首次生效**：撬棍IV級有效推擊後，後續攻擊的機率池為20%＋12.5個百分點＝32.5%；實際抽取前取整為33%。砍刀IV級為20%＋15個百分點＝35%。

- **相對增幅**：撬棍的機率池相對增加(32.5%－20%)÷20%＝62.5%，砍刀為(35%－20%)÷20%＝75%；這些是機率池的增幅，傷害仍依命中是否爆擊及武器結算。

- **逐級數值**：相同前提下，撬棍I–IV級的機率池為25%／27.5%／30%／32.5%，抽取前為25%／28%／30%／33%；砍刀為27.5%／30%／32.5%／35%，抽取前為28%／30%／33%／35%。

- **刷新算例**：t＝0有效推擊後，期限到t＝3；t＝2再次推到目標，期限改到t＝5，加成仍是一份。同次推到三個目標也不變成三份。

- **切換算例**：t＝0觸發、t＝1切出、t＝2切回，恢復剩餘約1秒；t＝3到期。離手期間推擊不能刷新原武器的期限。

- **機率上限**：若其他來源已有95%，撬棍IV級加算至107.5%，實際機率池截為100%；砍刀IV級加算至110%，同樣截為100%。
