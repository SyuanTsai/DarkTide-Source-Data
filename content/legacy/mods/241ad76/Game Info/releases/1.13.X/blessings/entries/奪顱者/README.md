# 奪顱者(Headtaker)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/5b4b4b01-18ea-447d-99d6-e73dd2ebdcfd" width="72" height="72" alt="奪顱者祝福圖示">

- **觸發方式**：使用裝有奪顱者的適用近戰武器，命中該次攻擊開始時仍存活的敵人，且該命中段會觸發祝福；事件被處理時仍須持用這把武器。每次合格命中增加一層，不需要暴擊或擊殺。
- **效果與層數**：每層提高近戰威力，最多 5 層。合格命中事件被處理後，重新開始 3.5 秒的共同計時；期間沒有新合格命中，到期時清除全部層數。滿層命中也會刷新期限。
- **I–IV 數值**：突擊鏈斧、戰鬥斧、戰術斧、戴維爾戰鎬與雷鎚，每層分別增加 3.5%、4%、4.5%、5% 近戰威力；重劍圖妥斯基 Mk VI／VII／IX 則為 6.5%、7%、7.5%、8%。實際最終傷害、踉蹌和順劈效果還取決於各自曲線及目標。
- **一般攻擊與追擊**：六系列的普通輕擊、重擊及推擊後直接追擊可提供合格近戰命中；純推擊不加層。
- **特殊攻擊**：鏈斧特殊啟用後的初始主攻擊、重劍第二段特殊斬擊、戰鎬特殊直擊，以及雷鎚蓄能後的直接揮擊可計層；按下啟用或切換特殊狀態的按鍵而沒有命中，不會觸發。
- **鏈斧追加傷害**：黏住目標後的追加鋸齒段會略過祝福命中事件，因此不增加層數；合格的初始主攻擊仍可加層。
- **首次生效與多目標**：命中傷害先結算，再處理加層與屬性更新；產生該層的那次傷害不回溯受益。後續攻擊在屬性更新後才使用新值，同一批已結算的命中也不回溯。一次揮擊命中多個目標，每個實際送出合格事件的命中都可加一層。
- **切換與移除**：切出武器時威力加成暫停，3.5 秒計時繼續；期限內切回，屬性更新後可恢復剩餘層數。其他武器命中不能替這把武器加層；卸下武器或移除祝福會清除其層數。
- **共同期限**：所有層數使用同一個計時器，每層不各自倒數；到期便一次清除。

## 計算與算例

- **一般五系列，IV 級滿層**：假設近戰威力曲線換算後、尚未乘合併威力加成的基值 B=500，且沒有其他同階段加成。一般五系列每層 +5%，因此輸入為 500 × (1 + 5×0.05) = 625，威力輸入 +25%。
- **既有同階段加成**：一般五系列 IV 級滿層，假設曲線換算後的同一威力池另有 q=20%。既有基線為 500×(1+0.20)=600；加入祝福後為 500×(1+0.20+5×0.05)=725，相對既有威力輸入增加 (725−600)÷600 = 20.83%，不是把 1.20 再乘 1.25。
- **重劍差異**：重劍 IV 級滿層、q=0 時，500×(1+5×0.08)=700，是該威力輸入 +40%。算例都停在威力輸入階段；最終結果還受傷害／踉蹌／順劈曲線及目標因素影響。
