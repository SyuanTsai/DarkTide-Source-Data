# 擊倒(Smackdown)

- **觸發方式**：持用裝有本祝福的戰刃或惡霸棍棒，以具武器特殊標記的近戰攻擊命中在祝福檢查時仍處於踉蹌狀態的小兵；被效果視為踉蹌的目標也符合。戰刃卡塔昌 Mk III、Mk VI 的特殊拳擊，以及惡霸棍棒三型號的兩種特殊拍擊都符合；布倫特得意之作 Mk II 在特殊拍擊後接出的拳擊也有特殊攻擊標記。目標不必在攻擊開始前已踉蹌；若這次命中使目標進入踉蹌且事件檢查時狀態仍有效，也符合。

- **效果**：合格命中被祝福事件處理後，持用同一武器時，近戰暴擊機率增加 I 級 +12.5、II 級 +15、III 級 +17.5、IV 級 +20 個百分點，持續 4.5 秒。這是機率輸入的加算，不是暴擊傷害或最終傷害倍率。

- **其他攻擊**：戰刃與惡霸棍棒的一般輕擊、蓄力重擊、推擊後追斬可在窗口內使用加成，但不觸發或刷新；純推擊沒有近戰暴擊擲定。布倫特猛擊 Mk IIIb 雖有名為拳擊的輕擊動作，實際使用一般傷害設定，不能以該攻擊觸發。

- **首次生效**：近戰掃掠在動作開始時擲定並保存暴擊旗標。若開始動作時沒有有效窗口，觸發加成的那次命中不會回頭改變自己的暴擊結果；同一次掃掠其他命中也沿用已保存的旗標。狀態與屬性快取更新後開始的新動作才讀到加成。若動作開始前已有有效窗口，該次特殊攻擊可以受益，也可在合格命中後刷新時間。

- **刷新與層數**：每次合格命中在祝福事件處理時重新啟動 4.5 秒計時；暴擊機率只有一份有效層，不會每次命中再疊一份。期限移除後，再命中踉蹌中的小兵可重新啟動。

- **切換與移除**：只有持用裝有祝福的那把武器時，這項暴擊機率才作用，也只有該武器的命中能觸發或刷新。切到另一武器時加成暫停，4.5 秒仍繼續倒數；在期限前切回且屬性快取更新後，可恢復剩餘時間。把該武器從裝備欄移除時，祝福與其子狀態一併移除。

## 計算與算例

- **前提**：把近戰暴擊擲定的輸入機率視為基礎 5%，沒有其他加成、機率上限、暴擊率轉傷害換算或強制／禁止暴擊；這不是單次擲骰結果。

- **IV 級，沒有同類加成**：5% + 20 個百分點 = 25%。本祝福令機率輸入增加 20 個百分點；相對原本 5% 增加 (25%−5%)÷5%=400%。

- **IV 級，已有其他加算 q=10 個百分點**：生效前 5%+10%=15%；生效後 5%+10%+20%=35%。差額仍是 20 個百分點，相對 15% 輸入增加 (35%−15%)÷15%=133.33%；不是把原本 15% 乘上 1.20。

- **作用階段**：實作先將基礎機率、一般暴擊機率、近戰暴擊機率與武器操作修正加總，再 clamp 到 0–100%；接著才套用暴擊率轉傷害設定。若有轉傷、上限、保證／禁止暴擊或特定動作覆寫，實際擲定會與純加算例不同。
