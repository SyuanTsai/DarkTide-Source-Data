# 破碎衝擊(Shattering Impact)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/4f6afe3b-84a0-4de9-826a-1bda5e3594b5" width="72" height="72" alt="破碎衝擊祝福圖示">

- **觸發方式**：使用帶有此祝福的武器命中敵人。四種適用武器的遠程直接命中都會觸發；擲彈兵臂鎧與震盪槍的爆炸也會觸發。

- **等級效果**：I–IV 每次符合條件的命中施加1／2／3／4層脆弱。

- **每層效果**：每層脆弱提供2.5個百分點撕裂；同一目標最多16層，合計40個百分點撕裂。

- **持續時間**：脆弱持續5秒。再次施加層數會刷新整組期限；已達16層時再觸發也會刷新。

- **爆矢槍**：洛克矛頭爆矢槍的直接命中會觸發；爆矢爆炸不會施加此祝福的層數。

- **擲彈兵臂鎧**：布拉斯托姆擲彈兵臂鎧的投射物直接命中、一般榴彈爆炸及特殊爆炸拳的爆炸都會觸發；近戰揮擊與爆炸拳的直接拳擊不會。

- **震盪槍**：洛倫茲 MkVI 震盪槍的直接命中與爆炸命中都會觸發。

- **電漿槍**：M35熔岩核心電漿槍的直接命中會觸發；過熱爆炸不會施加此祝福的層數。

- **同一目標多次受擊**：若同一目標受到多次符合條件的命中，每次各施加一組層數。例如臂鎧的直接命中與爆炸都擊中同一目標時，兩次命中都能疊層。

- **傷害時序**：這次命中的傷害先結算，之後才施加脆弱。新增層數不會回溯提高這次傷害，供脆弱生效後的後續攻擊使用。

- **共同作用**：脆弱附在敵人身上。期限內其他玩家或武器攻擊同一目標，也會讀取它的撕裂效果；同名目標減益共用層數與期限。

- **切換武器**：已施加的脆弱不會因切換武器而消失。新層數的觸發要求處理命中事件時仍持用帶有此祝福的武器。

- **傷害提升**：撕裂的效果取決於目標護甲類型與攻擊原有的裝甲倍率；40個百分點撕裂並不等於固定增加40%傷害。

## 計算與算例

- **條件**：IV級；目標護甲的撕裂係數為1（例如裝甲類型）；比較同一種攻擊，裝甲結算前傷害100、原裝甲倍率50%，沒有其他撕裂或傷害修正。

- **首次命中**：裝甲階段傷害仍為100×50%=50；這次命中結算後施加4層脆弱，共10個百分點撕裂。

- **後續攻擊**：4層脆弱生效後，相同攻擊的裝甲倍率由50%提高至60%；該階段傷害由50變成60，增加10點，相對增加20%。

- **疊到上限**：每次新增4層，在期限內由4→8→12→16層。第5次仍維持16層，並刷新5秒期限。

- **護甲差異**：滿層時，若原裝甲倍率為10%，相同100點攻擊的裝甲階段傷害由10提高至50；若原倍率為90%，則由90提高至107.5。

- **計算範圍**：以上比較裝甲結算階段；後續弱點、暴擊、傷害減免等仍會影響最終扣血量。

## 遊戲描述勘誤

- 本體描述只寫「投射物直接命中」，未列出符合觸發的爆炸：擲彈兵臂鎧的一般榴彈爆炸、特殊爆炸拳的爆炸，以及洛倫茲 MkVI 震盪槍爆炸。這些爆炸被傷害設定視為遠程攻擊，因此也會疊層。
