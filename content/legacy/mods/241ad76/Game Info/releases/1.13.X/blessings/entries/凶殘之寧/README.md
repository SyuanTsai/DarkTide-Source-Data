# 凶殘之寧(Murderous Tranquility)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/be8c86da-c7a2-49b0-a25f-93df4bb03455" width="72" height="72" alt="凶殘之寧祝福圖示">

- **適用型號**：烈焰力場巨劍 誓約 Mk VI（forcesword_2h_p1_m1）與 Mk VIII（forcesword_2h_p1_m2）；兩者共用 I–IV 效果。

- **觸發方式**：一次近戰橫掃處理到目標序號為 3 或以上的合格近戰命中事件時，建立一次待處理的反噬降低。目標序號是目前掃掠結果的序號，不是先前累積的三次成功傷害；事件仍須通過遊戲的命中事件派送條件。

- **降低幅度**：I／II／III／IV 級分別從目前反噬比例減去 2／3／4／5 個百分點，最低降至 0。這是固定百分點，不是把目前反噬乘以 98%／97%／96%／95%。

- **事件批次**：同一批命中事件處理內，即使有多個符合序號條件的命中，也只留下同一個待處理旗標，之後降低一次；旗標消耗後，新的事件批次可再次觸發。它不是每次橫掃固定一次，也不是每個第 3 個目標立即各降低一次。

- **動作差異**：一般輕擊、重擊及武器特殊能力啟用後的近戰斬擊走合格橫掃；特殊狀態啟動／取消本身不是本祝福的近戰 on_hit；特殊充能斬擊本體可觸發，額外發出的風刃範圍攻擊不符合近戰條件。推擊本身是另一種攻擊事件，不符合近戰命中條件；推擊後接出的橫掃才可能符合，兩型號的甩擊走遠程傷害事件，與額外風刃一樣不符合近戰條件。

- **持有與切換**：檢查命中事件時須仍持有此武器槽。若合格事件已通過檢查並存下旗標，下一次祝福更新仍會消耗它，即使在兩次更新之間切出武器；若在事件檢查前已切出，則不會建立旗標。沒有持續層數或倒數時間。

- **實際結果**：降低的是目前反噬比例，不是武器熱量，也沒有直接傷害倍率。若降低前處於爆裂狀態，來源另有中斷 Psyker 能力的分支；不代表一定存活。

- **首次生效**：合格命中先留下待處理旗標，於下一次祝福更新扣除反噬；多個同批事件不會各自立即扣除。旗標消耗後即可由新批事件再次建立，沒有另設觸發冷卻。

## 計算與算例

- **前提**：假設目前反噬為 70%，裝備 IV 級；一次近戰攻擊產生合格的目標序號 3 事件，且事件檢查時仍持有武器槽。
- **代入**：幅度 = 5 個百分點；新反噬 = clamp（70% − 5 個百分點，0%，100%）= 65%。相對起始 70% 的降幅為 5÷70≈7.14%，實作不是「目前值乘 95%」。
- **批次差異**：同一事件批次又有序號 4、5 的合格事件，仍只降一次：70%→65%。旗標消耗後，下一批次再符合才可 65%→60%。
- **下限**：IV 級從 3% 開始時，clamp（3%−5 個百分點，0%，100%）=0%。
