## 執行與計算

- 此實作直接複製近戰型通用 ProcBuff；Buff 不是預測型，監聽 `on_hit`。實際檢查依序要求同一 trait item、命中傷害大於 0，以及「近戰暴擊或 shout 暴擊」；同時 `ConditionalFunctions.is_item_slot_wielded` 要求武器仍在手持槽位。它沒有 `cooldown_duration`、`active_duration` 或自己的堆疊計時。`allow_weapon_special = true` 使特殊武器攻擊不會被目標加層 helper 排除，但仍須符合 item、持用、傷害及暴擊條件。
- 三個 Force Sword P1 Mark 的普通動作表均以 `ActionSweep` 執行近戰掃掠，事件包含暴擊旗標、傷害、物品與攻擊類型；特殊模式使用同一掃掠的 `damage_profile_special_active`／`damage_type_special_active`，不是獨立的遠程射擊路徑。因此普通或特殊近戰命中只有在實際成為暴擊且造成傷害時才可觸發。特殊啟用只切換武器模式，不產生符合檢查的傷害命中。
- 純推擊仍會送出一般命中事件，但 attack type 為 `push`，不符合此 ProcBuff 的 melee/shout 暴擊條件。三個型號的 push-follow 先找目標，再由 `ActionDamageTarget` 以 `attack_types.ranged` 執行命中；它也不符合。靈魂之火週期傷害的 attack type 是 `buff`，所以不會遞迴觸發同一暴擊祝福。
- I–IV tier 覆寫目標加層 helper 的每次請求數與此祝福的 tier cap：1/3、2/6、3/9、4/12。Helper 讀的是受擊目標目前共享的 `warp_fire` 堆疊，而不是此武器獨有的計數；目標需要存活並有 BuffExtension。新增量依 `min(每次請求數, max(本級上限 − 目前層數, 0))` 計算。新增層會刷新目標既有堆疊的開始時間；若新增量為 0 且目前層數不高於本級上限，也明確刷新期限；若目前層數高於本級上限，則零層迴圈不執行，沒有加層或刷新。
- 目標 `warp_fire` 是非預測型 IntervalBuff，最大 31 層，基礎 duration 8 秒（IntervalBuff 可讀取適用的 owner burning_duration 修正）、interval 0.75 秒、`interval_stack_removal` 開啟，且加層刷新開始時間。首次週期更新會在套用後超過 0.75 秒門檻的後續更新造成傷害；加層刷新開始時間不重設下一次週期時間。期限到後的到期週期更新先造成傷害，再移除一層。每次週期傷害以目前總層數除以 31 得到 x，再計算 `500 × x² × (3 − 2x)` 作為 Power Level，使用 warpfire 傷害 profile；最終生命傷害另受 profile、目標護甲及其他結算影響。
- 切槽會使父 ProcBuff 的持用條件不成立，因而阻止新觸發；但目標上已存在的 `warp_fire` 不由手持條件控制，繼續計時並衰退。卸下武器會移除裝備中的父 Buff，但不會回溯清除已加到敵人的堆疊。

- M1／M2 的指定輕／重 ActionSweep 使用 light_sticky／heavy_sticky；其黏附追加傷害透過 Attack.execute 傳同一武器、近戰攻擊類型與當下暴擊旗標，profile 沒有略過 on_hit 的設定，因此正傷害暴擊追加命中可再次符合本祝福。閃避脫離黏附時另用 sticky_dodge_push，其 attack 與各護甲攻擊修正皆為 0，故不滿足正傷害條件。M3 使用不同 special class 且沒有這些 sticky 設定。

令 `A` 為該級每次請求的層數、`C` 為該級上限、`S` 為目標目前共享的靈魂之火層數：

- I–IV：`(A, C) = (1, 3)、(2, 6)、(3, 9)、(4, 12)`。
- 新增量：`N = min(A, max(C − S, 0))`。
- 若 `N = 0` 且 `S ≤ C`，helper 刷新目標既有靈魂之火開始時間；若 `S > C`，helper 傳入 0 層而不刷新。
- `warp_fire` 的週期 Power Level：令 `x = S ÷ 31`，`P = 500 × x² × (3 − 2x)`。每 0.75 秒檢查一次，8 秒期限到後開始逐次移除一層。這是傷害計算輸入，不是固定生命傷害。

Trait formatter 讀 tier override 的整數層數，以 `number` 格式呈現；RAW 沒有百分比或額外加號。最終目標傷害由 warpfire profile、目標與實際傷害結算決定，不能把堆疊比例當成最終傷害倍率。
