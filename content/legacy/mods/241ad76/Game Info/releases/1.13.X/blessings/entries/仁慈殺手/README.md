# 仁慈殺手(Mercy Killer)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/b9fd0379-1424-48e1-8f8b-d7fbef8c9388" width="72" height="72" alt="仁慈殺手祝福圖示">

- **觸發方式**：持用帶有仁慈殺手的武器，以近戰攻擊命中弱點，且目標在該次傷害計算時已有流血狀態，便可取得加成；不需要先擊殺。這項祝福不會自行施加流血。
- **等級與作用部分**：I／II／III／IV 級向弱點／精準額外傷害乘區加入 52.5%／55%／57.5%／60%。它與既有同乘區加成相加，不會把整筆命中傷害乘上 1.525–1.60；目標流血層數也不會逐層放大這個加值。
- **首次生效**：第一次對已有流血狀態的目標造成合格近戰弱點命中，就能受益。若流血只在本次傷害結算後才新增，不能追溯增加這一擊；後續命中也須在計算時讀到已更新的流血狀態，不保證同一更新批次的下一擊已符合。
- **普通與特殊近戰**：四款型號的輕擊、重擊及推擊後追擊，各自判斷弱點與流血。戰刃卡塔昌兩款型號的特殊拳擊也是近戰 sweep，符合條件便可受益；前一段符合，不代表後續命中自動符合。
- **投擲與持續傷害**：短刀的特殊投擲屬遠程攻擊，不適用；它附帶的神經毒素也不是流血。純推擊不符合近戰攻擊類型；流血自身的持續傷害屬效果傷害，不會因這項祝福增加。
- **期限、切換與移除**：本祝福沒有自身觸發冷卻、疊層或期限。流血狀態消失後不再符合；切離這把武器時持用條件失效，切回後按當時條件重新判定。移除祝福後不再提供此加成。

## 計算與算例

- **前提**：持用本項武器，對已有流血狀態的目標造成一次近戰弱點命中，非本祝福影響的其他傷害部分為 200，弱點／精準額外部分在加成乘區前為 100；其他同乘區增量皆為 0，故原乘數 S=1。後續部位、背刺、減傷等因素均不改變結果，也沒有力場覆寫。
- **代入與結果**：無本祝福的最終傷害為 `200 + 100 × 1 = 300`。I 級為 `200 + 100 × (1 + 0.525) = 352.5`；IV 級為 `200 + 100 × (1 + 0.60) = 360`。IV 比無祝福多 60，最終傷害相對增加 `360 ÷ 300 − 1 = 20%`，並非 60%。
- **等級比較**：I 與 IV 的加成相差 7.5 個百分點；額外部分由 152.5 到 160，相對增加約 4.92%。同例的最終傷害由 352.5 到 360，相對增加約 2.13%；兩種相對增幅不可混用。
- **已有同乘區加成**：保持其他傷害 200、原額外部分 100，但原乘數改為 S=1.40。IV 級把乘數加為 `1.40 + 0.60 = 2.00`，最終傷害由 `200 + 100 × 1.40 = 340` 變為 400，相對增加約 17.65%；不是 `1.40 × 1.60`。
- **條件不成立時**：目標尚無流血、沒有命中弱點、純推擊或特殊投擲，都不取得本祝福增量；原有其他傷害仍照各自機制計算。
