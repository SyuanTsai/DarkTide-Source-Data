# 勢不可擋(Unstoppable Force)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

- **觸發方式**：當祝福武器仍在已裝備的武器槽位，完全蓄力輸入所產生的近戰重型掃掠會在傷害結算時讀取本祝福傷害增量。程式以動作輸入的自動完成旗標和傷害 profile 的重型近戰分類判定，不以動作名稱判斷。
- **傷害加成**：I–IV 級分別增加 2.5%、5%、7.5%、10% 的近戰完全蓄力傷害 stat。這是傷害計算的一項增量；實際傷害仍會受到武器 profile、目標護甲與其他修正影響。
- **命中質量**：符合自動完成條件的掃掠會讀取「完全蓄力攻擊無限貫穿」關鍵字，把可命中的敵人命中質量上限設為無限。這不會略過 breed 中止或其他獨立攻擊限制。
- **裝備與切換**：傷害 stat 和貫穿關鍵字是裝備祝福武器時加入玩家快取的普通效果；切到其他武器不會移除它們，消費端也不檢查攻擊物品，因此其他武器符合條件的完全蓄力近戰重擊也可能讀到。把祝福武器卸下才會移除。
- **裝甲攻擊中止例外**：祝福武器必須正在手持；重型近戰掃掠開始時產生事件，事件處理並更新關鍵字快取後，才會暫時忽略 `Armor.aborts_attack`。這項額外效果只改裝甲中止判定；不要求該次掃掠已完全蓄力，也不會略過 breed 中止。
- **特殊／推擊限制**：特殊模式切換本身不觸發；之後的攻擊仍依實際 profile 判定。純推擊不屬於重擊掃掠。M2 Mk III 有一個名稱含「light」的直接推擊追擊，但它實際使用重型 profile、預設輸入沒有自動完成旗標，因此只可能符合持用中的裝甲中止例外，不取得完全蓄力傷害或貫穿效果。三個實際武器族的五個型號均沒有投擲或遠程攻擊動作。
- **時限與中斷**：祝福沒有層數、冷卻或固定秒數；普通傷害與貫穿效果維持到祝福武器卸下。裝甲例外以單一 active 狀態在重型掃掠開始時設為啟用，掃掠結束事件處理後清除。若 M2 直接追擊在傷害視窗前被格擋中斷，且開始事件已處理而該次結束沒有送出 Buff 結束事件，active 可能殘留；切槽只會讓持用條件失效，不會自行清除此狀態。正常進入傷害視窗並結束的掃掠會送出清除事件。

## 計算與算例

- **範例一：完全蓄力重擊傷害**
  - **前提**：祝福為 IV 級；某符合條件的自動完成重型近戰攻擊，在套用本祝福前的傷害計算基礎值假設為 200，其他修正先不列入。
  - **代入**：`200 × 10% = 20` 點傷害增量。
  - **結果**：該攻擊的傷害計算值成為 220，之後仍會套用 profile、護甲與其他遊戲修正。
  - **玩家意義**：卡面 +10% 是合格攻擊的一項傷害加成，不保證最後跳出的傷害數字恰好增加 10%。
- **範例二：蠻牛屠夫 Mk III 直接推擊追擊**
  - **前提**：使用 Ogryn 砍刀「蠻牛屠夫 Mk III」，走推擊後直接接上的 `action_right_light_pushfollow`；該掃掠選用的 profile 是重型，但此直接追擊的輸入未標記自動完成。
  - **代入**：裝甲例外看 profile 是否為重型且祝福武器是否正手持；傷害加成與貫穿則還需要自動完成旗標。
  - **結果**：若開始事件已處理且關鍵字快取已更新，這條路徑可得到裝甲中止例外；但不取得 +2.5%–10% 傷害或無限貫穿。
  - **玩家意義**：看起來像「輕擊」的動作名稱不能決定結果；重型 profile 和自動完成是分開檢查的兩個條件。
