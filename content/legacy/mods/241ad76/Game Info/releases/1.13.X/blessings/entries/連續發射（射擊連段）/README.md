# 連續發射（射擊連段）(Blaze Away)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a8cc8dc4-8ad6-4da4-9949-7061743f05f4" width="72" height="72" alt="連續發射（射擊連段）祝福圖示">

- **觸發方式**：裝備本祝福並持用適用武器時，效果讀取該武器目前的動作連段計數；每個符合原生連段規則的武器動作開始，可增加一個有效步，不要求命中或擊殺。

- **每步效果**：等級 I–IV 每個有效步增加一般攻擊威力修正池：擲彈兵臂鎧與電漿槍為 5%、6%、7%、8%；反衝者、震盪槍與惡棍槍為 6%、7%、8%、9%。最多按 5 步計算，其他 Power 修正另行合併。

- **連段計數**：一次動作開始最多計一次；散彈多顆彈丸、投射物命中／爆炸、或一次蓄力射擊消耗多發彈藥，都不會將該動作拆成多步。蓄勢、瞄準、特殊動作與裝填依各 Mark 的保留／重設設定處理。

- **臂鎧近戰與特殊攻擊**：布拉斯托姆 Mk III 的普通近戰 sweep 每次動作開始增加一步。特殊蓄勢 windup 保留連段；開始特殊重擊 melee_explosive 時重設計數，不增加一步。該重擊使用近戰揮擊；符合掃掠中斷與彈藥條件時，再由玩家本體直接發起爆炸。爆炸使用當下玩家 stat／快取，不是榴彈發射時保存的投射物快照；連段重設後也不要假設先前步數在快取更新後仍存在。

- **保留與中斷**：本祝福沒有自己的逐步倒數計時；武器動作可以增加、保留或重設連段。非循環動作結束後，超過該 Mark 的連段重設時限才因逾時清零：Gauntlet、Kickback、Rumbler、Plasma 為 0.5 秒；Thugshot 使用預設 0.2 秒。特定動作仍可提早重設。

- **持用與切換**：威力修正只在對應武器持用時啟用。切出會關閉本祝福的持用效果；一般切槽會進入不增加／保留連段的持用動作，通常清除該武器動作元件的連段；切回後須重新建立。卸下對應裝備槽時，祝福 Buff 會移除。

- **首次生效與投射物**：動作開始更新連段後，Buff/stat 快取更新才會反映新一步，不回溯修改已結算攻擊。擲彈兵臂鎧與震盪槍榴彈在發射時保存玩家力量快照；快照已含有效步時，延後爆炸仍可使用該修正；切出不改寫已生成投射物。若新步尚未寫入快取，不保證它已進入快照。

- **效果讀法**：百分比增加一般攻擊威力修正池，會進入 Power／傷害曲線計算；護甲、命中部位、距離、武器設定檔及其他修正仍改變結果，不能直接當成相同比例的最終生命傷害。

## 計算與算例

- **算例一：反衝者 洛倫茲 Mk V（ogryn_thumper_p1_m1，等級 I）**
  - **前提**：成功開始 3 個可增加連段的散彈動作；每步 p=0.06，其他 Power 修正中性。
  - **代入**：K=min(5,3)=3；M=1+K×p=1+3×0.06=1.18。
  - **結果**：一般 Power 修正池比中性值增加 0.18（18 個百分點）。
  - **玩家意義**：一次散彈動作只加一步，多顆彈丸不各加一步；1.18 不是固定增加 18% 生命傷害。

- **算例二：擲彈兵臂鎧 布拉斯托姆 Mk III（ogryn_gauntlet_p1_m1，等級 II）**
  - **前提**：榴彈發射時已有 2 個有效連段步且快取已更新；Tier II 每步 p=0.06，其他 Power 修正中性；此榴彈 profile 的靜態 Power 輸入為 500。
  - **代入**：K=min(5,2)=2；M=1+2×0.06=1.12；500 再沿玩家快照進入 PowerLevel／傷害 profile 結算。
  - **結果**：此快照的一般 Power 池因本項增加 0.12；靜態 500 不略過後續通用修正。
  - **玩家意義**：只有發射快照已含該步時延後爆炸才能讀取；0.12 是池內增量，不是爆炸最終傷害百分比，也不可直接換算成 500×1.12 的生命傷害。

- **算例三：電漿槍 M35熔岩核心 Mk III（plasmagun_p1_m2，等級 IV）**
  - **前提**：一次蓄力 hitscan 動作開始前 K=2，蓄力完成並開始射擊；其他 Power 修正中性。
  - **代入**：該動作令 K=3；Tier IV p=0.08；M=1+3×0.08=1.24。即使蓄力消耗 1–8 發彈藥，仍只是一個動作步。
  - **結果**：一般 Power 修正池比中性值增加 0.24（24 個百分點）。
  - **玩家意義**：耗彈量不決定步數；1.24 仍不是最終生命傷害倍率。
