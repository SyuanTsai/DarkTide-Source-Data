# 推進(Thrust)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/82bed9ff-831f-4905-bcc5-3101a43fa29c" width="72" height="72" alt="推進祝福圖示">

- **觸發方式**：持用適用近戰武器時，蓄力動作進入實際的 windup 階段後，會在該次蓄力動作設定的首個事件門檻（動作時間）送出首個蓄力事件；仍停留在蓄力動作 時，之後每隔0.25秒的動作時間可再增加一層，每次固定更新最多處理一次事件。每個事件增加一層，最多三層有效效果。事件不要求先命中敵人。固定更新順序使事件進入快取後才作用；在事件尚未經下一次增益快取更新前發生的攻擊，不保證能用到剛增加的層數。

- **每層與上限**：I–IV 每層分別提高近戰力量輸入修正 +5、+10、+15、+20 個百分點；三層時分別最多提高 +15、+30、+45、+60 個百分點。表內數值作用於近戰力量修正池，不等於同百分比的最終生命傷害。

- **堆疊與清除**：新的 windup 動作會先清除先前蓄力；純推擊、格擋、特殊開關或其他不保留蓄力的動作開始時，以及切換武器時，也會清除。已進入揮擊動作的攻擊保留當前蓄力，直到該次 sweep 結束。蓄力沒有另外的倒數期限；祝福移除時，其所建立的子增益一併移除。

- **推擊與推擊後追擊**：純推擊不是 windup，不會增加層數；它採用 push 攻擊類型，不讀取近戰力量修正。一般推擊後追擊是 sweep，能使用仍有效的層數，但推擊已先清除舊層，追擊本身也不增加層數。砍刀克魯克 Mk VI 與蠻牛屠夫 Mk III 都有專用的推擊後 combo windup，但路徑不同；克魯克 Mk IV 沒有這兩種專用路徑。Mk VI 的推擊後可進入獨立 windup，之後以重攻擊銜接；Mk III 則是右輕推擊後 combo。Mk III 可在右輕推擊後約 0.45 秒進入這段蓄力；首個蓄力事件要到動作時間 0.5 秒才送出。light 追擊本身沒有等待門檻，提前選它會立即離開蓄力，不會等到 0.5 秒。若保持蓄力直到事件送出並經下一次增益快取更新，再選 light，這個 light sweep 起始不會清除已建立的層數，首次傷害窗口在 sweep 開始後 0.2 秒。這是按蓄力階段觸發的特例，不代表最後的 light 攻擊是重擊。

- **特殊攻擊**：祝福只要求持用適用武器，不要求特殊狀態已啟用；特殊揮擊可使用當前有效層數。特殊狀態開啟／切換本身不是蓄力事件，且會清除既有層數。型號不同，特殊招式是否包含 windup 也不同，請見逐型號對應。

- **實際作用**：近戰揮擊的力量計算會把本祝福納入 damage、impact 或 cleave 等力量類型輸入，再依攻擊設定與目標狀態分配。這表示祝福提高的是力量輸入，不保證每一擊的最終傷害、踉蹌或穿透提高相同比例。

## 計算與算例

- **算例一｜前提**：S=500 是原生 power-type 曲線換算後、套用近戰力量修正前的輸入；IV 每層 p=.20，n=3，其他力量修正 q=0。此例只比較力量輸入。
- **算例一｜代入**：S′=500×(1+0+3×.20)=800。
- **算例一｜結果**：力量輸入由 500 變為 800，增加 300；修正池增加 60 個百分點，總輸入倍率為 1.60。
- **算例一｜玩家意義**：800 是後續 damage／impact／cleave 計算的力量輸入，不代表最終生命傷害提高 60%。
- **算例二｜前提**：S=500、其他修正 q=+.20；II 每層 p=.10，n=2，攻擊與目標的其他條件固定。
- **算例二｜代入**：未套祝福時 500×(1+.20)=600；套用後 500×(1+.20+2×.10)=700。
- **算例二｜結果**：力量輸入由 600 變為 700，增加 100；本祝福在修正池另加 20 個百分點，相對原 600 輸入增加 16.67%。
- **算例二｜玩家意義**：16.67% 只比較這兩個力量輸入值，不等於最終命中傷害提高 16.67%。
