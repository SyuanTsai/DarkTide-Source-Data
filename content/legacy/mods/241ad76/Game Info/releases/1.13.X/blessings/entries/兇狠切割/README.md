# 兇狠切割(Vicious Slice)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/f9d23b25-7f50-4ce8-8e49-00770ecc048b" width="72" height="72" alt="兇狠切割祝福圖示">

- **觸發方式**：持用帶有兇狠切割的「惡魔之爪」劍，每個送達本祝福的命中事件各請求一層。實際程式未執行原定的道具匹配與「同一次橫掃已啟動」檢查，範圍比描述寬；仍須持用此劍，未送出一般命中事件的額外傷害不會憑空加層。
- **效果與上限**：I／II／III／IV 每個有效層分別增加 14／16／18／20 個百分點的近戰衝擊修正，最多五層，合計 70%／80%／90%／100%。零層沒有這項增量；等級值只隨有效子層提供，沒有另加一份常駐效果。
- **作用階段**：加成提高進入後續踉蹌計算的近戰衝擊輸入，不增加生命傷害，也不保證擊倒或最終踉蹌幅度提高同樣百分比。
- **首次生效**：命中傷害與踉蹌先結算，命中事件處理並更新效果屬性快取後，後續合格近戰命中才可能使用新層；造成該層的命中不回溯受益。同一幀內已先完成的多個命中不會逐目標即時增加修正。
- **橫掃界線與同批清層**：橫掃開始及結束事件清除額外層；整批事件先合計命中加層，再處理清層。因此同批若含橫掃開始或結束，新加的層也會被清除，不能把敵人命中序號直接當成必定有效的層數。
- **期限、刷新與移除**：此祝福沒有獨立秒數期限、逐層衰退或觸發冷卻；額外層依上述橫掃事件清除。移除實際父效果時，會一併移除其控制的子層。
- **普通與特殊攻擊**：三型號的輕擊、重擊、推擊後追擊及成功格擋後的特殊反擊，均有實際近戰橫掃路徑，能依已更新的效果快取使用此修正。特殊格擋準備本身不造成命中，也不會直接給予層數。
- **純推擊**：純推擊也可由送達命中事件請求加層，但其衝擊使用獨立推擊分支，這次推擊不使用本祝福的近戰衝擊修正，也不造成生命傷害。後續橫掃開始事件仍會清除原有額外層。
- **切換武器**：切出此劍時，持用條件停用加層和衝擊增量；切換本身不等於卸下祝福。切回時，若額外層尚未被橫掃事件或父效果移除，持用條件恢復並更新快取後才可能重新提供增量。

## 計算與算例

- **前提**：IV 級，持用此劍，三個有效層已完成事件處理與屬性快取更新；該批沒有橫掃開始／結束清層事件。其他衝擊修正及目標因素中性，原衝擊輸入為 100。
- **代入與結果**：近戰衝擊乘數為 `1+3×0.20=1.60`，輸入變為 `100×1.60=160`，相對原輸入增加 60%。
- **已有同類修正**：若其他同類修正使原乘數為 1.20，三層 IV 加入 0.60 後為 `1.20+0.60=1.80`。同一基礎輸入 100 原為 120、新為 180，相對原 120 增加 50%，不是把 1.20 再乘 1.60 得到 1.92。
- **同批清層例外**：若三個命中事件與橫掃結束同批處理，先請求三層後立即清除；該批完成的有效層為零，而非持續三層。算例的 160 必須滿足快取已更新且未被清層的前提。
- **玩家意義**：160 是進入後續踉蹌計算的衝擊輸入；攻擊資料、目標抗性與踉蹌門檻仍決定實際結果。這不是最終傷害增加 60%，也不是保證任一敵人踉蹌。

## 遊戲描述勘誤

- **同次攻擊的命中限制**：英文與繁中 RAW 指同一次攻擊中已命中的敵人；實際用於限制相符道具及橫掃啟動狀態的檢查未被執行。持用時送達本祝福的命中事件可加層，包含純推擊事件，不限於原文所述同次橫掃；開始／結束事件清層與快取更新仍限制效果何時可用。精確欄位差異見[來源與公式](SOURCE_INDEX.md)。
