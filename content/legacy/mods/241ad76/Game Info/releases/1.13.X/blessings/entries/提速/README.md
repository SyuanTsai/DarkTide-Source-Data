# 提速(Rev it Up)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8a6ba0a3-cdaf-403f-a87b-3743b3fcfe97" width="72" height="72" alt="提速祝福圖示">

- **觸發方式**：持用裝有提速的武器，並成功啟動武器特殊動作才會觸發；普通攻擊、蓄力、推擊、特殊攻擊命中或後續鋸切本身都不會觸發。六個實際型號的特殊狀態都不能在仍啟用時再次啟動；必須先回到停用狀態，並通過超過 0.5 秒的事件間隔條件。

- **首次生效**：合格啟動事件送入 Buff 系統後，固定更新會先處理 ProcBuff 事件、再重建角色 stat cache；加成在這次更新後才進入移動速度計算。

- **效果**：依等級將 +17% 至 +20% 加入 movement_speed 的加算值，持續 2 秒。走路及衝刺都會讀取此速度值；衝刺另有獨立速度倍率。這項數字不是所有狀態下最後移動速度的固定增幅。

- **再次啟動**：只有武器特殊狀態先回到停用、再成功啟動時，祝福才會重新開始 2 秒計時；合格事件會刷新同一個效果，不會累積層數。停用本身不會刷新祝福計時。

- **持用與切換**：效果只在持用該武器時套用。切換到其他武器時加成暫停套用，但 2 秒計時繼續；若到期前切回，只恢復尚未用完的時間。卸下武器會移除此裝備所安裝的祝福效果。

- **到期**：從最近一次合格啟動起滿 2 秒後，祝福效果結束。

## 計算與算例

- **前提**：假設提速 IV 的加算值 h=0.20，其他 movement_speed 加算值 q=0.25；比較時角色基礎速度與其他固定倍率 m 不變。

- **代入**：啟動前速度為 V×(1+q)×m=V×1.25×m；啟動後為 V×(1+q+h)×m=V×1.45×m。移動速度加算池由 1.25 變成 1.45。

- **結果**：相對啟動前的速度比例為 1.45÷1.25−1=0.16，也就是在這個假設下快 16%；祝福加入加算池的 h=20 個百分點，並非最終速度一律增加 20%。

- **玩家意義**：此算例適用於相同走路或衝刺計算、其他倍率維持不變時；衝刺尚有自己的 sprint_movement_speed 倍率，動作也可能帶有額外倍率，所以不能把 +20% 當成每種狀態固定的最終增幅。

- **前提**：假設第一次合格特殊啟動事件在 t=0，特殊狀態之後已回到停用；並假設第二次成功啟動在 t=1.2，兩次都通過持用及超過 0.5 秒啟動間隔條件。

- **代入**：第一次祝福計時原定於 t=2.0 到期；第二次事件使 active_start_time 更新為 t=1.2，因此到期時間改為 t=3.2。

- **結果**：仍只有一個祝福效果，從第二次合格事件起再維持 2 秒，不會出現兩層或把數值相加。

- **玩家意義**：只有成功而且符合事件守門的再次啟動才刷新計時；特殊狀態停用或切換武器本身不會把計時重置。
