# 迅雷反射(Marksman's Reflex)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/51ba138d-a251-4d0f-9e71-557dc791caee" width="72" height="72" alt="迅雷反射祝福圖示">

- **觸發方式**：裝備帶有迅雷反射的震盪槍 洛倫茲 Mk VI，玩家攻擊實際判為弱點命中且通過共通命中篩選時，第一次合格命中便能啟動效果；不需要擊殺。實作沒有投射物或來源武器限制。
- **等級、首次生效與刷新**：I／II／III／IV 級提供 15%／20%／25%／30% 換彈速度加值。命中事件處理、玩家效果統計更新後生效；每次持續 3 秒，只有一份效果，再次合格命中會刷新為新的 3 秒，不累加層數，也沒有本祝福自身觸發冷卻。不保證同一影格在統計更新前已使用新值。
- **普通與瞄準射擊**：兩種射擊均有直接投射物命中；直接命中須由遊戲實際判為弱點。爆炸逐目標選取中心部位的碰撞區域，再按它的實際區域判斷弱點；不是固定軀幹，也不會把整圈爆炸目標自動當成弱點命中。
- **特殊近戰**：左、右槍身揮擊的實際弱點命中也能觸發或刷新；未判為弱點或被共通命中篩選排除的攻擊不符合。
- **切換與其他武器**：換到另一把已裝備武器不會移除本祝福；它的合格弱點命中仍能啟動／刷新。加成是玩家換彈速度統計，其他武器的裝填動作若使用這項速度也能受益。
- **期限與移除**：由最近一次合格事件處理起計，滿 3 秒後效果不再提供新速度加值；切換武器不重設這個期限。從裝備槽卸下／替換該震盪槍，或移除本祝福，則不再由這項 Buff 提供效果。
- **裝填採樣**：每段裝填動作開始時決定時間倍率；若這段動作仍在進行，開始後才取得、刷新、到期或移除的效果，都不會追溯改寫該段已保存的倍率。下一段動作重新依當時統計取樣。

## 計算與算例

- **前提**：假設只有這項加成、沒有其他 `reload_speed` 效果，動作時間倍率未被上下限改動；只看 Mk VI 一段 `action_reload` 設定的 2.333 秒時間段，不把它當完整空彈裝滿的實測時間。
- **代入**：IV 級 為 `b=0.30`，基準倍率為 `1+b=1.30`；換彈該段時間 `T=T0/(1+b)=2.333/1.30`。
- **結果**：`T≈1.795` 秒，較 2.333 秒少約 `23.08%`，而非少 30%。
- **玩家意義**：+30% 是加到基準為 1 的換彈速度倍率上，不等於換彈時間直接減少 30%；實際完整換彈還可能包含其他動作階段與額外修正。
- **對照**：I 級 同前提下為 `2.333/1.15≈2.029` 秒，這一段約少 `13.04%`。

## 遊戲描述勘誤

本體英文「on Projectile Weakspot Hit」與繁中「投射物命中弱點時」把觸發限定為投射物；實際 trait ProcBuff 使用通用 on_weakspot_hit，只檢查 hit_weakspot，且沒有來源武器／攻擊類型限制。當祝福仍裝備時，其他武器的合格弱點命中，以及此槍特殊近戰的合格弱點命中也可能觸發或刷新。這是實作觸發範圍比描述更廣的明確差異。
