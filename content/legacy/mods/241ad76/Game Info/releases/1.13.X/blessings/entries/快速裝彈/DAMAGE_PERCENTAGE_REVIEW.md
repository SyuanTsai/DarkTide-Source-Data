# 快速裝彈：百分比與結算

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

- `reload_speed` 是 `additive_multiplier`。令 `p` 為每有效層的等級值（0.07／0.08／0.09／0.10），`n` 為有效層數（0–5），`q` 為相同取樣時點的其他裝填速度加成合計。則速度倍率 `M=1+q+n×p`。
- 若同一裝填動作段的 handling、其他條件與 cap狀態相同，基準速度倍率是 `1+q`，加入本項後 `T₁=T₀×(1+q)/(1+q+n×p)`。逐發裝填的每個新動作段分別取樣；不能把一段比例直接當成跨多段 reload chain 的固定總時間縮短。
- q=0且5層時，I／II／III／IV速度加成分別+35%／+40%／+45%／+50%；對應單段時間比例為74.07%／71.43%／68.97%／66.67%。速度增加百分比與時間縮短百分比不同。

本項 I–IV、12 個實際 tier/wrapper、23 個型號接線、雙語 RAW/hash、close-kill runtime條件、12種實際 duration、reload action consumers與公式均已固定來源核對；本體 RAW沒有「滑行觸發」矛盾，因其實際可見描述本來就是近距離擊殺。
