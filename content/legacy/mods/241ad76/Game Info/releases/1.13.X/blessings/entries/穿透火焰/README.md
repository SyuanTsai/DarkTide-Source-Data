# 穿透火焰(Penetrating Flame)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/0836e233-112e-4757-85cb-ee040d1bd4f7" width="72" height="72" alt="穿透火焰祝福圖示">

- **觸發方式**：持用淨化噴火器或烈焰力場法杖，以火焰直接命中敵人；目標在處理命中事件時仍存活，才會施加脆弱。

- **等級效果**：I–IV 每次直接火焰命中分別新增1／2／3／4層；兩種武器的層數相同。

- **每層效果**：每層脆弱提供1個百分點撕裂。同一目標最多20層，合計20個百分點撕裂。

- **淨化噴火器**：短按噴火與持續噴射的直接命中都會觸發。

- **烈焰力場法杖**：短按火焰爆發與蓄力火焰攻擊的直接命中都會觸發；只蓄力、沒有命中時不會。

- **燃燒跳傷**：燃燒持續傷害不會再次施加此祝福的層數。目標不必已經燃燒；首次直接火焰命中就能觸發。

- **持續時間**：脆弱持續5秒。再次直接命中會刷新整組期限；達20層後再命中仍刷新期限。

- **傷害時序**：直接命中的傷害先結算，之後才施加脆弱；新增層數供生效後的攻擊使用，不回溯提高這次傷害。

- **共同作用**：脆弱附在敵人身上，隊友與其他武器攻擊同一敵人也會讀取它的撕裂效果。同名目標減益共用層數與期限。

- **切換武器**：已施加的脆弱不因換武器而消失；新層數要求處理直接命中事件時仍持用帶有祝福的武器。

- **傷害提升**：實際增傷依攻擊原有裝甲倍率、目標護甲類型與其他撕裂來源計算；20個百分點撕裂不等於固定增加20%傷害。

## 計算與算例

- **層數**：IV級每次命中新增4層。期限內連續5次命中，依序為4→8→12→16→20層；之後維持20層並刷新5秒期限。

- **裝甲算例前提**：裝甲結算前傷害100，原裝甲倍率10%，目標護甲的撕裂係數為1，沒有其他撕裂來源。

- **首次命中**：傷害仍按原倍率，在裝甲階段造成10點；這次命中結算後才施加4層脆弱。

- **滿層後攻擊**：20層提供20個百分點撕裂；相同攻擊的裝甲倍率由10%提高至30%，裝甲階段傷害由10提高至30，相對增加200%。

- **溢出效果**：同樣滿層，若原裝甲倍率為90%，先補10個百分點至100%，其餘10個百分點以四分之一效率計入。裝甲階段倍率為102.5%，傷害102.5。

- **計算範圍**：這些算例比較裝甲結算階段；後續部位、弱點與減傷仍會影響最終扣血量。

## 遊戲描述勘誤

- **觸發範圍補充**：本體描述使用「直接命中」；固定版本的實際入口是直接火焰命中事件，燃燒DoT跳傷本身不觸發。烈焰力場法杖的短按與蓄力火焰攻擊都須直接命中才會疊層。
