# 堅定打擊(Confident Strike)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/7b342f87-845c-4859-b77e-9e8e911146e9" width="72" height="72" alt="堅定打擊祝福圖示">

- **觸發方式**：手持裝有本祝福的武器，完成近戰掃掠後，該次掃掠須命中至少一個在命中登記時存活的角色敵人，且掃掠開始時記錄的連擊數大於 0。ActionSweep 會在造成傷害前快照目標存活狀態；即使本次掃掠隨後擊殺該目標，它仍計入命中數。此條件不要求造成正生命值傷害。開始時的內部計數器為 0；合格事件使計數器加 1，不合格事件則把它設為 1。只有計數器超過 1 時才恢復韌性，因此起始計數為 0 時，第一個合格事件不恢復，後續合格事件才恢復；若先發生不合格但已送出的掃掠結束事件，下一個合格事件即可使計數器到 2。中斷在掃掠傷害判定開始前、沒有送出結束事件的動作不改變計數器。

- **恢復量**：每次符合上述條件且計數器已超過 1，依武器實作與等級恢復最大韌性的 4%–8%。一般八個實作 I–IV 為 +5%、+6%、+7%、+8%；電弧鎚 布蘭克斯 Mk III 實作為 +4%、+5%、+6%、+7%。每次掃掠結束最多判定一次；一個掃掠直接命中多個敵人仍只發生一個事件。沒有持續加成、額外層數或獨立冷卻。

- **首次生效、刷新與上限**：每個合格掃掠結束事件只要計數器大於 1，就直接呼叫韌性恢復；這不是攻擊前預存的傷害加成，也不回溯改變剛結束的攻擊。計數器無上限；每個後續合格事件都可再恢復一次。已送出的不合格事件將計數器重設為 1；動作未送出事件時不會重設。

- **可觸發動作**：普通、蓄力與實際特殊模式中的近戰掃掠都按自己的掃掠結束條件判定。純推擊本身、特殊模式切換、準備動作與獨立吶喊攻擊不會送出這項祝福監聽的掃掠結束事件；若某型號的推後攻擊實際配置為近戰掃掠，例如廁所鏟 兇殘 Mk III 的右輕擊推後掃掠，則仍按該掃掠自己的直接命中數與開始時連擊快照判定。沒有實際投擲或射擊路徑綁定到這 19 個 Mark。

- **特殊傷害路徑**：阿克利斯 Mk I 動力錘的特殊爆炸附著在直接掃掠命中後；爆炸額外命中的目標不增加掃掠計數或額外觸發次數。電弧鎚 布蘭克斯 Mk III 的連鎖電弧是掃掠命中後的次級傷害，同樣不另送掃掠事件；其特殊推擊後吶喊是獨立路徑。作戰大錘&板盾的特殊動作是格擋，不會送出本祝福監聽的掃掠結束事件；其普通／重擊掃掠仍照一般條件判定。法務官電擊鎚和鎮壓護盾 布蘭克斯 Mk VI／Mk XI 的特殊吶喊是獨立路徑，不會送出掃掠結束事件；其實際近戰掃掠仍照一般條件判定。鏟類特殊模式須完成切換後的實際掃掠，切換本身不算。

- **韌性計算**：恢復量以當前計算出的最大韌性為基準，並受目前缺少韌性上限限制；韌性恢復加成倍率不會再乘上這次固定百分比。若韌性恢復被遊戲狀態停用，該次恢復為 0。

- **持用、切槽與移除**：效果來自裝備時加入的武器 Buff，但事件處理及恢復都要求該武器仍在手持槽。切到其他槽不會移除 Buff 或重設計數器，只是切槽期間不接受掃掠事件；切回後可從原計數狀態繼續。真正移除武器或其祝福會移除該 Buff；重新裝備後計數器從 0 開始。

## 計算與算例

- **範例一：起始掃掠與後續連擊**
  - **前提**：使用廁所鏟 兇殘 Mk III，I 級（weapon_id `ogryn_club_p1`、Mark `ogryn_club_p1_m1`）；使用該 Mark 的 `action_left_light` Sweep（`DamageProfileTemplates.ogryn_shovel_light_tank`）。最大韌性為 100、至少缺少 5，韌性恢復未停用，武器持續在手持槽。初始計數器為 0；第一個 `action_left_light` Sweep 開始時連擊快照為 0，且直接命中一個在命中登記時存活的角色敵人；它的結束事件送出後，依實際連鎖先進入 `action_melee_start_right` 起手式，再連到 `action_right_light` Sweep，兩者使用相同的 `DamageProfileTemplates.ogryn_shovel_light_tank`。該起手式保留連擊數，因此右輕擊開始時快照為 1；第二個 Sweep 也命中命中登記時存活的角色敵人，即使該次傷害擊殺目標仍計數。兩個 Sweep 均完成並送出結束事件。
  - **代入**：第一事件不符合連擊門檻，計數器設為 1，不恢復。第二事件命中數大於 0 且連擊快照大於 0，計數器變為 2；I 級恢復量為 100 × 0.05。
  - **結果**：第二次掃掠結束時恢復 5 點韌性；第一次掃掠的命中不會追溯恢復。
  - **玩家意義**：起始連擊數為 0 的有效掃掠可讓計數器到 1；經實際允許的右側起手式接到右輕擊後，後一個 Sweep 以連擊快照 1 符合條件並恢復 5 點。值是最大韌性的 5%，不是對敵傷害或固定生命比例。

- **範例二：電弧鎚的等級差異與次級電弧**
  - **前提**：使用電弧鎚 布蘭克斯 Mk III，IV 級（weapon_id `powermaul_p3`、Mark `powermaul_p3_m1`）；接續使用 `action_light_1` Sweep（`DamageProfileTemplates.powermaul_p3_light_tank`）。計數器已為 1，最大韌性為 150、至少缺少 10.5，韌性恢復未停用，武器仍在手持槽。掃掠開始時連擊快照為 2，目標在命中登記時存活；即使本次掃掠隨後擊殺目標仍計數。特殊效果另產生的電弧可命中其他敵人。
  - **代入**：直接掃掠只送一個結束事件，計數器由 1 變為 2。電弧鎚 IV 級值為 0.07，因此請求恢復量為 150 × 0.07 = 10.5；次級電弧不再增加計數器或產生第二次恢復。
  - **結果**：本次掃掠結束恢復 10.5 點韌性，未超過可恢復的缺少量。
  - **玩家意義**：這個實作的四級值低於其他八個實作；連鎖電弧不把一次掃掠變成多次韌性觸發。
