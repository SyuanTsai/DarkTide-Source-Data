# 持續阻擊(Ceaseless Barrage)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/05a4b36e-fa00-4748-a557-c6b81575a32e" width="72" height="72" alt="持續阻擊祝福圖示">

- **觸發方式**：裝備適用的槍托自動槍或雙鏈重型機槍並連續射擊；每累積一個射擊步進，壓制強度加成與對已受壓制目標的傷害加成都提高，最多5層。
- 步進大小依此祝福所在裝備槽的最大彈匣容量計算：S=max(1,floor(C×2.5%))發。計數讀玩家射擊計數器，不按命中數、同發多個目標、彈丸或目前剩餘彈藥百分比計數。
- 每次成功進入射擊準備時，玩家射擊計數N會在命中處理前遞增；但步數來自 stepped-stat 與玩家 stat cache，觸發 N 變化的同一發不保證已讀到新層數。待後續 Buff/stat-cache 更新重算後，才可確定該層數已供後續結算使用。未能進入射擊準備的無彈嘗試不計。
- 命中掃描先處理傷害，之後才施加壓制；若此發才令目標初次受壓制，該次傷害不會回頭取得對已受壓制目標的加成。
- 射擊停止後，等目前選用散布狀態的清除門檻嚴格超過才清零；換武器本身不直接清零。N屬玩家射擊狀態，短時間內其他武器射擊也可能推進同一計數；祝福數值仍要求持用相符武器，清除門檻則隨目前武器的散布狀態選擇。
- 重裝填或沒有有效裝備槽時，步進函式回傳S=0；在該狀態被重新計算時 k=0，故本祝福當次數值貢獻為0，並非只把舊層凍結。離開適用武器後，持用條件不成立。六個型號的實際腰射／瞄準門檻列於變體頁。
- 腰射與瞄準連續射擊是壓制施加及射擊計數來源。特殊槍托推擊／重型機槍刺擊本身不是射擊，不增加N，也不走命中掃描的壓制施加路徑；若目標在特殊攻擊傷害計算前已受壓制，通用傷害路徑仍會檢查對受壓制目標的加成。

## 計算與算例

- **算例一：弗拉克斯 Mk II 的四層示例**
  - 前提：使用實際綁定的槍托自動槍弗拉克斯 Mk II（autogun_p2_m1）；其 weapon template 指向 autogun_p2_m1 彈藥模板。選擇該模板 lerp_basic 彈匣端點 C=50 發（假設沒有額外彈藥容量修正），連續射擊4發、沒有換槍或停火清零，且 Buff/stat cache 已重算至 N=4；使用 III 級。目標在本次攻擊前已受壓制，其他傷害修正中性。
  - 代入：S=max(1,floor(50×0.025))=1發；k=min(5,floor(4/1))=4。壓制倍率項=1+4×0.175=1.70；受壓制目標傷害倍率項=1+4×0.06=1.24。
  - 結果：若該傷害項的中性輸入為100，示意輸出為100×1.24=124；壓制項相對未加成本身為1.70倍。這是實際武器與可由其彈藥模板重建的容量端點，不是遊戲實測或最終HP保證。
  - 玩家意義：C=50時每發射擊計數形成一個步進，但N仍是準備射擊數，不是命中數；把N推到4的那一發不保證立即使用新cache，示例從 cache 已更新後的後續結算開始。
- **算例二：同一實際型號的五層上限**
  - 前提：仍使用槍托自動槍弗拉克斯 Mk II，取同一可重建彈匣端點C=50發且沒有額外容量修正；連續射擊25發後未清零，stat cache 已讀到N=25；使用IV級。目標已受壓制，其他傷害修正中性。
  - 代入：S=max(1,floor(50×0.025))=1發；k=min(5,floor(25/1))=5。壓制倍率項=1+5×0.20=2.0；傷害倍率項=1+5×0.07=1.35。
  - 結果：中性傷害輸入100乘以本項受壓制目標倍率項後為100×1.35=135；壓制倍率項為2.0倍。
  - 玩家意義：層數在5封頂；即使N繼續增加也不再提高本項倍率。N=25小於此彈匣端點容量；此數例仍只說明倍率項，不是最終生命值。
