# 創傷(Trauma)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/3a924413-234e-4bef-a8eb-1effc40b59ee" width="72" height="72" alt="創傷祝福圖示">

- **觸發方式**：持用裝有「創傷」的相應近戰武器，以該武器造成符合一般命中事件條件的攻擊命中；不要求連續命中同一名敵人。

- **計數方式**：每次獨立攻擊只計入第一個命中目標；一次橫掃命中多名敵人，後續目標不再加層或刷新期限。

- **首次生效**：從未開始計數的狀態，前兩次有效命中建立計數，第3次有效命中獲得第1層；其後每次有效命中增加1層，第7次達到5層。第一層形成前尚未開始2秒清除檢查，前兩次命中不受這個期限限制。

- **效果**：每層使近戰衝擊修正增加I級14%、II級16%、III級18%或IV級20%；最多5層。此數值影響攻擊造成踉蹌的強度，不是傷害加成。

- **額外效果**：每層還會使一般踉蹌持續時間乘以1.1；5層時為×1.61051。採用獨立踉蹌時間欄位的攻擊不套用這個倍率。

- **期限與重置**：開始獲得層數後，新的有效命中會刷新2秒期限；超過2秒沒有有效更新，層數與命中計數會清除。揮空或一次橫掃中的後續目標不會自行清零，也不會刷新期限。

- **重置後再疊**：期限清除後，第1次有效命中重新建立計數，第2次有效命中獲得第1層。

- **普通與重擊**：實際命中都可依上述規則累積；揮空、格擋與特殊模式啟動本身不算命中。

- **工兵鏟特殊攻擊**：Mk I的上勾命中可以計數；Mk III與Mk VII按特殊鍵切換折疊模式後，仍需以特殊輕擊或重擊實際命中。

- **惡魔之爪特殊攻擊**：招架的防禦姿態不加層；接出的反擊實際命中時，依第一目標規則計數。

- **撬棍特殊攻擊**：按特殊鍵只切換黏附模式；攻擊命中及黏附後的額外傷害可分別計數，拔出動畫本身不算命中。

- **碾壓者特殊攻擊**：按特殊鍵只啟動通電；通電揮擊命中後另有爆炸，其第一個有效命中目標可另外推進計數，爆炸後續目標不重複加層。

- **雷鎚特殊攻擊**：按特殊鍵啟動後，需以後續通電揮擊實際命中才計數。

- **切換武器**：切出該武器時，效果暫不作用且不會增加計數；2秒期限仍繼續倒數。期限內切回可恢復尚存層數，逾期後須重新累積。

## 計算與算例

- **疊層前提**：每次攻擊各有一個有效命中事件，沒有目標序號大於1的事件插入；每次間隔均短於2秒。

- **首次疊層**：第1次命中將計數設為0，第2次使計數為1但仍無有效層，第3次命中首次給1層；第7次命中達5層。

- **逾期後重疊**：5層時最後一次有效更新在`t=10.0秒`，之後直到`t>12.0秒`都沒有有效命中；更新檢查清除層數和計數。清除後第1次有效命中不給層，第2次有效命中給1層。

- **IV級衝擊階段**：假設基礎衝擊值為100、已達5層、其他衝擊修正均為1，並忽略蓄力與目標端修正。近戰衝擊修正為`1 + 5×0.20 = 2.0`，此結算階段的衝擊值為`100×2.0 = 200`；實際踉蹌強度仍由目標與攻擊設定決定。

- **IV級踉蹌時間**：假設同一踉蹌類型的基礎時間為0.5秒、已達5層、使用一般踉蹌時間設定，其他一般踉蹌時間修正為1，且攻擊設定的額外時間修正為0。計算為`0.5×1.1^5 = 0.805255秒`；使用獨立踉蹌時間設定的攻擊不採用此通用倍率。
