## 執行與計算

| 實際系列與型號 | 普通／重擊與追擊 | 特殊／額外命中 | 純推擊 |
|---|---|---|---|
| 突擊鏈斧 奧瑞斯特斯 Mk IV、Mk XII | 多種輕／重掃掠及推擊後追擊均為 ActionSweep 近戰 | 特殊主攻擊可計層；後續 sticky instances 雖為 melee Attack，profile 的 skip_on_hit_proc=true 會阻止 on-hit，故不計層 | 排除 |
| 戰鬥斧 拉沙德 Mk III、安塔克斯 Mk V、阿克利斯 Mk VIII | 輕／重掃掠與 action_right_light_pushfollow 追擊均為 melee | 直接特殊上勾、刺擊、上勾分別為 sweep/melee | 排除 |
| 戰術斧 埃托克斯 Mk II、Mk IV、Mk VII | 輕／重掃掠及追擊為 melee | 每型號 2／3／2 個直接特殊下斬 sweep；設定中的 blunt damage type 不取代 attack_type | 排除 |
| 重劍 圖妥斯基 Mk VI、Mk VII、Mk IX | 輕／重掃掠與推擊後刺擊為 melee | action_attack_special 與 action_attack_special_2 是兩段 sweep/melee | 排除 |
| 戴維爾戰鎬 布蘭克斯 Mk Ia、博羅維安 Mk III、卡索拉斯 Mk II | 各 Mark 輕／重掃掠、推擊後追擊為 melee | action_special 為直接 sweep；M1 用 ogryn_pickaxe_blunt，M2/M3 用 special_pull，均走近戰命中且 profile 無 skip 排除 | 排除 |
| 雷鎚 十字星 Mk II、鐵盔 Mk IV | 輕／重掃掠與推擊後追擊為 melee | 特殊啟用的直接揮擊使用 special-active melee profile；只執行 activate_special 不造成命中 | 排除 |

- 16 筆實際 binding、各 action 名稱與每個武器模板的精確區段／SHA 在 headtaker-agent-evidence.json。所有 ActionSweep 命中都依 action_sweep.lua:1498–1501 以 attack_type=melee 傳入 Attack；純推擊另走 attack_type=push，見 push_attack.lua:77–84。
- 鏈鋸黏附時程以固定來源 sweep_stickyness.lua:41–78 與 action_sweep.lua:720–809 為據：各後續 damage instance 確實另呼叫 Attack，傳 attack_type=melee 及原武器 item；但 M1/M2 實際接入的九種 normal／active／last sticky damage profiles 均設 skip_on_hit_proc=true。Attack.execute 的 on-hit 排程明確要求該旗標為 false，因此這些追加實例不增加 Headtaker 層數。其他系列的實際特殊／蓄能掃掠 profile 沿繼承鏈均未設該略過旗標；全域 no-proc damage type 集合僅列 grimoire，而對應 action 傳入的均為其武器傷害類型。
- 雷鎚／戰鎬特殊 profile 可含 weapon_special=true；此欄不等於 Attack 類型，也不把 ActionSweep 命中變成 projectile 或 explosion。純推擊、沒有傷害的特殊切換都不計。

對本項近戰命中，先依 power_type 曲線換算，再套用同一威力池內的加算修正。令 B 為 power_type 曲線換算後、尚未乘合併威力 modifier 的值，q 為既有同階段加成，n 為有效 Headtaker 層數，p 為本級每層 modifier，則輸入為 B×(1+q+n×p)。威力輸入之後仍進入傷害、踉蹌與順劈等計算，不可直接當作生命傷害倍率。
