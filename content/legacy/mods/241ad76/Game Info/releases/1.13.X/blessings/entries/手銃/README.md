# 手銃(Hand-Cannon)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ef8ee5ad-6fcc-4309-9000-f0533a247c20" width="72" height="72" alt="手銃祝福圖示">

- **觸發方式**：持用裝有此祝福的手槍，且攻擊結算為暴擊時，才會把對應等級的加值納入該次攻擊者撕裂倍率。祝福本身不提高暴擊率，也不保證暴擊；每次攻擊仍依該動作的暴擊判定。
- **卡面數值**：磷光爆破手槍依序增加 5%、7.5%、10%、15% 暴擊撕裂；快拔左輪手槍依序增加 30%、40%、50%、60%。這些是撕裂倍率加值，不是最終生命值傷害百分比。
- **會暴擊的武器動作**：三個實際型號的腰射與瞄準射擊都是可進行一般遠程暴擊判定的單發命中掃描。三者的手槍槍托特殊攻擊與可接續的第二下都是近戰掃掠，也會進行一般近戰暴擊判定；磷光爆破手槍另有兩個由裝填流程接出的槍托掃掠。命中並非必然暴擊，只有結果為暴擊的攻擊套用本加值。
- **爆炸與持續傷害**：磷光爆破手槍命中小兵後另觸發的背爆把暴擊旗標明確設為否；其磷光燃燒週期傷害也以非暴擊攻擊結算，因此本祝福不會提高這些額外傷害。磷光手槍本身另有遠程命中撕裂目標的效果，屬不同武器效果，不是本祝福的暴擊撕裂加值。
- **沒有獨立的充能射擊、投擲或純推擊動作**：本次實核的三個型號都沒有其自身的充能／投擲射擊；其特殊鍵接出的是帶有傷害設定、可擲暴擊的槍托掃掠，不等同純推擊。
- **切換與移除**：祝福是持用欄位條件式被動，沒有命中後才新增的層數、持續時間或冷卻。切換離開該手槍後，條件式撕裂數值會在 Buff／屬性快取更新時停用；切回後恢復。從裝備欄移除手槍會移除該來源的裝備 Buff。

## 計算與算例

- **前提**：取實際綁定的快拔左輪手槍 阿格里皮娜 Mk XIV（Stub Revolver P1 M2）普通單發命中；命中距離至少 25 公尺，使此傷害 profile 的 dropoff 到 far 端（dropoff_scalar=1），首個命中 target_index=1 使用 default_target，目標為「裝甲」，且沒有 target-settings armor override。固定 profile 兩處 lerp 輸入各為原生 fallback 0.5：far attack 修正由 0.6 端點內插為 0.6；critical armor 修正由 0 到 0.3 內插為 0.15。因此在 is_critical_strike=true 時，進入護甲分支的 A=0.6+0.15=0.75。假設沒有其他撕裂來源或目標撕裂 debuff，overdamage 係數取原生 0.25；將同一次暴擊攻擊進入護甲分支前的傷害正規化為 B=100，後續 finesse、命中區等因素不列入本段比較。
- **代入**：I 級本祝福增加 r=0.30；因 1−A=0.25<r，M=1+(0.30−0.25)×0.25=1.0125，護甲分支傷害為 100×1.0125=101.25。IV 級 r=0.60；M=1+(0.60−0.25)×0.25=1.0875，結果為 108.75。
- **結果**：相同暴擊、未裝祝福的 armor-scaled 基準為 100×0.75=75。I 級此分支增加 26.25，較 75 增加 35%；IV 級增加 33.75，較 75 增加 45%。
- **玩家意義**：卡面 +30%／+60% 是暴擊撕裂倍率加值；Mk XIV 暴擊本身另帶 profile critical armor 修正。護甲分支會依 A、撕裂總量與 overdamage 係數計算，之後還有其他傷害步驟，故這些數字不是最終生命值傷害百分比。
