# 煽風點火(Fan the Flames)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/0d297dab-50af-49f0-8303-46347b9ab040" width="72" height="72" alt="煽風點火祝福圖示">

- **觸發方式**：持用淨化噴火器奧特米亞 Mk III，使用未架槍主要攻擊。架槍持續射擊與特殊推擊不是本項有效動作。

- **灼燒目標效果**：在目標踉蹌判定當下，目標已有燃燒狀態時，降低其可受此效果影響的原生踉蹌減免：I–IV 為 40%、50%、60%、70%。任何來源造成的有效燃燒狀態都符合；命中後才施加的燃燒不會回溯改變同一次命中。

- **遠程衝擊效果**：未架槍主要攻擊的踉蹌衝擊加成為 I–IV +30%、+35%、+40%、+45%。這是踉蹌計算使用的衝擊值，不是生命傷害加成；此加成不以目標燃燒為條件。

- **首次生效**：未架槍主要動作及持用條件成立、條件數值更新後，即可作用於符合條件的命中。目標原先已燃燒時，第一個有效命中即可降低減免；若這次命中才讓目標燃燒，後來施加的燃燒不會回溯改變這次踉蹌判定。

- **期限、疊層與切換**：本祝福沒有命中疊層，也沒有命中後持續或刷新秒數；離開未架槍主要動作，或切換武器後，條件數值更新即不再提供兩項加成。它不延長燃燒時間或增加燃燒層數。

- **燃燒週期傷害**：燃燒 tick 不取得遠程衝擊加成，也沒有因此提高生命傷害。不過，若 tick 結算時持有者的本項條件數值仍有效、目標正燃燒，且踉蹌計算沒有跳過減免步驟，減免效果也能進入該次計算；不能把 tick 視為另一發主要遠程攻擊。

- 減免效果只改變實際會走到燃燒修正步驟的原生減免；攻擊原本已忽略減免、減免為零，或弱點命中採用敵人的專屬減免覆寫時，不會再靠本項把該值降低。是否能踉蹌以及踉蹌種類，仍取決於敵人門檻、既有踉蹌池與攻擊設定。

## 計算與算例

先分開看兩個數值，避免把衝擊加成誤當成最後踉蹌等級或傷害。假設未架槍主要攻擊命中時本項已啟用，目標已燃燒，原始踉蹌抗性減免為 R=100，攻擊進入踉蹌曲線前的 Impact input 為 P=100；忽略弱點專屬覆寫、finesse、護甲修正、既有踉蹌池和其他加成：

- IV 的遠程衝擊加成把踉蹌曲線的輸入從 P=100 提到 P=100×(1+0.45)=145。
- 燃燒減免修正另將 R=100 乘以 0.30，剩下 R=30，也就是忽略 70% 原生減免。
- 程式再把 Impact input 經過 power-level 百分比映射至武器／護甲範圍與後續踉蹌次數等計算；所以 P=145 不代表最後踉蹌強度固定乘 1.45。以中性護甲修正且無踉蹌池時，之後的合併判定形式為 `S(145) − 0.5×30`，再與敵人的踉蹌門檻比較；這個例子不保證必定踉蹌或指定踉蹌類型。

- 同一 Impact stat 若另有 q=+20%：P=100×(1+0.20)=120，加入 IV 後為 P=100×(1+0.20+0.45)=165，額外增加 45 點；相對原本 120 為 +37.5%。同 stat 以加算組合，不是 120×1.45=174。

- RAW 把衝擊寫在燃燒目標句旁；實作中只有踉蹌減免修正檢查目標燃燒。若目標未燃燒，已啟用的遠程衝擊仍可提高踉蹌曲線輸入。
