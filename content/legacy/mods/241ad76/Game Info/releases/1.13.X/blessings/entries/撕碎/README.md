# 撕碎(Lacerate)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/c3b80cbc-5c0a-4281-abc5-14ab66716a72" width="72" height="72" alt="撕碎祝福圖示">

- **觸發方式**：持用帶有此祝福的戰刃或短刀，近戰命中敵人的非弱點部位並造成傷害，對仍存活的敵人施加流血。

- **等級效果**：I–IV每次符合條件的命中新增1／2／3／4層流血；兩種武器的數值相同。

- **命中條件**：弱點命中不觸發；不要求暴擊或擊殺，普通命中與暴擊都能觸發。

- **特殊刺擊**：戰刃的特殊刺擊若命中非弱點並造成傷害，同樣能施加流血。

- **特殊投擲**：短刀的特殊投擲屬於遠程攻擊，不符合近戰條件，即使命中非弱點也不觸發。

- **多目標**：一次揮擊對多名敵人造成非弱點傷害，各名符合條件且存活的敵人各獲得層數，不限第一名目標。

- **層數上限**：同一敵人最多16層流血，相同流血效果共用層數。

- **跳傷與消退**：流血每約0.5秒跳傷；最後一次施加或刷新後約1.5秒開始退層。此後每次先按當前層數跳傷，再移除1層。

- **再次施加**：新增層數與滿層再次觸發都刷新等待退層的期限，並保留既有跳傷節奏。

- **切換武器**：已施加的流血繼續存在；新的觸發要求處理命中事件時仍持用帶有祝福的武器。

- **傷害成長**：跳傷依流血層數曲線、護甲與其他傷害修正計算；每層不是固定扣血或生命百分比。

## 計算與算例

- **IV級一般命中**：一次近戰命中存活敵人的非弱點部位並造成傷害，新增4層；同一次攻擊若命中弱點則不新增。

- **IV級特殊刺擊**：戰刃特殊刺擊命中非弱點並造成傷害，新增4層。

- **IV級多目標**：一記揮擊對兩名存活敵人各造成非弱點傷害，兩名敵人各新增4層。

- **疊到上限**：退層前連續4次IV級觸發，流血層數依序0→4→8→12→16；第5次維持16層並刷新期限。

- **停止施加**：最後刷新時有8層或16層，名義上分別約5–5.5秒或9–9.5秒退完；範圍依原有跳傷節奏而定，另加固定更新延遲。

## 遊戲描述勘誤

- 本體「擊中非弱點部位」補明為造成傷害的近戰命中；暴擊並非必要條件。

- 特殊攻擊依實際動作區分：戰刃特殊刺擊可觸發，短刀特殊投擲不觸發。

- 流血1.5秒後開始逐層消退，不會在該時點一次清空。
