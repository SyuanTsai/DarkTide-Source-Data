# 利刃攻勢(Bladed Momentum)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8ccd5628-1554-41a6-9e87-be2b49037a3e" width="72" height="72" alt="利刃攻勢祝福圖示">

- **觸發方式**：使用下列實際型號之一，在同一次揮擊中進入第 2 個或之後的目標命中事件；事件須為近戰攻擊、來自這件祝福武器，且處理事件時目前仍持有該武器。每次揮擊最多觸發一次。判定不要求擊殺或造成正生命值傷害。
- **階級效果**：重劍 P2 每有效層增加近戰撕裂倍率 I–IV 為 +5%、+6%、+7%、+8%；穿音速雙刀 P1 為 +4%、+5%、+6%、+7%。兩實作各級持續 2.5、3、3.5、4 秒。
- **堆疊與到期**：每次符合條件的揮擊增加 1 層，最多 4 層；成功觸發會刷新這組層數共用的計時，包括已到 4 層時。計時到期後，有效層數一併移除；不是每層輪流衰退。
- **首次生效**：命中傷害先結算，之後才排入並處理觸發事件，再更新玩家屬性快取；本次觸發的命中不會追溯取得新層。需等快取更新後的後續合格近戰命中；不保證同一揮擊內、同一影格的下一目標已套用新值。
- **持有與切換**：持有條件控制觸發及屬性貢獻；切換到其他武器時，既有計時仍走，快取更新後不再提供這項撕裂值，切回時若層數尚未到期可恢復。真正卸下／移除祝福會移除父效果所控制的子層。
- **攻擊範圍**：普通輕擊、重擊、重劍連段、穿音速雙刀的特殊揮掃，以及實際接入的推後追擊都是揮掃近戰命中，可依同一命中門檻判定；特殊模式切換本身不是命中。
- **純推擊與投射**：獨立純推擊的攻擊類型是推擊，不符合近戰命中檢查；這些實際型號的動作表沒有投射物或遠程攻擊路徑。
- **實際型號**：重劍 P2 為 重劍 圖妥斯基 Mk VI（Heavy Sword Turtolsky Mk VI）、重劍 圖妥斯基 Mk VII（Heavy Sword Turtolsky Mk VII）、重劍 圖妥斯基 Mk IX（Heavy Sword Turtolsky Mk IX）；穿音速雙刀 P1 為 穿音速雙刀 布蘭克斯 Mk XI（Paired Transonic Blades Branx Mk XI）。同名電漿劍定義沒有本項 inventory 綁定，不列為可用型號。

## 計算與算例

**例一：同一次揮擊的觸發**

- 前提：本次命中事件的 `attack_type=melee`、`target_number=2`，事件處理時來源 item 與本祝福相同且仍持有該武器；不假設擊殺。
- 代入：`required_num_hits=2`，故 `2 >= 2`；本次揮擊的觸發閂鎖尚開啟。
- 結果：最多新增 1 層；對該命中已結算的傷害不回溯改算。
- 玩家意義：這裡檢查的是揮擊命中事件帶來的目標序號，不是累計擊殺數。

**例二：每層數值不是最終傷害百分比**

- 前提：重劍 P2 IV，已有 3 個有效層；其他撕裂修正中立。
- 代入：`3 × 0.08 = 0.24`，即本效果向近戰撕裂計算池提供 `0.24`，而非將所有傷害乘以 `1.24`。
- 結果：該攻擊的撕裂計算仍按目標護甲、傷害設定及總撕裂上限結算。
- 玩家意義：較高撕裂會改變裝甲傷害修正的套用，不代表對每種目標固定增加 24% 最終生命傷害。

**例三：實際穿音速雙刀輕擊對裝甲目標的受控算術**

- 前提：穿音速雙刀 Branx Mk XI 的 `light_linesman` 普通近戰攻擊，限定第一個傷害目標（`target_index=1`）且 `armor_type=armored`；本例設為非暴擊，因此不套用 profile 的 `crit_mod`。該目標使用 `damage_lerp_values.lerp_0_75`，其端點為 0.48 與 1.02；在受控內插值 `t=0.5` 時，`a=math.lerp(0.48,1.02,0.5)=0.75`。Tier I 一層為 `R=0.04`，其他撕裂／傷害／後續修正中立。以此護甲調整段前的示意值 `B=100` 計算，不是遊戲實測。
- 代入：裝甲損失 `1-a=0.25`，且 `R=0.04 < 0.25`，所以此分支的裝甲傷害倍率是 `a+R=0.75+0.04=0.79`。
- 結果：僅看此裝甲調整段，示例值 `100×0.75=75` 變為 `100×0.79=79`，相對該段原值增加 `4÷75≈5.33%`；後續結算仍可能受其他設定影響。
- 玩家意義：Tier I 的 +4% 是近戰撕裂倍率貢獻，不等於完整攻擊固定 +4% 生命傷害。
