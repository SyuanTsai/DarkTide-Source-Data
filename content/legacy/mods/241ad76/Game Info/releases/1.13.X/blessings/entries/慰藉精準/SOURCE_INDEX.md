## 執行與計算

- **事件與門檻**：兩個 wrapper 都直接 clone `toughness_on_crit_kills` base。base 接收 `on_kill`，再檢查事件中的暴擊旗標、`attack_result == died`、攻擊 item 與祝福 item 相同，以及事件處理當下仍持用該 item。沒有武器類型或特殊動作限制；無 cooldown / active duration。
- **事件順序與回復**：`scripts/utilities/attack/attack.lua` 的局部 `_execute` 完成本次傷害與命中處理後，將擊殺事件送入攻擊者的 buff extension。ProcBuff 逐事件評估條件並呼叫 callback；每筆合格擊殺立即呼叫 toughness extension 的百分比回復。這是直接回復，不是週期恢復，也不是等待後續命中才生效的屬性加成。
- **重型鐳射手槍 奧克塔蘭MG Mk II**：一般與瞄準射擊皆為 hit-scan，攻擊攜帶當次暴擊旗標及手槍 item；若同時擊殺才符合。標準普通／靈能推擊經 PushAttack 呼叫 Attack 時沒有傳入暴擊旗標，Attack 預設為 false，所以推擊擊殺不符合。本 Mark 沒有蓄力射擊或近戰攻擊。
- **擲彈兵臂鎧 布拉斯托姆 Mk III**：普通與蓄力近戰掃擊、特殊動作的直接拳擊都經 ActionSweep 傳遞實際暴擊旗標與臂鎧 item，因此合格暴擊擊殺可觸發。特殊動作另外發出的爆炸固定以非暴擊結算，單靠該爆炸擊殺不符合。榴彈直擊、引信爆炸和命中爆炸保留發射時的暴擊旗標及原始臂鎧 item；投射物攻擊者會解析回持有者。這些擊殺仍須在事件處理時通過持用條件，若此前已切離臂鎧便不回復。
- **韌性回復上限**：callback 以目前最大韌性乘本武器 I–IV 比例作預算，實際回復再受當下韌性缺損封頂；callback 忽略一般 toughness regain stat multipliers。最大韌性計算包含角色的最大值修正。倒地且未處於 `force_assist`、死亡或原生阻止回復關鍵字會使韌性 extension 拒絕回復；此 callback 未傳 combat-ability recovery reason，不能享有依該 reason 放行的例外。

令 `M` 為事件處理時的目前最大韌性（包含已生效的最大值加成），`p` 為對應武器的 tier fraction，`D` 為當下缺損。合格且仍可回復時，預算 `B=M×p`，實際回復 `R=min(B,D)`。Callback 使用 `ignore_stat_buffs=true`，不乘一般韌性補充倍率；兩個 own template 都沒有 `toughness_regain_multiplier` producer，故倍率取預設1。

- 臂鎧 IV：假設 `M=100`、`D=50`、`p=.36`。代入 `B=100×.36=36`，所以 `R=min(36,50)=36`；韌性由50升至86。意義：+36%指最大韌性預算，不是缺損的36%。
- 手槍 IV：假設 `M=100`、`D=10`、`p=.16`。代入 `B=100×.16=16`，所以 `R=min(16,10)=10`；韌性回滿至100。意義：缺損不足時以缺損封頂。
- 上述 `M` 必須是事件當下的目前最大韌性，`D` 也是事件當下缺損；數值表示韌性點數，不是最大韌性永久增加。非暴擊擊殺、未擊殺、持用/item gate 不符、已滿韌性或原生回復被禁用時，這次回復為0。
