# 幽靈：等級數值

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

- 等級為 I–IV；五個實作的時間相同。

## 等級與數值

| 等級 | 持續時間 |
|---|---:|
| I | 0.6 秒 |
| II | 0.8 秒 |
| III | 1.0 秒 |
| IV | 1.2 秒 |

- 五個變體的 I–IV 數值相同；重複合格弱點命中會重設計時，不會累加持續時間或層數。
