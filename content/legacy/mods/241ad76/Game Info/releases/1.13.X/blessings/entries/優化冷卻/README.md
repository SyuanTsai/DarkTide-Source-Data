# 優化冷卻(Optimised Cooling)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/67729505-43c4-4069-9e4b-d2fda4ca0e44" width="72" height="72" alt="優化冷卻祝福圖示">

- **適用型號**：電漿槍 M35熔岩核心 Mk II、Mk III；兩型號共用本項等級與公式。

- **觸發方式**：普通與蓄力射擊的動作接續現有動作鏈時，連射計數增加一階，最高五階；不要求命中、擊殺或爆擊。接續直接或架槍蓄力會保留既有計數，蓄力本身不加階。

- **每階效果**：I–IV 級每階將生熱依序乘 0.96／0.94／0.92／0.90；五階累計降低約 18.4627%／26.6096%／34.0918%／40.951%。每階逐次相乘，不能把單階百分比直接乘五。

- **普通、蓄力與特殊模式**：普通及蓄力射擊的立即生熱、持續直接與架槍蓄力的生熱皆使用此倍率。其他生熱修正仍依各自來源相乘；此項不縮短蓄力時間、不減少已累積熱能，也不加快自然散熱或特殊排熱。

- **首次生效**：新連射計數在動作開始後寫入，後續祝福數值快取更新才讀到新階；不能將新階追溯套在先前已使用舊快取的生熱上。第一發前零階、後續已更新至一階時，IV 級生熱才乘 0.90。

- **維持與清除**：接續蓄力保留計數；裝填、特殊排熱、切換武器或其他既不增加也不維持連射計數的動作會清零。切回武器後從已清零的計數重新累積。

- **重新起手與期限**：沒有正在執行的動作時，手動開始且未指定保留計數的動作會先歸零；兩型號蓄力動作未指定保留重新起手時的計數。非持續動作結束超過 0.5 秒仍有計數時也會清零；沒有獨立的祝福層數計時器。清零以後續數值快取更新反映。

## 計算與算例

- **前提**：假設某次生熱在本項修正前為熱能表 20 百分點（內部比例 H=0.20），當前已有有效且已更新到數值快取的階數；其他生熱修正皆為 1、不在鎖定狀態、也未碰到熱能表上限。此為算術示意，不是武器實測值。

- **IV 級一階**：0.20×0.90=0.18，即增加 18 百分點；比原 20 百分點少 2 百分點，生熱相對降低 10%。

- **IV 級五階**：0.20×0.90⁵=0.118098，即增加 11.8098 百分點；比原值少 8.1902 百分點，生熱相對降低 40.951%，不是少 50 百分點。

- **與其他乘數合併**：假設其他生熱乘數積 q=0.80，原生熱為 0.20×0.80=0.16，即 16 百分點；加入本項五階後為 0.20×0.80×0.90⁵=0.0944784，即 9.44784 百分點。相較原 16 百分點再減少 40.951%，不同乘數不把百分比相加。

- **玩家意義**：這項倍率修正的是新產生的熱能，不會直接扣除目前熱能表上的熱量；若進入鎖定或熱能表達到上限，存入的最終差額還取決於該分支。

## 遊戲描述勘誤

- 英文 RAW 經 formatter 重建為 `reduces overheat generation by -4%`（I 級；其他等級同樣帶負號）。「減少負百分比」的文字方向與實際小於 1 的生熱倍率相反；玩家效果以 .96／.94／.92／.90 的實作倍率說明。

- 繁中 RAW 為「-4%持續射擊時的熱量生成。」等句，缺少完整動詞；它沒有明寫增加熱量，不另推定為相反方向。
