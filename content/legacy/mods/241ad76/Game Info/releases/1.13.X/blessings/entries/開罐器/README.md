# 開罐器(Can Opener)

- **觸發方式**：撬棍切換至次要模式後，用該模式的輕擊或重擊命中敵人；撕裂槍則用刺刀特殊攻擊命中敵人。

- **撬棍等級效果**：I–IV每次合格命中增加1、2、3、4層脆弱，單次合計2.5%、5%、7.5%、10%。

- **撕裂槍等級效果**：I–IV每次刺刀命中增加10、12、14、16層，單次合計25%、30%、35%、40%；本頁三個型號數值相同。

- **不觸發的動作**：撬棍普通模式與推擊後接擊不觸發；撕裂槍射擊不觸發。

- **額外命中要求**：不要求暴擊、弱點、重擊、蓄力或擊殺；施加時敵人必須仍存活。

- **層數上限**：每層2.5%，同一敵人最多16層，也就是40%脆弱；其他武器或隊友施加同一脆弱效果時共用層數。

- **持續與刷新**：全部層數共用5秒倒數；合格命中增加層數並刷新倒數，滿16層後命中仍會刷新。

- **生效時機**：觸發的那一擊先完成傷害，再施加新脆弱；不回溯增加同一擊傷害，脆弱生效後的後續攻擊才受益。

- **隊友與其他武器**：脆弱留在敵人身上，隊友與其他武器的攻擊也能受益；切出原武器不會清掉已施加的層數。

- **撬棍模式切換**：切出撬棍會保留次要模式；已排隊的合格命中在處理時仍是次要模式就能施加脆弱，手動關閉模式則停止提供。

- **撕裂槍切換**：處理命中時須仍持用撕裂槍；已排隊的刺刀命中若處理前已切出，不再新增脆弱。

- **移除方式**：5秒內沒有新的合格施加或刷新，整組脆弱到期消失；不逐層各自倒數。

- **傷害意義**：脆弱改善裝甲結算，並非固定增加相同百分比的最終傷害；無護甲傷害分類不從這筆脆弱提高傷害。

## 計算與算例

- **層數算例前提**：目標原本沒有脆弱，IV級撬棍連續合格命中，各次脆弱已生效且中途未到期。

- **層數算例結果**：依序4、8、12、16層，也就是10%、20%、30%、40%；IV級撕裂槍一個刺刀命中就能施加16層。

- **封頂算例前提**：目標已有14層，IV級撬棍命中且條件合格。

- **封頂算例結果**：只補到16層，不能變18層；倒數刷新為5秒，滿層後再次合格命中也刷新。

- **傷害算例前提**：裝甲前傷害100、原裝甲倍率10%，該分類適用脆弱，沒有其他撕裂；只比較脆弱生效後的裝甲階段。

- **傷害算例結果**：4層10%脆弱使該階段傷害由10到20；16層40%使其由10到50。觸發那一擊仍看施加前的狀態。

- **溢出算例前提**：裝甲前傷害100、原裝甲倍率90%，已施加16層40%脆弱。

- **溢出算例結果**：先補10個百分點至100%，餘下30個百分點按四分之一效率計入，倍率107.5%，該階段傷害107.5；後續弱點、部位和減傷另算。

## 遊戲描述勘誤

- **撬棍原文的「次要攻擊」**：實際是可切換的次要模式；在該模式下以合格輕擊或重擊命中才施加，推擊後接擊被排除。

- **每層與單次總量**：每層為2.5%脆弱，需乘本等級給的層數；IV級撕裂槍16層合計40%，不代表最終傷害固定增加40%。

- **原文未列模式與排隊命中時序**：撬棍在處理命中時讀取模式，撕裂槍則讀取是否持用；兩者切換規則不同。

- **原文未列當擊順序**：造成減益的那一擊先結算，後續攻擊才讀取已生效的脆弱。
