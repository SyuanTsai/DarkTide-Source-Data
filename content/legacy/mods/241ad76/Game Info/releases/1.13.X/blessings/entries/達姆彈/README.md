# 達姆彈(Dumdum)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a11fa52e-95d6-46e4-bfd1-5fb7bb132120" width="72" height="72" alt="達姆彈祝福圖示">

- **觸發方式**：帶有此祝福的武器，合格命中後累積近距離傷害加成。

- 命中不同敵人也可累積，不限近距離命中才能疊層。

- 步兵自動槍一發子彈穿透命中多個合格目標，可累積多次命中。

- 電弧步槍每批連鎖傷害，只計傷害結算順序中的第一個存活目標；其餘連鎖目標不增加命中計數。

- 這個目標不一定是直接射擊或連鎖起點的敵人。

- 直接射擊命中與連鎖的第一個命中可分別計數。

- **傷害加成**：依序對應I／II／III／IV級，最多5層。

- 步兵自動槍、偵察鐳射槍與重型鐳射手槍：每層4.5／5／5.5／6%，滿層22.5／25／27.5／30%。

- 電弧步槍：每層1／2／3／4%，滿層5／10／15／20%。

- 12.5公尺內完整生效，超過後依距離衰減，30公尺起這項近距離加成為零。

- **首次生效**：初次裝備時，第三次合格命中後取得第一層，之後每次命中加一層。

- 在有效層逾期清空後，第二次合格命中即可取得第一層。

- 新層數供後續傷害使用。

- **刷新與移除**：取得有效層後，合格命中刷新共同2秒期限，滿層也刷新。

- 射空不立即清層，但也不刷新。

- 超過期限時清空。

- 切出停止加成，期限仍繼續，期限內切回可沿用剩餘層數。

## 計算與算例

- **距離收益**：以下先以步兵自動槍、偵察鐳射槍與重型鐳射手槍為例，假設IV級五層、該傷害階段原值100點、沒有其他同階段加成。

- 12.5公尺內為`100 × (1 + 5 × 6%) = 130點`。

- 16.875公尺時距離比例為`(16.875−12.5)÷17.5=0.25`、平方根為0.5，加成只保留一半，為115點。

- 30公尺為100點。

- **電弧步槍算例**：同樣是IV級五層、原值100點，12.5公尺內為`100 × (1 + 5 × 4%) = 120點`。

- 16.875公尺時加成保留一半，為110點；30公尺起為100點。

- **已有加成**：同一100點階段原有20%加成時為120點。

- 12.5公尺內IV級滿層後為`100 × (1 + 20% + 30%) = 150點`，相對120增加25%。

- 電弧步槍同條件為`100 × (1 + 20% + 20%) = 140點`，相對120增加約16.67%。

- 其餘護甲、弱點與傷害倍率保持相同，不能當成所有敵人的固定傷害值。

- **單目標命中序列**：假設初次裝備，每發只命中一個合格目標、事件逐發結算且不逾期。

- 第3次命中後一層，第7次後五層，第8次可用滿層。

- 有效層逾期後，第2次命中後一層、第6次後滿層。

- 穿透多目標或電弧的連鎖首個命中，會改變所需射擊次數。

## 遊戲描述勘誤

- 繁中將「Close Range damage」翻成「近戰傷害」。

- 這項祝福提高本武器的近距離傷害，射擊也會受益。

- 應區分距離條件與攻擊類型。
