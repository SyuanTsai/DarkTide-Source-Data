# 行刑者(Executor)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/6b4dbf18-065c-4d5f-af6e-a06a6bb4adca" width="72" height="72" alt="行刑者祝福圖示">

- **觸發方式**：持用有「行刑者」的武器，以近戰攻擊命中弱點後獲得一層，首次合格命中就會加層；新層數供後續攻擊使用。

- **每層加成**：I／II／III／IV 級每層分別提高4.5%／5%／5.5%／6%威力，最多5層。

- **刷新與期限**：每次符合條件的弱點命中都會刷新2.5秒期限；已達5層後不再增加層數，但仍會刷新期限。期限過後，本效果已累積的層數會一併清除。

- **中斷連擊**：若近戰攻擊的第一個目標命中的部位不是弱點，會清除已累積層數。揮空不會立刻清層，但沒有新的弱點命中時，效果會在期限後消失。

- **同次揮擊多目標**：一記揮擊若命中多名敵人的弱點，每名符合條件的目標都可各增加一層；各命中事件處理後增加的層數供後續威力結算使用。

- **特殊攻擊**：戰刃的特殊近戰攻擊與力場劍的蓄能近戰揮擊，實際造成弱點命中時可觸發；短刀的投擲不算近戰命中，不會觸發。

- **切換武器**：切出後，行刑者不會繼續觸發，威力加成也暫停；2.5秒期限仍會流逝。期限內切回可恢復尚存層數，逾期後則需重新命中弱點。

- **加成解讀**：這是威力加成，不代表最終生命傷害必定增加相同比例；實際傷害、踉蹌與順劈仍取決於攻擊設定與目標。

- **力場劍黏附**：朦朧 Mk II／戴莫斯 Mk IV 蓄能攻擊黏住敵人時，每段弱點命中都能各增加一層；黏住身體部位的傷害命中會清層。伊利斯 Mk V 沒有這段黏附傷害，依一般揮擊命中計算。

- **投擲受益**：短刀投擲不會增加、清除層數或刷新期限，但開始投擲時已有的行刑者威力加成會供這把飛刀使用；之後切換武器或原層數到期，都不會改變已建立飛刀的加成。

## 計算與算例

- **IV級五層**：假設五次近戰弱點命中都在上一層到期前發生，累積為5 × 6% = 30%威力加成。若該次攻擊在威力類型曲線後、套用行刑者前的威力輸入為300，套用後為300 × 1.30 = 390；這不是最終生命傷害數字。

- **II級同次揮擊**：假設一記順劈揮擊依序命中三名敵人的弱點，且三次合格命中都完成加層，則增加3層、合計15%威力加成，後續攻擊的威力輸入乘以1.15。本次命中已完成的傷害不會因後來新增層數而重算。

- **身體命中重置**：已有4層時，下一次近戰攻擊的第一個目標命中的部位不是弱點，事件處理後有效層數歸零；若揮空則不會觸發這項重置，改由2.5秒期限到期清除。

- **同次攻擊目標順序**：已有層數的一記多目標揮擊，若先命中弱點、之後才命中身體部位，後面的非弱點目標是第二個或更後面受擊者，不會清除本次已建立的弱點連擊。

- **滿層刷新**：IV級已有5層時，再命中一次弱點不會變成第6層，但仍重設2.5秒期限；身體命中或遠程命中不會替這個子效果刷新期限。

- **已有加成**：假設同一威力結算階段原有+20%，IV級五層再加+30%，倍率由1.20變1.50；若曲線後基礎威力為300，輸入由360變450，相對增加 `(450−360) ÷ 360 = 25%`。這仍是威力輸入的相對變化。

- **黏附算例**：朦朧 Mk II 在黏附傷害開始前已有2層IV級行刑者，之後三段黏附傷害都實際命中弱點，且中途未逾時，會依序變3、4、5層，達到+30%威力；不是黏附整段只加一層。

- **投擲算例**：短刀的IV級行刑者已有3層，開始投擲時為+18%威力。假設曲線後、加成前威力為300，該飛刀使用 `300 × 1.18 = 354` 的威力輸入；飛行中原層數到期也不會把它改回300。這不代表飛刀最終扣血354點。
