# 最後防線(Last Guard)

- **觸發方式**：裝備並持用本項對應的盾錘武器。成功格擋來襲攻擊後，只有當該格擋實際耗盡耐力、格擋消耗大於零且冷卻已結束，並且來源武器在事件由本項處理時仍手持，才會排程一次自動推擊。單純舉盾、格擋未破防或零消耗格擋都不觸發。
- 推擊由你發出時的位置和面向起算，原生範圍半徑為 5；目標相對角度會選用內外推擊設定。推擊所用的 1000 是 PowerLevel 輸入，不是 1000 點生命傷害；實際效果由原生推擊攻擊設定和目標結算。
- I–IV 冷卻分別為 18／15／12／9 秒。新裝入時不必先等一輪冷卻；合格格擋事件被處理時開始該級冷卻，冷卻內的後續破防不會再排程。
- 格擋消耗倍率 I–IV 為 0.85／0.80／0.75／0.70，也就是相較同一格擋消耗降低 15／20／25／30%。這項減耗隨祝福裝備存在，不要求手持來源武器；切槽會阻止新的推擊觸發，但不會移除減耗或重設仍安裝的祝福冷卻。
- 合格事件一旦已排程推擊，單純切槽不會取消它。之後本項更新時會先清除待發標記，再以那次實際發出的當下位置與面向推擊；不會再檢查是否仍手持來源武器。真正從裝備欄卸下來源武器才會移除該祝福實例及減耗、冷卻與待發標記，尚未發出的推擊也不會再執行。
- 四個型號的一般格擋都接收近戰與遠程攻擊，仍須符合當前動作的可格擋類型、角度及耐力消耗條件。一般推擊鏈可短暫保留格擋狀態：板盾為 0.5 秒、鎮壓護盾為 0.4 秒；向外推擊本身不是觸發，只有該窗口內遭遇被當前格擋動作接受的來襲攻擊，且實際耗盡耐力時才可能觸發。
- 板盾兩型號的武器特殊格擋把格擋消耗設為零，所以該特殊格擋不會破防，也不會觸發本項；一般格擋仍可觸發。
- 電擊鎚與鎮壓護盾兩型號的特殊蓄勢本身也是格擋狀態，轉換後還保留 0.4 秒格擋窗口；其中若被接受的來襲攻擊真的格擋擊破耐力且本項已冷卻完畢，仍可觸發。特殊動作的推吼本身不是本項觸發事件。

## 計算與算例

- **前提**：示範以 normalized 格擋消耗 C=1.00、其他格擋與耐力消耗修正均為 1、當前耐力為 0.72 計算；這些是同一尺度的示例值，不代表每種敵人攻擊固定消耗 1。當前動作可格擋該攻擊，來源武器正手持且冷卻已結束。
- **代入**：I–IV 分別為 1.00×0.85=0.85、1.00×0.80=0.80、1.00×0.75=0.75、1.00×0.70=0.70。
- **結果**：I、II、III 的消耗都不小於 0.72，會耗盡耐力並符合推擊觸發的消耗條件；IV 的 0.70 小於 0.72，不會耗盡耐力，因此不觸發。
- **玩家意義**：減耗數值越高，不代表越容易觸發推擊；當減耗把消耗降至剩餘耐力以下時，這次格擋反而不會破防。實際結果還取決於入站攻擊、格擋動作與其他修正。
