## 執行與計算

- 父效果只在持用來源物品且合格命中事件通過物品匹配、弱點旗標與持用條件時，按每個成功事件增加子層；弱點依 `hit_weakspot`，不由身體部位名稱自行推斷。
- 攻擊先擲暴擊並計算當次命中，之後才排入命中事件。父效果對事件批次先處理新增子層，再處理清除子層；同一批若同時含合格命中與成功暴擊事件，批次結果清除至基線（有效0層）。不同批次間不作同批推論。成功擲出暴擊即可排清除事件，即使之後攻擊落空；已結算攻擊不回溯，新層要在事件與快取更新後才影響後續擲骰。
- 13個綁定型號的主射擊及瞄準射擊接 hitscan。自動槍P3、電能步槍P1特殊鍵接近戰 Sweep，仍可按同物品、持用、弱點旗標觸發；步兵鐳射槍、偵察鐳射槍及重伐木槍特殊鍵只切手電筒。這些標記沒有接蓄力或投擲動作。穿透命中各自產生事件才逐次判斷；自動連發的暴擊節奏依實際 action state / max_critical_shots 設定，不假設每顆彈丸都獨立擲骰。
- 層數最多5且無獨立TTL。切槽不刪父／子層，但持用 gate 停止後，快取更新會停用加成；若尚未被暴擊清除，切回來源武器可恢復。真正卸下來源武器移除祝福 buff。

暴擊擲骰輸入先計算 `clamp(base_crit + other_additive_chances + stacks × p, 0, 1)`；若有暴擊轉傷害設定，再按該設定轉換。`p` 是每層直接增加的機率百分點，`stacks` 最多5；此公式描述擲骰輸入，不是命中、傷害或最終暴擊結果。
