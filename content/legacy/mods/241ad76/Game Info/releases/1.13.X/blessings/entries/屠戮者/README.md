# 屠戮者(Decimator)

- **觸發方式**：使用帶有此祝福的戰鬥斧、戰術斧、工兵鏟或骨鋸，近戰揮擊命中敵人後取得一層。

- 每次揮擊最多取得一層，命中多名敵人仍只取得一層。

- 新增加成供後續攻擊使用。

- **威力加成**：每層近戰威力增加2／3／4／5%，依序對應I／II／III／IV級，最多10層。

- IV級滿層為50%。

- 威力會參與傷害、順劈攻擊容量與踉蹌計算，實際收益隨攻擊與目標改變。

- **刷新與移除**：每次合格命中重新計算2秒持續時間，滿層也會刷新。

- 揮空或超過期限時清空有效層數。

- 更換目標可繼續疊層。

- **切換武器**：離開此武器時加成停止，倒數仍繼續。

- 期限內切回可沿用剩餘層數。

- **特殊攻擊**：軍務部標配工兵鏟的上勾攻擊命中時，也能取得一層。

- Mk III／VII工兵鏟的模式切換、骨鋸的塗層切換本身不取得層數。

## 威力計算與算例

- **滿層**：假設該威力階段輸入為500、沒有其他威力加成，使用IV級每層5%。

- 一層為`500 × (1 + 5%) = 525 威力`。

- 10層為`500 × (1 + 10 × 5%) = 750 威力`，增加250威力。

- 最終傷害還要經過武器與目標的結算。

- **已有加成**：相同500威力，原有25%同階段加成時為`500 × 1.25 = 625 威力`。

- IV級滿層後為`500 × (1 + 25% + 50%) = 875 威力`。

- 相對原本625增加`(875 − 625) ÷ 625 = 40%`。

- **首次生效**：假設由零層開始、每次揮擊均合格且間隔未超過2秒。

- 第一擊結束取得1層，第二擊使用1層加成。

- 第10擊結束取得10層，第11擊可使用滿層加成。

- 揮空後下一擊由零層開始。

## 遊戲描述勘誤

- 本體中英描述寫「連續兩次以上攻擊」，但實際在第一次合格揮擊結束後就取得一層，下一擊可受益。
