# 開啟齊射(Opening Salvo)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/1bec65ee-05df-46b5-9df6-b4fcf1d4d724" width="72" height="72" alt="開啟齊射祝福圖示">

- **觸發方式**：持用適用武器，且玩家的共用射擊計數為 0 時，就為下一次遠程射擊提供力量加成；不需要先命中或擊殺。有效射擊在命中前增加計數，所以首發落空仍會消耗首發資格。空彈匣乾扣若未通過彈藥檢查，不增加計數。

- **等級效果**：I–IV 提供 +14／+16／+18／+20% 遠程力量修正。五種實作各自具有相同數列；等級值取代備用的 +2%，兩者不相加。力量還會進入傷害、踉蹌與穿透的後續計算，因此不能直接視為同幅度最終傷害。

- **一般與瞄準射擊**：全部 11 個適用型號的一般及瞄準射擊都接入即時命中射擊路徑，每次射擊動作更新只執行一次射擊分支。首發的力量使用本次更新已算好的條件加成；增加射擊計數後，後續更新會撤掉加成。判定單位是射擊計數，不是擊中的敵人數，也不是每換一個目標就重新取得首發。

- **期限、疊層與重新可用**：本祝福沒有命中後倒數、獨立層數或彈匣層數；射擊計數保持 0 時條件持續有效。停火後，計數依當前武器及移動狀態的停火清除門檻重設，之後再取得首發資格；沒有一個所有型號通用的固定等待秒數。

- **裝填與切換武器**：裝填與切換本身不直接重設射擊計數。切走後持用條件失效；停火計數仍按當前武器條件更新。其他射擊也會使用同一份玩家計數，不能把切回原槍當成保證獲得首發。若停火清除條件已滿足，切回後可重新生效。

- **特殊攻擊**：自動槍、電能步槍與磷光手槍的槍托或手槍打擊屬近戰，不使用這項遠程力量修正。步兵鐳射槍與重伐木槍的手電筒切換不造成射擊傷害；格拉亞型號另有手電筒切換。

- **磷光爆破手槍的差異**：一般與瞄準射擊的直接命中可使用遠程力量加成。布蘭克斯 Mk XI 一般射擊命中後另觸發的爆炸使用爆炸類型，並採固定力量；燃燒則以增益效果攻擊類型另行結算，兩者都不讀取本項遠程修正。瞄準射擊沒有這個命中爆炸。

## 計算與算例

- **力量階段的前提**：取某一力量類型經原生曲線轉換後、套用增益修正前的力量輸入為 500，且其他適用力量修正為 0。這個 500 不是武器的原始或預設力量，也不是敵人扣除的生命值。

- **I–IV 代入**：I 為 500 × (1 + .14) = 570；II 為 580；III 為 590；IV 為 600。IV 在這個階段多出 100 力量，後續傷害、踉蹌與穿透仍依各自曲線及目標條件結算。IV 的 .20 取代備用 .02，所以不是 500 × 1.22 = 610。

- **與其他力量修正合併**：假設其他適用修正已合計 +30%。未套本祝福時，500 × (1 + .30) = 650；符合 IV 首發條件時，500 × (1 + .30 + .20) = 750。多出 100 力量，相對 650 為 100 ÷ 650 ≈ 15.38%，不是把既有 650 再乘 1.20 得 780，也不能把 15.38% 當成最終傷害比例。

- **命中與首發**：停火已清除計數後，第一發射出但落空，計數仍由 0 增加；持續射擊的下一發不會因前一發落空而重新獲得首發。空彈匣乾扣未進入有效射擊準備，則不增加計數。

- **停火與移動算例**：假設重伐木槍一般模式已停止射擊，距射擊結束時間 0.6 秒，且沒有阻止清除的動作。站立靜止時，0.6 尚未超過 1.5，計數仍保留；未蹲移動時，0.6 已超過 0.25，清除檢查可將計數歸零，之後條件加成重算即可再次取得首發。這說明移動狀態會改變門檻，不代表單憑按移動鍵就同步取得加成。
