# 凌遲(Torment)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/4a26461f-b7ea-4fcc-a54c-529c4ebfeca9" width="72" height="72" alt="凌遲祝福圖示">

- **觸發方式**：持用戴維爾戰鎬 布蘭克斯 Mk Ia、博羅維安 Mk III 或卡索拉斯 Mk II，以武器特殊攻擊命中敵人。布蘭克斯的上勾、另外兩型號的勾拉都能觸發；揮空不會觸發或刷新。

- **效果與疊層**：I–IV 級分別增加 12%／16%／20%／24% 的近戰威力修正，只有一層有效加成。這會修正傷害、衝擊及順劈相關的威力計算輸入；不保證最終生命傷害、踉蹌結果或順劈目標數等比例增加。

- **首次生效**：觸發命中的傷害與踉蹌先結算，命中事件之後才啟用效果，首次命中的結果不會回溯加成。後續命中要等加成進入威力快取後才可受益；同一揮擊較晚處理的命中也可能受益，不能把整次揮擊一律視為已加成。

- **期限與刷新**：合格命中事件處理時開始計算 3.5 秒。有效期間再次以特殊攻擊命中，會從這次事件處理時間重算 3.5 秒，不疊高數值。伺服器在更新時間超過期限時移除有效層；等於期限的那一刻尚未通過到期判定。效果啟用、移除及切換的實際攻擊讀值仍取決於狀態快取更新。

- **普通與特殊攻擊**：輕攻擊、重／蓄力攻擊，以及推擊後接續的斬擊不能觸發或刷新；在效果有效且持用戰鎬時，它們與後續特殊近戰命中都可讀取近戰威力加成。純推擊使用另一種攻擊類型，既不觸發，也不套用本項近戰威力修正。

- **順劈預算**：揮擊開始時已保存順劈的命中質量預算；之後在同一揮擊內觸發本祝福，不會因此重新計算該預算。下一次揮擊可以採用已更新的加成；伺服器校正另有重算流程。

- **切換武器與移除**：切到其他武器槽後，持用條件停用這個加成，但 3.5 秒計時繼續。期限內切回，待快取更新後可恢復剩餘時間的效果；到期後切回不會重新取得加成。若裝備的戰鎬祝福效果被移除，它建立的子效果也會一起清除。

## 計算與算例

- **前提**：S 是同一攻擊經過武器原生威力類型曲線後、加入本項修正前的輸入；武器、目標、護甲與其他條件固定。以下是計算示例，沒有把威力輸入當成實測生命傷害。

- **IV 級、無其他同類修正**：S＝100、p＝0.24，代入 100×(1＋0.24)＝124。此階段增加 24%，代表後續公式得到較高威力輸入；不代表最後一定多 24% 傷害。

- **已有同類修正 q＝0.20**：原本是 100×(1＋0.20)＝120；加入 IV 級後是 100×(1＋0.20＋0.24)＝144。比原本增加 24，相對增幅為 24÷120＝20%；不是把 120 再乘 1.24 得到 148.8。

- **刷新與到期**：假設事件在 t＝10 秒處理，期限為 13.5 秒；t＝12 秒再次處理合格特殊命中，期限刷新為 15.5 秒。t＝15.5 秒尚未通過嚴格「超過期限」判定；下一次更新若為 t＝15.6 秒，便移除有效層，後續快取更新才反映移除。玩家意義是以再次命中延長同一層效果，不能靠連續命中提高層數。
