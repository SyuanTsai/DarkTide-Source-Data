# 死亡噴吐(Deathspitter)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/5057bc6d-9f7b-44e9-a6dd-afb72af7cf3e" width="72" height="72" alt="死亡噴吐祝福圖示">

- **觸發方式**：持用裝有死亡噴吐的遠程武器，並由這個武器的實際道具造成擊殺；攻擊須是遠程類型，或其傷害設定明確標記為可計作遠程，且命中點距離攻擊者當前位置不超過 12.5 公尺。這是近距離遠程擊殺條件。
- **效果與等級**：每個通過條件的擊殺事件增加一個有效層。I／II／III／IV 每層分別提高 5／5.5／6／6.5 個百分點的通用威力修正，最多五層，滿層為 25／27.5／30／32.5 個百分點。此值進入威力計算，不代表最終生命傷害等比例增加。
- **首次生效**：擊殺目標的傷害先完成結算，之後才送出並處理擊殺事件。待事件增加層數且玩家屬性快取更新後，後續攻擊才可使用新威力；造成該層的擊殺不會回溯受益。
- **層數與期限**：合格擊殺事件每次增加一層；每次重新觸發會重設同一個倒數，即使已達五層也會延長現有層數。離開持用狀態不會暫停倒數；計時到期後的固定更新，現有有效層一併移除，而非逐層獨立衰退。除雙管霰彈槍外，持續 3.5 秒；雙管霰彈槍十字星 Mk XI、克魯克 Mk IV 持續 5 秒。
- **直接射擊與特殊彈**：自動槍、偵察鐳射槍、重型機槍與霰彈槍的直接遠程射擊、瞄準射擊及霰彈槍直接彈丸命中，仍按相同近距離擊殺條件判斷。載入或切換特殊彈本身不造成攻擊；直接特殊彈丸擊殺仍可符合條件。
- **延遲效果**：戰鬥霰彈槍奧克塔蘭 Mk IX 的特殊燃燒彈以及滅絕者霰彈槍鐵腕 Mk III 的特殊電擊彈，其直接彈丸擊殺可判定；後續燃燒或電擊間隔傷害以 buff 類型攻擊結算，且對應傷害設定沒有遠程計算標記，因此不會自行觸發本祝福。鐵腕 Mk VIII 特殊彈增加的是破甲狀態，沒有額外傷害跳數。
- **不觸發的近戰動作**：雙鏈重型機槍的刺擊、衝覆者霰彈手槍和防暴盾牌的盾擊／推擊及重擊揮掃，都是近戰或推擊路徑，不會觸發近距離遠程擊殺條件。它們不增加層數；若既有層數仍在且該攻擊使用通用威力輸入，才依當時持用狀態與屬性快取判斷其結算。
- **切換與移除**：切到其他武器時，原武器的持用條件關閉，威力增量停用；原有倒數仍繼續。倒數結束前切回，尚存層數在條件及快取更新後可再次生效。真正卸下或移除該武器祝福會移除父效果並清理其子層。

## 計算與算例

- **算例一：五層威力輸入**
  - 前提：IV 級、五個有效層已完成事件及屬性快取更新；正持用本祝福武器。令 B=100 為攻擊套用威力類型曲線後、套用通用威力修正前的輸入；其他威力修正 q=0。
  - 代入：每層 p=0.065，總增量 5×0.065=0.325；P=100×(1+0+0.325)=132.5。
  - 結果：威力輸入由100變成132.5，增加32.5；修正池增加32.5個百分點。
  - 玩家意義：132.5是後續傷害、衝擊與穿透計算使用的威力輸入；最終生命傷害仍由攻擊設定、目標護甲及後續計算決定。
- **算例二：已有其他威力修正**
  - 前提：沿用 B=100、IV 級五個有效層與相同攻擊／目標條件；其他威力修正 q=0.20。
  - 代入：原輸入100×(1+0.20)=120；加入本祝福後100×(1+0.20+0.325)=152.5。
  - 結果：輸入由120變成152.5，增加32.5；相對原輸入增加32.5÷120≈27.08%。
  - 玩家意義：同一修正池的增量相加，不能把1.20再乘1.325；27.08%只比較這兩個威力輸入，不是最終傷害增幅。剛觸發的擊殺也不會回溯使用新層。

## 遊戲描述勘誤

繁中 RAW 的「近戰攻擊擊殺後」將觸發寫成近戰攻擊；實際條件是 ranged attack 或明確標記 `count_as_ranged_attack` 的攻擊所造成的近距離擊殺，這是用詞勘誤。應理解為「近距離擊殺」，不是近戰武器擊殺。英文 `Close Range Kill` 與近距離條件相符。兩種 RAW 均未列 12.5 m 數值、精確 item/持用條件、層數上限、事件更新時點、期限刷新及特殊傷害 tick 分流；這些是文件未涵蓋，不另列翻譯矛盾。
