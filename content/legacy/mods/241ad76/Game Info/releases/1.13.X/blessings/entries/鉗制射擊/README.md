# 鉗制射擊(Pinning Fire)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/dd48f273-eab9-465a-9179-dbd6dd092e92" width="72" height="72" alt="鉗制射擊祝福圖示">

- **觸發方式**：持有這些實際綁定型號時，攻擊命中並在伺服器命中處理中得到「實際造成踉蹌」結果，且命中事件所帶的攻擊物品與祝福來源武器相同，才會加層。每個通過檢查的命中事件最多增加一層；不要求擊殺，也沒有額外攻擊類型篩選。具有「堅忍衛士近戰弱點命中視為踉蹌」特殊規則時，近戰弱點命中也會通過這項踉蹌檢查。
- I–IV 每層分別提高通用威力修正值 4.25%、4.5%、4.75%、5%；有效上限五層。
- 每次合格命中會將共用 2.5 秒期限重新計時；到達五層後再觸發不會加出第六層，但仍會刷新期限。期限到後，實際層數在後續祝福更新中移除。
- 祝福效果及新增層數都要求當下持有來源武器。切換到另一把武器時，新增觸發停止，威力加成也暫時不提供，但已建立的期限繼續流逝；期限內切回可恢復仍存在的層數。從配置中真正卸下該祝福武器會移除它的祝福效果。
- 命中傷害先結算，之後才檢查踉蹌並排入祝福事件；新層須待後續威力快取更新才供後續攻擊讀取，不會回頭提高觸發它的那一擊。
- 七個實際型號為：撕裂者自動手槍 尤斯 Mk IV（autopistol_p1_m1）、矛頭爆矢槍 洛克 Mk IIb（bolter_p1_m1）、矛頭爆矢槍 洛克 Mk III（bolter_p1_m2）、雙持自動手槍 布蘭克斯 MkIII（dual_autopistols_p1_m1）、重伐木槍 克魯克 Mk IIa（ogryn_heavystubber_p2_m1）、重伐木槍 戈爾貢努姆 Mk IIIa（ogryn_heavystubber_p2_m2）、重伐木槍 阿克利斯 Mk II（ogryn_heavystubber_p2_m3）。七者的普通腰射與瞄準射擊都是 hitscan；洛克 Mk IIb／Mk III 和布蘭克斯 MkIII 的特殊動作實際是近戰揮掃，若實際造成踉蹌也可觸發；尤斯 Mk IV 與三款重伐木槍的特殊動作是切換手電筒，不產生命中事件。
- 洛克 Mk IIb／Mk III 的 hitscan 彈另有條件式爆炸路徑：Mk IIb 的基礎引爆距離為 5，Mk III 為 3；達到距離後，若命中結果耗盡 hit-mass 或進入設定的停止／穿透停止分支，伺服器會排入對範圍目標逐一執行的爆炸攻擊。這些目標攻擊帶原 Bolter 物品、攻擊類型為 explosion；若目標實際被踉蹌，且當下仍持有來源武器，仍可通過本祝福檢查。此類爆炸 profile 使用固定基礎威力 500，通用威力修正則在爆炸目標攻擊計算時由當下的攻擊者威力快取讀取；不代表每發必爆、每個目標都踉蹌，或爆炸必定增加層數。
- 「純推擊」的獨立推擊通知不是本祝福監聽的 on_hit；只有實際攻擊設定另走 Attack 命中並得到踉蹌時才符合共同檢查。洛克兩個特殊動作雖以 `action_push` 命名，實際類型是會造成近戰命中的 sweep，不是純推擊。
- `power_level_modifier` 先作用於原生威力曲線後的威力值，再由各攻擊傷害設定轉成傷害；它不是最終生命傷害的固定百分比。

## 計算與算例

- **前提**：使用實際綁定的撕裂者自動手槍 尤斯 Mk IV 腰射；該路徑的 `shoot_hit_scan` 使用 `default_autopistol_bullet`，其命中傷害 profile 是 `default_autopistol_assault`。以下假設同一目標的兩次直接命中都由伺服器判定為實際踉蹌，且每次都通過來源物品／持用檢查；這是事件序列前提，不代表該 profile 對所有目標必定踉蹌。令每次攻擊原生威力曲線輸出 `P_curve=100`，其他威力修正 `q=0`，選 IV 每層 `p=0.05`。100 是供此實際武器事件路徑計算的正規化中間威力輸入，不是固定傷害值。
- **事件次序與代入**：起始 `k=0`。第一發先以 `100 × (1 + 0 × 0.05)=100` 計算命中；傷害結算後才送出踉蹌事件，增加第 1 層，待威力快取更新後 `k=1`。第二發先讀到第 1 層，以 `100 × (1 + 1 × 0.05)=105` 計算；其傷害同樣先結算，若本次也實際造成踉蹌，之後才增加第 2 層，下一次快取更新後的威力輸入為 `100 × (1 + 2 × 0.05)=110`。每次合格事件各刷新 2.5 秒期限。
- **玩家意義**：這條真實的尤斯 Mk IV 腰射 hitscan 路徑示範每個踉蹌事件如何逐層提高後續攻擊的威力輸入；例中的 +5%／+10% 是威力階段的變化，不是最終生命傷害百分比，實際傷害仍由 `default_autopistol_assault` profile、命中部位、護甲與其他修正決定。
