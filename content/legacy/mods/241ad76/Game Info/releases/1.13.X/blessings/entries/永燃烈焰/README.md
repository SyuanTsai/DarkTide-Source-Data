# 永燃烈焰(Everlasting Flame)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/4a057aec-b5c7-4d9c-8399-a70094eb498a" width="72" height="72" alt="永燃烈焰祝福圖示">

- **觸發方式**：持用帶有永燃烈焰的噴火器時，新的暴擊判定成功便觸發從備彈移入燃料箱；不要求命中或擊殺，未命中也可觸發。

- **等級效果**：I–IV每次最多移入2、3、4、5單位燃料。

- **容量限制**：實際移入量以處理效果時的燃料箱缺額與剩餘備彈為上限；缺額只有1單位就只補1，備彈只有2單位就最多補2。

- **彈藥來源**：補入燃料箱的數量會從備彈扣除；沒有備彈就不補，這不是生成免費燃料。

- **射擊耗料**：點射和連噴仍按原本規則消耗燃料箱；暴擊不會讓每次射擊都免耗燃料。

- **點射與連噴**：兩種模式都能觸發；連噴一次新的成功判定最多帶出三次連續暴擊射擊，但這一段只觸發一次補入。

- **命中次數**：同一次噴射打中多個敵人，不會為每個敵人再補一次；燃燒傷害的每次跳傷也不另觸發補入。

- **持續與層數**：沒有疊層、效果倒數或觸發冷卻；下一次新的暴擊判定成功時再處理一筆。

- **切換武器**：切出後不再提供補入；已經補進燃料箱的燃料仍保留，切回後可由新的成功判定再次觸發。

- **滿箱時的點射**：暴擊點射在這發射出前處理補入；燃料箱仍滿時補入量為0，這發之後照常消耗1單位。

- **滿箱時的連噴**：新暴擊射擊先消耗1單位，隨後再補入；若備彈足夠，剛少1單位便只補1單位。

## 計算與算例

- **正常補入前提**：IV級，在處理補入時燃料箱容量40、現有20、備彈60；先只比較這筆轉移。

- **正常補入結果**：`min(5,40－20,60)＝5`，燃料箱由20到25，備彈由60到55；總燃料仍是80。

- **缺額限制前提**：IV級，在處理補入時容量40、燃料39、備彈60。

- **缺額限制結果**：`min(5,1,60)＝1`，燃料箱到40、備彈到59；不是固定扣5單位備彈。

- **備彈限制前提**：IV級，處理時容量40、燃料20、備彈2。

- **備彈限制結果**：只移入2單位，燃料箱到22、備彈歸零；之後沒有備彈時不再補入。

- **滿箱前提**：處理補入效果時燃料箱仍已滿，或備彈為0。

- **滿箱結果**：這筆轉移為0；不能用按下射擊時是否滿箱代替處理效果時的缺額。

- **連續暴擊前提**：IV級一次新判定成功，帶出三次連續暴擊射擊；這次處理補入時缺額與備彈都足夠補5，期間沒有另一次新判定。

- **連續暴擊結果**：整段只轉移5單位，三次射擊仍各耗1單位；不能按三次暴擊命中算成移入15單位。

- **滿箱點射算例**：IV級、容量40、起始燃料40、備彈60；成功判定暴擊後，補入時缺額0，這發射出後為燃料39、備彈60。

- **滿箱連噴算例**：同樣條件，連噴新的暴擊射擊先耗1，隨後這筆補入為`min(5,1,60)＝1`；燃料回40、備彈59。若後兩次射擊沿用暴擊，這兩次不再補入，各耗1，整段結束為燃料38、備彈59。

## 遊戲描述勘誤

- **本體把觸發寫成命中**：英文Critical Hits與繁中「致命一擊」未表明實際是在新暴擊判定成功時觸發；不需要擊中敵人。

- **本體把效果寫成改扣備彈**：實際是從備彈轉入燃料箱，I–IV最多2／3／4／5單位；原本射擊耗料流程仍運作。

- **本體省略補入上限**：燃料箱缺額與備彈不足都會限制實際轉移，滿箱和零備彈的這筆轉移為0。

- **本體省略延續暴擊**：連噴延續的後續暴擊射擊不會為這段再觸發新的補入。
