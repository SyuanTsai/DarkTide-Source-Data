# 閃電反射(Lightning Reflexes)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a5db31b7-608a-488a-8d23-6ccfec4c2f3f" width="72" height="72" alt="閃電反射祝福圖示">

- **觸發方式**：持用帶有此祝福的武器格擋近戰攻擊，獲得近戰威力加成；格擋遠程攻擊不會觸發。

- **等級效果**：I–IV分別增加10%／15%／20%／25%近戰威力，四種武器數值相同。

- **持續時間**：電弧鎚維持5秒；電擊錘、法務官電擊鎚，以及法務官電擊鎚和鎮壓護盾維持3秒。

- **普通格擋**：不必完美格擋就能獲得威力加成。格擋時即使耐力耗盡而破防，這項效果仍能觸發。

- **完美格擋**：在效果可觸發時完美格擋近戰攻擊，除了威力加成，另對進攻者施加3秒電擊減益。

- **完美格擋時間窗**：基礎時間窗為開始舉防後0.3秒，可受其他延長完美格擋時間的效果修正。

- **再次觸發**：威力效果維持期間，後續格擋與完美格擋不會再觸發或延長這項效果；威力加成也不疊層。期限結束後可再次觸發。

- **電擊效果**：電擊期間會按約0.3–0.8秒的隨機間隔處理傷害與踉蹌；實際傷害及控制反應依敵人的護甲與抗性結算。3秒是減益期限。

- **效果機率**：符合條件時施加效果，不需額外抽取觸發機率。

- **切換武器**：切出後近戰威力加成停止作用，3秒／5秒倒數繼續；期限內切回可恢復剩餘效果。已施加在敵人身上的電擊繼續存在。

- **傷害意義**：百分比增加的是近戰威力，會影響後續傷害與踉蹌計算；不等於最終扣血必定增加相同比例。

## 計算與算例

- **IV級電擊錘**：一次普通近戰格擋後獲得+25%近戰威力，持續3秒；1秒後再次格擋不疊加、不延長期限。

- **IV級電弧鎚**：完美格擋後的+25%近戰威力維持5秒，敵人的電擊減益維持3秒；這兩段期限各自計算。

- **與其他威力加成**：同一威力加成組原有+20%，再獲得IV級+25%後合計+45%；這兩項加成不直接相乘。

- **切換武器**：電擊錘觸發後1秒切出，2秒時切回仍有約1秒加成；切換期間倒數繼續。

## 遊戲描述勘誤

- 本體泛稱「格擋攻擊」，實際只接受近戰格擋，且沒有排除格擋破防。

- 本體的威力持續與冷卻欄位都讀取同一武器期限：電弧鎚5秒，其他武器3秒。期間鎖住再次觸發，而非效果結束後再額外等待同一段冷卻。

- 敵人電擊減益固定3秒，與電弧鎚的5秒威力加成分開。
