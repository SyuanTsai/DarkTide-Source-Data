# 懲罰射擊(Punishing Fire)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/63d34e16-454f-4ece-8051-9c473c0a1619" width="72" height="72" alt="懲罰射擊祝福圖示">

- **效果**：I–IV 分別提高遠程攻擊的力量修正 +6%、+9%、+12%、+15%，每次觸發持續 3 秒。
- **觸發方式**：持用具備本祝福的武器，以武器特殊攻擊 Bash 掃擊時，合格近戰命中事件的當前目標序號達到第 3 個或之後，即可觸發。序號在每次 Bash 掃擊重新開始；不會累積不同次攻擊的命中，也不要求擊殺、踉蹌或正傷害數值達到門檻。
- **生效與刷新**：觸發後形成一個不疊層的 3 秒效果。再次符合條件可在效果期間重新觸發並刷新 3 秒計時；命中更多目標不會把同一級數值逐次堆高。
- **適用攻擊**：效果加在遠程攻擊的力量修正上。反衝者洛倫茲 Mk V 的一般射擊以多彈丸命中掃描取得命中；惡棍槍洛倫茲 Mk VII 的一般射擊是命中掃描。Bash 本身是近戰掃擊，只用來觸發，不會吃到遠程力量修正。
- **推擊與切換**：推擊本體走獨立的推擊事件，不符合近戰命中條件；後續 Bash 是另一個動作，須自行達到序號門檻。切到其他武器時本效果不提供力量修正，但 3 秒計時仍繼續；在到期前切回仍可使用剩餘時間。移除該武器時，附著於武器的祝福效果會一併移除。

## 計算與算例

**例一：首次觸發**

- **前提**：持用反衝者洛倫茲 Mk V 的 IV 級祝福，一次 Bash 掃擊依序處理至少 3 個目標，且第三個目標產生符合條件的近戰命中事件。
- **代入**：本級修正為 +15%；檢查的是此事件的 `target_number >= 3`，不是累積三次先前命中事件。
- **結果**：ProcBuff 啟動一次 3 秒遠程力量修正；同次掃擊的後續合格事件只刷新同一效果，不增加層數。
- **玩家意義**：第一個符合序號條件的事件可以是第 3 個目標；前兩個目標不必先各自造成正傷害或觸發成功事件。

**例二：力量修正的代入**

- **前提**：把完成原生武器力量類型曲線後、套用力量修正前的遠程力量輸入記為 `S_native = 500`；假設其餘當次適用力量修正（含全域、遠程、弱點與條件修正；不適用項目為 0）的淨加總為 `q = +0.20`，再觸發 IV 級 `p = +0.15`。
- **代入**：觸發前 `500 × (1 + 0.20) = 600`；觸發後 `500 × (1 + 0.20 + 0.15) = 675`。
- **結果**：力量輸入增加 75，相對原本 600 增加 12.5%；本級的 +15% 是加到力量修正總和，不是把既有 +20% 再乘 1.15。
- **玩家意義**：675 是後續傷害、踉蹌及順劈計算的力量輸入，不代表最終傷害必定增加 15%。
