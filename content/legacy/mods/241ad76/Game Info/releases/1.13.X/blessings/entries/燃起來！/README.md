# 燃起來！(Gets Hot!)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/f71da10a-4d18-4981-be0e-6c4d185e59db" width="72" height="72" alt="燃起來！祝福圖示">

- **適用武器**：電漿槍 M35熔岩核心 Mk II 與 Mk III 共用本項 I–IV 數值與熱能機制。

- **觸發方式**：持用且未裝填或散熱時，依熱能分成 0–5 階，理論升階門檻為 19%、37%、55%、73%、91%。沒有靠命中累積的獨立層數或固定秒數期限；熱能上升或下降時，階數隨之重新評估。

- **爆擊機率**：I–IV 每階增加 5.5／7／8.5／10 個百分點，五階合計增加 27.5／35／42.5／50 個百分點。加成加入一般爆擊機率池，再與其他適用來源結算；不保證固定射擊頻率。

- **遠程爆擊傷害**：I–IV 每階增加 4%／6%／8%／10% 的額外傷害係數，五階合計為 20%／30%／40%／50%。這項係數放大爆擊命中的額外傷害部分；爆擊兼弱點命中時，使用兩者合併後的一份額外傷害。

- **一般與蓄力射擊**：兩個型號都在射擊動作開始時判定該發是否爆擊；一般及蓄力單發的武器處理設定另加 5 個百分點爆擊率。該發命中結算完才加入射擊產生的熱能，因此不會追溯取得自己造成的新熱階加成。

- **首次生效**：射擊開始時已進入機率池的熱階加成，第一發即可使用，不必先命中。後續射擊在熱階更新後使用新數值。

- **裝填與散熱**：裝填及特殊散熱動作被判定為裝填中，狀態更新讀到裝填或散熱時，本祝福評估為零階。散熱自傷不會爆擊，不能使用爆擊額外傷害加成。

- **切換武器**：狀態更新讀到離手時，持用條件關閉，兩種加成停止貢獻；切回後依當下熱能重新評估，沒有另外儲存的祝福層數或倒數可延續。

- **過熱爆炸**：過熱爆炸與爆炸前的週期自傷固定不爆擊，不能取得這項爆擊傷害加成。

- **更新時點**：步階由武器狀態更新；固定來源未確認切回武器同一影格內的快取刷新先後，因此不把同影格立即射擊的加成當作已驗證行為。

## 計算與算例

- **熱階代入例**：假設熱能比例為 92%，`n = round(clamp01((0.92 − 0.10) / 0.90) × 5) = round(4.555…)=5`。IV 級在此提供爆擊機率 `5 × 10 個百分點 = +50 個百分點`，以及遠程爆擊傷害係數 `5 × 10% = +50%`（後者只套用於爆擊 finesse 額外部分）。

- **機率池例**：假設機率轉傷害係數為 0，且沒有保證或禁止爆擊的其他效果；除本祝福與單發處理值外的適用機率合計為 20%，IV 級五階的一般射擊機率池為 `20% + 50 個百分點 + 5 個百分點 = 75%`。這是進入遊戲爆擊判定前的示例機率，不是保證每四發必有三發爆擊；程式另有百分之一精度取整與 PRD。

- **傷害公式**：令 `B` 為同一命中中不受本係數影響的傷害部分，`F` 為 `base_finesse_damage`（爆擊兼弱點時是合併後的一份額外值），`c` 為相同 finesse 乘數階段已有的加成，`h` 為本祝福的遠程爆擊傷害加成。固定其他結算時，`D_before = B + F(1+c)`、`D_after = B + F(1+c+h)`，所以 `ΔD = Fh`，相對增幅為 `Fh / D_before`。

- **額外部分占總命中三分之一**：假設 IV 級五階 `h=0.50`、`B=100`、`F=50`、`c=0`。代入前 `100 + 50×1 = 150`；代入後 `100 + 50×1.50 = 175`；增加 25 傷害單位，相對完整命中 `25/150 = 16.67%`。F 原本只占總量 1/3，因此整體命中不會增加 50%。

- **額外部分占總命中一半**：假設 `B=100`、`F=100`、`c=0`、`h=0.50`。代入前為 200，代入後為 250，增加 50；相對完整命中為 `50/200 = 25%`。

- **已有同階加成**：假設同階段已有 `c=0.25`，`B=100`、`F=100`、本祝福 `h=0.50`。代入前 `100+100×1.25=225`；代入後 `100+100×1.75=275`；增加 50，相對完整命中為 `50/225 = 22.22%`。兩項在此乘數階段加算為 1.75，而不是相乘成 1.875。

- 以上 `B`、`F` 與傷害單位均為明示假設，不是 Mk II／Mk III 的實戰傷害測量；假設同一命中的其餘增減傷與後續倍率保持不變，並假設 `critical_strike_chance_to_damage_convert=0`。

## 遊戲描述勘誤

- RAW 的「最高/up to `{crit_chance:%s}`」在靜態 formatter 中只讀每熱階值：I–IV +5.5／+7／+8.5／+10%。runtime 可到五階，實際上限為 +27.5／+35／+42.5／+50 個百分點；應補充這個五階總量，不能把 RAW 佔位值當成最高值。

- 遠程爆擊傷害句正確描述了增加，但未說明跟隨熱階逐步累積，亦未列五階 +20／+30／+40／+50% 上限；這是說明未涵蓋完整機制，不判為繁中翻譯錯誤。

- 英文與繁中使用相同 localization key/hash，沒有繁中單獨偏離英文的證據。
