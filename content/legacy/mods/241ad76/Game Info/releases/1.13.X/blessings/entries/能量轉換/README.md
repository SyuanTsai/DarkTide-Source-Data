# 能量轉換(Energy Transfer)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/71e66fb6-ddd3-461a-9283-4dbdfa7e5d96" width="72" height="72" alt="能量轉換祝福圖示">

- **觸發方式**：持用帶有能量轉換的武器，格擋攻擊後啟動效果；一般格擋即可，完美格擋也能觸發。

- **等級效果**：I–IV讓充能的持續產熱量分別乘以0.84、0.82、0.80、0.78，也就是減少16%、18%、20%、22%。

- **產熱範圍**：降低充能期間持續增加的熱量；揮擊開招時的立即產熱維持原量。

- **自然散熱**：I–IV自然散熱速度分別乘以1.03、1.04、1.05、1.06，增加3%、4%、5%、6%。

- **散熱啟動**：加成在自然散熱原本可運作時提高速度；格擋本身不扣除既有熱量，也不省略停用充能後的散熱等待。

- **持續與刷新**：效果持續5秒；期間再次格擋會把期限延至該次格擋後5秒，倍率不疊加。

- **冷卻與到期**：沒有觸發冷卻；到期後恢復原本產熱與散熱速度，再次格擋即可重新啟動。

- **切換武器**：切出時停止提供兩項倍率，5秒期限仍流逝；期限內切回恢復剩餘時間，超時後需再次格擋。

- **破防格擋**：這次格擋即使耗盡體力而破防，仍可觸發。

## 計算與算例

- **持續產熱前提**：IV級效果生效中，某段充能原本持續產生20個百分點熱量，起始熱量50%，沒有其他倍率、散熱或上限截斷。

- **持續產熱結果**：新增`20×0.78＝15.6個百分點`，熱量由50%到65.6%；若同時有一筆開招立即產熱，該筆另照原量增加。

- **已有產熱倍率前提**：同一段原本產熱20個百分點，已有0.90倍持續產熱效果，IV級能量轉換再生效。

- **已有產熱倍率結果**：新量為`20×0.90×0.78＝14.04個百分點`，相對原始20減少29.8%；不是把兩個減少百分比直接相加。

- **自然散熱前提**：IV級仍有效，武器已經開始自然散熱；假設某一秒原本散掉8個百分點，期間散熱區間、其他倍率與狀態固定，也未降到0%。

- **自然散熱結果**：該秒散掉`8×1.06＝8.48個百分點`；起始40%熱量會降至31.52%，原本則降至32%。

- **已有散熱倍率前提**：同一秒原本散8個百分點，已有1.20倍自然散熱速度，再加入IV級能量轉換。

- **已有散熱倍率結果**：共散掉`8×1.20×1.06＝10.176個百分點`；相對已有1.20倍效果，速度再增加6%。

- **刷新前提**：10秒格擋，13秒再次格擋。

- **刷新結果**：原本15秒到期改為18秒，IV級仍是持續產熱0.78倍、自然散熱1.06倍。

- **切換前提**：10秒觸發，11秒切出，14秒切回，期間沒有再次格擋。

- **切換結果**：切回剩約1秒，15秒到期；切出期間沒有這兩項倍率。
