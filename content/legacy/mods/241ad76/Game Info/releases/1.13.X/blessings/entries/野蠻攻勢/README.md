# 野蠻攻勢(Brutal Momentum)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/6c47b470-d79e-4ffd-bf34-7d0b080ad5c0" width="72" height="72" alt="野蠻攻勢祝福圖示">

- **觸發方式**：持用帶有此祝福的武器時，近戰弱點額外傷害增加7.5／10／12.5／15%，依序對應I／II／III／IV級。

- 首擊即可享有。

- 加成作用於弱點額外部分，整次命中的增幅隨該部分占比改變。

- **順劈條件**：同一次揮擊中，前三次擊殺若以弱點命中殺死非歐格林敵人，該敵人不累加命中質量，攻擊可繼續。

- 符合質量回退條件的弱點擊殺，也不推進順劈的傷害順位。

- 每次揮擊重算擊殺數。

- 先前的非弱點擊殺也占用這三次擊殺的名額。

- **例外**：弱點命中但沒有擊殺，或擊殺歐格林類敵人，都不享有這個質量回退。

- 不是每次弱點命中都無視敵人質量，也不保證無限貫穿目標。

- **持續與切換**：沒有疊層、刷新、冷卻或擊殺後倒數。

- 持用時生效，切出時停止。

- 切回後弱點加成立即恢復，無需先擊殺。

## 特殊攻擊

- 盾推本身不套用順劈質量回退。

- 推擊後的近戰揮擊可按相同條件受益。

- 動力錘的特殊爆炸不套用此近戰弱點加成或順劈質量回退。

## 計算與算例

- **額外部分占20%**：假設一次非暴擊弱點命中的傷害拆成80點基本部分、20點弱點額外部分，其他條件不變。

- IV級15%使`80 + 20 × 1.15 = 103點`，由100增加3點，整次增幅3%。

- **額外部分占50%**：假設改為50點基本、50點額外，則`50 + 50 × 1.15 = 107.5點`，整次增幅7.5%。

- 相同15%不代表相同整次增幅。

- **已有同階段加成**：沿用80點基本、20點未加成額外，原有25%同階段加成時為`80 + 20 × 1.25 = 105點`。

- 加上IV級後為`80 + 20 × (1 + 25% + 15%) = 108點`，相對105增加約2.86%。

- **命中質量**：假設一擊順劈容量為5、先前累計0，下一敵人質量3，且本次是前三次擊殺之一並以弱點擊殺非歐格林敵人。

- 命中後累計回到0，保留5容量。

- 若沒有擊殺，則累計3、剩2容量。

- 這個例子中，弱點擊殺讓此次揮擊保留完整順劈容量。

- **順位保留**：假設同一攻擊在相同命中條件下，第一順位造成100點傷害、第二順位50點，且順劈容量足夠。

- 前四名敵人都是非歐格林，並且都被本次弱點命中擊殺。

- 前三名的合格擊殺不推進順位，因此第四名仍按第一順位造成100點傷害。

- 第四次擊殺不再回退質量或保留順位；下一名按第二順位造成50點傷害。

## 遊戲描述勘誤

- 繁中把英文「Weakspot Kills」寫成「弱點傷害」。

- 實際需要以弱點命中擊殺，單純造成弱點傷害不會無視該敵人的命中質量。
