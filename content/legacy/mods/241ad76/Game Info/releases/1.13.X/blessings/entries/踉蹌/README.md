# 踉蹌(Falter)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/9a227f1b-06ae-4521-995a-22719d62e917" width="72" height="72" alt="踉蹌祝福圖示">

- **觸發方式**：持用裝有「踉蹌」的武器，且該次攻擊命中符合弱點判定，才會套用弱點減免修正；持用自動槍或步兵鐳射槍時，攻擊類型為遠程的攻擊另有 +30% 踉蹌強度輸入修正。
- 弱點修正會乘在一般目標已經經過弱點 finesse 減半後的基準減免：I–IV 再乘 0.4／0.3／0.2／0.1（即相對於該弱點基準減少 60%／70%／80%／90%）；不是直接提高同幅度的最終踉蹌或傷害。
- 遠程 +30% 是踉蹌強度輸入修正，僅攻擊類型為遠程時才會讀取，與是否弱點分開；實際強度還經威力、護甲、目標與踉蹌次數曲線計算。
- 攻擊 profile 若忽略踉蹌減免，或目標有自己的弱點減免覆寫，原生計算會在本級乘數前分流；不保證本項改動所有目標／profile。
- 純推擊走推擊類型且命中區固定為軀幹；不會觸發弱點修正，也不是遠程攻擊。推擊後若有攻擊，按追擊自己的命中區、類型與 profile 判定。
- 電擊錘的直接蓄能特殊命中有各自 profile；上勾與部分重型蓄力 profile 忽略減免，獨立間隔電擊不是弱點或遠程命中。自動槍刺刀／槍托 profile 也忽略減免；鐳射槍手電筒切換不造成攻擊。
- 本項沒有層數、觸發冷卻或計時；持用含有祝福的武器時效果進入該武器的屬性計算。
- 首次裝備時加入buff；持用條件控制屬性，切槽後於下次屬性快取更新時停用，切回後再啟用；真正卸裝才移除buff。

## 計算與算例

- **弱點減免例**：前提是一般目標的原始減免值 R=50（是減免輸入的數值，非50%），profile 不忽略減免、目標沒有弱點專用覆寫、且沒有其他減免修正（包含燃燒修正）。合格弱點命中必先由 finesse 乘0.5：無本祝福基準 `50 × 0.5 = 25`。I：`50 × 0.5 × 0.4 = 10`；II：`50 × 0.5 × 0.3 = 7.5`；III：`50 × 0.5 × 0.2 = 5`；IV：`50 × 0.5 × 0.1 = 2.5`。結果是與同一弱點基準相比，四級分別再降60%／70%／80%／90%；這不是生命傷害或最終踉蹌的比例。
- **遠程強度例**：前提是持用裝有本祝福的 autogun_p3 或 lasgun_p1、攻擊類型確為遠程、基準 impact modifier 為1.00且其他八個影響項中性。代入：`1.00 + 0.30 = 1.30`，踉蹌曲線輸入 P=100 因此成130。意義是進入後續威力百分比／護甲與踉蹌次數曲線的輸入增30%；不是生命傷害或最終踉蹌保證增30%。
