# 雷鳴(Thunderous)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/bdf43380-ae08-4838-9db7-bef2a972e2cb" width="72" height="72" alt="雷鳴祝福圖示">

- **觸發方式**：使用目前持用、且實際裝有「雷鳴」的那把武器命中一個在本次傷害結算後仍存活、符合遊戲 Minion 判定的敵人；該次攻擊必須通過一般命中事件規則，並以同一武器物品送出事件。這不是「所有敵人／所有傷害來源」都會觸發；個別傷害設定若略過 on-hit，或傷害類型屬全域 no-proc，仍不會觸發。
- **每擊新增**：I／II／III／IV 對每個合格命中目標分別新增 1／2／3／4 層「脆弱」減益；每層對目標的 rending 修正為 +2.5 個百分點。新增量受該目標 16 層上限限制。
- **期限與刷新**：目標上的減益持續 5 秒；每次合格命中加層時刷新期限。即使目標已達 16 層，合格命中仍刷新 5 秒期限，但不會超過上限。相同目標上的 `rending_debuff` 以同一個命名層數合併，不依來源武器分開計數。切換武器會停止由未持用物品觸發新層，但不會直接移除已施加的目標減益。
- **第一次命中**：攻擊先結算本次傷害，再處理 on-hit 事件並施加目標減益，所以造成觸發的那一擊不會回溯受益。後續攻擊要在目標狀態更新後才讀到減益；不保證同一影格內後續攻擊已看見更新。
- **普通與重擊**：九種實際武器族的普通掃掠、重擊掃掠及已接入的推擊後斬擊都能進入一般命中事件路徑；各個實際傷害設定仍受 profile 略過與 no-proc 規則限制。
- **推擊**：推擊也有獨立的 Attack 命中路由並傳入來源武器物品；本祝福本身沒有 `melee`／`weapon_special`／正傷害門檻。因此，符合 Minion、同物品及一般事件過濾的實際推擊命中可施加層數，不能只因攻擊種類是 push 而排除。
- **特殊命中與追加攻擊**：直接特殊掃掠按其實際 Attack profile 判斷。2H 碾壓者的 powered 爆炸及電弧鎚的連鎖電弧各自呼叫 Attack 並帶回原武器物品；若其命中目標仍符合 Minion／item／profile 條件，也會各自送出 on-hit。僅啟動特殊模式或未呼叫 Attack 的效果不會單靠啟動觸發。
- **鏈斧追加段例外**：突擊鏈斧的黏附鋸齒追加傷害使用 9 個已實際接入且設 `skip_on_hit_proc=true` 的 profile，不會額外疊加雷鳴；初始命中仍按它自己的 profile 與事件條件判定。
- **疊層意義**：最多 16 層是目標 `rending_debuff` 的共用上限，不是每把武器各自的 16 層。每層 +2.5% 是目標 rending 屬性輸入，不等於每次攻擊最終傷害固定增加 2.5%。

## 計算與算例

- **前提**：IV 級命中一個尚未有 `rending_debuff` 的存活 Minion；命中由當前持用的實際武器物品送出一般 on-hit，且該 profile 沒有略過事件。
- **代入與結果**：IV 每次合格命中新增 `n=4` 層；每層目標修正 `r=0.025`，所以 `ΔR=min(4,16-0)×0.025=0.10`，即目標 rending 屬性輸入增加 10 個百分點，目標狀態最多 16 層並持續 5 秒。
- **上限例**：若目標原已有 14 層，IV 命中最多再新增 2 層，`ΔR=min(4,16-14)×0.025=0.05`；另外兩層不會突破目標上限。
- **玩家解讀**：+10 個百分點是本次可新增的目標 rending 修正，不是最終傷害乘以 1.10。後續傷害仍由其攻擊／護甲設定及其他 rending 輸入共同計算；觸發命中本身已先完成傷害結算。
