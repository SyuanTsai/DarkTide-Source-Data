## 執行與計算

- 八個實際武器 trait wrapper 都直接複製共用的多目標近戰命中 ProcBuff。共用模板訂閱 on_hit，要求 required_num_hits=3、攻擊物品相同、攻擊類型為 melee 且 target_number>=3，並以目前持用欄位作為效果條件；各 wrapper 的四級 stat_buffs.melee_power_level_modifier 和 active_duration=3.5 覆蓋共用基礎值。
- 近戰掃擊開始時重設命中序號；逐目標把序號與 weapon item 傳入攻擊結算。只有存活角色目標的序號留給後續目標。攻擊先結算傷害，再於目標在該目標傷害結算前仍存活且有 breed 資料時才排 on_hit；條件沒有擊殺、精英、弱點、暴擊或敵種限制。
- 純推擊使用 push 類型，不符合 melee；推擊接續 sweep 是新攻擊，須自行命中三個目標。重擊或特殊傷害 profile 不改門檻；特殊動作只有實際走 melee sweep 並送合格 on_hit 才可能觸發。
- 命中事件先排入 Buff 佇列，固定更新處理後寫 active start time，再重算屬性與關鍵字。第三個目標已先結算傷害，不會追溯取得效果；同次掃擊後續目標是否讀取更新後傷害／削韌值沒有保證。
- melee_power_level_modifier 進入 attack、impact 與 cleave 威力曲線；damage calculation 由 attack power 計算傷害，stagger calculation 由 impact power 計算削韌，sweep 依 cleave／attack／impact power 與 profile 求穿透質量上限。掃擊開始時快照 hit-mass 上限；觸發效果不會改寫已開始掃擊的穿透上限，之後新掃擊才在起始時計算更新值。
- ProcBuff 沒有 cooldown_duration 或 max_stacks；allow_proc_while_active=true。再次成功更新同一實例起始時間，重設 3.5 秒期限。切槽不移除 on_equip buff，期限照走；期限內回切可恢復剩餘效果。卸下移除 on_equip buff，extension 銷毀也清實例。
- Common proc stat 基礎 0.5；每級 trait_override.stat_buffs 取代同一 key。stat 類型 additive_multiplier；實際傷害、削韌與穿透結果還受 Power Type curve、damage profile 和其他修正影響。
- 鏈鋸兩家族黏附鋸切追加傷害再次 Attack.execute，但傳 target_number=1，實際 sticky profiles 也設 skip_on_hit_proc；不能獨自達門檻。普通掃擊仍按自己的 target_number 判定。

- 此祝福改 melee_power_level_modifier；Power Level 先依攻擊類型套 Power Type curve，再乘修正。該修正參與 attack、impact、cleave 威力計算，影響傷害、削韌和掃擊穿透質量上限；profile／曲線決定實際結果，不等同最終傷害固定百分比。
- 一般七類四級值 0.24/0.28/0.32/0.36，卡面 +24/+28/+32/+36%；穿音速雙刀 0.09/0.12/0.15/0.18，卡面顯示 9%/12%/15%/18%，formatter 不加「+」前綴。
- 算例將 100 設為已過 Power Type curve、尚未套用本項的近戰 Power Level；一般武器 IV 得 136，穿音速雙刀 IV 得 118。這是威力中間值，不是最終傷害、削韌或穿透結果。
