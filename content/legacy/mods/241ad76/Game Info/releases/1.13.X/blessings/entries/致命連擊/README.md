# 致命連擊(Chained Deathblow)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/d941be9f-1923-42e9-99b4-356cc86720f4" width="72" height="72" alt="致命連擊祝福圖示">

- **適用型號**：重劍 圖妥斯基 Mk VI、Mk VII、Mk IX，以及機械神教動力劍 布蘭克斯 Mk VI。

- **觸發方式**：以裝有此祝福的武器命中敵人弱點並擊殺；事件處理時仍須持用該武器，攻擊物品也須與祝福所屬武器相符。

- **可觸發的攻擊**：這些型號的普通輕擊、重擊、推擊後續揮擊與武器特殊攻擊中的傷害揮擊，只要該次攻擊確實造成弱點擊殺，就能符合觸發條件。動力劍啟動蓄能特殊狀態本身不算命中；後續蓄能揮擊仍可觸發。

- **純推擊**：純推擊本身不會觸發本祝福。這四個綁定型號的純推擊使用攻擊傷害為 0 的推擊 profile；推擊後續揮擊是另一個近戰攻擊，符合弱點擊殺條件時可以觸發。

- **效果**：觸發後，近戰爆擊率提高 I／II／III／IV 級 +5／+10／+15／+20 個百分點，持續 3 秒。

- **刷新與疊加**：3 秒內再次以同一祝福武器取得合格的弱點擊殺，會重新開始 3 秒計時；沒有額外冷卻，加成不會逐次疊高。計時到期後，加成停止作用；移除這個祝福效果後也不再提供加值。

- **切換武器**：切出該武器時，計時不會暫停，但加成暫不計入；若 3 秒尚未到期便切回，加成會在該武器仍被持用且屬性快取更新後恢復。

- **生效時點與爆擊率**：擊殺攻擊先完成傷害與爆擊判定，再排入觸發事件；這次攻擊不會回頭取得新加成。後續近戰攻擊在事件處理與屬性快取更新後才會讀到加成。此數值加入近戰爆擊率計算，不等於傷害提高相同百分比，也不保證每次攻擊爆擊。既有機率上限、爆擊轉傷害換算與其他強制／禁止爆擊效果仍按遊戲計算處理。

## 計算與算例

- **前提**：以 IV 級為例，假設原本近戰爆擊率為 20%，沒有其他爆擊率修正、沒有爆擊轉傷害換算、沒有強制或禁止爆擊效果，也不受 100% 上限影響。

- **代入**：20% + IV 級 20 個百分點 = 40%。

- **結果**：理論爆擊率由 20% 變為 40%，增加 20 個百分點；實際每次攻擊仍由遊戲的 PRD 爆擊流程決定。

- **玩家意義**：+20 個百分點是加入近戰爆擊率池的機率加值，不是整次命中傷害 +20%。

- **轉傷害對照前提**：再假設原始爆擊率 20%、IV 級加值 20 個百分點、爆擊轉傷害係數為 25%，沒有上限或其他修正。

- **代入與結果**：無祝福為 20% × (1−0.25) = 15%；有祝福為 (20%+20%) × (1−0.25) = 30%，理論差值為 15 個百分點。

- **玩家意義**：轉換係數在爆擊率加算與上限處理後作用，所以此受控例中的最終差值不是完整的 20 個百分點；PRD 仍會影響實際逐擊結果。
