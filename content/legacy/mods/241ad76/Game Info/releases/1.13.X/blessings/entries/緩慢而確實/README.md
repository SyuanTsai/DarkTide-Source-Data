# 緩慢而確實(Slow and Steady)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/5279832c-d7d6-4681-8397-a840feb26d4c" width="72" height="72" alt="緩慢而確實祝福圖示">

- **觸發方式**：持用裝有本祝福的戰鎬或碎骨者，蓄能動作跨過該連段設定的蓄能門檻時會累積計數；後續同一物品的合格命中會依這些已累積事件回復韌性。每次命中的回復倍率最多採用前三個已處理的蓄能門檻；尚未被命中、掃掠結束或重新持用清除的計數可繼續累積，超過三次不會增加回復量。
- **階級效果**：I–IV 顯示 +5%、+6%、+7%、+8% 最大韌性；命中時計數最多再乘 3，因此三次門檻後單次要求回復最大韌性的 15%、18%、21%、24%。實際回復不會超過當前缺少的韌性。
- **首次生效與蓄能節奏**：第一次門檻依該次輸入連段的動作設定；其後戰鎬每 0.20 秒、碎骨者每 0.25 秒累積一次。這是離散蓄能事件，不是從按下按鈕起連續計秒；只有之後的合格命中處理時計算回復，蓄能本身不回復韌性。
- **消耗與重置**：第一個處理的同物品合格命中會使用當時計數後歸零；沒有新蓄能事件時，同一掃掠裡的後續命中不會再次使用舊計數。進入傷害階段後結束的掃掠（即使揮空）也會歸零；在傷害階段開始前取消不會經過此掃掠結束重置。重新持用事件也會歸零。視覺層數只是 HUD 提示，不是實際回復計數；沒有獨立持續時間或冷卻。
- **攻擊條件差異**：RAW 寫「重攻擊」，但程式沒有檢查命中是否屬於重攻擊。若仍有蓄能計數，其他同物品且符合一般命中事件條件的攻擊也可能消耗它；四種綁定的純推擊命中同樣會送出一般 on_hit，是否能形成命中事件仍取決於該攻擊自己的設定。
- **型號差異**：三種戴維爾戰鎬的普通輕／重連段有多個蓄能起始段，武器特殊攻擊則直接出招，不先產生自身蓄能事件。碎骨者普通輕／重連段及兩種特殊攻擊都先蓄能再進入重擊。四個綁定都是近戰武器，沒有本祝福接入的遠程、投擲或投射物攻擊。
- **推擊與後續攻擊**：純推擊本身不增加蓄能計數，但四種綁定的 push 命中會經 Attack.execute 送出一般 on_hit，並另送 on_push_hit；本祝福只聽 on_hit。若仍有計數、該命中來自同一祝福武器且通過一般命中條件，首個處理的 push on_hit 會消耗並清除舊計數。推擊後追擊則是掃掠攻擊，也可在相同條件下消耗舊計數。
- **回復上限**：回復按最大韌性比例計算並封頂於缺失韌性；它不受一般韌性回復倍率影響，但仍遵守原生存活、倒地（僅 `force_assist` 例外）、防止韌性回復及僅限能力回復等限制。

## 計算與算例

- **前提**：最大韌性 100、目前韌性 85（缺少 15）；裝備 IV 級；三個蓄能門檻事件已處理；之後同物品的合格命中通過通用命中條件，且角色可回復韌性。
- **代入**：要求回復 `100 × 0.08 × min(3, 3) = 24`。
- **結果**：實際回復受缺失韌性 15 封頂，韌性由 85 升至 100。若當時缺少至少 24，才會實際回復完整 24。
- **玩家意義**：階級比例以最大韌性為基準，蓄能事件最多將單次要求乘三；滿韌性時命中仍會消耗計數，但實際回復為 0。

## 遊戲描述勘誤

RAW 將 heavy attack 寫成必要條件，但兩個 wrapper 的同物品命中 callback 沒有 attack_type／攻擊強度 gate；只有仍有 windup 計數且 Attack 通用 on_hit 條件通過時，其他同物品命中也可能使用該計數。
