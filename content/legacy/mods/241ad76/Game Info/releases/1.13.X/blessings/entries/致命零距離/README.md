# 致命零距離(Lethal Proximity)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/18053992-dda1-48a5-a975-6e9d2102c20a" width="72" height="72" alt="致命零距離祝福圖示">

- **觸發方式**：手持裝有此祝福的爆彈手槍時，彈頭的爆炸啟動距離降為0；命中後仍依彈頭原有的停彈、穿透停止或命中質量規則決定是否爆炸。

- **距離判定**：原始5m／3m啟動距離是從射擊起點到命中點的彈道距離；持用祝福槍時此門檻降為0。

- **爆炸範圍**：I／II／III／IV級分別增加10%／15%／20%／25%；近距離無距離衰減區也按相同比例擴大；這兩型號各自的近距離與一般爆炸使用同一傷害設定，並不另加傷害。

- **切換武器**：只要爆彈手槍仍在裝備欄，範圍加成會保留並作用於持有者的其他爆炸；啟動距離降為0的效果只在手持該手槍時生效。

- **傷害與掩體**：祝福不直接增加爆炸傷害設定；半徑變大會改變可命中的距離與既有衰減計算，掩體檢查仍保留。此手槍爆炸不傷害持有者或隊友。

- **爆彈手槍 戈德溫–布蘭克斯 Mk IV**：原始爆炸半徑3m、近距離爆炸區0.75m；原始彈頭啟動距離5m。

- **爆彈手槍 戈德溫–布蘭克斯 Mk VI**：原始爆炸半徑5m、近距離爆炸區1.75m；原始彈頭啟動距離3m。

- **射擊與特殊動作**：腰射與瞄準射擊都使用該型號的彈頭規則；特殊推擊是近戰攻擊，不會觸發彈頭爆炸。

## 計算與算例

- **半徑算例前提**：只套用此祝福的等級加成，沒有其他爆炸半徑修正；半徑採各型號的原始設定。

- **Mk IV I級結果**：半徑倍率1.10，3m×1.10=3.3m；近距離區0.75m×1.10=0.825m。手持時啟動距離5m×0=0m。

- **Mk VI IV級結果**：半徑倍率1.25，5m×1.25=6.25m；近距離區1.75m×1.25=2.1875m。

- **距離衰減算例**：採Mk IV I級半徑，假設目標經尺寸修正後距爆炸中心2m，距離衰減參數為 `((2−0.825) ÷ (3.3−0.825))² ≈ 0.2254`。它會送入武器原有的傷害計算，不等於生命傷害降低22.54%。

- **切換武器算例**：切換到另一把武器後，仍裝備的爆彈手槍保留該級半徑加成；但持用槽位條件解除，彈頭啟動距離恢復該型號的5m或3m。

- **其他範圍加成**：若原有同階段+20%爆炸半徑，再加IV級+25%，總倍率為1.45；Mk IV半徑變為3m×1.45=4.35m，近距離區變為0.75m×1.45=1.0875m。
