# 遊擊(Hit & Run)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/e0cc7da1-f63c-4ac4-aa8a-c987737212e5" width="72" height="72" alt="遊擊祝福圖示">

- **觸發方式**：使用裝有遊擊的同一把遠程武器擊殺敵人，且角色位置到命中點不超過12.5m；這是近距離遠程擊殺，不是近戰武器擊殺。

- **效果**：觸發後，I／II／III／IV級分別持續0.7／0.8／0.9／1.0秒；期間，採用遠程閃避判定的可閃避攻擊會被視為已閃避。

- **移除**：持續時間結束便失去效果；之後的合格擊殺可再次觸發。

- **距離**：從角色位置量到實際命中點；12.5m整也符合條件。

- **刷新**：效果期間再次以同一把武器完成符合條件的擊殺，會將計時重設為該級完整時間，不會疊加層數。

- **切換武器**：切到其他武器不會取消已觸發效果的剩餘時間；使用另一把武器擊殺，不會替這把祝福武器觸發或刷新。

- **限制**：無法閃避的遠程攻擊不會因遊擊變成可閃避攻擊，因此不能把效果視為抵擋所有遠程傷害。

- **射擊模式**：腰射、瞄準或架槍射擊都可依相同條件觸發；雙管霰彈槍的雙管射擊也屬遠程射擊。

- **槍托攻擊**：槍托自動槍的推擊／槍托揮擊，以及雙管霰彈槍的輕重槍托揮擊都屬近戰攻擊，不能觸發。

- **手電筒**：步兵自動槍與偵察鐳射槍的手電筒切換不算擊殺。

- **特殊彈藥**：戰鬥霰彈槍的特殊彈藥仍需實際射擊並符合距離與擊殺條件。

## 計算與算例

- **前提**：使用偵察鐳射槍 奧克塔蘭 Mk XII，持有III級遊擊；用該槍擊殺敵人，角色位置至命中點距離恰為12.5m。

- **距離計算**：`12.5² = 156.25平方公尺`，符合不超過156.25平方公尺的距離判斷。

- **結果**：包含等於12.5m的邊界，因此成功觸發0.9秒。

- **距離邊界**：其他條件相同，命中點距離為12.51m時不觸發。

- **刷新**：假設III級效果從`t=0`開始，在`t=0.7秒`再次完成合格擊殺，原本剩0.2秒；新到期時間為`0.7+0.9=1.6秒`，重新得到完整0.9秒。

- **切換**：觸發後0.3秒切到近戰武器，仍剩`0.9−0.3=0.6秒`；切換不清除此計時。

- **不可閃避攻擊**：若來襲攻擊標記為不可閃避，遊戲會略過此閃避判定，遊擊不會阻止該攻擊。

## 遊戲描述勘誤

- **觸發翻譯**：繁中「近戰擊殺後」應改為「使用此武器完成近距離遠程擊殺後」；實際需要遠程攻擊擊殺，命中點距角色不超過12.5公尺。

- **效果範圍**：英文Immune to Ranged Attacks與繁中「免疫遠端攻擊」過度概括；效果只使採用遠程閃避判定的可閃避攻擊視為已閃避，不可閃避攻擊會繞過該判定。

- **建議描述**：使用此遠程武器在近距離以遠程攻擊擊殺敵人後，接下來{time:%s}秒內，可閃避的遠程攻擊會被視為已閃避。
