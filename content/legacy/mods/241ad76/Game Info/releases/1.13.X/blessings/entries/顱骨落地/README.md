# 顱骨落地(Cranial Grounding)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/70fe9149-f3f2-4e40-8c6c-062b858e1938" width="72" height="72" alt="顱骨落地祝福圖示">

- **觸發方式**：持用帶有顱骨落地的武器，揮擊的第一個命中目標受到弱點命中時增加1層；不需要擊殺或啟用武器充能。

- **計數限制**：同一次揮擊後面的弱點命中不加層；首個目標沒有命中弱點，也不會由後面的目標補觸發。

- **首次生效**：第一次符合條件的命中後便有1層；該次傷害先結算，新增層數作用於後續攻擊。

- **等級效果**：等級I–IV每層增加1%、2%、3%、4%弱點或暴擊的額外傷害部分。

- **滿層效果**：最多5層；額外傷害部分的總加成分別為5%、10%、15%、20%，整次攻擊的增傷取決於額外部分的占比。

- **熱量效果**：I–IV每層使之後的產熱量乘以0.97、0.96、0.95、0.94；五層分別減少約14.13%、18.46%、22.62%、26.61%產熱量。

- **熱量範圍**：減少武器充能期間的持續產熱與開招產熱；弱點命中不會直接消除已累積的熱量。

- **持續與刷新**：所有層數共用3秒期限；符合條件的弱點命中會刷新全部層數的期限，滿5層時仍會刷新。

- **中斷情況**：揮空或沒有命中弱點不會立刻清層，也不會刷新；距離最後一次合格命中超過3秒後，全部層數一起消失。

- **切換武器**：切出時停止提供傷害與產熱加成，3秒計時照常流逝；期限內切回恢復剩餘層數，超時則從0層重新累積。

## 計算與算例

- **疊層前提**：IV級從0層開始，連續五次揮擊都以第一個目標的弱點命中，間隔均小於3秒。

- **疊層結果**：各次命中後依序為1、2、3、4、5層，額外傷害加成為4%、8%、12%、16%、20%；第五次命中本身使用命中前的4層，第六次才可用滿層。

- **第一種傷害前提**：假設原本一次弱點或暴擊命中共100傷害，其中普通部分80、額外部分20；其他倍率固定，沒有其他同階段加成。

- **第一種傷害結果**：IV級5層為`80＋20×1.20＝104傷害`，整次命中增加4%。

- **第二種傷害前提**：假設同樣原本100傷害，但普通與額外部分各50。

- **第二種傷害結果**：IV級5層為`50＋50×1.20＝110傷害`，整次命中增加10%。

- **已有加成前提**：沿用普通80、額外20，原本已有25%同階段額外傷害加成，生效前為`80＋20×1.25＝105傷害`。

- **已有加成結果**：IV級5層後為`80＋20×(1＋0.25＋0.20)＝109傷害`，相對105傷害增加約3.81%。

- **熱量前提**：假設某次產熱原本增加20個百分點，IV級已有5層，起始熱量50%，不計自然散熱與其他倍率，也未達過熱上限。

- **熱量結果**：新增熱量為`20×0.94⁵≈14.678個百分點`，熱量到約64.678%；已存在的50%不會因命中直接減少。

- **刷新與切換前提**：5層時在10秒又合格命中，11秒切出，12秒切回，期間沒有合格命中。

- **刷新與切換結果**：切回仍是5層，剩約1秒；超過13秒後全部消失。再次合格命中便重新取得1層。
