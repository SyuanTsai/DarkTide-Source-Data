# 超壓(Overpressure)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/93d0d585-1ac5-4d54-bc29-d7f399538522" width="72" height="72" alt="超壓祝福圖示">

- **適用型號**：淨化噴火器 奧特米亞 Mk III。

- **觸發方式**：持用這把噴火器時，效果依目前可用彈匣內的剩餘比例計算；不需要命中、擊殺或爆擊，也不是每次射擊各累積一層。

- **階數與等級**：彈量越少，程式計算的階數越高；I／II／III／IV 級每階分別增加 +2%／+3%／+4%／+5% 通用威力修正，最多五階，五階上限為 +10%／+15%／+20%／+25%。滿彈時為 0 階；彈匣比例不高於10%時達五階。

- **一般射擊與持續火焰**：一般射擊的火焰爆發與架槍後的持續火焰，都以當時已計算的威力修正處理直接命中。架槍只切換射擊模式，不另加一層；每次射擊事件消耗彈藥後，彈量變化會在後續祝福數值快取更新時反映。

- **燃燒傷害**：火焰附加的燃燒效果會在後續週期另行結算；每次燃燒傷害使用持有者當下的威力數值。若燃燒仍持續但你已切出噴火器，燃燒本身不會因此消失；持用條件更新後，本祝福不再提供額外威力。

- **特殊推擊**：特殊推擊的傷害與衝擊威力也讀取通用威力修正；仍受內／外圈傷害檔與目標護甲倍率限制，原本為零的護甲傷害倍率仍使該項傷害為零。推擊範圍、體力消耗與擊退設定維持原值，推擊本身不消耗彈藥。

- **裝填與切換**：裝填不會主動關閉本項，期間仍依目前彈匣比例與持用狀態計算；切出後持用條件不成立，切回後依該武器當時彈量，在數值快取更新時重新評估。沒有本祝福專屬命中層數或固定倒數。

- **彈匣與階數公式**：只合計目前使用中彈匣的剩餘量與容量，不包含備彈。令 r 為該比例，n=clamp(floor(5×(1−(r−0.10)/0.90)),0,5)；滿彈 n=0，r=0.56 時 n=2。

- **首次生效與移除**：持用條件進入祝福數值快取後，依目前彈匣比例即可生效；不需要先命中。彈匣補滿會在數值更新後回到零階，切出後停止計入；沒有每次射擊保存的層數、固定期限或刷新倒數。

## 計算與算例

- **算例前提**：只計算威力修正階段。假設目前可用彈匣內彈量比例 r=0.56、IV 級、沒有其他適用威力修正；S=500 是已經通過 PowerLevel power-type 曲線、尚未乘 buff modifier 的示意威力值。這是公式算例，不是武器測試或最終生命值傷害。

- **代入階數**：n=clamp(floor(5×(1−(0.56−0.10)/0.90)),0,5)=floor(2.444…)=2。

- **代入 tier 值**：IV 級每階 p=0.05，所以 A=n×p=2×0.05=0.10；S′=500×(1+0.10)=550。

- **結果與玩家意義**：此條件下，本項讓威力修正階段增加 10%，示意威力值由 500 變成 550；最終傷害仍依火焰命中／燃燒／推擊各自的 profile、目標與後續結算決定，不能直接說最終傷害固定增加 10%。

- **與其他威力分量合併**：保持 S=500、IV 兩階 A=0.10，假設其他適用分量相對基準的加法貢獻合計 q=0.20。原階段值為500×1.20=600；加入本項後為500×(1+0.20+0.10)=650，差50相對原600約8.33%。這是威力階段的相對增幅，其他分量與本項先相加，生命值傷害仍按後續結算。
