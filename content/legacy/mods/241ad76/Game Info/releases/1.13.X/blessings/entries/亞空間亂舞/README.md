# 亞空間亂舞(Warp Flurry)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a24dfe97-3d90-44b2-afb5-99309f88e6f4" width="72" height="72" alt="亞空間亂舞祝福圖示">

- **適用型號**：虛空爆破力場法杖 陰陽 Mk III、烈焰力場法杖 裂隙避難所 Mk II、電流力場法杖 諾瑪努斯 Mk VI、虛空打擊力場法杖 陰陽 Mk IV。四者各自的 I–IV 數值相同。

- **觸發方式**：持用適用型號，開始對應的蓄力次要攻擊釋放動作時獲得一層。程式實際接線分別是陰陽 Mk III 的觸發爆炸、裂隙避難所 Mk II 的蓄力火焰釋放，以及諾瑪努斯 Mk VI、虛空打擊 Mk IV 的蓄力攻擊釋放。只檢查動作開始，不要求擊中目標；連續火焰的一次釋放動作只在開始時計一次。

- **蓄力時間**：I／II／III／IV 每層分別使蓄力時間縮短 5.5%／6.5%／7.5%／8.5%；最多三層，三層合計縮短 16.5%／19.5%／22.5%／25.5%。直接修正的是蓄力所需時間；這些百分比是時間縮短幅度。

- **首次生效**：從零層開始時，第一次蓄力仍以零層計算；該次釋放動作開始後才建立第一層。快取更新後，後續蓄力才讀取這層效果。

- **持續與刷新**：最後一次合格釋放後，效果最多保留 5 秒。5 秒內再次開始合格釋放會增加一層並重新計時；三層時仍會重設期限。超過 5 秒沒有合格釋放，三層一起移除。

- **切換武器**：切出適用法杖時，持用條件會讓蓄力時間加成暫停；五秒期限仍繼續倒數。期限內切回仍可使用剩餘層數，超時則已清除。移除或替換該祝福而使父效果結束時，所控制的子層也會移除。

- **特殊動作**：只有上述實際列出的釋放動作會觸發。裂隙避難所 Mk II 未蓄力的火焰攻擊不觸發；陰陽 Mk III、諾瑪努斯 Mk VI、虛空打擊 Mk IV 的近戰特殊攻擊也不觸發。諾瑪努斯 Mk VI 的蓄力連鎖閃電屬於合格釋放動作。

- **普通攻擊與追加命中**：一般未蓄力主要攻擊、通風及近戰特殊動作都不符合上述釋放動作名；命中數量、連鎖目標數、火焰持續命中與追加傷害不會額外增加層數。

## 計算與算例

- **共同前提**：以虛空爆破力場法杖 陰陽 Mk III 為例，取充能模板插值值 x=0.40；其端點為3／0.5秒，因此 T0=3+(0.5−3)×0.40=2秒，再以這個已解析的基準時間作算例，假設沒有其他蓄力時間修正。法杖 charge template 的 lerp_basic／lerp_perfect 是蓄力時間解析的插值端點，不是兩種獨立射擊模式；實際 T0 會依目前模板插值值改變；其他 charge_up_time 修正另以 q 計入。以下是固定來源數值的公式算例，不是遊戲內計時測試。

- **首次釋放後的一層**：假設 IV 級從零層開始，第一次釋放前仍是 0 層，因此該次蓄力按假設為 2 秒。第一次合格釋放動作開始後得到 1 層；下一次蓄力代入 2×(1−0.085×1)=1.83 秒，較 2 秒縮短 0.17 秒，也就是 8.5%。

- **三層上限**：仍取 T0=2 秒、IV 級、q=0，假設快取已反映 3 層：2×(1−0.085×3)=1.49 秒，比未修正的 2 秒縮短 0.51 秒，也就是 25.5%。

- **其他蓄力時間修正**：以同一 T0=2 秒為例，假設其他來源先合計為 charge_up_time 的 q=+0.20，亦即相對 T0 延長20%。只有其他加成時為 2×(1+0.20)=2.40 秒；加入 IV 級三層後為 2×(1+0.20−0.085×3)=1.89 秒，相對於 q-only 的 2.40 秒再縮短 (2.40−1.89)÷2.40=21.25%。這個比例是相對 q-only 時間；祝福的三層係數仍是從同一 additive multiplier 加入，不是把 2.40 秒再乘 0.745。


## 遊戲描述勘誤

- 數值符號勘誤：固定格式重建把負向 charge_up_time 值原樣插入繁中「充能時間縮短{charge_time}」，因此字面呈現「縮短−5.5%」等，與實作的時間實際變短方向相反。這是 formatter 靜態重建結果，不是遊戲畫面；實作將負值加到以 1 為基準的 charge_up_time additive multiplier，故玩家效果應表述為每層正向縮短 5.5%／6.5%／7.5%／8.5%，而不是「縮短負百分比」。英文 RAW 僅列負值與 Charge Time，沒有明確 reduces-by 動詞，不另判英文字面方向錯誤。
