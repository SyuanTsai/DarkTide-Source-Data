## 執行與計算

### 實際執行鏈

- 三組 tier 分別將 movement_speed 設為 .17、.18、.19、.20，持續皆為 2 秒；各 wrapper 都 clone movement_speed_on_activation base template。[tier values](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/settings/equipment/weapon_traits/weapon_traits_bespoke_chainaxe_p1.lua#L92-L145) [wrappers](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/settings/buff/weapon_traits_buff_templates/weapon_traits_bespoke_chainaxe_p1_buff_templates.lua#L12) [base](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/settings/buff/weapon_traits_buff_templates/base_weapon_trait_buff_templates.lua#L1177-L1190)

- Base ProcBuff 只監聽 on_weapon_special_activate。發送端讀取該 Mark 的 weapon_special_tweak_data.allow_reactivation_while_active；逐項核對六個實際 Mark 設定後，此欄位皆缺省，因此特殊狀態仍啟用時不能再次觸發 activation event。持用條件同時限制事件與 stat 套用。[base event](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/settings/buff/weapon_traits_buff_templates/base_weapon_trait_buff_templates.lua#L1177-L1190) [activation field gate](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/weapon/player_unit_weapon_extension.lua#L1149-L1188) [held predicate](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/settings/buff/helper_functions/conditional_functions.lua#L43-L59)

- 首次事件在成功狀態轉換後、且通過大於 0.5 秒的發送間隔時送入 Buff extension；server 將事件交給已安裝的 ProcBuff，ProcBuff 接受事件後更新 active_start_time，active stat 再以 tier override 取代 base .5，交由 movement_speed additive_multiplier 聚合。首次加成在 ProcBuff 更新並重建角色 stat cache 後才可供移動計算讀取。[event emitter](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/weapon/player_unit_weapon_extension.lua#L1149-L1188) [event delivery](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buff_extension_base.lua#L233-L271) [refresh](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buffs/proc_buff.lua#L304-L355) [cache order](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/player_unit_buff_extension.lua#L131-L145) [stat override](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buffs/proc_buff.lua#L288-L300) [stat aggregation](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buffs/buff.lua#L689-L733) [stat type](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/settings/buff/buff_settings.lua#L893)

- ProcBuff 自身沒有 cooldown；每個合格事件重設同一個 active_start_time，故為刷新單一 2 秒效果而不疊層；有效條件為 current_time < active_start_time + 2。停用 event 不被此 ProcBuff 監聽。[timer](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buffs/proc_buff.lua#L78-L104) [no cooldown](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buffs/proc_buff.lua#L173-L185) [refresh](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/buff/buffs/proc_buff.lua#L304-L355) [deactivation](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/weapon/player_unit_weapon_extension.lua#L1190-L1245)

- 走路最終速度中 movement_speed 只乘一次；傳入移動 helper 的同值只參與滑行門檻判定。衝刺最終速度會另外乘 sprint_movement_speed 與 weapon action multiplier。若其他 movement_speed 加算值為 q、本祝福為 h、其餘固定倍率為 m，則 V_before=V×(1+q)×m，V_after=V×(1+q+h)×m。[walking](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/character_state_machine/character_states/player_character_state_walking.lua#L109-L116) [sprint](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/character_state_machine/character_states/player_character_state_sprinting.lua#L150-L157) [helper](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/character_state_machine/character_states/utilities/accelerated_local_space_movement.lua#L55-L97)

movement_speed 的 type 是 additive_multiplier。本項 .17/.18/.19/.20 覆寫並取代 shared ProcBuff 的 .5，不是與 .5 疊加。令 q 為其他 movement_speed 加算值，h 為本祝福值，m 為其他固定倍率：V_before=V×(1+q)×m，V_after=V×(1+q+h)×m；相對變化=(1+q+h)/(1+q)−1。走路將 movement_speed 乘入一次；helper 中該參數只用於 slide threshold。衝刺另乘 sprint_movement_speed，並乘獨立 weapon action 倍率。[walking calculation](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/character_state_machine/character_states/player_character_state_walking.lua#L109-L116) [sprint calculation](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/character_state_machine/character_states/player_character_state_sprinting.lua#L150-L157) [helper boundary](https://github.com/Aussiemon/Darktide-Source-Code/blob/7e662fcda16219d775b84af50322be2e9cd9d62e/scripts/extension_systems/character_state_machine/character_states/utilities/accelerated_local_space_movement.lua#L55-L97)
