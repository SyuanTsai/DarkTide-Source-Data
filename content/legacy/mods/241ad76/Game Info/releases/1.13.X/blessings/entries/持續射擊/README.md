# 持續射擊(Sustained Fire)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/d18d3791-7468-4d27-ba66-d93c39162ab5" width="72" height="72" alt="持續射擊祝福圖示">

- **觸發方式**：持用裝有本祝福的遠程武器，且目前屬性快取判定射擊計數為 1、2 或 3 時，符合遠程傷害消費條件的攻擊取得加成。一般武器讀射擊次數，鐵腕霰彈槍兩型號改讀連段次數。

- **等級效果**：I／II／III／IV 的遠程傷害加算係數為 +14%／+16%／+18%／+20%。它加入同一傷害加算池，不是威力、踉蹌或穿透加成；最終生命值傷害還有其他結算因素。

- **首次生效**：一般閒置首發通常從計數 0 開始，後續快取讀到 1–3 時可受益，常見連射因此對應第二至第四發。屬性快取先於武器動作更新，不能保證動作內剛改變的計數立即影響同一次結算。投射物延遲命中與霰彈分批結算更須依實際命中時的快取判斷，不把 RAW 序號視為所有模式固定有效的發數。

- **計數與重置**：一般射擊使用玩家共用的射擊計數；射出即計入，未命中也會消耗。停止射擊後，且目前動作沒有保留計數設定，時間嚴格超過「停止射擊時間＋目前散布模板門檻」才清零。門檻依目前動作、瞄準模式及移動狀態選取；重新射擊後從當時的計數繼續。本祝福沒有自己的疊層或獨立倒數；計數清零後，屬性快取更新才停用加成。

- **各武器停火門檻**：
  - 步兵自動槍：腰射 0.1 秒，瞄準 0.25 秒。
  - 尤斯單持自動手槍：腰射 0.5 秒，瞄準 0.25 秒；布蘭克斯雙持自動手槍兩模式均 0.5 秒。
  - 三種本項法杖：腰射／替代模式的射擊計數門檻均 0.8 秒。
  - 盧修斯三型號：腰射站定、蹲定或地面蹲移 0.5 秒，未蹲移動及騰空 1.2 秒；瞄準均 1 秒。其腰射／瞄準的蓄力起始及蓄力發射動作明確保留射擊計數，僅在這四類動作仍是目前動作時抑制清零；保留設定本身不會額外增加計數，實際射出仍照常計入。
  - 偵察鐳射槍三型號：腰射 0.5 秒，瞄準 1 秒。
  - 快拔左輪兩型號：腰射／瞄準均 0.5 秒。
  - 鐵腕霰彈槍改用下一項的連段重置，不能套用散布模板的停火門檻。

- **霰彈槍連段例外**：鐵腕 Mk III／Mk VIII 以每殼的連段計數判斷，單殼多顆霰彈不各自增加連段。一般閒置首殼為 0；若仍在裝填、瞄準或特殊裝填等可接續動作中，直接連到首殼可以從 1 開始。動作結束後嚴格超過 0.2 秒才重置連段；仍只在快取判定 1–3 時加成。末批霰彈傷害使用處理當時的玩家屬性。

- **法杖特殊模式**：陰陽 Mk III 的蓄力爆炸以爆炸類型結算，實際 profile 沒有視為遠程攻擊的旗標，排除本加成。諾瑪努斯 Mk VI 的蓄力連鎖攻擊以遠程類型結算，但不增加普通射擊計數，也沒有保留舊計數的例外；只有命中時舊計數仍在 1–3 且快取有效才可能受益，長蓄力不能當作必然延續第二至第四發。陰陽 Mk IV 蓄力投射物直擊以遠程類型結算；其命中後範圍爆炸另以爆炸類型派發，實際 profile 沒有遠程旗標，因此直擊與爆炸必須分開判斷。三法杖 wrapper 的 +5% 蓄力條件 map 會被本項 tier map 整張取代，不另提供該蓄力加成。

- **其他特殊攻擊**：單持自動槍／自動手槍的手電筒切換不是攻擊；雙持自動手槍的槍托擊、法杖近戰及左輪近戰特殊掃擊不符合本項遠程傷害條件。特殊裝填後的射擊仍按實際攻擊類型、計數與命中時快取判斷。

- **切換與移除**：切到其他槽後，本武器的持用條件與快取更新會停用加成。切槽不直接把共用射擊計數寫成 0，但散布選擇為空時門檻變為 0，中途更新可以清掉已停止射擊的計數；先持用另一武器時則按新武器目前門檻繼續更新。切回後須重新符合持用及有效計數條件，不能假定仍保存原槍的連射進度；卸下武器會移除對應祝福實例。

- **適用型號**：步兵自動槍 阿格里皮娜 Mk I；步兵自動槍 弗拉克斯 Mk V；步兵自動槍 哥倫努 Mk VIII；撕裂者自動手槍 尤斯 Mk IV；雙持自動手槍 布蘭克斯 MkIII；虛空爆破力場法杖 陰陽 Mk III；電流力場法杖 諾瑪努斯 Mk VI；虛空打擊力場法杖 陰陽 Mk IV；冥潮鐳射槍 盧修斯 MK IIIa；冥潮鐳射槍 盧修斯 MK V；冥潮鐳射槍 盧修斯 Mk IV；偵察鐳射槍 奧克塔蘭 Mk VIc；偵察鐳射槍 奧克塔蘭 Mk XII；偵察鐳射槍 奧克塔蘭 Mk XIV；滅絕者霰彈槍 鐵腕 Mk III；滅絕者霰彈槍 鐵腕 Mk VIII；快拔左輪手槍 紮羅娜 Mk IIa；快拔左輪手槍 阿格里皮娜 Mk XIV。

## 計算與算例

- **前提**：以`D`表示進入後續damage乘算前、同一筆命中的中性傷害池基數；假設其他來源的同類加算遠程傷害係數為`q=20%`，且命中是實際`attack_type=ranged`或damage profile明確`count_as_ranged_attack`的遠程傷害。忽略其他後續曲線、護甲、距離、減傷與取整。

- **代入與結果**：無本祝福時`D×(1+q)=D×1.20`；持用武器且計數1–3時再加入tier係數`p`，結果為`D×(1+q+p)`。以`D=100`：I級`100×(1+.20+.14)=134`；II級136；III級138；IV級140。

- **意義**：IV級在此例把傷害池由120提高至140，即相對原池+20、相對原有120約+16.67%；這不是最終生命值必定多20點，也不是1.2再乘1.2得到144。未通過遠程attack/profile條件的近戰或爆炸攻擊不套用。
