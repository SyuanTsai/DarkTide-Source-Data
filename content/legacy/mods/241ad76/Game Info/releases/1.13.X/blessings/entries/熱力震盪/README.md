# 熱力震盪(Volatile)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/bb4dde18-82c5-4a0a-b0f6-a0e16651bf5a" width="72" height="72" alt="熱力震盪祝福圖示">

- **適用型號**：電漿槍 M35熔岩核心 Mk II、Mk III，兩者的祝福等級與蓄力時間修正相同。

- **觸發方式**：持用此武器時，依目前過熱比例動態計算零至五階；不需要命中、爆擊或累積射擊次數。每階令蓄力時間縮短 I／II／III／IV 級的 2.5%／3%／3.5%／4%，五階合計為 12.5%／15%／17.5%／20%。

- **熱量與階數**：令 h 為 0–1 的過熱比例，n=round(5×[1−clamp01((h−0.1)÷0.9)])。過熱不高於 10% 為五階，46% 為三階，100% 為零階；中間值依來源的四捨五入函式算成整數階。熱量越低，加成越多。

- **首次與持續生效**：持用且未在裝填／通風中，Buff 快取反映熱量後，第一次蓄力即可使用當時階數。沒有事件疊層、固定期限或命中後才生效的等待。

- **蓄力中的變化**：熱量可以在蓄力中增加；後續 Buff 更新會改變階數，蓄力進度再依當時時間乘數計算。固定秒數的算例只適用於熱量、其他修正與目標充能比例保持不變的前提。

- **一般與架槍射擊**：兩者都會修正射擊前的蓄力時間。這不是直接傷害加成；在相同充能比例與其他條件下，不另乘一個傷害倍率。更快累積充能比例仍會影響何時能發射、或固定等待時間後得到的充能比例。

- **蓄力參數與完成門檻**：一般直接蓄力的原始時間參數端點為 1／0.5 秒，架槍蓄力為 2／1 秒，均依武器數值插值。直接蓄力的完成充能門檻是 0.525，進度公式的最低比例為 0.05，因此時間參數本身不是直接射擊的實際完成秒數；下方算例分開計算。

- **裝填與通風**：這兩類動作期間階數歸零。通風速度使用另一項修正，不受本祝福直接提高；通風後離開該狀態，下一次快取依降低後的熱量重算階數。

- **切換武器與散熱**：切出時不套用本項；各武器槽的熱量仍由該武器的散熱規則更新。切回依目前熱量重新計算，沒有保存的事件層數；自然散熱、射擊增熱與通風都可改變之後的階數。

## 計算與算例

- **共同前提**：假設直接蓄力的插值 x=0.40，熱量固定 h=0.46，Buff 已反映三階，IV 級每階修正 −0.04。原始時間參數 D₀=1+(0.5−1)×0.40=0.80 秒；沒有其他蓄力時間修正、沒有額外充能延遲或提前中斷。

- **先算時間參數**：n=round(5×[1−clamp01((0.46−0.1)÷0.9)])=3；D=0.80×(1−3×0.04)=0.704 秒。這是充能比例公式使用的時間參數，較基準參數少 0.096 秒，縮短 12%。

- **實際直接蓄力門檻**：另假設最大可充能比例沒有被限制在 0.525 以下。此路徑最低充能比例 a=0.05、完成門檻 L=0.525，所需比例因子=(L−a)/(1−a)=0.475/0.95=0.5。因此原本達門檻需 0.80×0.5=0.40 秒；加入本項需 0.704×0.5=0.352 秒。玩家在這組固定條件下提早 0.048 秒達到直接射擊門檻；實際更新、熱量變化或中斷會改變結果。

- **時間與反比速率**：相同路徑與目標比例下，時間縮短 12%；反比速率增加為 1/0.88−1≈13.64%。RAW 的 Charge Speed 標籤不能直接代作此反比速率增幅。

- **其他時間修正**：若其他加法修正 q=+0.20，只有其他修正時 Dq=0.80×1.20=0.96 秒，達門檻需 0.48 秒；加入本項 D=0.80×(1+0.20−0.12)=0.864 秒，達門檻需 0.432 秒。相對原 0.48 秒縮短 10%，不是把 0.48 再減 12%，也不是最終傷害增幅。

- **架槍參數**：同樣假設 x=0.40，原始時間參數 D₀=2+(1−2)×0.40=1.60 秒；三階 IV 級、q=0 時為 1.408 秒。這是該路徑的時間參數，完成時間仍依它自己的起始比例、目標比例與其他條件決定。
