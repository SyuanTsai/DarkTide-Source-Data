# 集中火力(Concentrated Fire)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/b66dd253-275d-4c41-8ec0-8543458fa629" width="72" height="72" alt="集中火力祝福圖示">

- **觸發方式**：重型鐳射手槍奧克塔蘭MG Mk II、針彈手槍布蘭克斯 MkVI 或 MKII，每次射擊結果命中任何目標的弱點時增加一層。加層發生在該次命中處理後，不會回頭提高剛完成的這一發。

- **每層效果**：依等級，每層提高一般爆擊率 I +2、II +3、III +4、IV +5 個百分點；最多五層，總上限依序為 +10、+15、+20、+25 個百分點。這是加算的機率，不是相對乘算。

- **連段重設**：下一個射擊結果不是弱點命中（身體命中或未命中）時，該事件會立即把層數歸零。換成攻擊另一個敵人不會中斷連段；同一發即使弱點命中多個敵人，也只增加一層。

- **維持與切換**：層數沒有時間衰減；停火、等待、裝填或切換針彈手槍的化學模式本身不會清層。切離這把手槍時加成暫停，其他武器的射擊不替它累積或重設；切回後原層數恢復作用，直到這把手槍下一次射擊未命中弱點。

- **特殊動作**：重型鐳射手槍的普通及瞄準射擊都依該發命中結果變更層數；槍托推撞不是射擊事件，不會增加或清除連段。兩種針彈手槍的普通、瞄準及化學模式射擊都依同一射擊事件的弱點結果處理；毒素持續傷害本身不會另外加層。

- **機率欄位**：觸發條件限遠程弱點射擊，但增加的是一般爆擊率。只有攻擊實際進行爆擊機率計算、且這把手槍仍在持用時才會納入；上限仍受遊戲爆擊機率封頂。

- **化學針的附帶爆炸**：直接命中的針彈可按開火時的機率爆擊；附帶爆炸固定不爆擊，也不會另外增加連段層數。

- **特殊推擊的爆擊**：重型鐳射手槍的普通與靈能推擊固定不爆擊，已有的連段加成不會改變這點。

## 計算與算例

- 初始零層、I 級時，第一發弱點命中仍按開火前機率結算；命中處理後加 +2 個百分點，下一發才有這一層加成。

- 假設後續攻擊在套用本祝福前的爆擊率為 20%，且沒有其他變動，五次連續弱點射擊後：I 級為 30%，II 級 35%，III 級 40%，IV 級 45%。以 IV 級為例，從 20% 到 45% 是增加 25 個百分點。

- 同樣假設套用前為 80%，IV 級五層的未封頂合計是 105%；爆擊計算將結果限制在 100%。

- 已達五層後再命中弱點仍維持五層；下一發若只打中身體或未命中，該發完成後立即歸零，再下一發弱點命中只回到一層。

- IV 級三層提供 +15 個百分點。切到其他武器後這項加成暫停，其他武器的射擊不改變此層數；切回時仍有三層，直到本手槍下一次非弱點射擊。

- 對不同敵人連續命中弱點可延續連段；單次穿透掃描即使回報多個弱點目標，仍只產生一次射擊事件，因此只加一層。

- **相對變化與爆炸**：20%升到45%是增加25個百分點，相對增加125%；化學針直接命中可使用既有層數的加成，其附帶爆炸仍固定不爆擊。

## 遊戲描述勘誤

玩家解讀需補正RAW的總量：{crit_chance:%s}顯示的是單層值；執行效果可累積五層，I–IV總上限為+10／+15／+20／+25個百分點。不能把RAW佔位數字直接當成連段封頂總量。
