# 超載(Overload)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/c05b0b5b-2f43-48d2-a309-370bcdb98a57" width="72" height="72" alt="超載祝福圖示">

- **觸發方式**：持用帶有超載的武器，啟用充能後熱量達100%而進入過熱鎖定時，在自身周圍產生一次爆炸；不需要命中或擊殺。

- **熱量效果**：等級I–IV立即減少10、15、20、25個百分點熱量，從100%分別降至90%、85%、80%、75%。

- **鎖定狀態**：爆炸同時關閉武器充能；熱量仍高於0%時保留鎖定，散熱至0%才可重新啟用。

- **爆炸半徑**：I–IV的基礎作用半徑為3、3.5、4、4.5公尺；近區半徑為2、2.25、2.5、2.75公尺。

- **近區效果**：造成傷害並施加踉蹌；各等級使用相同傷害與衝擊設定，提高等級主要擴大作用範圍並增加散熱量。

- **外圈效果**：近區以外、爆炸範圍內的敵人受到踉蹌；外圈的基礎生命傷害為0。

- **範圍倍率**：通用爆炸半徑效果會同時放大近區與總半徑；實際傷害區分依爆心到敵人受擊位置的距離計算，並計入敵人體型。

- **掩體與友軍**：爆炸會檢查掩體，完整遮擋可阻止命中；不傷害自己或友軍。

- **再觸發**：每次重新充能並再次進入過熱鎖定都可觸發，沒有額外的祝福冷卻，也不累積持續層數。

- **切換武器**：切出或切回本身不會爆炸；觸發時必須正持用這把武器。

## 計算與算例

- **熱量前提**：IV級武器充能使熱量達100%，本次進入鎖定並觸發超載。

- **熱量結果**：立即扣除25個百分點，熱量變為75%；此時仍處於鎖定，繼續散熱至0%才可重新充能。

- **近遠區前提**：沒有其他爆炸半徑效果、沒有掩體，並以已計入敵人體型後的判定距離比較。

- **I級範圍**：1.5公尺落在2公尺近區內；2.5公尺落在2至3公尺外圈，只使用外圈的踉蹌設定。

- **IV級範圍**：同樣2.5公尺改落在2.75公尺近區內，改用帶傷害的近區設定；3.5公尺仍位於外圈，4.8公尺則超出4.5公尺基礎範圍。

- **範圍倍率前提**：IV級已有20%通用爆炸半徑加成。

- **範圍倍率結果**：總半徑為`4.5×1.20＝5.4公尺`，近區為`2.75×1.20＝3.3公尺`；不會因此把25個百分點散熱變成30。

- **再觸發前提**：第一次爆炸後熱量降至0%，重新啟用充能，再次累積到100%。

- **再觸發結果**：再次爆炸並扣除該等級的固定熱量；在第一次仍維持鎖定時，不會因75%熱量每幀重複爆炸。
