# 斷肢者(Limbsplitter)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/fde18f48-0180-49ae-9b9f-cc40a0ebf109" width="72" height="72" alt="斷肢者祝福圖示">

- **觸發方式**：持用實際綁定型號時，本項等待截止初值為 0；裝備後第一次適用的統計快取更新即可選用加成，因此第一個符合條件的近戰攻擊不必先等一次命中。
- 加成由目前持用條件與本項當前統計快取決定；近戰攻擊在傷害計算時讀取快取中的 `melee_power_level_modifier`。事件處理後快取何時更新依固定流程；不保證已結算攻擊或同影格後續目標立即改用新值。
- **重新計時方式**：命中先完成傷害結算；之後只有符合來源物品、近戰攻擊類型與持用檢查的 `on_hit` 事件，才把等待截止重設為事件處理時間加該級秒數。命中事件控制等待重設，不是加成首次生效的開關。
- 六個家族各級等待時間 I／II／III／IV 為 5／4.5／4／3.5 秒；碎骨者 克魯克 Mk IIa 各級均為 2 秒。期限未到時，之後再次通過來源物品、近戰類型及持用檢查的命中仍會重設等待，但該次不獲得本項加成；期限到期且快取更新後，加成重新可用。
- 本效果不是疊層。一般輕擊、重擊、實際命中的特殊近戰攻擊，以及推擊後接續的獨立近戰攻擊可在通過相應事件條件時受益；純推擊不是 `melee` 攻擊，不觸發重設，也不消耗近戰威力加成。
- 骨鋸 外科醫師 型號4（Bone Saw Chirurgeon's Mk IV）的直接黏附命中可依一般 `on_hit` 規則重設等待。延遲撕裂追加傷害的 profile 設有跳過命中觸發的旗標，因此追加傷害不會重設等待；若結算時持用與快取仍提供本項，該追加傷害仍可讀取當時近戰威力，不沿用直接命中的威力快照。
- 切換到其他武器時，等待時間繼續流逝；原武器不再持用時，其持用條件使加成停止貢獻。切回後，若期限已到且快取更新，近戰攻擊可再取用加成。真正卸下裝有本祝福的武器會移除此來源效果。
- **適用型號**：戰鬥斧 拉沙德 Mk III（Combat Axe Rashad Mk III）、戰鬥斧 安塔克斯 Mk V（Combat Axe Antax Mk V）、戰鬥斧 阿克利斯 Mk VIII（Combat Axe Achlys Mk VIII）；戰術斧 埃托克斯 Mk II／Mk IV／Mk VII（Tactical Axe Atrox Mk II／Mk IV／Mk VII）；工兵鏟 軍務部 Mk I／Mk III／Mk VII（Sapper Shovel Munitorum Mk I／Mk III／Mk VII）；撬棍 科技教士 型號6（Crowbar Enginseer's Mk VI）；戴維爾戰鎬 布蘭克斯 Mk Ia／博羅維安 Mk III／卡索拉斯 Mk II（Delver's Pickaxe Branx Mk Ia／Borovian Mk III／Karsolas Mk II）；碎骨者 克魯克 Mk IIa（Cruncher Krourk Mk IIa）；骨鋸 外科醫師 型號4（Bone Saw Chirurgeon's Mk IV）。前六個家族各級為 +60%；只有碎骨者採不同的威力值。

## 計算與算例

- **戰鬥斧示例前提**：戰鬥斧 拉沙德 Mk III（Combat Axe Rashad Mk III）IV 級；統計快取已更新且本項可用。假設武器 power-type 曲線後 `B=500`、`q=0`，沒有力場覆寫或其他後續修正。
  - **代入**：`P = 500 × (1 + 0.60) = 800`。
  - **結果與玩家意義**：此次近戰攻擊計算使用的威力輸入為 800，相對於 500 增加 60%；這不是固定的目標生命傷害增幅。
- **碎骨者示例前提**：碎骨者 克魯克 Mk IIa（Cruncher Krourk Mk IIa）IV 級；快取可用，曲線後 `B=500`、`q=0`，其餘條件中立。
  - **代入**：`P = 500 × (1 + 0.25) = 625`。
  - **結果與玩家意義**：威力輸入為 625，碎骨者的 +25% 不同於其他六家族的 +60%；仍非最終生命傷害百分比。
- **等待期限前提**：戰鬥斧 拉沙德 Mk III（Combat Axe Rashad Mk III）IV 級，統計快取已更新。命中在 `t=10.0` 結算時可消耗當前加成；其合格事件於傷害結算後處理。
  - **代入**：事件把截止設為 `10.0+3.5=13.5`；`t=12.0` 再命中時已在等待期，該次不消耗本項，但合格事件仍把截止重設為 `12.0+3.5=15.5`。
  - **結果與玩家意義**：命中事件負責重新計時；截止到期並由後續快取更新重新選用加成組後，近戰攻擊才再次受益。
