# 歎為觀止(Showstopper)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/c028ae7c-f62f-4407-b9b2-7420eebf0fe8" width="72" height="72" alt="歎為觀止祝福圖示">

- **觸發方式**：擊殺事件必須由裝有「歎為觀止」的那件武器物品造成；目標還須符合該祝福的敵人與燃燒判定。

- **敵人與燃燒條件**：目標須為精英或專家敵人；淨化噴火器與磷光爆破手槍檢查一般燃燒狀態，烈焰力場法杖檢查扭曲火焰狀態。由該武器留下的燃燒傷害擊殺也能觸發。

- **直接燃燒擊殺**：淨化噴火器直接以燃燒傷害擊殺時也符合燃燒判定，不必先讓目標帶有燃燒狀態。

- **等級機率**：I／II／III／IV級每次合格擊殺事件分別有14%／16%／18%／20%機率觸發；不要求暴擊，也沒有額外冷卻。

- **噴火器差異**：淨化噴火器（奧特米亞 Mk III）的基本爆炸半徑為3、固定威力值1000，且不隨距離衰減。

- **烈焰力場法杖差異**：烈焰力場法杖（裂隙避難所 Mk II）檢查扭曲火焰狀態；基本爆炸半徑為4、固定威力值600，且會隨距離衰減。

- **磷光手槍差異**：磷光爆破手槍（布蘭克斯 Mk XI）的基本爆炸半徑為4、固定威力值600，且會隨距離衰減。

- **持續燃燒與切換**：三種武器施加燃燒時都保留來源物品；同名燃燒後續加層或刷新不會改寫既有狀態的來源。因此由該祝福武器留下的燃燒跳傷，即使切出後造成擊殺，仍能觸發歎為觀止的機率判定。

- **多人來源**：擊殺事件只送到本次擊殺者所屬玩家的祝福系統；隊友擊殺不會替你觸發本祝福。

- **首領判定**：首領身分本身不符合條件。本版本的首領敵人都沒有精英或專家標籤，因此不會只因是首領而觸發。

- **爆炸範圍**：成功時在死亡敵人的身體中心產生爆炸，可波及範圍內其他敵人；爆炸仍會受掩體判斷。

- **爆炸後續**：爆炸不傷害自己或隊友；爆炸本身造成的擊殺也不會再次連鎖本祝福。

- **傷害解讀**：爆炸威力值不是固定生命傷害。目標護甲、距離、掩體與傷害設定都會影響實際結果。

## 計算與算例

- **I級機率示例**：假設5次是彼此獨立的合格擊殺事件，每次各有14%機率，預期觸發數為5 × 0.14 = 0.7次；至少觸發一次的機率為1 − 0.86^5 = 52.95729824%，約52.96%。這是機率示例，不代表每5次必定觸發。

- **IV級單次事件**：一個合格擊殺事件只有20%機率觸發；長期平均約5個合格事件觸發1次，不代表固定每5次觸發。

- **武器爆炸差異**：同為I級且各自判定成功時，淨化噴火器的爆炸固定威力值為1000、基本半徑3且不隨距離衰減；烈焰力場法杖與磷光爆破手槍則固定威力值600、基本半徑4並隨距離衰減。不能把1000或600直接當作扣除的生命值。

- **護甲與掩體**：即使威力輸入相同，目標護甲、爆炸距離和掩體判斷也會改變實際傷害；沒有指定目標條件時，不能推成固定生命傷害。
