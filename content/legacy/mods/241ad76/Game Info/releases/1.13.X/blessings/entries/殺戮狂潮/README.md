# 殺戮狂潮(Slaughter Spree)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8e6c5fe7-7b0f-4912-95bb-f139924250e7" width="72" height="72" alt="殺戮狂潮祝福圖示">

- **觸發方式**：使用「戰術斧 埃托克斯 Mk II／Mk IV／Mk VII」造成近戰暴擊，命中目標弱點並將其擊殺；處理這次擊殺事件時仍須持用來源戰術斧。一般揮擊、蓄力重擊、推擊後續揮擊及特殊揮擊只要實際符合條件都可觸發；單純推擊不符合近戰暴擊條件。
- **效果**：I／II／III／IV級分別增加+40／+60／+80／+100個有效近戰暴擊機率百分點。這是加算機率，不是傷害倍率；有效加成最多+100個百分點。
- **下一次攻擊**：實作在下一次近戰揮擊開始時計算暴擊機率；該揮擊的開始事件會標記此效果結束，之後的buff更新才移除。觸發擊殺的那次攻擊已在動作開始擲定暴擊，不會回溯提高。
- **時間與重複觸發**：子效果最長5秒；再次合格擊殺可增加有效層數，但不重設最初的5秒計時。若下一次近戰揮擊或5秒期限先到，效果即結束。
- **切換武器**：切出來源斧會阻止新的擊殺事件觸發；已生成的暴擊機率效果沒有持用條件，仍可能被另一把武器的近戰揮擊使用／消耗，或等5秒到期。卸下來源斧會移除裝備中的觸發父效果，但已內部建立的子效果依自身揮擊事件／期限管理，不與父效果同步移除。
- **重複擊殺的邊界**：若效果已存在，下一次揮擊開始事件會標記它結束；同一批事件中的合格擊殺雖可追加層數，仍不保證重開一個新的有效窗口。首次擊殺才新建立的效果則不會被同批較早的揮擊開始事件立即消耗。
- **暴擊限制**：加成送入近戰暴擊機率判定。禁止暴擊條件優先把機率設為 0；沒有禁止條件時，其他保證暴擊效果或動作自動暴擊可直接設為 100%。普通判定才加算本祝福；暴擊機率轉傷害修正會在機率封頂後再扣減，IV 級因此不能在所有條件下一概當成必定暴擊。

## 計算與算例

- 前提：基礎近戰暴擊機率5%，既有其他加算來源q=10個百分點，無武器操作修正、無暴擊機率轉傷害、沒有防暴擊或保證暴擊條件。

- II級：6層×每層0.10=+0.60。原值clamp(5%+10%,0,100%)=15%；加入後clamp(5%+10%+60%,0,100%)=75%。本祝福增加60個百分點；相對原15%是400%增加（最終為原來5倍），不是對既有暴擊率乘1.6，也不是傷害增加60%。
- IV級：10層×0.10=+1.00。以5%基礎且q=0、無轉換為例，clamp(5%+100%,0,100%)=100%暴擊機率；若有暴擊機率轉傷害轉換，會在clamp後再乘(1−轉換值)，所以不能一概說最後必定100%。
