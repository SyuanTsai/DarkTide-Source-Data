# 火藥灼傷(Powderburn)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/14fa8657-5caa-4aaa-8bff-b3cf8df9d129" width="72" height="72" alt="火藥灼傷祝福圖示">

- **觸發方式**：持用裝有此祝福的武器，以遠程攻擊擊殺目標；事件處理時，命中位置須距攻擊者當時位置不超過 12.5 公尺（含邊界）。遊戲也接受傷害設定明確標記為遠程的命中。一般近戰攻擊、純推擊或近戰擊殺不會因此通過遠程條件；近戰攻擊若另有遠程標記則按該標記判定。
- **擊殺判定**：必須是擊殺事件；無菁英、敵人種類或額外標籤限制。命中位置缺失或超出距離不觸發，距離以事件處理時的攻擊者位置計。
- **I–IV 效果**：後坐力修正依序為 −28%、−32%、−36%、−40%；壓制輸出依序 +28%、+32%、+36%、+40%；對已被壓制目標的傷害加算依序 +14%、+16%、+18%、+20%。各項只在持用該武器且效果生效時提供。
- **首次生效**：擊殺攻擊先完成傷害結算，合格事件再啟動效果；屬性由後續正常 Buff／stat cache 更新採用，不回溯改寫已結算的擊殺那一擊。
- **時間與刷新**：每次合格擊殺啟動或刷新 2 秒效果；不累積層數。持續時間內再次合格擊殺仍可刷新。
- **傷害條件**：傷害加成只在目標於該次傷害取樣時已被壓制才計入；同一發子彈之後才造成的壓制不會追溯改寫這發已結算的傷害。該屬性進入一般傷害加算，不代表最終生命值固定增加同百分比。
- **實際射擊範圍**：撕裂者自動手槍尤斯 Mk IV、雙持自動手槍布蘭克斯 MkIII、磷光爆破手槍布蘭克斯 Mk XI 的腰射與瞄準射擊，以及滅絕者霰彈槍鐵腕 Mk III／Mk VIII 的腰射、瞄準與從裝填接續射擊，均為可觸發的遠程命中路徑。
- **特殊動作**：雙持自動手槍與磷光爆破手槍的手槍揮擊及其接續揮擊是近戰橫掃，不能觸發遠程擊殺窗口；但窗口已啟動且仍持用祝福武器時，這些實際近戰橫掃若打到傷害取樣時已被壓制的目標，仍可讀取通用 `damage_vs_suppressed` 加算。磷光手槍的背爆是獨立爆炸攻擊，不能啟動或刷新遠程擊殺窗口；若目標在背爆傷害取樣前已被壓制、窗口仍啟動且玩家仍持用，通用傷害欄位會被取樣；但該實際背爆 profile 的 `power_distribution.attack=0`、`impact=1` 且沒有目標覆寫，因此這項加算不會憑空產生背爆生命值傷害。背爆附加的燃燒每 0.55 秒以來源玩家與物品呼叫一次 `Attack.execute`，攻擊類型為 buff；它同樣不能啟動或刷新遠程擊殺窗口，但在每次 tick 傷害取樣時目標已被壓制、效果仍啟動且玩家仍持用時，可使用通用加算。燃燒是獨立的 buff profile，`power_distribution.attack=20`；這個非零 PowerLevel 輸入與 attack=0 的背爆不同，但不等於固定最終生命值傷害。此處描述的是受益條件，不把爆炸或燃燒說成遠程擊殺觸發來源。兩款滅絕者霰彈槍的武器特殊鍵只裝填特殊彈，不造成攻擊；之後實際射出的霰彈仍走遠程散射射擊路徑。上述五個實際綁定沒有蓄力射擊動作；撕裂者自動手槍另有照明切換，亦非傷害攻擊。
- **切換與移除**：切出武器時效果計時繼續，但持用條件關閉各項加成；在計時結束前切回可恢復剩餘時間內的效果。真正卸下裝有祝福的武器會移除此來源效果。

## 計算與算例

- **實際型號的觸發與刷新**：以磷光爆破手槍布蘭克斯 Mk XI（`phosphor_pistol_p1_m1`）的一般腰射 `shoot_hit_scan` 為例；它是直接遠程命中。假設 IV、攻擊者持用該槍，第一發在事件處理時的命中位置恰距攻擊者 12.5 公尺並擊殺，距離等於門檻仍合格，於 `t=10.0` 啟動單一 2 秒窗口。假設下一發仍是合格的直接遠程近距離擊殺，於 `t=11.9` 處理，便刷新起點並延至 `t<13.9`；不增加層數。這是按實際型號與來源條件代入的示例，不是遊戲量測。觸發窗口的那一擊已先結算；之後仍須等正常屬性快取更新，持用時的後續傷害才讀到效果。玩家可據此理解：窗口可由近距離射擊擊殺重新計時，邊界 12.5 公尺包含在內。
- **已壓制目標的傷害加算**：同一布蘭克斯 Mk XI 一般腰射命中路徑；假設先前的合格近距離擊殺已啟動祝福、正常屬性快取已更新，並且仍持用該槍。對下一個在傷害取樣前已被壓制的目標，假設控制用基數 `B=100`、既有傷害加算池 `q=0.10`，且其他下游修正中立。IV 的 `d=0.20` 使算式由 `100×(1+0.10)=110` 變為 `100×(1+0.10+0.20)=130`。新增量是基數的 20；相對原本 110 為 `20÷110≈18.18%`。100 是用來說明加算池的假設基數，不是此槍固定傷害；這不代表最終生命值固定增加 18.18% 或 20%。玩家意義是：效果只提高已壓制目標的通用傷害加算池，結果仍會受後續傷害步驟影響。
- **壓制輸出**：假設某傷害設定的 suppression 輸入為正規化值 `S=10`、沒有其他壓制修正；這是控制輸入，不是已核實的實際武器 profile 固定值。IV 的 `suppression_dealt=0.40` 得 `10×(1+0.40)=14`。這只說明輸入倍率，不保證壓制持續時間、擊殺或敵人數量。
- **後坐力修正**：以正規化 `recoil_modifier=1` 為輸入、且沒有其他同類修正，IV 的 −0.40 令該屬性成為 `1−0.40=0.60`。這不是已核實武器的固定後坐力輸入，也不表示總後坐力振幅固定減少 40%；實際軌跡還受其他武器設定及衰減計算影響。

## 遊戲描述勘誤

- **繁中擊殺類型矛盾**：繁中 RAW 寫「近戰擊殺後」，但實際檢查要求 ranged attack，或傷害設定有 `count_as_ranged_attack`。依本次實際型號路徑，普通近戰揮擊不會觸發；不把翻譯差異改寫成「實作也接受一般近戰擊殺」。
- **繁中負號措辭矛盾**：recoil tier 是負值且 formatter 保留負號，繁中 RAW 又使用「後坐力減少」；卡面靜態重建會出現「減少-28%」至「減少-40%」的雙重負號措辭。實際屬性方向仍為後坐力修正下降，不代表後坐力增加。
- 英文 `Close Range Kill` 沒有明寫 ranged 類型，是描述省略而非與實作相反；其餘 RAW 未列出持用、同物品及 12.5 公尺位置條件，屬文件未涵蓋，不另列矛盾。
