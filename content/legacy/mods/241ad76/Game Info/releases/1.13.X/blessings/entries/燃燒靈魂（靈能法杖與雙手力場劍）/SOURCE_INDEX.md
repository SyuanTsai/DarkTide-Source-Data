## 執行與計算

P1、P4 法杖的獨立 trait wrapper 都複製 ranged base，並把 check_proc 改成「手持欄位中的同一武器物品」且「遠程命中或爆炸命中」且「暴擊」；這個覆寫沒有沿用 base 的正傷害條件。Buff 仍監聽 on-hit 事件，所以判定單位是每個實際命中目標的 Attack，而不是一次射擊的全域事件。普通與蓄力投射物由 ProjectileDamageExtension 以 ranged attack type、保存的武器物品和暴擊旗標執行 Attack；P1 的蓄力動作由 ActionTriggerExplosion 帶入力場法杖物品與當前暴擊旗標，P4 的重型蓄力投射物則由投射物 impact explosion 沿用這兩者。WeaponSystem 對爆炸範圍內每個目標再執行 Attack，傳入 attack_type、is_critical_strike 與 item；Explosion 自身另發的全域 on_explosion_hit 不等於這些逐目標 on-hit 事件。法杖的 bash special 是 ActionSweep 近戰 profile，不符合這個 ranged／explosion 條件；純推擊發 on-push-finish，不送此 on-hit。

雙手力場巨劍 wrapper 複製 melee-and-special base，保留手持欄位、同武器物品與正傷害 gate。一般 melee critical 走一般請求量；special 請求量僅由 `is_critical_strike && damage_profile.warp_slice` 選取。實際 M1/M2 Warpshock Slash 用 native effect 對目標執行 ranged action，但傳入該武器項目及建立時保存的暴擊旗標；其 profile 帶 `warp_slice`，故即使不是 melee attack type，仍符合專用特殊暴擊 predicate。啟用 special 與 target finder 本身不產生命中。純推擊由 ActionPush 呼叫 PushAttack.push，對各目標執行 Attack.execute 並傳入攻擊類型 push、沒有暴擊旗標輸入，因此不符合法杖的 ranged／explosion 或巨劍的 melee-crit／warp_slice 條件；擲飛目標的 ranged hit 另因未傳入暴擊旗標而不符合巨劍條件。若推擊後連到一個近戰掃掠，則該掃掠另按一般 melee critical gate 判定。

三個 wrapper 都把 Soulblaze 套到目標共用的 `warp_fire` stacking buff。其總層數讀目標現有的同名 stacks；法杖沿用 base max 6，巨劍由 I–IV 覆寫為 3／6／9／12。helper 依「本次請求」與「上限剩餘空間」取較小值：恰好到上限而新增量為零時刷新期限；超過本祝福上限時，新增量為零且不刷新。這不是武器持有者獨有的計數器。目標 `warp_fire` 基礎期限 8 秒、全域層數上限 31；每層共用目標期限並由 IntervalBuff 週期衰退，適用的持有者 `burning_duration` 可改變期限。下一個 interval 不因加層或 refresh 重排，首次 damage tick 在套用後越過 0.75 秒門檻才跑。 切槽只影響來源武器的 held 條件；真正卸下武器會移除其 on_equip 祝福來源 Buff，但敵方已套用的 warp_fire 是獨立目標 Buff，仍按自身期限與週期結算。


層數新增量：`add = min(requested_stacks, max(tier_target_cap − current_warp_fire_stacks, 0))`。Staff I–IV `(requested, cap) = (1,6), (2,6), (3,6), (4,6)`；Force Greatsword 一般 `(requested, cap) = (1,3), (2,6), (3,9), (4,12)`；Warpshock Slash 每次 special request 為 `1, 1, 2, 3`，並使用同級巨劍 cap。若 `current == cap`，helper 走期限 refresh；若 `current > cap`，不加層也不 refresh。

`warp_fire` 的週期攻擊基礎 Power Level 依目前總層數 `S` 計：`x = S / 31`、`smoothstep(x) = x²(3 − 2x)`、`power_level = 500 × smoothstep(x)`。例如 `S=6` 時約為 `48.94`。這是輸入 profile 的 Power Level，不是最終生命傷害。
