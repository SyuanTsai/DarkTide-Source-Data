# 獵頭者(Headhunter)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/413ac562-7f2a-4358-9bee-bff1c8d5313e" width="72" height="72" alt="獵頭者祝福圖示">

- **觸發方式**：來源武器必須持用；命中事件的 `attacking_item` 必須是這把來源武器，且該次命中實際帶有 `hit_weakspot=true` 才會增加一層。弱點以事件旗標為準；其他效果可改寫命中部位映射，本祝福本身不授予保證弱點。
- **等級效果**：自動槍、電能步槍、步兵鐳射槍與重伐木槍每層增加 +14%、+16%、+18%、+20% 致命一擊機率；偵察鐳射槍每層增加 +3.5%、+4%、+4.5%、+5%。兩組都最多5層，數值是機率百分點相加，不是乘算基準機率。
- **生效與清除**：攻擊先按當下機率擲骰，再結算命中；新層不回溯影響觸發它的這次攻擊，須等命中事件處理及屬性快取更新後才供後續擲骰使用。成功擲出致命一擊會送出清除事件，無須實際命中目標。若本祝福的同一事件批次同時處理合格弱點命中與致命一擊清除，程式先加層再清層，批次結束時有效層數為0；不要把這說成所有先後排隊的事件都在同批。層數沒有獨立到期時間。
- **連發與實際動作**：自動連發的暴擊判定依射擊動作狀態及武器設定的連續暴擊上限處理，不代表每顆子彈／每枚彈丸都各自獨立擲骰。13個實際型號的普通及瞄準射擊會送出各自命中事件；自動槍P3與電能步槍P1的特殊鍵是槍托近戰掃擊，若通過同一來源物品、持用及弱點旗標條件也能增加層數。步兵／偵察鐳射槍與重伐木槍的特殊鍵是手電筒切換，沒有攻擊命中事件；本交集沒有蓄力或投擲攻擊接線。穿透後只按實際送出的各次命中事件判斷。
- **切換與卸下**：切換武器本身不刪除層數，但來源武器的持用條件停止後，快取更新會停用這項加成；若層數尚未被暴擊清除，切回來源武器後可恢復。真正卸下來源武器才移除其祝福 buff。
- **適用型號**：機動自動槍 哥倫努 Mk III、機動自動槍 格拉亞 Mk VII、機動自動槍 阿格里皮娜 Mk IX、電能步槍 布蘭克斯 Mk CV、步兵鐳射槍 卡特雷爾 Mk VII、步兵鐳射槍 卡特雷爾 Mk IIb、步兵鐳射槍 卡特雷爾 Mk IX、偵察鐳射槍 奧克塔蘭 Mk VIc、偵察鐳射槍 奧克塔蘭 Mk XII、偵察鐳射槍 奧克塔蘭 Mk XIV、重伐木槍 克魯克 Mk IIa、重伐木槍 戈爾貢努姆 Mk IIIa、重伐木槍 阿克利斯 Mk II。

## 計算與算例

- **一般型號算例（I級）**：步兵鐳射槍 卡特雷爾 Mk VII（`lasgun_p1_m1`）的普通動作 `action_shoot_hip`；該動作使用 `immediate_single_shot`，由非自動 `ActionShoot.start` 在命中前擲骰。前提是假設每次擲骰在套用本祝福前、已合併其他來源後的輸入為20%（不是此武器固定基礎值），沒有其他加成、保證／禁止暴擊或機率轉傷害轉換。連續5次單發攻擊都命中弱點且未擲出暴擊，每次事件後快取均更新；第五發仍以原有4層擲骰，下一次 `action_shoot_hip` 前已有5層。代入：clamp(20% + 5×14%, 0%, 100%) = 90%。結果是下一次擲骰輸入90%，比假設的20%高70百分點、相對增加350%；不是實測武器傷害或固定武器暴擊率。
- **偵察鐳射槍算例（IV級）**：偵察鐳射槍 奧克塔蘭 Mk XIV（`lasgun_p3_m3`）普通動作 `action_shoot_hip`；它接 `lasgun_p3_m3_full_auto`，暴擊擲骰按 `ActionShoot` 的射擊狀態與 `max_critical_shots=2` 設定處理。前提是假設本祝福前、已合併其他來源的該次擲骰輸入為20%，且5層在此擲骰前已生效，沒有其他加成、保證／禁止暴擊或機率轉換。代入：clamp(20% + 5×5%, 0%, 100%) = 45%。結果為45%，比假設輸入高25百分點、相對增加125%；不是該武器固定基礎暴擊率。
