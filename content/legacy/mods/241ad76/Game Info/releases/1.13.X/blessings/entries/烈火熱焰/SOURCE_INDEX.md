固定範圍為7個 exact variants、17個UI item/Mark bindings。逐組 own I–IV 均為 damage_near .07/.08/.09/.10、child_duration 3.5秒；custom wrapper 逐一核對 parent/child clones 與綁定，無額外 own writes。Base parent 監聽 on_kill、相同 event add-child；check 同時套 exact on_item_match、on_ranged_close_kill，parent proc 與 child stat 都有 held-slot gate。Base child max_stacks=5、stack_offset=-1；一個零效果 placeholder 使有效層上限5。建立 child 時帶 parent_buff_template/item slot；parent tier 的 stat_buffs.damage_near override merge 到 child override_data，覆寫 child conditional_stat_buffs 的 .01 fallback，不是父級常駐 stat。Own .07–.10 由 additive_multiplier 按有效層加總。Base allow_proc_while_active=true，沒有 cooldown_duration；每筆合格 event 增層、重設共同3.5秒 timer。即使滿層，零新增 add path 仍刷新 timer。Buff fixed_update 每次先更新 parent timer，held predicate不暫停計時；切換關閉觸發與 stat cache，切回有效期限內剩餘層恢復，卸下 parent 時 destroy 移除 children。Attack 先算傷害與 died，再排 on_kill；玩家固定更新處理 proc events 後重建 stat cache，新層只影響之後的攻擊。Ranged-close trigger 以事件 hit_world_position 到攻擊者當前位置 ≤12.5m；傷害 distance consumer 另取本次結算的 attacker owner/target unit POSITION_LOOKUP 距離。damage_near 是 damage calculation 的近端，用12.5–30m的 clamped sqrt interpolation 連到 damage_far與（ranged 時）ranged_damage_far遠端。melee_damage 有獨立 is_melee_attack gate，因此近端 stat不等於 melee-only。這個 stat只影響讀到該 cache並走此傷害計算分支的封包，不代表最後傷害／所有動作同率增加。17個Marks逐一核對hitscan/pellet和special action。Autogun P2、Boltgun special action_push是 melee sweep；Shotpistol輕盾bash attack=0、重bash melee；Ripper stab melee。Shotgun P1 M3 burn tick與P4 M1 stun tick為attack_type=buff且profile無ranged opt-in，只能是額外狀態傷害；tick不符合on_ranged_close_kill/ranged gate，擊殺不觸發新層。

令有效層數n≤5，每層b依I–IV為0.07／0.08／0.09／0.10，q近為其他適用的damage_near加法修正。近端值N=1+q近+n×b。遠端值F=damage_far+(遠程攻擊時的ranged_damage_far−1)；非遠程攻擊不加入後一項。兩個遠端值未受其他修正時均為1。

- 距離比例s=clamp((d−12.5)/(30−12.5),0,1)，d是這次傷害結算時攻擊者與目標的位置距離。
- 距離分支D=lerp(N,F,sqrt(s))。原生結算把D−1加入其他適用的傷害加法修正，不直接把整次最終傷害乘以D。
- 與其他條件相同而沒有本祝福時相比，本祝福提供的距離分支增量為n×b×(1−sqrt(s))。在12.5公尺內為n×b；30公尺起為0。
- 下列算例明確令其他近遠修正中性；其中D相對1的增幅只描述距離分支，並非最終傷害保證。
