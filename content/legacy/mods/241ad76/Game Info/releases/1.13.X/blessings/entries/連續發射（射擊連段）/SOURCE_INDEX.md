## 執行與計算

## 固定範圍與本體

- 固定 Release 1.13.1、公開來源 SHA 7e662fcda16219d775b84af50322be2e9cd9d62e；本項 exact inventory/UI 交集為 5 個實際 trait 實作、6 個 Mark binding。RAW 名稱「連續發射」與一般版同名但 name key／description key 不同；文件標題加「（射擊連段）」區分，不改 RAW。
- 五個 own wrapper 各自設定 use_combo=true，讀 weapon_action_component.combo_count 並封頂 5；不選一般 Blaze Away 的 shared num_shots／彈匣比例分支。每個 combo step 是武器動作，不是命中、彈丸、爆炸或耗彈單位。
- 臂鎧與電漿槍 I–IV 每步 5/6/7/8%；三型 Thumper 6/7/8/9%。各 wrapper .02 是 fallback，tier stat override 取代；底層 stepped stat offset=-1、範圍 0–5，Buff max_stacks=1 不等於只有一步。三型 Thumper formatter 另有 unused ammo=10% 欄位，但 Alternative RAW 沒有 ammo placeholder，故不顯示也不形成彈藥門檻。
- action_handler_settings 預設 sweep、shoot_hit_scan、shoot_pellets、shoot_projectile、spawn_projectile 增加 combo；windup 保留。顯式 increase_combo／hold_combo／reset_combo 可覆寫。idle timeout 是非循環動作結束後嚴格超過時限；Gauntlet／Kickback／Rumbler／Plasma 明設 .5 秒，Thugshot 用 .2 秒預設。
- Gauntlet Mk III：普通近戰 sweep 依 action kind 增加一步；特殊蓄勢 action_start_special 是 windup、暫時保留連段，開始 action_execute_special 的 melee_explosive 時 _update_combo_count 因其既非 increase 亦非 hold 而將 combo_count 重設為 0，不增加一步。特殊動作繼承 ActionSweep，以 melee attack_type 對玩家直接發起近戰揮擊；符合掃掠中斷與 ammunition 條件才排程 explosion_delay 後的爆炸。該爆炸由玩家本體呼叫 Explosion.create_explosion，special_gauntlet_grenade 的 static_power_level=500 是 Attack 前基底，Attack 讀玩家當下 stat_buffs 並將 generic power_level_modifier 送入 PowerLevel；這不是投射物快照。因特殊執行開始已重設 combo，快取更新後不可假設先前連段加成仍在；爆炸本身也不增加連段。
- Kickback Mk V：hip／aimed 散彈動作開始時各加一步；多顆彈丸不拆步。兩種射擊保留既有連段，zoom／裝填 hold，bash 轉換含 reset 邊。
- Rumbler Mk VI：hip／aimed 各是一個榴彈動作；hip 未設 keep_combo，aimed 設 keep_combo。直接命中、引信／爆炸不另加步；zoom／裝填 hold，bash 轉換含 reset 邊。
- Thugshot Mk VII：hitscan 射擊動作開始加一步；瞄準不保留，裝填保留，bash 轉換含 reset 邊。此 Mark 沒有本項直接投射物／爆炸路由。
- Plasma Mk II／III：普通與蓄力 hitscan 開始各加一步；普通耗 3 發、蓄力耗 1–8 發仍各一步。windup 保留；裝填、排氣、過熱不屬增加／保留類別。兩 Mark 分別核實動作模板。
- on_equip 安裝，conditional stat 讀當下持用槽；切出停用威力修正，卸下裝備槽移除 Buff。一般切槽動作不增加／保留 combo，通常重設該武器動作連段。沒有本祝福的逐步 TTL；新增步須等 Buff/stat cache 更新才反映。
- 實際投射物爆炸僅 Gauntlet Mk III 與 Rumbler Mk VI：模板 static_power_level=500 先進 Explosion/Attack/DamageCalculation，projectile 保存的玩家 stat-buff 快照再由 PowerLevel 消費；generic power_level_modifier 會套用，不因靜態輸入消失。快照固定發射時的 cache；已生成榴彈不受之後切槽改寫，剛增加而尚未進 cache 的步不保證包含。爆炸不另增 combo；不得擴到 Kickback、Thugshot。
- generic power_level_modifier 是一般 Power 池修正，非 melee/ranged 專屬 gate；最後傷害仍由攻擊型別、profile curve、部位、護甲、距離與其他修正結算。

令 K 為動作連段計數、p 為該實作／等級每步修正、K_eff=min(K,5)。其他 Power 修正中性時 M=1+p×K_eff；沒有彈匣比例項。Kickback I 級 p=.06、K=3 得 M=1.18；Gauntlet II 級 p=.06、K=2 得 M=1.12。Rumbler 的靜態 500 輸入仍經帶玩家快照的一般 PowerLevel 結算；上述是修正池，不是最終生命傷害公式。
