# 完美一擊(Perfect Strike)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/823e905c-f740-41dd-abbc-b3b11a5ecad9" width="72" height="72" alt="完美一擊祝福圖示">

- **觸發方式**：持用裝有完美一擊的近戰武器，且爆擊元件啟用時，玩家 Buff 更新會將本祝福的條件屬性與關鍵字寫入快取；後續命中依該次攻擊與快取判定。
- **近戰爆擊傷害**：I／II／III／IV 向弱點／爆擊共用的精準額外傷害乘區加入 2.5%／5%／7.5%／10%。只有本次傷害為近戰爆擊才使用這個加值；本祝福不增加爆擊率，也不將整筆命中傷害乘以 1.025–1.10。
- **打擊質量與護甲**：掃掠命中合資格的存活角色時，目標基礎打擊質量乘以 0.25；玩家、道具及活體道具不走這個減量分支，其他質量修正仍照常計入。同時略過護甲造成的攻擊中止，但累積質量預算與敵人品種的中止規則仍生效。
- **首次生效**：第一次近戰爆擊就能按條件受益，不需要先命中或疊層；效果以 Buff 更新後的快取為準。爆擊元件變更與快取重建是不同步驟，不把狀態變更當下視為快取已更新。
- **普通、重擊與推擊**：一般揮砍、重擊與推擊後追擊各自判定；直接特殊掃掠也走相同的質量／護甲中止路徑。純推擊、格擋及只切換特殊狀態不會形成這種近戰掃掠命中。
- **特殊攻擊**：重劍的特殊第二段與部分穿音速雙刀特殊揮砍本身已能略過護甲中止，減少質量仍是另外的效果。動力錘的額外爆炸屬非爆擊的爆炸傷害，不使用本項近戰爆擊加值；板盾特殊動作是格擋。重型開膛劍的黏附鋸擊按各次實際近戰爆擊狀態計算傷害，但不重走掃掠質量／護甲中止。
- **廁所鏟差異**：Mk III 的特殊拳擊是掃掠；Mk XIX 的折鏟特殊攻擊未配置額外後退。Mk V 啟用折鏟特殊狀態並命中先前存活的目標時，另有玩家自身後退；即使這一擊擊殺目標仍可發生。後退不推敵人，也不增加一次傷害。
- **期限、切換與移除**：本項沒有命中觸發冷卻、疊層或獨立期限。爆擊元件停用或切離這把武器後，條件失效並在後續快取更新反映；切回後重新按當時條件判定。卸下祝福後不再提供這項效果。

## 計算與算例

- **Hit Mass**：假設目標存活且為非玩家／非道具 breed 角色，基礎目標質量 `H=40`，其他目標、攻擊者與動作質量倍率皆為 1。`H′=40×0.25=10`，基礎質量貢獻少 30（降低 75%）；累積預算與品種中止仍生效。
- **近戰爆擊傷害**：假設快取已更新至 IV `t=.10`、當次為 melee critical、沒有力場覆寫或其他 crit-chance-to-damage 轉換，且後續修正中性。`B=200,F=100,S=1`：基準 `D=200+100×1=300`；套用後 `D=200+100×(1+.10)=310`。只多 10 點，即總值 +3.3333%，不是整次命中 +10%；弱點與爆擊額外部分合併在同一 `S`。
