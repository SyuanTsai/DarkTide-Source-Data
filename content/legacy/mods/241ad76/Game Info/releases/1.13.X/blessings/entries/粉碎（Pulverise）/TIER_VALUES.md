# 粉碎（Pulverise）：等級數值

[玩家說明](README.md)｜[來源索引](SOURCE_INDEX.md)

- 等級為 I–IV；以下列出各級實際效果。


## 武器變體來源數值

| 等級 | 通用爆擊率加成 | 持續時間 |
|---|---:|---:|
| I | +10個百分點 | 3秒 |
| II | +15個百分點 | 3秒 |
| III | +20個百分點 | 3秒 |
| IV | +25個百分點 | 3秒 |

- 上表為實際等級效果；機率顯示從當級覆寫讀取，時間顯示卻讀取 base 的2秒。預設 +5個百分點不再額外加算，實際時間由各級覆寫為3秒。
