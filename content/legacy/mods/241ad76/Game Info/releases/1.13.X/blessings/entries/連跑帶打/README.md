# 連跑帶打(Run 'n' Gun)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/c00f0d06-a32b-43c4-a438-76598dd7c8f9" width="72" height="72" alt="連跑帶打祝福圖示">

- **觸發方式**：裝備帶有連跑帶打的武器，即可在衝刺時使用該武器的腰射；不需要先命中、擊殺或暴擊。

- **傷害條件**：持用這把武器且正在衝刺時，I–IV近距離傷害增加6%、9%、12%、15%；停止衝刺就停止這筆傷害加成。

- **衝刺跳躍**：衝刺跳躍期間也符合衝刺傷害條件；一般行走與一般跳躍不會啟動這筆加成。

- **距離範圍**：12.5公尺內取得完整傷害加成；12.5至30公尺之間逐漸降低，30公尺起歸零。

- **散布效果**：多數適用武器的散布減少30%；雙管霰彈槍減少10%，四個等級相同。

- **散布持續**：散布減少不要求正在衝刺，站立射擊也生效；它縮小武器射擊散布，不改後座力。

- **衝刺腰射範圍**：允許邊衝刺邊腰射；瞄準、蓄力或其他動作仍依武器本身的衝刺限制，不能因此保持衝刺瞄準。

- **等級差異**：I–IV都解鎖衝刺腰射；升級只提高這項近距離傷害，散布減少量不變。

- **持續與層數**：沒有疊層、倒數或觸發冷卻；開始和結束衝刺直接改變傷害加成。

- **切換武器**：切出後停止這項近距離傷害加成，散布減少仍保留；切回且再次衝刺即可恢復傷害加成。

- **組合方式**：散布減少與其他散布修正相加；衝刺近距離傷害也加入既有的傷害加成，不把每筆百分比各自相乘。

## 計算與算例

- **近距離前提**：IV級正在持用並衝刺，目標10公尺；傷害加成結算前基礎100，沒有其他傷害加成，只比較這一階段。

- **近距離結果**：`100×(1＋0.15)＝115`；同條件I級為106。

- **中距離前提**：同條件改為21.25公尺，I–IV原始近距離加成仍依各等級。

- **中距離結果**：IV級加成為`15%×(1－√0.5)≈4.3934%`，該階段由100到約104.3934；30公尺起這筆加成為0。

- **已有傷害加成前提**：IV級10公尺，已有25%同一傷害加算池的加成，基礎100。

- **已有傷害加成結果**：`100×(1＋0.25＋0.15)＝140`；相對原有125增加12%，不是125×1.15。

- **散布前提**：相同射擊姿態與武器狀態，某一散布角原為2度，不計壓制額外偏移與其他散布修正。

- **散布結果**：一般適用武器`2×(1－0.30)＝1.4度`；雙管霰彈槍`2×(1－0.10)＝1.8度`。

- **已有散布修正前提**：一般適用武器已有20%散布減少，再加入連跑帶打；基礎角仍為2度。

- **已有散布修正結果**：`2×(1－0.20－0.30)＝1度`，原本為1.6度；相對原有角度減少37.5%。

- **停止與切換前提**：IV級衝刺射擊後停下，再切出並切回。

- **停止與切換結果**：停下後沒有15%近距離加成，散布減少仍在；切回後必須再次衝刺才恢復傷害加成。
