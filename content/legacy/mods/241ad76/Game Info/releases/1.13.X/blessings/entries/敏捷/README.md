# 敏捷(Agile)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/5e8c5a82-2a11-4d70-9418-d14acb4c4f6d" width="72" height="72" alt="敏捷祝福圖示">

- **適用武器**：戰術斧 埃托克斯 Mk II／Mk IV／Mk VII，以及決鬥劍 馬卡比安 Mk II／Mk IV／Mk V。
- **觸發方式**：持用配有本祝福的武器，並由這件武器以近戰攻擊命中弱點時，連續閃避次數歸零。各等級均設為0；命中身體、純推擊或其他武器的命中不重置。
- **近戰弱點傷害**：持用時，I–IV 常駐增加2.5／5／7.5／10%的近戰弱點靈巧額外傷害。不必先命中啟動，第一次合格弱點命中也可使用加成；主傷害部分不乘上這個倍率，整次命中增幅取決於靈巧部分占比。
- **閃避次數與冷卻**：合格命中把連續次數設為0，後續閃避照常增加次數並計算遞減倍率。普通閃避冷卻與連續次數的自然恢復期限分開管理，本祝福不清除這兩個計時欄位。
- **閃避途中觸發**：不會重開目前這次閃避，也不會補滿其剩餘距離；但後續速度更新會讀取已歸零的次數，重新計算速度的遞減倍率。
- **反覆命中**：第一次與之後每次合格弱點命中都設為0，沒有暖機、累積層數或本祝福自己的固定秒數期限。次數之後如何增加或自然恢復，仍依一般閃避規則。
- **普通、蓄力與特殊攻擊**：普通與蓄力近戰弱點命中均可觸發。戰術斧特殊攻擊是近戰傷害攻擊，命中弱點可觸發；決鬥劍特殊格擋／招架本身不觸發，後續反擊命中弱點可觸發。純推擊不符合近戰攻擊條件，推擊後的斬擊弱點命中可觸發。
- **切換武器**：切換本身不歸零次數。切走後這件武器的觸發條件與常駐加成都停用；切回並恢復持用條件後可再次使用。先前歸零的次數不因切換直接撤回，之後依實際閃避繼續更新。

## 計算與算例

- **觸發方式與計數代入**：前提：敏捷武器正持用，該武器近戰弱點命中前計數為 4；下一次閃避成本為 1，沒有免費閃避效果。代入：合格命中後 `4→0`；下一次閃避按一般規則 `0+1=1`。結果：下一次閃避從較低計數重新計算遞減係數，原本冷卻仍照常。玩家意義：重新整理計數，不會清除普通冷卻；閃避途中觸發時，後續速度更新會讀新次數，但剩餘距離不重新填滿。

- **弱點額外部分占比較低**：前提：IV 級 `h=0.10`，非本項傷害 `B=100`、Finesse 額外部分 `F=50`、同階既有加成 `c=0`，其他倍率不變。代入：前 `100+50(1+0)=150`；後 `100+50(1+0+0.10)=155`。結果：增加 5，完整命中增幅 `5/150=3.33%`。玩家意義：+10% 只套在 F，不是整次命中。

- **弱點額外部分占一半**：前提：IV 級 `h=0.10`，`B=100`、`F=100`、`c=0`，其他倍率不變。代入：前 `100+100=200`；後 `100+100×1.10=210`。結果：增加 10，完整命中增幅 `10/200=5%`。玩家意義：總增幅取決於額外部分在命中中的占比。

- **已有同階加成**：前提：IV 級 `h=0.10`，`B=100`、`F=100`、同階已有 `c=0.25`，其他倍率不變。代入：前 `100+100(1+0.25)=225`；後 `100+100(1+0.25+0.10)=235`。結果：增加 10，整體增幅 `10/225=4.44%`；該階段相加為 1.35，不是 `1.25×1.10`。玩家意義：加成仍只作用於弱點 Finesse 額外部分。

- **弱點兼爆擊**：前提：同次命中為弱點爆擊。代入：以爆擊與弱點 boosts 合併後形成的同一份 `base_finesse_damage` 作為 F，再乘 `1+c+h`。結果：不會把 F 複製成兩份。玩家意義：不能說成對整次命中或兩份額外傷害各增一次。

- 上述 B、F 和傷害單位都是明示假設，不是武器實戰測量；若有額外轉換或下游倍率，需依完整攻擊結算另算。

- **閃避距離算例**：假設採六型號共用設定的基本端點，沒有額外閃避次數、免費閃避、距離增益或攻擊黏著修正；下一次閃避在連續次數自然恢復期限內、且普通冷卻已允許開始，每次成本為1：起始次數門檻3、遞減參數2、距離遞減比例0.3、基礎距離2.75、距離比例0.95。原次數4，未觸發時下一次為5，倍率=0.7+0.3×[1−(5−3)÷(3+2)]=0.88；合格命中歸零後，下一次為1，倍率為1。距離計算值由2.75×0.95×0.88=2.299變成2.75×0.95=2.6125，增加0.3135，約13.64%。這是指定端點與中性修正的靜態代入；武器數值、額外閃避次數及其他條件會改變實際結果。
