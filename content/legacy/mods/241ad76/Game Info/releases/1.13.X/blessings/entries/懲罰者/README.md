# 懲罰者(Punisher)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/329f2103-f30b-4830-aed7-b0abb3a073fc" width="72" height="72" alt="懲罰者祝福圖示">

- **適用型號**：步兵自動槍 阿格里皮娜 Mk I、弗拉克斯 Mk V、哥倫努 Mk VIII；三個型號皆有此祝福的實際綁定。
- **觸發方式**：持用裝有本祝福的步兵自動槍，以該槍造成一次遠程擊殺，且命中位置距射手不超過 12.5 公尺，才會取得一層；只命中、沒有擊殺，或由近戰／其他武器造成擊殺，都不會觸發。
- **等級效果**：每個有效層提供一般傷害加成：I 級每層 2%，II 級每層 3%，III 級每層 4%，IV 級每層 5%。每次實際處理的合格擊殺事件最多增加一層，最多五層，故五層分別為 10%、15%、20%、25%。
- **持續與刷新**：有效層共用 1.75 秒期限；再取得合格擊殺會增加一層（未達上限時）並重設整組期限。滿五層後再觸發不再增加層數，但仍刷新期限。期限到後，有效層會一併移除。
- **加成何時套用**：這是攻擊者的一般傷害加成，只有持用該武器時才加入傷害計算；擊殺條件限定距離，但之後的傷害加成不再另設近距離條件。
- **切換與移除**：切出該武器時，持用條件使效果暫不計入，也不能用切出期間的擊殺觸發本項；1.75 秒計時仍繼續。未到期前切回可依剩餘層數重新計入。若該父 Buff 本身被卸除或摧毀，其建立的子層也會移除。
- **三型號攻擊方式**：腰射與瞄準射擊皆為命中掃描遠程射擊，符合距離及擊殺條件時都可觸發。特殊輸入只切換手電筒，按下本身不造成攻擊；切換後仍可用腰射或瞄準射擊。
- **首次生效**：造成擊殺的攻擊先完成命中／死亡結果，之後才排入擊殺事件；不把該次擊殺的傷害視為已取得新層加成。
- **後續生效時序**：新的子層在擊殺事件處理後建立，後續傷害要等 Buff 快取反映新加成才會讀到；不保證同一更新中較晚的命中已使用新層。

## 計算與算例

- 以下是固定來源數值的算術示例，不是遊戲實測。假設其他攻擊者／目標修正不存在或保持不變，並以進入一般加傷池前的傷害值 B 作為基準；q 表示其他既有一般加傷的加法貢獻，n 是本項有效層數，p 是每層數值。
- **單層 I 級**：假設 B=100、q=0、n=1、p=0.02，則 D=100×(1+0+1×0.02)=102；本項令此算例增加 2 點，亦即基準值的 2%。
- **IV 級五層上限**：假設 B=100、q=0、n=5、p=0.05，則 D=100×(1+0+5×0.05)=125；五層合計為基準值的 25%，不是每層再乘一個獨立的 1.05。
- **與既有加成合併**：假設 B=100、其他一般加傷 q=0.20，IV 級已有三層 n=3、p=0.05。基準 D₀=100×(1+0.20)=120；加入本項後 D₁=100×(1+0.20+3×0.05)=135。差額 15 相對於原 120 為 12.5%；不應將 120 再乘 1.15 得出 138。

## 遊戲描述勘誤

- **描述占位符接線勘誤**：英繁 RAW 皆要求 `{damage:%s}`，但本實作 formatter 只提供 `movement_speed` 與 `time`；`movement_speed` 實際讀取傷害值。TraitValueParser 保留原鍵名，沒有改名為 `damage`。在語系管理器已就緒且找到這份 RAW 的前提下，固定 Lua 缺參數回呼會代入帶引號的 `"damage:undefined"`。這是描述與 formatter 的鍵名不一致，傷害效果仍按實作數值生效；下列原文比較是靜態來源重建，未做遊戲畫面實測。
