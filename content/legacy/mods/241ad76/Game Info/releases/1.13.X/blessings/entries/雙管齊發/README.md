# 雙管齊發(Both Barrels)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/6d2d415f-b370-43ef-a384-3c4da0f579f3" width="72" height="72" alt="雙管齊發祝福圖示">

- **適用型號**：雙管霰彈槍 十字星 Mk XI與克魯克 Mk IV；兩者共用 I–IV 效果。

- **觸發方式**：以雙管特殊射擊擊殺敵人；擊殺事件處理時，雙發動作起始狀態仍須有效。十字星 Mk XI 只有舉鏡射擊、克魯克 Mk IV 只有腰射射擊會啟動雙發；開始時至少需要 2 發彈藥。彈藥不足時雖允許單發，但不會啟動雙發特殊狀態。

- **擊殺判定**：擊殺事件之後才會處理。判定會查看事件處理時仍有效的雙發動作起始狀態；若事件處理前已被後續動作改寫，不能保證該次擊殺建立效果。

- **效果**：效果存在時提高換彈速度：I級 +40%、II級 +50%、III級 +60%、IV級 +70%。這是速度倍率，不等於換彈時間直接縮短相同百分比；已有的換彈速度加成與它按同一加法倍率合併。

- **消耗與期限**：一次合格擊殺留下一個待用效果；不會因多個擊殺疊成多層，也沒有固定秒數期限。實際補彈點會觸發消耗；在補彈點前中斷換彈，效果仍保留。只進行上膛／槍機動作而沒有補彈，也不消耗。

- **換彈進行中**：換彈速度在動作開始時讀取。效果於換彈開始後才建立，不會改快已開始的動作。補彈點觸發消耗後，內部標記會在換彈流程離開相應階段時清除；目前動作已讀取的倍率仍會照常完成。

- **切換武器**：來源武器仍裝備時，切換使用欄位不會只因切出而卸除此效果。本項不以持用欄位作效果開關；此處列出已核實的兩個雙管型號及實際觸發模式。

- **型號差異**：十字星 Mk XI 的雙發模式是舉鏡射擊、普通腰射為單發；克魯克 Mk IV 的雙發模式是腰射、普通舉鏡為單發。兩者四級數值相同。

- **排除動作**：兩型號的槍托特殊攻擊走近戰橫掃，傷害檔未將它視為遠程攻擊；該動作的擊殺不符合本項遠程擊殺條件。

- **首次生效與移除**：合格擊殺事件處理後建立待用效果，換彈速度會在數值快取更新後供新動作讀取。實際補彈事件先把效果標為待移除，仍在對應的裝填動作期間保留；離開裝填動作後才清除。切出武器不等於已補彈，沒有額外刷新倒數。

## 計算與算例

- **前提**：以空彈匣起始的 eject_mag 或 eject_mag_restart 階段為例；程式在 1.3 個 action-time 秒時補彈。假設沒有其他換彈速度加成、引擎倍率上下限或固定步進誤差。這是補彈功能點，不是完整動畫總長。

- **公式**：`reload_speed` 的加法倍率基底為 1；只有本祝福時 `scale = 1 + p`，補彈點約在 `1.3 / scale` 秒到達。

- **I級**：`p = 0.40`，`scale = 1.40`；`1.3 / 1.4 = 0.9286` 秒，比基準 1.3 秒早 28.57%。

- **IV級**：`p = 0.70`，`scale = 1.70`；`1.3 / 1.7 = 0.7647` 秒，比基準早 41.18%。+70% 是速度提高，不是時間縮短 70%。

- **既有加成**：若原有 `reload_speed` 加成 `q = 0.20`，IV級前 `1.3 / 1.20 = 1.0833` 秒；加入本祝福後 `1.3 / (1 + .20 + .70) = 0.6842` 秒，相對 q 單獨生效再縮短 36.84%。倍率為 1.90，不是把 1.20 與 1.70 相乘成 2.04。
