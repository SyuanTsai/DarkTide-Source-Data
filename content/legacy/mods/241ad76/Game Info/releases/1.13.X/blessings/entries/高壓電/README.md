# 高壓電(High Voltage)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a5bb3fdd-036e-4b45-b53c-bfea7b800645" width="72" height="72" alt="高壓電祝福圖示">

- **觸發方式**：持用適用武器，且目標在本次傷害計算時已有有效電擊狀態，便取得本階級的加成。不限由自己或這把武器施加；隊友等其他來源的電擊也適用。

- **效果**：所有適用型號的 I–IV 級均為 +10%／+15%／+20%／+25% 傷害，加入一般傷害加算池。這不是固定乘在整次最終傷害上；原有同池加成、弱點額外傷害及後續結算會影響最終比例。

- **首次生效**：傷害計算時已電擊的目標，第一次命中就可受益。若這次攻擊先造成傷害、事後才施加電擊，剛加入的狀態不會回溯增加先前傷害；目標狀態更新後的後續傷害才可受益。同一更新內連續結算多次傷害，也不能保證下一次已讀到剛加入的狀態。

- **持續、刷新與移除**：祝福本身沒有觸發機率、層數、冷卻或固定倒數，不會越打越強。每次傷害重新檢查目標；電擊結束或移除後，狀態判定更新即不再加成。重複電擊可依來源刷新或延長目標狀態，但不疊加本祝福的百分比。

- **普通攻擊與蓄力攻擊**：適用近戰武器的普通攻擊、蓄力重擊、推擊後追擊，以及遠程普通射擊，皆按命中時的電擊狀態判定。普通電擊錘命中的電光效果本身不等於有效電擊狀態；純推擊的攻擊傷害設定為 0，本祝福不增加推開或踉蹌效果。

- **電擊錘充能黏附特攻**：阿格尼 Mk Ia、軍務部 Mk III 都有五個傷害實例，各自先算傷害再加黏附電擊。目標狀態最多五層，期限為 0.7 秒乘當前層數，最多 3.5 秒；新施加會刷新整體起算時間，滿層再次施加仍刷新。這是共同倒數，不是五個各自到期的計時器；層數延長期限，不把本祝福變成五倍。有效電擊狀態更新後，仍持續的後續命中與間隔電擊傷害可受益。

- **法務官電擊鎚特攻**：布蘭克斯 Mk III 先算命中傷害，再檢查電擊。已電擊目標會取得 3.5 秒的電擊間隔效果；未電擊目標只取得 0.1 秒的基本暈眩，沒有本祝福所需的電擊狀態。因此對未電擊目標的首擊，不能靠事後的基本暈眩自我觸發。兩種狀態各自最多一層，重複施加刷新期限。

- **法務官電擊鎚和鎮壓護盾特攻**：布蘭克斯 Mk VI、Mk XI 的盾牌喊聲不自行施加電擊；近、遠距離的各護甲傷害倍率均為 0。未由其他機制改變該倍率時，不造成可被本項放大的生命傷害。本祝福也不增加喊聲的踉蹌或壓制。

- **滅絕者霰彈槍特殊彈**：鐵腕 Mk III 先算完該輪全部彈丸傷害，再施加 3 秒電擊，最多一層、重複施加刷新；同輪彈丸不會被自己事後施加的狀態追溯增傷。後續射擊與間隔電擊傷害可受益；該間隔傷害對正在踉蹌的瘟疫爆破者跳過結算。鐵腕 Mk VIII 的特殊彈改為 8 秒、+25% 破甲效果，最多一層、重複刷新；它不施加電擊，須有其他有效電擊來源才能觸發本祝福。

- **衝覆者霰彈手槍和防暴盾牌**：審判 Mk IV 的普通射擊與盾擊不自行施加電擊。重盾擊為獨立傷害，可對已電擊目標受益；輕盾推的傷害設定為 0。

- **切換武器**：離開適用武器的持用狀態即不再提供該實作的加成；目標的電擊期限仍照常流逝。切回時若目標狀態仍有效便可再次適用，切換不會刷新電擊期限。持續傷害也依每次結算時攻擊者當下可用的加成判定。

## 計算與算例

- **前提**：只看一般命中的主傷害加算池；目標已電擊、相符武器仍持用，後續乘區保持中性；不含 finesse、flat damage、rending、背刺、側擊、傷害轉換、上限或遞減效果。這是公式算例，不是遊戲測量值。

- **IV 級、沒有同池加成**：令基礎傷害 B＝100、其他同池加成 q＝0、本祝福 p＝0.25，則 D前＝B×(1＋q)＝100；D後＝B×(1＋q＋p)＝125，增加 25，隔離主傷害相對增加 25%。

- **IV 級、已有同池 +20%**：B＝100、q＝0.20、p＝0.25，D前＝100×1.20＝120，D後＝100×1.45＝145，仍增加 25；相對原本 120 的增幅是 25÷120＝20.83%。本祝福加進同一池，不是把既有 1.20 再乘 1.25。

- **逐級對照**：在 B＝100、q＝0 的相同前提下，I／II／III／IV 級分別為 110／115／120／125；其他同池加成改變相對百分比，但不改本祝福所加的 p。
