# 精煉殺意(Refined Lethality)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/b2155c24-1abc-4d51-a55a-53e295c0bdee" width="72" height="72" alt="精煉殺意祝福圖示">

- **觸發方式**：持用帶有精煉殺意的骨鋸 外科醫師 型號4，以近戰攻擊命中弱點，且目標在傷害計算時已有毒素狀態，便可套用加成；不需要先擊殺或累積本祝福層數。
- **等級效果與作用部分**：I／II／III／IV 級分別向弱點／精準額外傷害的加成乘區加入 52.5%／55%／57.5%／60%。它增加的是這個額外部分，其他基礎傷害不會整筆乘上 1.525–1.60；既有同乘區加成與本祝福相加。
- **首次上毒的時序**：骨鋸的普通塗層與特殊模式都能在命中後施加符合毒素條件的效果；首擊對原先無毒的目標先計算傷害，之後才施加效果，不能吃到自己這次新加的毒素。目標效果統計更新後，後續弱點命中才可能受益；不保證同一更新批次的下一次追加命中已讀到新狀態。
- **普通與特殊攻擊**：普通揮砍、重擊、推擊後追擊、特殊模式下的直接揮砍，以及貼附後的追加近戰命中，都逐次檢查近戰、弱點與當下毒素狀態。前一段符合條件，不代表下一段自動符合。
- **不適用的傷害**：純推擊與單純切換特殊模式不適用；毒素自身的持續傷害屬效果傷害，亦不會因這項祝福增加。未命中弱點或目標沒有毒素狀態時，不套用此加成。
- **期限、切換與移除**：本祝福沒有自身觸發冷卻、疊層或持續期限；目標毒素狀態消失便不再符合。切離此武器後持用條件失效，切回後依當時條件重新判定；移除祝福後不再提供這項加成。

## 計算與算例

- **前提**：一次符合全部條件的近戰弱點命中，非本祝福影響的其他傷害部分為 200，弱點／精準額外部分在加成乘區前為 100；其他同乘區增量皆為 0，故原乘數 S=1。後續部位、背刺、減傷等因素均不改變結果，也沒有力場覆寫。
- **代入與結果**：無本祝福的最終傷害為 `200 + 100 × 1 = 300`。I 級為 `200 + 100 × (1 + 0.525) = 352.5`；IV 級為 `200 + 100 × (1 + 0.60) = 360`。IV 比無祝福多 60，最終傷害相對增加 `360 ÷ 300 − 1 = 20%`，並非 60%。
- **等級比較**：I 與 IV 的加成相差 7.5 個百分點；額外部分由 152.5 到 160，相對增加約 4.92%。同例的最終傷害由 352.5 到 360，相對增加約 2.13%；兩種相對增幅不可混用。
- **已有同乘區加成**：保持其他傷害 200、原額外部分 100，但原乘數改為 S=1.40。IV 級把乘數加為 `1.40 + 0.60 = 2.00`，最終傷害由 `200 + 100 × 1.40 = 340` 變為 400，相對增加約 17.65%；不是 `1.40 × 1.60`。
- **首次上毒的邊界**：若上述首擊的目標在傷害計算時尚無毒素，這次本祝福增量為 0。首擊之後新施加的毒素只能供狀態已更新後的合格命中使用；任何一次非近戰、非弱點或無毒素的命中，也各自不符合。
