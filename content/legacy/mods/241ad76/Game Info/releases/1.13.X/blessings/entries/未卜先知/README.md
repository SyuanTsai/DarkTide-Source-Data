# 未卜先知(Precognition)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/9a361b5a-a825-4cb1-a115-953bdc3075e6" width="72" height="72" alt="未卜先知祝福圖示">

- **觸發方式**：持用適用武器並成功閃開敵方攻擊後，獲得2秒效果。只按下閃避但沒有成功閃開攻擊，不會觸發。
- **等級效果**：戰刃、決鬥劍、烈焰力場巨劍與烈焰力場劍 I–IV 的靈巧額外傷害（Finesse）加成為45／50／55／60%；短刀與穿音速雙刀為30／35／40／45%。六個家族均持續2秒。
- **增傷範圍**：提高暴擊或弱點命中的靈巧額外傷害部分。主傷害部分不乘上這個倍率，整次命中的增幅取決於靈巧部分占比；未暴擊且未命中弱點的攻擊沒有此增傷。
- **首次生效與刷新**：第一次合格成功閃避即給完整階級值；期間再次成功閃避會重新起算2秒。不疊層、無額外冷卻，也不提高暴擊機率或改變攻擊已決定的暴擊結果。
- **切換武器**：切走後，這個武器的加成暫停，2秒倒數仍繼續；到期前切回，恢復剩餘效果。離手時的成功閃避不刷新它。
- **普通、蓄力與特殊攻擊**：依每次實際命中是否為暴擊或弱點結算。格擋、招架與姿態切換本身不是傷害命中；特殊刺擊、充能後斬擊及反擊則按自己的傷害設定計算。
- **投刀與追加毒素**：短刀投刀在生成時保存當下增益數值；效果必須已生效才會被保存。之後途中切走或效果到期，該投刀仍使用保存的數值，命中仍須為暴擊或弱點才有靈巧增傷。合格的非盾牌吸收投刀命中施加4層毒素，暴擊與弱點各另加2層；週期毒傷另行結算，不繼承投刀的暴擊與靈巧增傷。
- **力場巨劍風刃**：每次風刃命中都讀取玩家當下的增益；該次命中為暴擊或弱點、且效果仍有效時，才提高靈巧部分。切走或2秒到期後，不保留投刀式的增傷快照；風刃保存的暴擊結果不代表本祝福提高暴擊機率。
- **到期移除**：最後一次合格成功閃避後經過2秒，效果歸零；下一次觸發重新給完整效果。已生成投刀的數值快照依上段處理。
- **推擊與追擊**：純推擊使用攻擊值為0的設定、固定命中身體部位，且不傳入暴擊結果；本祝福不提高推擊的踉蹌力，也不因推擊本身啟動。推擊後的斬擊是另一個攻擊，效果仍有效且實際命中為暴擊或弱點時，依它自己的靈巧部分加成。力場劍與巨劍的抓擊選取目標可用的弱點部位，預設非暴擊；實際弱點命中可使用本效果。

## 計算與算例

- **算例前提**：以下均為假設的暴擊或弱點命中，主傷害部分 B=100、靈巧基礎額外傷害 F0 依各例指定；效果已啟動，未列出的同階段加成為0，後續傷害修正取中性值。計算的是這次命中的傷害階段值。
- **戰刃 IV，靈巧部分 F0=50**：未啟動時為100+50=150；啟動後為100+50×(1+0.60)=180。靈巧部分增加60%，整次命中增加30，即30÷150=20%。玩家得到的整體增幅取決於靈巧部分占比。
- **同為戰刃 IV，靈巧部分 F0=100**：未啟動時為100+100=200；啟動後為100+100×1.60=260，增加60，即60÷200=30%。相同的祝福加成，在靈巧部分較大的攻擊上提高更多傷害。
- **短刀或穿音速雙刀 IV，F0=50**：未啟動時150；啟動後100+50×1.45=172.5，增加22.5，即22.5÷150=15%。這兩個家族的 IV 為45%，應使用各自數值。
- **已有同階段加成 q=15%，再啟動戰刃 IV**：F0=50時，原本為100+50×1.15=157.5；新增60%後為100+50×(1+0.15+0.60)=187.5。此祝福新增30，即30÷157.5約19.05%；不能把兩個倍率相乘，也不能把既有15%的收益算成祝福新增傷害。
- **刷新算例**：0秒成功閃避，原到期點為2秒；1.5秒再成功閃避，到期點改為3.5秒，效果數值維持同一階級。
- **切換算例**：0秒觸發後，0.5秒切走、1.5秒切回；若中間沒有新的合格觸發，切回時約剩0.5秒，仍於2秒到期。離手時成功閃避不刷新這個武器的效果。
