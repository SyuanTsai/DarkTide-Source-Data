# 魔力彈藥(Charmed Reload)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/63f0f4f1-edb0-4269-84ee-ac75d14d1c92" width="72" height="72" alt="魔力彈藥祝福圖示">

- **觸發方式**：持用帶有此祝福的武器，新的暴擊判定成功時，從備彈移入彈匣。

- 雙鏈重型機槍：每次最多2／3／4／5發，依序對應I／II／III／IV級。

- 電弧步槍：I–IV每次最多1發。

- 射空仍可觸發，不必先暴擊命中敵人。

- **連續暴擊**：雙鏈重型機槍的三個型號，一次成功判定可延續最多六發暴擊。

- 電弧步槍每次射擊重新判定，沒有六發延續；連鎖命中多名敵人不額外補彈。

- 延續中的每一發不會再次補入同一份彈藥。

- 下一次新的成功暴擊判定才再觸發。

- **容量與來源**：實際移入量不超過彈匣缺少的子彈數，也不超過剩餘備彈。

- 滿匣或沒有備彈時移入零發。

- 備彈同步減少，沒有生成新子彈。

- 射擊本身仍正常消耗彈匣。

- **持續與切換**：沒有疊層、持續時間或獨立冷卻。

- 只在持用時處理觸發。

- 切出沒有待保存的加成層數或倒數。

## 計算與算例

- **完整轉移**：以雙鏈重型機槍IV級5發為例，假設效果讀取時彈匣80／100發、備彈50發。

- `min(5, 100−80, 50)=5發`。

- 彈匣變85、備彈變45，總量仍130發。

- 玩家可延後換彈匣，但總彈藥未增加。

- **容量限制**：假設彈匣98／100、備彈50，`min(5, 2, 50)=2發`。

- 彈匣100、備彈48，原本148發總量不變。

- **備彈限制**：假設彈匣80／100、備彈2，`min(5,20,2)=2發`。

- 彈匣82、備彈0。

- 備彈0或彈匣已滿時結果均為0發。

- **電弧步槍**：假設效果讀取時彈匣20／40、備彈50，任一級的`min(1,20,50)=1發`，彈匣21、備彈49，總量仍70發。

- 同次射擊連鎖命中多名敵人，仍只移入這1發。

- **延續暴擊**：以雙鏈重型機槍為例，假設一次新成功判定帶出六發暴擊，整段始終有足夠彈匣缺額與備彈、IV級效果正常觸發一次。

- 這段共轉移5發，不能按六次暴擊傷害計成30發。

## 遊戲描述勘誤

- 英文使用「Critical Hit」，但實際在新暴擊判定成功時處理，並不要求擊中。

- 射空也可從備彈移入彈匣。

- 延續暴擊的後續每發不會重複觸發。
