# 強化電流弧(Enhanced Voltaic Arcs)

- **觸發方式**： 僅適用於電弧步槍 布蘭克斯 Mk IV 與電弧鎚 布蘭克斯 Mk III。裝備對應祝福且持用條件已反映在角色屬性快取後，第一個符合條件的新電弧連鎖搜尋就會讀到加值；不必先累積觸發層數。
- **加值內容**： 增加連鎖搜尋使用的最大角度、跳躍距離與最大跳躍次數。這些是目標搜尋參數，不是傷害百分比。
- **電弧步槍**： 腰射與架槍射擊都會建立電弧連鎖，原生最多分別跳躍 1 次與 2 次；祝福再依等級增加跳躍次數。此型號的特殊槍托攻擊沒有連鎖路徑，這個實際型號的動作表也沒有獨立的蓄力射擊或投擲連鎖路徑。
- **電弧鎚**： 八種輕／重掃擊，以及一般推擊後的掃擊，只有在動作開始時特殊攻擊已啟用，且命中符合條件時才建立連鎖。純推擊沒有連鎖；特殊推擊後的範圍攻擊採用獨立動作，沒有接入實際連鎖，因此不算連鎖攻擊。
- **切槽、卸下與既有連鎖**： 持用條件會在後續屬性快取重建時影響加值；只要武器仍在物品欄，裝備時套用的 wrapper 不等於已移除。實際卸下該武器槽才移除裝備效果。來源沒有證明切槽會立刻重建快取，因此不推定即時時序。既有連鎖不會因持用條件改變而回溯重算；後續新搜尋才讀取當時快取。兩類連鎖動作結束時都會清除該動作的連鎖狀態。
- **目標與傷害**： 原有根目標、導電狀態、存活、角度、距離及視線等原有目標檢查仍有效；放寬搜尋參數不保證找到更多目標。祝福不改變連鎖傷害設定。它沒有獨立的觸發疊層、持續時間、冷卻或 proc 刷新機制。
- **擊殺後的步槍根目標**：如果沒有可用的直接命中存活敵人，步槍仍可在最後命中死亡敵人的周圍，依原生尋根流程選取另一名存活且可鎖定的敵人，優先已觸電者。這項前置尋根使用獨立設定；本祝福不擴大其原生四公尺搜尋半徑。選出根目標後，後續連鎖搜尋才使用本祝福加值。

## 計算與算例

- **前提**： 使用對應武器並以已符合持用條件的屬性快取進行新連鎖搜尋。原生跳躍基線來自實際接入的武器動作；根命中不算額外跳躍，也不保證場上一定有足夠合法目標。
- **代入**： 電弧步槍腰射為原生 1 次 + 各等級額外 1 次；架槍為原生 2 次 + 額外 1 次。電弧鎚掃擊原生 2 次，I／II 各加 1 次，III／IV 各加 2 次。
- **結果**： 電弧步槍腰射最多 2 次、架槍最多 3 次；電弧鎚 I／II 最多 3 次、III／IV 最多 4 次。這是搜尋上限，不代表實際一定完成這些跳躍。
- **代入**： 電弧步槍 III 的實際角度加值為 +7.5°、距離加值為 +0.75；若該次原生最大角度為 A、半徑為 R，搜尋值為 A+7.5°、R+0.75。電弧鎚 IV 的實際角度加值為 +12.5°、距離加值為 +2；最大角度為 A+12.5°，若有獨立近距角 C 則為 C+12.5°，沒有時沿用最大角度，半徑為 R+2。
- **結果**： 原生角度與半徑會依解析出的 profile 在 basic／perfect 端點間變化，因此不指定單一原生值，也不捏造唯一最終角度或半徑。上列是可由來源確認的加值。
- **玩家意義**： 角度 formatter 先將弧度轉為度數再向下取整；卡面角度會顯示整數，實際計算仍保留精值。因此電弧步槍 III 與電弧鎚 II 的實際加值都是 +7.5°、卡面顯示 +7；電弧鎚 IV 是實際 +12.5°、卡面顯示 +12。角度、距離與跳躍數加值都不是傷害增幅。
