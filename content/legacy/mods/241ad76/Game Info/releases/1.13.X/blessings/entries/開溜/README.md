- **觸發方式**：持用有本祝福的步兵自動槍，正在衝刺，並成功以遊戲的「衝刺閃避」判定避開一發可閃避的敵方射線攻擊。僅普通閃避、未在衝刺或不可閃避的攻擊不會觸發；投射物與爆炸不能一律視為會送出這個事件。

- **效果與首次生效**：合格事件被處理後啟動一秒加速，並在屬性快取與移動更新讀到效果時套用；不保證命中判定的同一影格已改變速度。I／II／III／IV 的衝刺速度加算係數為 +10%／+12.5%／+15%／+15%，不提高一般走路速度。

- **刷新與期限**：再次成功觸發會重設同一個一秒期間，不疊加層數；剛好到達期限時已失效。

- **III／IV 額外效果**：只要持用這把槍，衝刺閃避的角度門檻就降低 10°，不必先觸發加速。I／II 沒有此項。一般側向判定的門檻由 70° 降為 60°，實際角度須嚴格大於門檻；計算取視線與攻擊者方向內積的絕對值，因此前後方向對稱，不能把背向敵人一律視為側向閃避。已有其他同類角度修正時取最大值，不與這 10° 相加。

- **判定例外**：處於遊戲的衝刺超時狀態時，須另有「允許超時衝刺閃避」效果才可通過。若該次攻擊允許逃離閃避，直接量測的視線與敵人方向水平夾角嚴格超過 60° 也可通過；此分支不折算前後方向，包含敵人在身後的情況。

- **切換與移除**：切出步兵自動槍後，持用條件與屬性快取更新會停用速度及角度貢獻，一秒計時仍繼續。到期前切回仍裝備的原槍，更新後可恢復剩餘加速時間；卸下該槍則移除對應祝福實例。

- **射擊與特殊動作**：自己的腰射、瞄準射擊或手電筒切換均不直接觸發；觸發來自避開符合條件的敵方攻擊。

- **適用型號**：步兵自動槍 阿格里皮娜 Mk I、步兵自動槍 弗拉克斯 Mk V、步兵自動槍 哥倫努 Mk VIII。

## 計算與算例

- **速度前提**：以 `V₀` 表示尚未乘入同類衝刺速度係數的速度基數，其他角色、一般移動速度及武器動作乘數固定。先假設沒有其他同類衝刺速度加成，`V₀=100` 個任意速度單位／秒，且本祝福一秒期間有效：I 為 `100×1.10=110`；II 為 `100×1.125=112.5`；III／IV 為 `100×1.15=115`。這是公式代入，不是遊戲實測速度，也不代表走路速度增加。

- **已有同類加成**：若其他衝刺速度加算係數 `q=20%`，原值 `100×(1+.20)=120`；加入 IV 級後為 `100×(1+.20+.15)=135`。多 15 個速度單位，相對原值增加 `15÷120=12.5%`，不能把 120 再乘 1.15 得到 138。

- **角度前提與結果**：角色正在衝刺、沒有衝刺超時、沒有其他角度修正、攻擊可閃避，且不使用允許逃離閃避的分支。若程式計算的 `look_away_angle=65°`，I／II 的 `70°<65°` 不成立；III／IV 持用時 `(70°−10°)<65°` 成立，可進入衝刺閃避與祝福觸發流程。若剛好 60°，`60°<60°` 不成立。角度修正取最大值：已有另一項 15° 同類修正時仍為 15°，不合計成 25°。

- **重設與切出**：第一次合格事件在伺服器處理時間 `t=10.0` 啟動，期間為 `t<11.0`；第二次在 `t=10.7` 處理後重設為 `t<11.7`，沒有第二層。`t=11.0` 切出，更新後速度貢獻停用但時間照走；`t=11.4` 切回，更新後仍只到 `t<11.7`。這是處理時間與嚴格期限的示意。
