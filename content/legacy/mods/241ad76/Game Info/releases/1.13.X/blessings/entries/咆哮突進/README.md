# 咆哮突進(Roaring Advance)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/a2c35e00-cdf2-43c6-a566-f132883bed9e" width="72" height="72" alt="咆哮突進祝福圖示">

- **觸發方式**：持續以本頁列出的武器開火；每次射擊動作登記一發，就增加共用的射擊計數。計數在命中判定之前更新，因此射偏不會阻止計數；多個命中目標也不會把一發算成多發。
- **計數門檻**：令 M 為目前武器彈匣最大容量，單層門檻 S=max(1，向下取整(M×5%))。每累積 S 發射擊，增加一層，最多五層。M 會隨武器型號與容量數值變動，並非固定每五發。
- **每層效果**：每層逐次乘上原有移動減速幅度的剩餘比例。電弧步槍與槍托自動槍 I–IV 每層分別保留 90%、85%、80%、75% 的原有減速；雙鏈重型機槍分別保留 93%、92%、91%、90%。五層上限見集中等級表。
- **效果範圍**：祝福修改瞄準／ alternate fire 的移動減速修正，以及武器動作移動減速修正；它削弱已有減速，不是直接增加全局移動速度。若當下沒有這類減速，就沒有可削弱的幅度。
- **開火模式**：普通腰射、瞄準／架槍射擊都屬於射擊動作，會計數；電弧步槍的多目標電弧也不會按目標數額外計數。推擊、刺擊與 bash 是近戰動作，不會增加射擊計數；既有層數仍可短暫保留，直到射擊計數重置。
- **重新整理與重置**：這不是命中觸發或有獨立持續時間的增益。停火後，只有在射擊狀態已結束且時間嚴格超過目前擴散模板的 `num_shots_clear_time`，計數才歸零；未超過時重新開火會沿用尚未清除的計數。重新裝填時，本祝福的步進函式回傳零。各型號腰射與瞄準所用的停火門檻不同；弗拉克斯 Mk II 實際採用 Mk VIII 瞄準擴散模板的 0.1 秒門檻，詳見來源索引。
- **首次生效與切換**：首發從零計數開始；只有達到該武器的 S 發並在 Buff 統計快取更新時讀到新計數，才出現第一層，不能保證該發已開始的動作立即受益。效果只在持用此武器時套用；切槽本身不清零玩家共用的射擊計數；改持另一把會射擊的武器開火，也會增加同一計數。若在計數被清零前切回，這些發數會按本武器的彈匣容量門檻計入層數；祝福效果仍只在持用帶有此祝福的武器時套用。

## 計算與算例

- **算例一：槍托自動槍 格拉亞 Mk IV，II級**
  - 前提：持續射擊、未裝填、沒有停火超過 0.1 秒；彈匣最大容量 M=60，命中／未命中以外條件不變；只看一項原有 40% 移動減速，其他修正視為中性。
  - 代入：S=max(1，floor(60×0.05))=3 發；12 發後層數=min(floor(12÷3),5)=4。II級 每層剩餘倍率 r=0.85，因此減速 D'=0.40×0.85^4=0.2088025。
  - 結果：該項減速由 40% 降至約 20.88%；移動倍率由 0.60 變為約 0.7912。原減速幅度縮小約 19.12 個百分點，或相對縮小約 47.80%。
  - 玩家意義：這不是把角色移動速度直接加 47.8% 或 60%；它只削弱指定的既有減速乘區，且四層取決於射擊計數與快取更新。

- **算例二：雙鏈重型機槍 戈爾貢努姆 Mk IV，IV級**
  - 前提：連續腰射、未裝填、未觸發停火重置；彈匣最大容量 M=80；只看一項原有 40% 武器動作移動減速，其他修正視為中性。
  - 代入：S=max(1，floor(80×0.05))=4 發；20 發後層數=min(floor(20÷4),5)=5。IV級 每層剩餘倍率 r=0.90，D'=0.40×0.90^5=0.236196。
  - 結果：該項減速降至約 23.62%；移動倍率由 0.60 變為約 0.7638，原減速幅度縮小約 16.38 個百分點（相對縮小 40.951%）。
  - 玩家意義：五層已封頂；持續射擊只維持／更新依射擊計數讀出的層數，不會把 10% 逐層加成 50 個百分點。
