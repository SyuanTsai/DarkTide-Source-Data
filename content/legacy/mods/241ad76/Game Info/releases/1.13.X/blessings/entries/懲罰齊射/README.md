# 懲罰齊射(Punishing Salvo)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/e96c1d1f-19f3-42fc-91f8-1809cfb9c8c6" width="72" height="72" alt="懲罰齊射祝福圖示">

- **適用型號**：自動槍阿格里皮娜 Mk I、弗拉克斯 Mk V、哥倫努 Mk VIII；偵察鐳射槍奧克塔蘭 Mk VIc、Mk XII、Mk XIV；滅絕者霰彈槍鐵腕 Mk III、Mk VIII。

- **觸發方式**：持用這把武器，且射擊計數符合 1、2 或 3 時，取得遠程弱點傷害修正；實際命中弱點才會使用這份修正。打身體、打空都不會產生弱點額外傷害，但射擊仍會消耗計數。

- **等級效果**：I／II／III／IV 級分別提高 35／40／45／50% 的精準額外傷害部分。弱點與爆擊的精準加成會先合成同一份額外傷害；本項作用於這一部分，並非整筆命中傷害提高 35–50%。

- **自動槍與偵察鐳射槍：首次生效**：在停火計數已清為 0、祝福快取也已更新的前提下，重新連射通常是第 1 發不加成，第 2–4 發符合，第 5 發起不符合。每發先更新射擊計數；命中結算使用已更新的祝福快取，因此不要把當下計數直接當成同影格已重算的效果。

- **自動槍與偵察鐳射槍：停火清除**：停止射擊後，經過目前腰射／瞄準姿態的清除時間才會清為 0；自動槍為 0.1／0.25 秒，偵察鐳射槍為 0.5／1.0 秒。比較是嚴格超過，正好到時間邊界仍不清除；站立、移動、蹲姿沿用各自已核對的設定。

- **霰彈槍：一般連射**：鐵腕兩型號讀取行動連擊數，而非上述射擊計數。從閒置手動開始的首殼為 0，直接接續連射通常第 2–4 殼為 1–3；繼續到 4 以上就不符合。每殼散射彈會分批處理，在最後一批才使用當時的祝福快取結算命中。

- **霰彈槍：首殼例外**：裝填、特殊彈裝填或進入瞄準後直接接續開火，行動鏈可讓該段首殼的連擊數變成 1；末批命中跨過祝福更新後，這一殼也可能受益。等動作結束、回到閒置後才手動開火，首殼仍從 0 開始。這是轉場條件的差異，不能把所有模式固定說成第 2–4 殼。

- **霰彈槍：清除**：行動不是循環動作、連擊數大於 0，且距離動作結束嚴格超過 0.2 秒時，行動連擊可被清除；這不是兩發射擊必須相隔 0.2 秒的限制。裝填、特殊彈裝填與瞄準等動作也有自己的重設／接續規則。散布使用的 1.0／1.1 秒停火計時不控制本祝福。

- **疊層、刷新與移除**：本項沒有疊加層數或獨立增傷倒數；只判斷目前計數是否符合。重新射擊、停止射擊及行動轉場會改變計數；條件改變後，效果在下一次祝福更新反映，不會追溯改寫已結算的命中。

- **特殊攻擊**：自動槍與偵察鐳射槍的手電筒切換不是射擊。鐵腕霰彈槍普通彈及特殊彈均走遠程散射攻擊，命中弱點且實際結算時符合條件便可受益；裝填特殊彈的動作本身沒有弱點傷害。

- **切換武器與裝填**：切出後持用條件不成立，加成在下一次祝福更新撤除；切回須重新符合目前計數，並經更新才生效。自動槍／偵察鐳射槍的裝填或切槽本身不是這段射擊計數的獨立清除條件；停火清除仍依當時姿態與行動是否允許清除判斷。霰彈槍依自己的行動連擊規則，不沿用這兩家的停火計數。

## 計算與算例

- **前提**：令 W 為這次遠程弱點命中，已合併弱點與爆擊精準加成後的額外傷害；假設沒有其他同類遠程弱點修正，且祝福條件及快取已生效。

- **四級代入**：W＝100 時，I–IV 級分別為 100×1.35＝135、100×1.40＝140、100×1.45＝145、100×1.50＝150。玩家得到的是這份額外傷害增加 35／40／45／50；基本傷害部分不會一併乘上這些係數。

- **整筆傷害算例**：假設另有基本傷害 300，IV 級使此階段由 300＋100＝400 變成 300＋150＝450；相對增加 (450−400)÷400＝12.5%。這說明 50% 精準額外傷害增幅不等於 50% 整筆傷害增幅，後續其他結算仍另計。

- **同類加成算例**：若另外已有 20% 同類遠程弱點修正，W＝100 原本為 100×1.20＝120；再有 IV 級本項後為 100×(1＋0.20＋0.50)＝170。新增 50，相對原本這份額外傷害增加 50÷120≈41.7%；同類係數相加，不能算成 120×1.50＝180。

## 遊戲描述勘誤

- **鐵腕霰彈槍的射擊序號例外**：RAW 只寫齊射第 2、3、4 發；實作改讀行動連擊。裝填、特殊彈裝填或瞄準後直接接續開火時，該段首殼可成為連擊 1，並在跨過祝福更新後的末批命中受益。此條件下 RAW 的固定射擊序號不完整符合實作；閒置手動首殼仍為 0。兩語均有這項序號限制，不能只歸因於繁中翻譯。
