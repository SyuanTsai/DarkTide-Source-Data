## 執行與計算

11 個實際武器特質各自提供 I–IV 的 `toughness_fixed_percentage`，`format_type=percentage` 會先將比例乘以 100；各變體未設定 `num_decimals`，遊戲格式化器依顯示數值自動選擇 0–2 位小數，再加上百分比符號，並由實際 UI 使用 `+` 前綴。因此 0.175／0.225 顯示為 17.5%／22.5%，保留小數而不改寫成整數。各自的 buff wrapper 都直接複製共用 `toughness_on_elite_kills` 模板。共用模板是 `proc_buff`，監聽 `on_kill`，並在事件上同時套用目前持用欄位、物品名稱相符與精英標記三項條件。`on_elite_kill` 要求 `attack_result` 為 `died` 且目標 breed 的 `tags.elite` 為真；`on_item_match` 比對 `params.attacking_item.name` 和祝福所在物品名稱。

共用擊殺事件在攻擊結果為死亡時由攻擊結算路徑送出，事件帶有攻擊類型、替代射擊、充能等資料和 `attacking_item`。祝福條件沒有查看攻擊類型、傷害類型、充能或 weapon-special 欄位，因此不只限定某一種射擊；但次要、範圍或持續傷害只有在真正的擊殺事件保留相同物品名稱時才能確認適用。

成功通過條件後，共用回呼取用該變體的固定百分比，忽略一般韌性補充 stat buffs，再呼叫 `recover_percentage_toughness`。該函式把比例乘以最大韌性，並以目前韌性損傷封頂；若韌性恢復被停用則不恢復。祝福不增加攻擊傷害，也不留下一個可累積或計時的個別 buff。

UI 實際交集為 11 個特質變體、18 個遠程武器型號綁定。榴彈手套與 Rumbler 雖有近戰或發射動作，其裝備分類仍是遠程；Thumper P2 變體實際綁定 Rumbler Lorenz Mk VI（P1 M2）。

已追查實際追加傷害的物品歸屬：兩款針彈手槍毒傷與特殊死亡爆炸省略source_item／item，因此不符合本祝福同物品條件；磷光backblast及burn兩路、臂鎧彈體／爆炸近戰、震盪槍彈體與撞擊爆炸、電漿對敵過熱爆炸保留武器物品。這些可觸發路徑仍逐次檢查精英死亡與事件處理時的持用欄位，不因先前發射時持用而跳過後續檢查。

令 `Tmax` 為最大韌性，`Tnow` 為觸發時目前韌性，`p` 為對應武器／等級的 `toughness_fixed_percentage`，`m` 為模板資料中的恢復倍率（未設定時為 1）。`p` 在程式中是比例，例如 0.175；百分比格式再乘以 100，並由遊戲格式化器依顯示值選擇小數位，所以該值呈現為 17.5%，不是由文件端四捨五入。模板傳入 `ignore_stat_buffs=true`，所以此回復不乘一般韌性補充 stat-buff 修正。

- 請求回復：`wanted = Tmax × p × m`。
- 可用缺額：`missing = max(0, Tmax − Tnow)`。
- 實際回復：`recovered = min(wanted, missing)`；目前值變成 `Tnow + recovered`。
- 例：若 `Tmax=100`、`Tnow=63`、`p=0.225`、`m=1`，請求 22.5，缺額 37，實際恢復 22.5。

因此卡面 `+22.5%` 表示以最大韌性計出的請求量；它不是對目前韌性乘 1.225，也不是傷害加成。若韌性恢復被停用，函式在計算前回傳 0。
