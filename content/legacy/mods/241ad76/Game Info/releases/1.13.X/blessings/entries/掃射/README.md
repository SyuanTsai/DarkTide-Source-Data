# 掃射(Raking Fire)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/8ad696a1-e0d1-4a5b-a352-4597b5c71b90" width="72" height="72" alt="掃射祝福圖示">

- **觸發方式**：持用帶有掃射的武器，從敵人背面射擊命中即套用傷害加成；不要求擊殺、弱點命中或暴擊。

- **等級效果**：I–IV分別增加32.5%、35%、37.5%、40%傷害。

- **背面範圍**：敵人背後整個半圈都可生效，也包含偏左後方或右後方；正側面90度邊界與前半圈不生效。

- **判定依據**：每次命中按該次攻擊的入射方向與敵人當時朝向判定；敵人轉身後，下一次命中會重新判定。

- **攻擊範圍**：只對遠程攻擊生效；槍托近戰不套用。

- **特殊動作**：步兵自動槍 阿格里皮娜 Mk I可腰射或瞄準射擊，兩種射擊都套用背面判定；特殊操作是切換手電筒，切換本身不造成攻擊。

- **持續與層數**：這是持用期間的條件效果，沒有疊層、持續秒數或觸發冷卻；打中正面或射空不會產生需要維持的增益。

- **切換武器**：切出後停止提供加成；切回後，符合背面射擊條件的命中直接生效。

- **傷害組合**：暴擊與弱點造成的傷害也一起受背面倍率影響；與其他同類背面傷害加成相加。

## 計算與算例

- **普通命中前提**：IV級，命中屬於背面射擊；其他因素固定，沒有其他背面加成；結算至背面加成前的傷害100，算例只比較這一階段。

- **普通命中結果**：`100×(1＋0.40)＝140`；同條件I級為132.5。

- **弱點命中前提**：同一發弱點命中，結算至背面加成前的傷害150，已包含弱點加成；IV級掃射生效，算例只比較這一階段。

- **弱點命中結果**：`150×1.40＝210`；不是只替弱點額外傷害部分增加40%。

- **同類加成前提**：背面加成前的傷害100，已有20%背面傷害加成，再加入IV級掃射；算例只比較這一階段。

- **同類加成結果**：`100×(1＋0.20＋0.40)＝160`；相對原有120提高約33.33%，不是120再乘1.40。

- **方向前提**：分別從敵人正後方、斜後方、正側面與正前方命中，敵人朝向固定。

- **方向結果**：正後方與斜後方生效；正側面邊界和正前方不生效。

- **切換前提**：射擊時由背面繞到正面，之後切出再切回。

- **切換結果**：正面命中沒有掃射加成；切回後仍需背面命中，但不用先開槍累積層數。
