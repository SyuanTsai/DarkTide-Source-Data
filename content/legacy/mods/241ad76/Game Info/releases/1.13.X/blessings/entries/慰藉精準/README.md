# 慰藉精準(Reassuringly Accurate)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/22eb124d-e729-4b45-b8ed-31e47d3e1085" width="72" height="72" alt="慰藉精準祝福圖示">

- **觸發方式**：持用裝有本祝福的武器，並用該武器造成暴擊擊殺。只有暴擊但沒有擊殺，或擊殺時沒有暴擊，都不會回復韌性；判定時也必須是這把武器造成擊殺，而且它仍在手上。
- **重型鐳射手槍 奧克塔蘭MG Mk II**：一般與瞄準射擊都會判定暴擊；符合條件的擊殺依 I–IV 回復目前最大韌性的 10／12／14／16%。
- **擲彈兵臂鎧 布拉斯托姆 Mk III**：普通與蓄力近戰攻擊，以及特殊動作的直接拳擊，都可能以實際暴擊擊殺觸發；I–IV 分別回復目前最大韌性的 24／28／32／36%。特殊動作後另出的爆炸不會暴擊，單靠它擊殺不觸發。
- 臂鎧榴彈在投出時會保留當時的暴擊狀態與武器來源；榴彈直擊、引信爆炸或命中爆炸造成暴擊擊殺時都可能觸發。若擊殺判定時已切離臂鎧，這次不會回復。
- 每次符合條件的擊殺各自嘗試立即回復一次，沒有觸發冷卻、持續效果或累積層數。回復量按目前最大韌性計算，並以當下缺損封頂；韌性已滿就不增加。
- 切換武器不會卸下祝福，但切離後不符合持用條件，切回才能再次符合；真正卸下祝福才移除它。倒地通常不能回復；若遊戲設為強制協助起身狀態，該倒地檢查可略過；死亡或禁止回復狀態仍會阻止回復。

## 計算與算例

- **擲彈兵臂鎧 IV**：前提是角色仍可回復韌性、最大韌性 `M=100`、缺損 `D=50`，並由該臂鎧造成合格暴擊擊殺。代入 `p=.36`：回復預算 `100×.36=36`；結果 `min(36,50)=36`，韌性從50回到86。玩家意義：36是最大韌性比例，不是缺損比例。
- **重型鐳射手槍 IV**：前提 `M=100`、只缺 `D=10`，且由該手槍造成合格暴擊擊殺。代入 `p=.16`：預算 `100×.16=16`；結果 `min(16,10)=10`，回到100。玩家意義：缺多少就最多補多少，不會超過上限。
- **分開處理的連續擊殺**：前提 `M=100`，每次事件處理前都至少缺36，且每次都是臂鎧 IV 合格暴擊擊殺。每筆事件分別代入 `min(36,D)`；若兩次前皆缺至少36，總共回復72。玩家意義：每次擊殺各自嘗試回復，沒有把同批事件合併成一個回復，也不保證韌性缺損足夠時都能拿滿預算。
