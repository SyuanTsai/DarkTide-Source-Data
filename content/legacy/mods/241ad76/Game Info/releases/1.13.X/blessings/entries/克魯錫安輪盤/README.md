# 克魯錫安輪盤(Crucian Roulette)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/590356c8-aa5c-40dc-8cf5-ee127c7925ab" width="72" height="72" alt="克魯錫安輪盤祝福圖示">

- **觸發方式**：持用裝有此祝福的武器時，彈匣每少一發，就提高一份通用爆擊機率。

- **自動槍**：機動自動槍 哥倫努 Mk III、機動自動槍 格拉亞 Mk VII、機動自動槍 阿格里皮娜 Mk IX 每少一發，I–IV 級分別提高 0.45、0.50、0.55、0.60 個百分點。

- **手槍**：磷光爆破手槍 布蘭克斯 Mk XI、快拔左輪手槍 紮羅娜 Mk IIa、快拔左輪手槍 阿格里皮娜 Mk XIV 每少一發，I–IV 級分別提高 4.5、5、5.5、6 個百分點。

- **彈匣狀態**：計算持用武器彈匣內彈藥，不計備用彈。換彈期間與彈匣完全打空時加成為零；換好彈後依新彈匣狀態重新計算。

- **適用攻擊**：通用爆擊機率可影響射擊、自動槍槍托敲擊與手槍近戰推擊。磷光手槍命中後產生的背向爆破明確不會爆擊。

- **切換武器**：切到其他武器時加成不再生效；切回持用該武器後按目前彈匣狀態重新計算。

- **期限、疊層與冷卻**：沒有獨立計時期限或觸發冷卻；加成按即時缺彈數計算，計算步數最多100。保持同一彈匣狀態就保持同一加成，不會自行按時間增加或減少。

- **射擊與最後一發**：射擊判定使用當時已生效的機率池；耗彈後缺彈數改變，後續按新狀態計算。最後一發可以使用射擊前的加成，彈匣打空後則歸零。

- **彈匣容量**：使用當時的實際彈匣上限；提高容量會改變可累積的缺彈數，並不改變每缺一發的等級加成。

## 計算與算例

- **零步與首次受益**：假設快拔左輪手槍彈匣上限5發，IV級滿5發時加成0；剩4發時缺1發，提供6個百分點。

- **持續與上限**：同一把左輪剩1發時缺4發，提供24個百分點；不開火、不換彈且繼續持用時，這24個百分點持續存在。再射完最後一發後，空匣加成變0，不能把5×6算成30個百分點。

- **自動槍等級算例**：假設機動自動槍實際彈匣上限36發，剩26發，缺10發；I–IV分別增加4.5、5、5.5、6個百分點。

- **手槍與容量差異**：磷光爆破手槍上限6發、剩4發，II級缺2發×5個百分點=10個百分點；IV級剩1發時缺5發，提供30個百分點。

- **既有加成與相對變化**：假設左輪IV剩1發，原有基礎、全域與攻擊類型來源合計20%，沒有爆擊率轉傷害修正；機率池為20%+24%=44%，增加24個百分點，相對增加(44−20)÷20=120%。這是機率變化，不是傷害增幅。

- **機率封頂**：若原有同池來源合計90%，再加24個百分點，會由114%限制為100%；其他爆擊率轉傷害修正在限制後處理。

- **換彈與中斷**：左輪IV上限5發、剩2發時有18個百分點；開始換彈期間變0。若未補入子彈就中斷換彈，仍剩2發且持用條件成立時，按缺3發恢復18個百分點；完成補滿則為0。

- **切換**：以上左輪剩2發時切出，加成失效；切回且彈匣仍剩2發、沒有換彈時，重新按缺3發提供18個百分點，不須先再射一發。
