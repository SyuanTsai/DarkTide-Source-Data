# 機會主義者(Opportunist)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/e292ed7d-8b36-4da5-9f39-528bed983004" width="72" height="72" alt="機會主義者祝福圖示">

- **觸發方式**：持用帶有機會主義者的武器時，對已踉蹌或被效果視為踉蹌的敵人提供近戰撕裂。

- **等級效果**：I–IV為10%、15%、20%、25%近戰撕裂；本頁九種武器實作的數值相同。

- **判斷時機**：以這一擊傷害結算前的狀態為準；這一擊才把原本正常的敵人打踉蹌，不會回頭讓同一擊取得加成。

- **踉蹌來源**：不要求由自己造成踉蹌；隊友先打出的踉蹌也能符合條件，不要求暴擊、弱點或擊殺。

- **攻擊類型**：只作用於近戰傷害；遠程、爆炸、吶喊與電弧傷害不取得這筆近戰撕裂。

- **撕裂意義**：改善攻擊對指定傷害分類的裝甲倍率，不是直接增加同百分比傷害。原本裝甲倍率越低，實際提升的比例可能越大。

- **超出正常倍率**：把裝甲倍率補到100%後，多出的撕裂只以四分之一效率提高該階段傷害。

- **同類合併**：符合條件的其他撕裂與目標脆弱加算，總撕裂最高100%；不是各來源彼此相乘。

- **持續與層數**：不累積命中層數，沒有祝福效果倒數或觸發冷卻；每一擊重新看當下條件。

- **停止生效**：敵人不再符合踉蹌條件，或切出這把武器時，這筆近戰撕裂停止提供；切回後對符合條件的敵人再生效。

- **無護甲目標**：無護甲傷害分類的撕裂係數為0，因此不會因本祝福提高該分類的傷害。

## 計算與算例

- **算例共同前提**：IV級、合格踉蹌目標、普通近戰命中；只比較裝甲結算階段，裝甲前傷害100，先不加入後續弱點、部位或減傷。

- **低裝甲倍率前提**：傷害分類有撕裂效果，原裝甲倍率10%，沒有其他撕裂。

- **低裝甲倍率結果**：倍率由10%加25個百分點到35%，該階段傷害由10到35；相對增加250%，不是增加25%。

- **接近正常倍率前提**：原裝甲倍率90%，沒有其他撕裂。

- **接近正常倍率結果**：先用10個百分點補到100%，剩餘15個百分點以四分之一效率計入，倍率為103.75%；傷害由90到103.75。

- **正常倍率前提**：原裝甲倍率100%，該傷害分類仍適用撕裂，沒有其他撕裂。

- **正常倍率結果**：25%撕裂以四分之一效率額外增加6.25%，該階段傷害由100到106.25。

- **加算前提**：原裝甲倍率10%，本祝福25%近戰撕裂，另有20%符合條件的撕裂或脆弱。

- **加算結果**：總撕裂45%，倍率為55%，該階段傷害55；不是把10乘1.25再乘1.20。

- **封頂前提**：原裝甲倍率10%，另有90%撕裂；加入本祝福25%後總量超過100%。

- **封頂結果**：總量只採100%，先補90個百分點到100%，剩餘10個百分點以四分之一計入，該階段傷害102.5。

- **未踉蹌前提**：敵人在傷害結算前沒有踉蹌，也未被視為踉蹌。

- **未踉蹌結果**：本祝福不加入撕裂；即使這一擊隨後造成踉蹌，也不回溯改寫已結算傷害。

## 遊戲描述勘誤

- **本體未說明判斷時機**：傷害結算前已踉蹌才符合；本擊隨後造成的踉蹌不回溯加成。

- **本體未說明被視為踉蹌**：相應狀態效果也可符合，不只依畫面上敵人是否正在後仰。

- **本體只列撕裂值**：實際提升取決於傷害分類與原裝甲倍率；不可把IV級25%撕裂改寫成固定25%傷害。
