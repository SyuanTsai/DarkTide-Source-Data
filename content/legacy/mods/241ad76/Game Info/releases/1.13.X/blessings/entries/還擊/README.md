# 還擊(Riposte)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/0ca33a46-e0ab-4da3-abb3-ae014acaa376" width="72" height="72" alt="還擊祝福圖示">

- **觸發方式**：持用適用武器時成功閃避敵方攻擊，即啟動效果；單純做出閃避動作、沒有成功閃過攻擊，不會觸發。

- **一般變體**：戰刃、決鬥劍、短刀、烈焰力場劍及烈焰力場巨劍，I／II／III／IV級分別提高12.5／15／17.5／20個百分點的爆擊率，持續6秒。

- **穿音速雙刀**：布蘭克斯MkXI的I／II／III／IV級分別提高10／12／14／16個百分點的爆擊率，持續4秒。

- **成功閃避**：可由敵方近戰、遠程、網槍、撲擊或衝撞等攻擊的成功閃避判定觸發；不是按鍵或動畫本身的獎勵。

- **刷新與移除**：第一次合格閃避即取得該級全額加成。期間再次成功閃避會重設6秒或4秒期限，不疊加層數，沒有額外冷卻；期限結束後加成消失。

- **切換武器**：切出後加成暫停，期限繼續倒數；期限結束前切回，剩餘時間內恢復加成。離手期間的成功閃避不會刷新這把武器的效果。

- **近戰攻擊**：普通、蓄力斬擊、突刺及力場劍充能後的斬擊，在攻擊開始時判定爆擊；穿音速雙刀切換模式時帶出的斬擊也依此判定。

- **推擊與啟動**：力場劍及力場巨劍的推擊傷害固定不爆擊。特殊啟動、格擋或招架本身不觸發還擊；後續斬擊仍按其攻擊開始時的爆擊率判定。

- **短刀投擲**：特殊投刀在動作開始時判定爆擊，直接命中可受益；已生成投射物保存當時的爆擊結果與數值，之後切換武器不會改寫它。

- **力場巨劍風刃**：風刃在效果建立時保存當下的爆擊狀態，不重新擲爆擊；後續命中目標沿用這個結果。由還擊提高機率的斬擊若判為爆擊，其風刃可沿用；其他保證風刃爆擊效果也會生效。切出時若風刃尚未產生，這次風刃會取消；已產生風刃的爆擊結果不會因祝福到期而重判。

- **加成意義**：提升的是爆擊機率池，不是每擊保證爆擊或傷害增幅；實際判定還會套用100%上限、角色的機率轉傷害效果，以及整數百分比取整規則。

- **投刀毒素**：投刀附帶的毒素施加會依命中的爆擊結果多加2層，弱點命中另加2層；打在盾牌上不施加這份毒素。後續毒傷本身不再判定爆擊。

## 計算與算例

- **算例前提**：以下假設其他來源合計的爆擊機率池為20%，且沒有機率轉傷害效果；數值是假設算例。

- **首次生效**：觸發前本祝福加成為0；一般變體IV級首次成功閃避後，20%＋20個百分點＝40%。穿音速雙刀IV級則為20%＋16個百分點＝36%；相對提升分別為100%與80%。

- **逐級比較**：一般變體I–IV級的加算結果為32.5%／35%／37.5%／40%；穿音速雙刀為30%／32%／34%／36%。實際爆擊判定前會取整至整數百分比，前者32.5%／37.5%分別取為33%／38%。

- **刷新而不疊加**：一般變體IV級在t＝0觸發，期限原到t＝6；若t＝4再次成功閃避，期限改到t＝10，加成仍為20個百分點。

- **較短期限**：穿音速雙刀IV級在t＝0觸發，期限原到t＝4；若t＝3再次觸發，期限改到t＝7，加成仍為16個百分點。

- **切換與到期**：沿用一般變體t＝4刷新、期限到t＝10的案例；t＝5切出後加成暫停，t＝8切回時恢復剩餘約2秒，t＝10失效。若離手期間t＝7成功閃避，期限仍到t＝10。

- **機率上限**：若其他來源合計85%，一般變體IV級加算至105%，上限截為100%；溢出的5個百分點不自行變成傷害。

- **投刀與風刃**：在加成生效的40%機率池下開始攻擊，判定為爆擊時，該投刀或風刃保存這次結果；同一風刃打中多個目標沿用同一結果。
