# 粉碎（Pulverise）

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/aa25ecae-6e09-442c-9eed-d14e3cadc750" width="72" height="72" alt="粉碎（Pulverise）祝福圖示">

- **觸發方式**：持用附有「粉碎」的擲彈兵臂鎧，並以這把臂鎧的近戰攻擊擊殺敵人，才會啟動；沒有近距離限制，換用其他武器擊殺不會觸發。

- **等級效果**：I、II、III、IV級分別提高10、15、20、25個百分點的爆擊率，持續3秒。加成進入通用爆擊率，因此近戰與遠程致命一擊計算都會讀取；它不是只限其中一種攻擊。

- **再次觸發**：效果期間再次以同一把臂鎧的近戰攻擊擊殺，會重新開始3秒計時，不會疊加多層，也沒有額外冷卻。

- **切換武器**：切出擲彈兵臂鎧不會重設或停止計時，但切出期間加成暫停生效；若在3秒內切回，剩餘時間內恢復加成。

- **特殊攻擊與射擊**：普通輕擊、重擊和特殊攻擊的直接拳擊若造成擊殺，都能符合近戰條件；特殊爆炸擊殺、射擊彈體命中或射擊爆炸擊殺都不能觸發。特殊爆炸固定為非爆擊。

- **榴彈射擊**：加成有效時，普通榴彈發射會讀取通用爆擊率；彈體直擊、引信與撞擊爆炸沿用同次發射的爆擊結果，爆炸不另擲骰。射擊不會消耗或刷新計時。

- **期限**：從最後一次符合條件的近戰擊殺起算3秒，期限結束後失效。

## 計算與算例

- **零加成到首次啟動**：假設IV級尚未觸發，沒有粉碎加成；在t=0由持用中的擲彈兵臂鎧近戰擊殺後，立即加入25個百分點，計時到t=3秒。首次擊殺即可取得完整加成。

- **機率算例前提**：假設一次近戰或遠程爆擊判定在粉碎加入前為20%，包含基礎值與其他加成，未達上限，且爆擊率轉傷害修正為0。

- **各級機率與相對變化**：在上述前提下，I級為30%、II級35%、III級40%、IV級45%；IV級增加25個百分點，相對於20%增加(45−20)÷20=125%。

- **上限算例**：若其他加成已使檢定前機率為92%，IV級加入25個百分點後原始值為117%，再由遊戲的0至100%上限限制為100%。

- **刷新算例**：t=0以臂鎧近戰擊殺，期限到t=3秒；t=2再次以該臂鎧近戰擊殺後，期限重設為t=5秒，不會疊成50個百分點。

- **切換算例**：t=0啟動、t=1切出時，計時仍走到t=3但加成暫停；t=2切回時恢復最後1秒的加成，到t=3失效。t=1改用另一把武器擊殺不會刷新。

- **特殊攻擊算例**：特殊動作的直接拳擊在t=0造成擊殺時會啟動；若直接拳擊未擊殺、其後只有爆炸造成擊殺，則不啟動，因為爆炸事件不是近戰攻擊。

## 遊戲描述勘誤

- **時間描述**：遊戲描述的時間占位符讀取2秒；I–IV實際效果均持續3秒。正文與等級表採實際3秒，RAW模板原樣保留。
